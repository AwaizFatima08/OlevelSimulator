Show answer
  1. (a) upper 0.7456, lower 0.6456

Show answer

    B1: 1/n < 0.01 ⇒ n > 100, so n = 101B1: Uₙ → 2n²/(6n²) = 1/3

  3. (c) 0 ≤ tan x ≤ 1 on [0, π/4] so tanⁿ⁺¹x ≤ tanⁿx; then 2Iₙ < Iₙ + Iₙ₋₂ = 1/(n − 1) and 2Iₙ > Iₙ + Iₙ₊₂ = 1/(n + 1).
