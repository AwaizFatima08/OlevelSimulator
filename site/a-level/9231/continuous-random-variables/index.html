Q1Expectation & variance · Core · Paper 4 style · 5 marks

The continuous random variable X has probability density function given by f(x) = kx² for 0 ≤ x ≤ 3, and f(x) = 0 otherwise, where k is a constant.

  1. (a) Show that k = 1/9. [1]
  2. (b) Find E(X) and Var(X). [4]
Show answer
  1. (a) Shown
    B1 ∫₀³ kx² dx = 9k = 1.
  2. (b) E(X) = 9/4, Var(X) = 27/80
    M1 E(X) = ∫₀³ x³/9 dx; A1 81/36 = 9/4; M1 E(X²) = ∫₀³ x⁴/9 dx = 27/5; A1 Var(X) = 27/5 − 81/16 = 27/80.
Q2Expectation & variance · Core · Paper 4 style · 7 marks

The continuous random variable X has probability density function f(x) = k(6 − x) for 2 ≤ x ≤ 6, and f(x) = 0 otherwise.

  1. (a) Find the value of k. [2]
  2. (b) Find E(X). [2]
  3. (c) Find Var(X). [3]
Show answer
  1. (a) k = 1/8
    M1 ∫₂⁶ k(6 − x) dx = k[6x − x²/2]₂⁶ = 8k; A1 k = 1/8.
  2. (b) 10/3
    M1 (1/8)∫₂⁶ (6x − x²) dx; A1 10/3.
  3. (c) 8/9
    M1 E(X²) = (1/8)∫₂⁶ (6x² − x³) dx = 12; M1 subtract (E(X))²; A1 8/9.
Q3Expectation & variance · Core · Paper 4 style · 6 marks

The time X hours that a mobile phone repair shop in Rawalpindi takes to fix a screen is modelled by the probability density function f(x) = 3/x⁴ for x ≥ 1, and f(x) = 0 otherwise.

  1. (a) Verify that f is a valid probability density function. [2]
  2. (b) Find E(X) and Var(X). [4]
Show answer
  1. (a) Shown
    M1 f(x) ≥ 0 and ∫₁^∞ 3x⁻⁴ dx = [−x⁻³]₁^∞; A1 = 1.
  2. (b) E(X) = 3/2, Var(X) = 3/4
    M1 E(X) = ∫₁^∞ 3x⁻³ dx; A1 3/2; M1 E(X²) = ∫₁^∞ 3x⁻² dx = 3; A1 Var(X) = 3 − 9/4 = 3/4.
Q4Expectation & variance · Standard · Paper 4 style · 8 marks

The waiting time, T minutes, for a bus at a stop in Lahore has probability density function f(t) = k(10t − t²) for 0 ≤ t ≤ 10, and f(t) = 0 otherwise.

  1. (a) Show that k = 3/500. [2]
  2. (b) State the value of E(T), giving a reason, and find Var(T). [4]
  3. (c) A passenger's total journey time is (3T + 12) minutes. Find the mean and variance of the total journey time. [2]
Show answer
  1. (a) Shown
    M1 k∫₀¹⁰ (10t − t²) dt = k(500 − 1000/3); A1 = 500k/3 = 1, k = 3/500.
  2. (b) E(T) = 5; Var(T) = 5
    B1 E(T) = 5 because the graph of f is symmetrical about t = 5; M1 E(T²) = (3/500)∫₀¹⁰ (10t³ − t⁴) dt; A1 (3/500)(25 000 − 20 000) = 30; A1 Var(T) = 30 − 25 = 5.
  3. (c) Mean 27 minutes, variance 45 minutes²
    B1 3(5) + 12 = 27; B1 9 × 5 = 45.

  1. (a) Find E(X). [3]
  2. (b) Find Var(X). [3]
Show answer
  1. (a) 8/3

  2. (b) 14/9
    M1 E(X²) = ∫₀² x³/6 dx + ∫₂⁶ x²(6 − x)/12 dx = 26/3; M1 subtract (E(X))²; A1 14/9.
Q6Expectation & variance · Standard · Paper 4 style · 6 marks

The continuous random variable X has probability density function f(x) = (1/2) sin x for 0 ≤ x ≤ π, and f(x) = 0 otherwise.

  1. (a) Write down E(X), giving a reason. [1]
  2. (b) Show that E(X²) = π²/2 − 2, and hence find Var(X), giving your answer correct to 3 significant figures. [5]
Show answer
  1. (a) π/2
    B1 f is symmetrical about x = π/2.
  2. (b) Var(X) = π²/4 − 2 ≈ 0.467
    M1 (1/2)∫₀^π x² sin x dx by parts; M1 = (1/2)([−x² cos x]₀^π + 2∫₀^π x cos x dx); A1 (1/2)(π² + 2[x sin x + cos x]₀^π) = (1/2)(π² − 4); M1 Var = π²/2 − 2 − π²/4; A1 0.467.
Q7Expectation & variance · Challenge · Paper 4 style · 8 marks

The lifetime X, in years, of a solar panel inverter is modelled by the probability density function f(x) = (1/4)xe^(−x/2) for x ≥ 0, and f(x) = 0 otherwise.

  1. (a) Show that f is a valid probability density function. [3]
  2. (b) Find E(X) and Var(X). [5]
Show answer
  1. (a) Shown
    M1 integrate by parts: (1/4)∫₀^∞ xe^(−x/2) dx = (1/4)([−2xe^(−x/2)]₀^∞ + 2∫₀^∞ e^(−x/2) dx); A1 = (1/4)(0 + 4); A1 = 1, and f ≥ 0.
  2. (b) E(X) = 4, Var(X) = 8
    M1 E(X) = (1/4)∫₀^∞ x²e^(−x/2) dx; M1 by parts twice (or ∫₀^∞ xⁿe^(−x/2) dx = n!·2ⁿ⁺¹); A1 (1/4)(16) = 4; M1 E(X²) = (1/4)∫₀^∞ x³e^(−x/2) dx = (1/4)(96) = 24; A1 Var(X) = 24 − 16 = 8.
Q8Expectation & variance · Challenge · Paper 4 style · 9 marks

The continuous random variable X has probability density function f(x) = a + bx for 0 ≤ x ≤ 2, and f(x) = 0 otherwise, where a and b are constants. It is given that E(X) = 7/6.

  1. (a) Find the values of a and b. [4]
  2. (b) Find Var(X). [3]
  3. (c) Find P(X > E(X)). [2]
Show answer
  1. (a) a = 1/4, b = 1/4
    M1 ∫₀² (a + bx) dx = 2a + 2b = 1; M1 ∫₀² (ax + bx²) dx = 2a + 8b/3 = 7/6; M1 solve simultaneously; A1 a = 1/4, b = 1/4.
  2. (b) 11/36
    M1 E(X²) = ∫₀² (x² + x³)/4 dx = 2/3 + 1 = 5/3; M1 5/3 − (7/6)²; A1 11/36.
  3. (c) 155/288
    M1 ∫ from 7/6 to 2 of (1 + x)/4 dx = [x/4 + x²/8] from 7/6 to 2; A1 1 − (7/24 + 49/288) = 155/288.
Q9Expectation & variance · Challenge · Paper 4 style · 8 marks

The continuous random variable X has probability density function f(x) = k/x² for 1 ≤ x ≤ 4, and f(x) = 0 otherwise.

  1. (a) Find the value of k. [2]
  2. (b) Find E(X) in exact form and Var(X) correct to 3 significant figures. [4]
  3. (c) Find E(1/X). [2]
Show answer
  1. (a) k = 4/3
    M1 k[−1/x]₁⁴ = 3k/4 = 1; A1 k = 4/3.
  2. (b) E(X) = (4/3) ln 4; Var(X) ≈ 0.583
    M1 E(X) = (4/3)∫₁⁴ (1/x) dx = (4/3) ln 4; M1 E(X²) = (4/3)∫₁⁴ 1 dx = 4; M1 Var(X) = 4 − (16/9)(ln 4)²; A1 0.583.
  3. (c) 5/8
    M1 (4/3)∫₁⁴ x⁻³ dx = (4/3)(1/2)(1 − 1/16); A1 5/8.
Q10PDF & CDF · Core · Paper 4 style · 4 marks

  2. (b) Find P(1 ≤ X ≤ 2). [2]

Q12PDF & CDF · Core · Paper 4 style · 6 marks

The lifetime of an electronic component, X hundred hours, has cumulative distribution function F(x) = 0 for x < 2 and F(x) = 1 − 4/x² for x ≥ 2.

  1. (a) Find the probability density function of X. [2]
  2. (b) Find the probability that a component lasts more than 400 hours. [2]
  3. (c) Find the probability that a component lasts between 300 and 500 hours. [2]
Show answer
  1. (a) f(x) = 8/x³ for x ≥ 2, 0 otherwise
    M1 differentiate 1 − 4x⁻²; A1 8x⁻³ for x ≥ 2.
  2. (b) 1/4

  3. (c) 64/225
    M1 F(5) − F(3) = (1 − 4/25) − (1 − 4/9); A1 4/9 − 4/25 = 64/225.
Q13PDF & CDF · Standard · Paper 4 style · 6 marks

The continuous random variable X has probability density function given byf(x) = x/8 for 0 ≤ x ≤ 2,f(x) = (8 − x)/24 for 2 < x ≤ 8,f(x) = 0 otherwise.

  1. (a) Find the cumulative distribution function of X. [4]
  2. (b) Find P(1 < X < 4). [2]
Show answer
  1. (a) F(x) = 0 for x < 0; x²/16 for 0 ≤ x ≤ 2; (16x − x² − 16)/48 for 2 < x ≤ 8; 1 for x > 8
    M1 ∫₀ˣ t/8 dt = x²/16; A1 correct; M1 F(2) + ∫₂ˣ (8 − t)/24 dt = 1/4 + (8x − x²/2 − 14)/24; A1 (16x − x² − 16)/48, with F = 0 and 1 outside.
  2. (b) 29/48
    M1 F(4) − F(1) = 32/48 − 1/16; A1 29/48.
Q14PDF & CDF · Standard · Paper 4 style · 7 marks

  3. (c) Find P(0.5 < X < 1.5). [2]

Q15PDF & CDF · Standard · Paper 4 style · 7 marks

The time, T minutes, that a customer waits to be served at a bank in Karachi has cumulative distribution function F(t) = 1 − e^(−0.2t) for t ≥ 0, and F(t) = 0 for t < 0.

  1. (a) Find the probability density function of T. [2]
  2. (b) Find the probability that a customer waits between 3 and 8 minutes. [2]
  3. (c) Given that a customer has already waited 5 minutes, find the probability that they wait at least 3 more minutes. [3]
Show answer
  1. (a) f(t) = 0.2e^(−0.2t) for t ≥ 0, 0 otherwise
    M1 differentiate; A1 0.2e^(−0.2t).
  2. (b) 0.347
    M1 F(8) − F(3) = e^(−0.6) − e^(−1.6); A1 0.347.
  3. (c) e^(−0.6) ≈ 0.549
    M1 P(T ≥ 8 | T ≥ 5) = P(T ≥ 8)/P(T ≥ 5); M1 e^(−1.6)/e^(−1); A1 e^(−0.6) = 0.549.

Q20Median, quartiles & percentiles · Standard · Paper 4 style · 8 marks

The continuous random variable X has cumulative distribution functionF(x) = 0 for x < 0,F(x) = x²/20 for 0 ≤ x ≤ 2,F(x) = (20x − x² − 20)/80 for 2 < x ≤ 10,F(x) = 1 for x > 10.

Q24Median, quartiles & percentiles · Challenge · Paper 4 style · 9 marks

Q25Distribution of Y = g(X) · Core · Paper 4 style · 5 marks

The continuous random variable X has probability density function f(x) = x/2 for 0 ≤ x ≤ 2, and f(x) = 0 otherwise.

  1. (a) F(x) = x²/4 for 0 ≤ x ≤ 2
    B1 ∫₀ˣ t/2 dt.
  2. (b) G(y) = y/4 for 0 ≤ y ≤ 4; Y is uniformly distributed on [0, 4] with pdf 1/4
    M1 G(y) = P(X² ≤ y) = P(X ≤ √y); M1 = F(√y); A1 y/4 for 0 ≤ y ≤ 4; A1 pdf g(y) = 1/4, so Y is uniform on [0, 4].
Q26Distribution of Y = g(X) · Core · Paper 4 style · 6 marks

The continuous random variable X has probability density function f(x) = 3x² for 0 ≤ x ≤ 1, and f(x) = 0 otherwise. The random variable Y is defined by Y = 2X + 1.

  1. (a) Find the cumulative distribution function of Y. [3]
  2. (b) Hence find the probability density function of Y, and find E(Y). [3]
Show answer
  1. (a) G(y) = ((y − 1)/2)³ for 1 ≤ y ≤ 3 (0 for y < 1, 1 for y > 3)
    M1 G(y) = P(2X + 1 ≤ y) = P(X ≤ (y − 1)/2); M1 F(x) = x³; A1 ((y − 1)/2)³ with range 1 ≤ y ≤ 3.
  2. (b) g(y) = (3/8)(y − 1)² for 1 ≤ y ≤ 3; E(Y) = 5/2
    M1 differentiate G; A1 (3/8)(y − 1)²; B1 E(Y) = 2E(X) + 1 = 2(3/4) + 1 = 5/2.
Q27Distribution of Y = g(X) · Standard · Paper 4 style · 7 marks

The continuous random variable X has probability density function f(x) = 3/(2x²) for 1 ≤ x ≤ 3, and f(x) = 0 otherwise.

  1. (a) Find the cumulative distribution function of X. [2]
  2. (b) The random variable Y = 1/X. Show that the cumulative distribution function of Y is G(y) = (3y − 1)/2 for 1/3 ≤ y ≤ 1, and identify the distribution of Y. [4]
  3. (c) Hence write down E(Y). [1]
Show answer
  1. (a) F(x) = (3/2)(1 − 1/x) for 1 ≤ x ≤ 3
    M1 ∫₁ˣ (3/2)t⁻² dt; A1 (3/2)(1 − 1/x).
  2. (b) Y is uniform on [1/3, 1], with pdf 3/2
    M1 G(y) = P(1/X ≤ y) = P(X ≥ 1/y); M1 = 1 − F(1/y) = 1 − (3/2)(1 − y); A1 (3y − 1)/2; A1 pdf 3/2: uniform on [1/3, 1].
  3. (c) 2/3
    B1 midpoint of [1/3, 1].
Q28Distribution of Y = g(X) · Standard · Paper 4 style · 7 marks

The continuous random variable X has probability density function f(x) = 2x for 0 ≤ x ≤ 1, and f(x) = 0 otherwise.

  1. (a) Find the probability density function of Y, where Y = √X. [4]
  2. (b) Find E(Y) and the median of Y. [3]
Show answer
  1. (a) g(y) = 4y³ for 0 ≤ y ≤ 1, 0 otherwise
    M1 G(y) = P(√X ≤ y) = P(X ≤ y²); M1 F(x) = x² so G(y) = y⁴; A1 for 0 ≤ y ≤ 1; A1 g(y) = 4y³.
  2. (b) E(Y) = 4/5; median = (1/2)^(1/4) ≈ 0.841
    M1 ∫₀¹ 4y⁴ dy; A1 4/5; B1 y⁴ = 1/2 gives 0.841.
Q29Distribution of Y = g(X) · Challenge · Paper 4 style · 7 marks

The random variable X is uniformly distributed on the interval [0, 4], so its probability density function is 1/4 for 0 ≤ x ≤ 4. The random variable Y is defined by Y = (X − 2)².

  1. (a) Show that, for 0 ≤ y ≤ 4, P(Y ≤ y) = √y/2. [3]
  2. (b) Find the probability density function of Y and use it to find E(Y). [3]
  3. (c) Explain why your answer to part (b) is equal to Var(X). [1]
Show answer
  1. (a) Shown
    M1 P((X − 2)² ≤ y) = P(2 − √y ≤ X ≤ 2 + √y); M1 = (2√y)/4 using the uniform pdf 1/4; A1 √y/2.
  2. (b) g(y) = 1/(4√y) for 0 < y ≤ 4; E(Y) = 4/3
    M1 differentiate; A1 1/(4√y); A1 ∫₀⁴ √y/4 dy = (1/6)(8) = 4/3.
  3. (c) E((X − 2)²) = Var(X) since E(X) = 2
    B1 Var(X) = E((X − μ)²) with μ = 2, and Var(X) = 4²/12 = 4/3.
Q30Distribution of Y = g(X) · Challenge · Paper 4 style · 8 marks

The continuous random variable X has probability density function f(x) = 2e^(−2x) for x ≥ 0, and f(x) = 0 otherwise. The random variable Y is defined by Y = e^X.

  1. (a) Show that the cumulative distribution function of Y is G(y) = 1 − 1/y² for y ≥ 1. [4]
  2. (b) Find the probability density function of Y, and find E(Y) and the median of Y. [4]
Show answer
  1. (a) Shown
    M1 F(x) = 1 − e^(−2x); M1 G(y) = P(e^X ≤ y) = P(X ≤ ln y); M1 = 1 − e^(−2 ln y); A1 1 − y⁻², for y ≥ 1 since X ≥ 0.
  2. (b) g(y) = 2/y³ for y ≥ 1; E(Y) = 2; median = √2 ≈ 1.41
    B1 2y⁻³; M1 E(Y) = ∫₁^∞ 2y⁻² dy; A1 2; B1 1 − m⁻² = 1/2 gives m = √2.
