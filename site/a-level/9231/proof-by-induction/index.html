Q1Sequences & inequalities · Core · Paper 1 style · 5 marks
  1. (a) Prove by mathematical induction that, for all positive integers n,Σ (from r = 1 to n) r(r + 2) = (1/6)n(n + 1)(2n + 7). [5]
Show answer
  1. (a) Proof by induction (see working).
    B1: n = 1: LHS = 1 × 3 = 3, RHS = (1/6)(1)(2)(9) = 3.M1: assume true for n = k and add the (k + 1)th term (k + 1)(k + 3).M1: factorise (1/6)(k + 1)[k(2k + 7) + 6(k + 3)] = (1/6)(k + 1)(2k² + 13k + 18).A1: = (1/6)(k + 1)(k + 2)(2k + 9) = (1/6)(k + 1)((k + 1) + 1)(2(k + 1) + 7).A1: correct conclusion stating that the result is true for n = k + 1 when true for n = k, and true for n = 1, so true for all positive integers n.
Q2Sequences & inequalities · Core · Paper 1 style · 5 marks
  1. (a) Prove by mathematical induction that, for all positive integers n,Σ (from r = 1 to n) 1/((2r − 1)(2r + 1)) = n/(2n + 1). [5]
Show answer
  1. (a) Proof by induction (see working).
    B1: n = 1: LHS = 1/(1 × 3) = 1/3, RHS = 1/3.M1: assume true for n = k; add 1/((2k + 1)(2k + 3)).M1: common denominator: [k(2k + 3) + 1]/((2k + 1)(2k + 3)) = (2k² + 3k + 1)/((2k + 1)(2k + 3)).A1: = (k + 1)(2k + 1)/((2k + 1)(2k + 3)) = (k + 1)/(2(k + 1) + 1).A1: correct conclusion stating that the result is true for n = k + 1 when true for n = k, and true for n = 1, so true for all positive integers n.

Q4Sequences & inequalities · Core · Paper 1 style · 5 marks
  1. (a) Prove by mathematical induction that, for all positive integers n,Σ (from r = 1 to n) r × r! = (n + 1)! − 1. [5]
Show answer
  1. (a) Proof by induction (see working).

Q7Sequences & inequalities · Standard · Paper 1 style · 7 marks
  1. (a) Prove by mathematical induction that, for all positive integers n,Σ (from r = 1 to n) r × 2ʳ = (n − 1)2^(n+1) + 2. [5]
  2. (b) Hence find the value of Σ (from r = 11 to 20) r × 2ʳ. [2]
Show answer
  1. (a) Proof by induction (see working).
    B1: n = 1: LHS = 2, RHS = 0 + 2 = 2.M1: assume true for n = k; add (k + 1)2^(k+1).M1: (k − 1)2^(k+1) + (k + 1)2^(k+1) + 2 = 2k × 2^(k+1) + 2.A1: = k × 2^(k+2) + 2 = ((k + 1) − 1)2^((k+1)+1) + 2.A1: correct conclusion stating that the result is true for n = k + 1 when true for n = k, and true for n = 1, so true for all positive integers n.
  2. (b) 39 827 456
    M1: S(20) − S(10) = (19 × 2²¹ + 2) − (9 × 2¹¹ + 2) = 19 × 2 097 152 − 9 × 2048.A1: = 39 845 888 − 18 432 = 39 827 456.
Q8Sequences & inequalities · Standard · Paper 1 style · 6 marks
  1. (a) Prove by mathematical induction that 2ⁿ > n² for all integers n ≥ 5. [5]
  2. (b) State the values of n, with 1 ≤ n ≤ 4, for which 2ⁿ > n² is false. [1]
Show answer
  1. (a) Proof by induction (see working).
    B1: n = 5: 2⁵ = 32 > 25.M1: assume 2ᵏ > k² for some k ≥ 5; then 2^(k+1) = 2 × 2ᵏ > 2k².M1: 2k² − (k + 1)² = k² − 2k − 1 = (k − 1)² − 2 > 0 for k ≥ 5 (indeed for k ≥ 3).A1: so 2^(k+1) > (k + 1)².A1: true for n = 5 and true for k + 1 whenever true for k ≥ 5, so true for all n ≥ 5.
  2. (b) n = 2, 3, 4
    B1: 2² = 4 = 4, 2³ = 8 < 9, 2⁴ = 16 = 16 (n = 1: 2 > 1 is true).
Q9Sequences & inequalities · Standard · Paper 1 style · 6 marks

  2. (b) u₁₀₀ = 2/199
    B1: 2/(200 − 1).

Q11Sequences & inequalities · Challenge · Paper 1 style · 8 marks
  1. (a) The sequence u₁, u₂, u₃, … is defined by u₁ = 1 and u_(n+1) = √(u_n + 6). Prove by mathematical induction that 0 < u_n < 3 for all positive integers n. [4]
  2. (b) Prove that u_(n+1) > u_n for all positive integers n. [3]
  3. (c) Find u₃ correct to 4 decimal places. [1]
Show answer
  1. (a) Proof by induction (see working).
    B1: n = 1: 0 < 1 < 3.M1: assume 0 < u_k < 3; then 6 < u_k + 6 < 9.A1: so √6 < u_(k+1) < 3, hence 0 < u_(k+1) < 3.A1: conclusion for all n.
  2. (b) Proof (see working).
    M1: u_(n+1)² − u_n² = u_n + 6 − u_n² = −(u_n − 3)(u_n + 2).A1: since 0 < u_n < 3, (u_n − 3) < 0 and (u_n + 2) > 0, so u_(n+1)² > u_n².A1: both terms positive, so u_(n+1) > u_n.
  3. (c) u₃ = 2.9404
    B1: u₂ = √7 = 2.64575…, u₃ = √8.64575… = 2.9404.
Q12Sequences & inequalities · Challenge · Paper 1 style · 7 marks
  1. (a) A sequence is defined by u₁ = 1, u₂ = 5 and u_(n+2) = 5u_(n+1) − 6u_n for n ≥ 1. Prove by mathematical induction that u_n = 3ⁿ − 2ⁿ for all positive integers n. [6]
  2. (b) Find u₈. [1]
Show answer
  1. (a) Proof by induction (see working).
    B1: n = 1: 3 − 2 = 1; n = 2: 9 − 4 = 5 (both base cases needed).M1: assume u_k = 3ᵏ − 2ᵏ and u_(k+1) = 3^(k+1) − 2^(k+1).M1: u_(k+2) = 5(3^(k+1) − 2^(k+1)) − 6(3ᵏ − 2ᵏ).M1: = 3ᵏ(15 − 6) − 2ᵏ(10 − 6) = 9 × 3ᵏ − 4 × 2ᵏ.A1: = 3^(k+2) − 2^(k+2).A1: true for n = 1, 2 and if true for n = k and k + 1 then true for k + 2, so true for all positive integers n.
  2. (b) u₈ = 6305
    B1: 3⁸ − 2⁸ = 6561 − 256 = 6305.
Q13Sequences & inequalities · Challenge · Paper 1 style · 7 marks
  1. (a) Prove by mathematical induction that, for all positive integers n,Σ (from r = 1 to n) 1/r² ≤ 2 − 1/n. [6]
  2. (b) Deduce an upper bound for Σ (from r = 1 to ∞) 1/r². [1]
Show answer
  1. (a) Proof by induction (see working).
    B1: n = 1: 1 ≤ 2 − 1 = 1.M1: assume Σ (1 to k) 1/r² ≤ 2 − 1/k; then Σ (1 to k + 1) ≤ 2 − 1/k + 1/(k + 1)².M1: need −1/k + 1/(k + 1)² ≤ −1/(k + 1), i.e. 1/(k + 1)² ≤ 1/k − 1/(k + 1) = 1/(k(k + 1)).A1: true since k(k + 1) < (k + 1)².A1: so Σ (1 to k + 1) 1/r² ≤ 2 − 1/(k + 1).A1: correct conclusion stating that the result is true for n = k + 1 when true for n = k, and true for n = 1, so true for all positive integers n.
  2. (b) 2 (the sum is at most 2)
    B1: 2 − 1/n < 2 for every n, so the partial sums are bounded above by 2.
Q14Sequences & inequalities · Challenge · Paper 1 style · 8 marks

    B1: (−2)⁴ × 4! / 1 = 16 × 24 = 384.

Q29Matrix powers · Standard · Paper 1 style · 7 marks
  1. (a) The matrix M is given by M = (4 −3; 2 −1), rows separated by a semicolon. Prove by mathematical induction that, for all positive integers n,Mⁿ = (3 × 2ⁿ − 2 3 − 3 × 2ⁿ ; 2^(n+1) − 2 3 − 2^(n+1)). [6]
  2. (b) Find M⁵. [1]
Show answer
  1. (a) Proof by induction (see working).
    B1: n = 1: (6 − 2, 3 − 6; 4 − 2, 3 − 4) = (4 −3; 2 −1) = M.M1: assume formula for Mᵏ; form M^(k+1) = Mᵏ M.M1: top-left: 4(3 × 2ᵏ − 2) + 2(3 − 3 × 2ᵏ) = 6 × 2ᵏ − 2 = 3 × 2^(k+1) − 2; top-right: −3(3 × 2ᵏ − 2) − (3 − 3 × 2ᵏ) = 3 − 6 × 2ᵏ = 3 − 3 × 2^(k+1).A1: bottom-left: 4(2^(k+1) − 2) + 2(3 − 2^(k+1)) = 2^(k+2) − 2.A1: bottom-right: −3(2^(k+1) − 2) − (3 − 2^(k+1)) = 3 − 2^(k+2).A1: correct conclusion stating that the result is true for n = k + 1 when true for n = k, and true for n = 1, so true for all positive integers n.

Q30Matrix powers · Challenge · Paper 1 style · 8 marks
  1. (a) The 3 × 3 matrix B has rows (1, 1, 0), (0, 1, 1) and (0, 0, 1). Prove by mathematical induction that, for all positive integers n, Bⁿ has rows(1, n, n(n − 1)/2), (0, 1, n) and (0, 0, 1). [6]
  2. (b) Hence find the value of n for which the top-right entry of Bⁿ equals 190. [2]
Show answer
  1. (a) Proof by induction (see working).
    B1: n = 1: rows (1, 1, 0), (0, 1, 1), (0, 0, 1) = B.M1: assume formula for Bᵏ; form B^(k+1) = Bᵏ B.A1: first row: (1, 1 + k, k + k(k − 1)/2).M1: k + k(k − 1)/2 = k(k + 1)/2 = (k + 1)((k + 1) − 1)/2.A1: second row (0, 1, 1 + k), third row (0, 0, 1).A1: correct conclusion stating that the result is true for n = k + 1 when true for n = k, and true for n = 1, so true for all positive integers n.
  2. (b) n = 20
    M1: n(n − 1)/2 = 190 ⇒ n² − n − 380 = 0 ⇒ (n − 20)(n + 19) = 0.A1: n = 20.
