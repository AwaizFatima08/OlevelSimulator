Q1Method of differences · Core · Paper 1 style · 5 marks
  1. (a) Express 1/((r + 1)(r + 2)) in partial fractions. [2]
  2. (b) Hence use the method of differences to find Σ (r = 1 to n) 1/((r + 1)(r + 2)) in terms of n, simplifying your answer. [3]
Show answer
  1. (a) 1/(r + 1) − 1/(r + 2)
    M1 correct form A/(r + 1) + B/(r + 2); A1 A = 1, B = −1.
  2. (b) n/(2(n + 2))
    M1 write out terms: (1/2 − 1/3) + (1/3 − 1/4) + … + (1/(n + 1) − 1/(n + 2)); M1 cancellation shown at both ends; A1 1/2 − 1/(n + 2) = n/(2(n + 2)).
Q2Method of differences · Core · Paper 1 style · 6 marks
  1. (a) Let f(r) = 1/r². Show that f(r) − f(r + 1) = (2r + 1)/(r²(r + 1)²). [2]
  2. (b) Hence find Σ (r = 1 to n) (2r + 1)/(r²(r + 1)²) in terms of n. [3]
  3. (c) Find the value of the sum when n = 9. [1]
Show answer
  1. (a) Shown
    M1 common denominator: ((r + 1)² − r²)/(r²(r + 1)²); A1 numerator 2r + 1 (AG).
  2. (b) 1 − 1/(n + 1)² = n(n + 2)/(n + 1)²
    M1 sum of f(r) − f(r + 1) from r = 1 to n; M1 at least three terms at the start and end showing cancellation; A1 f(1) − f(n + 1) = 1 − 1/(n + 1)².
  3. (c) 99/100
    B1 1 − 1/100 = 0.99.
Q3Method of differences · Core · Paper 1 style · 6 marks
  1. (a) Express 1/((2r − 1)(2r + 1)) in partial fractions. [2]
  2. (b) Show that Σ (r = 1 to n) 1/((2r − 1)(2r + 1)) = n/(2n + 1). [3]
  3. (c) Find the value of n for which the sum equals 20/41. [1]
Show answer
  1. (a) 1/(2(2r − 1)) − 1/(2(2r + 1))
    M1 A/(2r − 1) + B/(2r + 1); A1 A = 1/2, B = −1/2.
  2. (b) Shown
    M1 (1/2)[(1 − 1/3) + (1/3 − 1/5) + … + (1/(2n − 1) − 1/(2n + 1))]; M1 cancellation; A1 (1/2)(1 − 1/(2n + 1)) = n/(2n + 1) (AG).
  3. (c) n = 20
    B1 n/(2n + 1) = 20/41 gives n = 20.
Q4Method of differences · Core · Paper 1 style · 6 marks
  1. (a) Show that (r + 1)! − r! = r × r!. [1]
  2. (b) Hence find Σ (r = 1 to n) r × r! in terms of n. [3]
  3. (c) Find the least value of n for which the sum exceeds 1 000 000. [2]
Show answer
  1. (a) Shown
    B1 (r + 1)! − r! = r!(r + 1 − 1) = r × r! (AG).
  2. (b) (n + 1)! − 1
    M1 use of differences: (2! − 1!) + (3! − 2!) + … + ((n + 1)! − n!); M1 cancellation; A1 (n + 1)! − 1.
  3. (c) n = 9
    M1 (n + 1)! > 1 000 001; 9! = 362 880, 10! = 3 628 800; A1 n + 1 = 10 so n = 9.

  3. (c) Find the value of n for which the sum is 9. [1]

    B1 √(n + 1) = 10 so n = 99.

Show answer
  1. (a) Shown
    M1 write term as log₁₀(r + 2) − log₁₀ r; M1 list terms: (log 3 − log 1) + (log 4 − log 2) + (log 5 − log 3) + … + (log(n + 2) − log n); M1 surviving terms log(n + 1) + log(n + 2) − log 1 − log 2; A1 log₁₀((n + 1)(n + 2)/2) (AG).
  2. (b) n = 44

Show answer

Q9Method of differences · Standard · Paper 1 style · 6 marks
  1. (a) Show that r/(r + 1)! = 1/r! − 1/(r + 1)!. [2]
  2. (b) Hence find Σ (r = 1 to n) r/(r + 1)! in terms of n. [2]
  3. (c) Find the least value of n for which the sum differs from 1 by less than 10⁻⁸. [2]
Show answer
  1. (a) Shown
    M1 1/r! = (r + 1)/(r + 1)!; A1 ((r + 1) − 1)/(r + 1)! = r/(r + 1)! (AG).
  2. (b) 1 − 1/(n + 1)!
    M1 (1/1! − 1/2!) + (1/2! − 1/3!) + … + (1/n! − 1/(n + 1)!); A1 1 − 1/(n + 1)!.
  3. (c) n = 11
    M1 1/(n + 1)! < 10⁻⁸, i.e. (n + 1)! > 10⁸; 11! = 39 916 800, 12! = 479 001 600; A1 n + 1 = 12, n = 11.

Q11Method of differences · Challenge · Paper 1 style · 7 marks
  1. (a) Show that 2 sin(½θ) cos(rθ) = sin((r + ½)θ) − sin((r − ½)θ). [2]
  2. (b) Hence show that, for sin(½θ) ≠ 0, Σ (r = 1 to n) cos(rθ) = (sin((n + ½)θ) − sin(½θ))/(2 sin(½θ)). [3]
  3. (c) Use this result to evaluate Σ (r = 1 to 10) cos(rπ/7), giving your answer correct to 3 significant figures. [2]
Show answer
  1. (a) Shown
    M1 expand sin((r ± ½)θ) with compound-angle formulae; A1 the sin(rθ)cos(½θ) terms cancel, leaving 2cos(rθ)sin(½θ) (AG).
  2. (b) Shown
    M1 sum both sides from r = 1 to n; M1 right-hand side telescopes: (sin(3θ/2) − sin(θ/2)) + (sin(5θ/2) − sin(3θ/2)) + …; A1 divide by 2 sin(½θ) (AG).
  3. (c) −(1 + sin(π/14))/(2 sin(π/14)) = −2.75
    M1 substitute n = 10, θ = π/7: (sin(3π/2) − sin(π/14))/(2 sin(π/14)); A1 sin(3π/2) = −1, giving −2.75.
Q12Method of differences · Challenge · Paper 1 style · 6 marks
  1. (a) Show that 4r⁴ + 1 = (2r² + 2r + 1)(2r² − 2r + 1). [1]
  2. (b) Hence express 4r/(4r⁴ + 1) in the form 1/(2r² − 2r + 1) − 1/(2r² + 2r + 1) and use the method of differences to find Σ (r = 1 to n) 4r/(4r⁴ + 1). [4]
  3. (c) State the sum to infinity of the series. [1]
Show answer
  1. (a) Shown
    B1 expand: (2r² + 1)² − (2r)² = 4r⁴ + 4r² + 1 − 4r² (AG).
  2. (b) 1 − 1/(2n² + 2n + 1)
    M1 verify difference: ((2r² + 2r + 1) − (2r² − 2r + 1))/(4r⁴ + 1) = 4r/(4r⁴ + 1); M1 note 2(r + 1)² − 2(r + 1) + 1 = 2r² + 2r + 1, so consecutive terms cancel; M1 terms 1/1 − 1/5 + 1/5 − 1/13 + …; A1 1 − 1/(2n² + 2n + 1).
  3. (c) 1
    B1 1/(2n² + 2n + 1) → 0 so the sum → 1.

  1. (a) Shown

Q15Method of differences · Challenge · Paper 1 style · 6 marks
  1. (a) Use the formula for tan(A − B) to show that tan⁻¹(r + 1) − tan⁻¹ r = tan⁻¹(1/(r² + r + 1)) for r ≥ 0. [2]
  2. (b) Hence find Σ (r = 1 to n) tan⁻¹(1/(r² + r + 1)) in terms of n. [3]
  3. (c) Find the sum to infinity of the series. [1]
Show answer
  1. (a) Shown
    M1 tan(A − B) = ((r + 1) − r)/(1 + r(r + 1)); A1 = 1/(r² + r + 1), and the angle lies in (0, π/2) (AG).
  2. (b) tan⁻¹(n + 1) − π/4
    M1 (tan⁻¹2 − tan⁻¹1) + (tan⁻¹3 − tan⁻¹2) + …; M1 cancellation; A1 tan⁻¹(n + 1) − π/4.
  3. (c) π/4
    B1 tan⁻¹(n + 1) → π/2, so the sum → π/2 − π/4 = π/4.

Q22Standard results (MF19) · Standard · Paper 1 style · 6 marks
  1. (a) Let f(r) = r²(r + 1)². Show that f(r) − f(r − 1) = 4r³. [2]
  2. (b) Hence, using the method of differences, show that Σ (r = 1 to n) r³ = (1/4)n²(n + 1)². [3]
  3. (c) Deduce that the sum of the first n cubes equals the square of the sum of the first n positive integers. [1]
Show answer
  1. (a) Shown
    M1 r²[(r + 1)² − (r − 1)²]; A1 r² × 4r = 4r³ (AG).
  2. (b) Shown
    M1 sum from r = 1 to n; M1 telescoping to f(n) − f(0); A1 f(0) = 0, so 4Σr³ = n²(n + 1)² (AG).
  3. (c) Shown
    B1 (1/4)n²(n + 1)² = [(1/2)n(n + 1)]² = (Σr)².
Q23Standard results (MF19) · Challenge · Paper 1 style · 6 marks

Show answer
  1. (a) Shown
    M1 odd cubes = all cubes up to 2n minus even cubes; M1 (1/4)(2n)²(2n + 1)² − 8 × (1/4)n²(n + 1)²; M1 n²[(2n + 1)² − 2(n + 1)²]; A1 n²(2n² − 1) (AG).
  2. (b) 1 599 200
    M1 21 = 2(11) − 1 and 59 = 2(30) − 1, so S(30) − S(10); A1 900 × 1799 − 100 × 199 = 1 599 200.

Q27Sum to infinity & convergence · Standard · Paper 1 style · 7 marks
  1. (a) Show that 1/(r × 2^(r − 1)) − 1/((r + 1) × 2^r) = (r + 2)/(r(r + 1)2^r). [2]
  2. (b) Find Σ (r = 1 to n) (r + 2)/(r(r + 1)2^r) and deduce the sum to infinity. [3]
  3. (c) Find the least n for which the sum to n terms is within 0.001 of the sum to infinity. [2]
Show answer
  1. (a) Shown
    M1 common denominator r(r + 1)2^r; A1 2(r + 1) − r = r + 2 (AG).
  2. (b) S_n = 1 − 1/((n + 1)2^n); sum to infinity 1
    M1 telescoping; A1 1 − 1/((n + 1)2^n); B1 (n + 1)2^n → ∞ so S∞ = 1.
  3. (c) n = 7
    M1 (n + 1)2^n > 1000; n = 6 gives 448, n = 7 gives 1024; A1 n = 7.
Q28Sum to infinity & convergence · Standard · Paper 1 style · 7 marks
  1. (a) Given that 1/(r(r + 1)(r + 2)) = (1/2)[1/(r(r + 1)) − 1/((r + 1)(r + 2))], find Σ (r = 1 to n) 1/(r(r + 1)(r + 2)) in terms of n. [3]
  2. (b) Explain why the series converges and state its sum to infinity. [2]
  3. (c) Find the least value of n for which the sum to infinity minus the sum to n terms is less than 10⁻⁴. [2]
Show answer
  1. (a) 1/4 − 1/(2(n + 1)(n + 2))
    M1 telescoping with at least two terms each end; M1 (1/2)(1/2 − 1/((n + 1)(n + 2))); A1.
  2. (b) 1/4
    B1 1/(2(n + 1)(n + 2)) → 0 as n → ∞, so S_n tends to a finite limit; B1 1/4.
  3. (c) n = 70
    M1 (n + 1)(n + 2) > 5000; n = 69 gives 4970, n = 70 gives 5112; A1 n = 70.
Q29Sum to infinity & convergence · Challenge · Paper 1 style · 7 marks
  1. (a) Show that Σ (r = 1 to n) ln(1 + 1/r) = ln(n + 1), and explain why Σ (r = 1 to ∞) ln(1 + 1/r) is divergent. [3]
  2. (b) Show that Σ (r = 1 to n) ln((r + 1)²/(r(r + 2))) = ln(2(n + 1)/(n + 2)). [3]
  3. (c) Deduce that the series in part (b) is convergent and state its sum to infinity. [1]
Show answer
  1. (a) ln(n + 1); diverges since ln(n + 1) → ∞
    M1 ln((r + 1)/r) = ln(r + 1) − ln r; A1 telescopes to ln(n + 1) − ln 1; B1 ln(n + 1) increases without bound, so no finite sum to infinity.
  2. (b) Shown
    M1 write term as [ln(r + 1) − ln r] − [ln(r + 2) − ln(r + 1)]; M1 sum each part: ln(n + 1) − [ln(n + 2) − ln 2]; A1 ln(2(n + 1)/(n + 2)) (AG).
  3. (c) ln 2
    B1 (n + 1)/(n + 2) → 1, so the sum → ln 2.
Q30Sum to infinity & convergence · Challenge · Paper 1 style · 7 marks
  1. (a) Show that 1/√r − 1/√(r + 1) = 1/(√(r(r + 1)) (√r + √(r + 1))). [3]
  2. (b) Hence find Σ (r = 1 to n) 1/(√(r(r + 1)) (√r + √(r + 1))) and state the sum to infinity. [2]
  3. (c) Find the least value of n for which the sum to n terms exceeds 0.99. [2]
Show answer
  1. (a) Shown
    M1 combine: (√(r + 1) − √r)/√(r(r + 1)); M1 multiply top and bottom by √(r + 1) + √r; A1 numerator becomes 1 (AG).
  2. (b) 1 − 1/√(n + 1); sum to infinity 1
    M1 telescoping; A1 1 − 1/√(n + 1), sum to infinity 1.
  3. (c) n = 10 000
    M1 1/√(n + 1) < 0.01, so n + 1 > 10 000 (strict); A1 n = 10 000.
