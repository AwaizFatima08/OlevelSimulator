Q1Mean & variance from a PGF · Core · Paper 4 style · 5 marks
  1. (a) The number of goals, X, scored by a school hockey team in a match has probability generating function G(t) = (1/8)(1 + 3t + 4t²). Write down P(X = 2). [1]
  2. (b) Use G(t) to find E(X) and Var(X). [4]
Show answer
  1. (a) 1/2
    B1: coefficient of t² = 4/8.
  2. (b) E(X) = 11/8; Var(X) = 31/64
    M1: G′(t) = (3 + 8t)/8, G′(1) = 11/8.A1: E(X) = 11/8.M1: G″(1) = 1; Var = 1 + 11/8 − 121/64.A1: = 31/64.

  1. (a) A random variable W has probability generating function G(t) = (1/27) t(2 + t)³. Find E(W) and Var(W). [4]

Show answer
  1. (a) E(W) = 2; Var(W) = 2/3

Q5Mean & variance from a PGF · Core · Paper 4 style · 5 marks

  2. (b) Find Var(X). [3]
Show answer

    M1 E(X) = G′(1); A1 0.5 + 2(0.3) = 1.1.

Q16Mean & variance from a PGF · Challenge · Paper 4 style · 6 marks
  1. (a) A random variable X has probability generating function G(t) = t²/(3 − 2t). Show that G(1) = 1 and find E(X). [3]
  2. (b) Find Var(X). [3]
Show answer
  1. (a) E(X) = 4
    B1: G(1) = 1/1 = 1.M1: G′(t) = [2t(3 − 2t) + 2t²]/(3 − 2t)² = (6t − 2t²)/(3 − 2t)².A1: G′(1) = 4.

    M1: differentiate G′(t) = (6t − 2t²)(3 − 2t)⁻²: G″(t) = (6 − 4t)(3 − 2t)⁻² + 4(6t − 2t²)(3 − 2t)⁻³.A1: G″(1) = 2 + 16 = 18.A1: Var = 18 + 4 − 16 = 6.
