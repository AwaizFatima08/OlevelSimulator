    For λ = 2: 2x − 2y = 0, so v = (1, 1). For λ = 3: x − 2y = 0, so v = (2, 1). Check: B(2, 1) = (6, 3) = 3(2, 1). M1 A1 A1.

  2. (b) Find all the eigenvalues of C, and state the number of independent eigenvectors for the repeated eigenvalue. [3]
Show answer
  1. (a) C(1, 0, 1) = (3, 0, 3) = 3(1, 0, 1); C(0, 1, 0) = (0, 3, 0) = 3(0, 1, 0). (shown)

  2. (b) 3, 3 and −1; the eigenvalue 3 has two independent eigenvectors, (1, 0, 1) and (0, 1, 0)

Show answer
  1. (a) λ = 2 with eigenvector (1, 0); λ = −1 with eigenvector (1, −1)
    A is upper triangular, so λ = 2 or −1. For λ = 2: (A − 2I)v = 0 gives v = (1, 0). For λ = −1: 3x + 3y = 0, so v = (1, −1). Check: A(1, −1) = (−1, 1). M1 A1 A1.

  3. (c) Find an eigenvector corresponding to each eigenvalue. [2]
Show answer

Q55Eigenvalues & eigenvectors · Standard · Paper 2 style · 6 marks
  1. (a) The matrix N = (a 2; 3 b) has eigenvector (2, 1) with eigenvalue 4. Find the values of a and b. [3]
  2. (b) Find the other eigenvalue of N and a corresponding eigenvector. [3]
Show answer
  1. (a) a = 3, b = −2
    N(2, 1) = (2a + 2, 6 + b) = 4(2, 1) = (8, 4). So 2a + 2 = 8 and 6 + b = 4, giving a = 3 and b = −2. M1 equation, M1, A1.
  2. (b) λ = −3; eigenvector (1, −3)
    The sum of the eigenvalues is the trace, 3 − 2 = 1, so the other eigenvalue is 1 − 4 = −3. (N + 3I)v = 0 gives 6x + 2y = 0, so v = (1, −3). Check: N(1, −3) = (−3, 9) = −3(1, −3). M1, A1, A1.

  3. (c) Hence find the other eigenvalues of A. [2]
Show answer
  1. (a) A(1, 0, −1) = (2, 0, −2) = 2(1, 0, −1), so the eigenvalue is 2 (shown).

  2. (b) λ³ − 6λ² + 10λ − 4 = 0 (shown)

  1. (a) The 3 × 3 matrix A has eigenvalues 1, 2 and −3. Write down the characteristic polynomial of A, and find the trace and the determinant of A. [3]
  2. (b) Find the determinant of A² − 3A + I. [3]
Show answer
  1. (a) λ³ − 7λ + 6 = 0 (characteristic equation); trace 0; determinant −6
    (λ − 1)(λ − 2)(λ + 3) = λ³ − 7λ + 6. The trace is the sum of the eigenvalues, 0. The determinant is their product, −6. M1 expansion, M1 trace, A1 determinant.
  2. (b) 19
    The eigenvalues of A² − 3A + I are λ² − 3λ + 1: for λ = 1 this is −1, for λ = 2 it is −1, and for λ = −3 it is 19. So det(A² − 3A + I) = (−1)(−1)(19) = 19. M1 eigenvalues of the polynomial, M1 product, A1.
Q59Eigenvalues & eigenvectors · Challenge · Paper 2 style · 6 marks
  1. (a) The matrix A = (1 2; −2 1). Show that A has no real eigenvalues. [2]
  2. (b) Find the eigenvalues of A. [2]
  3. (c) Find an eigenvector corresponding to the eigenvalue 1 + 2i. [2]
Show answer
  1. (a) No real eigenvalues (shown)
    The characteristic equation is (1 − λ)² + 4 = 0, that is λ² − 2λ + 5 = 0. The discriminant is 4 − 20 = −16 < 0, so there are no real roots. M1, A1.
  2. (b) 1 + 2i and 1 − 2i
    λ = (2 ± √(−16))/2 = 1 ± 2i. M1, A1.
  3. (c) (1, i)
    (A − (1 + 2i)I)v = 0 gives −2iv₁ + 2v₂ = 0, so v₂ = iv₁. Taking v₁ = 1 gives (1, i). Check: A(1, i) = (1 + 2i, −2 + i) = (1 + 2i)(1, i). M1, A1.

  2. (b) Show that all eigenvectors of A are multiples of (1, 0). [3]
  3. (c) Deduce that A is not diagonalisable. [2]
Show answer

    A is upper triangular with both diagonal entries 1, so the characteristic equation is (λ − 1)² = 0.
