Q1Security threats & protection · Core · Paper 1 style · 5 marks
  1. (a) A school in Peshawar has a network of 120 computers. Describe the difference between a virus and a worm. [2]
  2. (b) Describe what spyware does and give one way it could harm the school. [2]
  3. (c) State one software measure that protects the network against both viruses and spyware. [1]
Show answer
  1. (a) A virus attaches itself to (is hidden inside) another program or file and needs that file to be run/opened to spread; a worm is a standalone program that replicates itself and spreads across the network on its own, without a host file or user action.
    1 mark: virus needs a host file / user action to run and spread. 1 mark: worm is standalone and self-replicates across the network by itself.
  2. (b) Spyware secretly monitors/records activity on a computer (e.g. key presses with a key-logger) and sends the data to a third party. Harm: teachers' passwords or students' personal data could be stolen.
    1 mark: secretly records/monitors user activity and sends it to a third party. 1 mark: a relevant harm in context, e.g. stolen login details giving access to the results system.
  3. (c) Anti-malware software (anti-virus / anti-spyware) that is kept up to date.
    B1 anti-virus or anti-spyware/anti-malware software (accept up-to-date scanning software).
Q2Security threats & protection · Core · Paper 1 style · 7 marks
  1. (a) Customers of an online bank receive an email that looks as if it is from the bank. It asks them to click a link and 'confirm' their card details. Identify this threat and describe how it works. [3]
  2. (b) Another customer types the bank's correct web address but is taken to a fake site. Identify this threat and explain how it differs from the threat in (a). [3]
  3. (c) Give one action a customer can take to avoid being caught by the threat in (a). [1]
Show answer
  1. (a) Phishing. A legitimate-looking email is sent to many people; the link leads to a fake website; details the user types in are captured by the criminal.
    B1 phishing. Then 1 mark each for any two of: email/message pretends to be from a trusted organisation; contains a link to a fake website; user is tricked into entering personal/financial details; details are sent to the criminal.
  2. (b) Pharming. Malicious code on the user's computer or a compromised (poisoned) DNS server redirects the correct URL to a fake website. Unlike phishing, the user does not have to click a link in a message – typing the genuine address is enough.
    B1 pharming. 1 mark: malicious code installed on the computer / DNS cache or server altered. 1 mark: redirection happens even when the correct URL is typed / no email link needed.
  3. (c) Do not click links in unexpected emails; type the bank's address directly / check the sender and the URL carefully.
    B1 any sensible action.
Q3Security threats & protection · Core · Paper 1 style · 5 marks
  1. (a) A small accountancy firm in Dubai connects its LAN to the internet. Describe how a firewall helps to protect the LAN. [3]
  2. (b) State two other security measures the firm could use to protect client data on its server, other than a firewall. [2]
Show answer
  1. (a) The firewall sits between the LAN and the internet and examines every packet entering or leaving. It compares packets with a set of rules/criteria (e.g. allowed IP addresses, ports, protocols). Packets that do not meet the rules are blocked; it can also log traffic and stop unauthorised access from outside.
    1 mark each for any three of: positioned between LAN and internet (or on a computer); monitors incoming and outgoing traffic/packets; checks against rules/criteria set by the administrator; blocks/rejects packets that fail; can block certain IP addresses/ports/websites; keeps a log of attempted access.
  2. (b) Any two of: strong passwords / user accounts; access rights; encryption of stored data; anti-malware software; biometrics; two-step verification.
    1 mark each for any two distinct measures.
Q4Security threats & protection · Core · Paper 3 style · 5 marks
  1. (a) Define the terms plaintext, ciphertext and encryption key. [3]
  2. (b) Describe the difference between symmetric and asymmetric encryption. [2]
Show answer
  1. (a) Plaintext: the original, readable data before encryption. Ciphertext: the scrambled data produced by encryption, unreadable without the key. Key: a value used by the encryption algorithm to encrypt/decrypt the data.
    1 mark for each correct definition.
  2. (b) Symmetric encryption uses the same (secret) key to encrypt and decrypt. Asymmetric encryption uses a pair of mathematically related keys: a public key and a private key – data encrypted with one key can only be decrypted with the other.
    1 mark: symmetric – one shared secret key. 1 mark: asymmetric – public/private key pair.
Q5Security threats & protection · Core · Paper 3 style · 5 marks
  1. (a) Describe how quantum cryptography is used to share an encryption key. [3]
  2. (b) Give one benefit and one drawback of quantum cryptography. [2]
Show answer
  1. (a) The key is sent as a stream of photons (light particles) whose polarisation represents the bits, using a quantum key distribution protocol. The receiver measures the photons with randomly chosen filters and the two sides compare which filters they used to build a shared key. Any attempt to observe the photons changes their state, so eavesdropping can be detected.
    1 mark each for any three of: uses the properties of photons/quantum mechanics; bits represented by polarisation; quantum key distribution (QKD); measuring a photon changes its state; eavesdropper is detected; key is then used for encryption.
  2. (b) Benefit: eavesdropping on the key exchange can always be detected, so the key is (in theory) completely secure / longer keys can be shared. Drawback: needs expensive specialist hardware/dedicated fibre links, limited distance, and the technology is still developing.
    1 mark for a benefit; 1 mark for a drawback.

Q7Security threats & protection · Standard · Paper 1 style · 6 marks
  1. (a) A hospital in Karachi gives doctors access to patient records. At present each doctor logs in with a user ID and password. Explain why adding two-step (two-factor) verification would make the system more secure. [2]
  2. (b) The hospital considers fingerprint scanners instead of passwords. Give one advantage and one disadvantage of using biometrics in this situation. [2]
  3. (c) Explain how access rights should be used so that reception staff cannot view patients' medical history. [2]
Show answer
  1. (a) A second, different factor is required (e.g. a one-time code sent to the doctor's phone, or a fingerprint). A criminal who has stolen or guessed the password still cannot log in without that second factor.
    1 mark: a second, independent form of authentication is needed (something you have/are). 1 mark: a stolen/guessed password alone is no longer enough.
  2. (b) Advantage: fingerprints are unique and cannot be forgotten, shared or guessed. Disadvantage: e.g. scanners may fail with dirty or gloved hands (doctors wear gloves) / cost of equipment / biometric data cannot be changed if stolen.
    1 mark for a valid advantage; 1 mark for a valid disadvantage (credit context such as surgical gloves).
  3. (c) Each user account is placed in a group with set permissions. Reception staff are given access only to contact/appointment data (read/write) and no access (or read-only to limited fields) for medical history, which only doctors can read/edit.
    1 mark: different users/groups given different permissions. 1 mark: reception have no access to medical-history data while doctors do.
Q8Security threats & protection · Standard · Paper 1 style · 6 marks
  1. (a) A photographer in Lahore stores all her client images on one external hard disk. Identify two ways her data could be lost other than by malware or hacking. [2]
  2. (b) Describe two measures she could take to reduce the risk of losing her data, and explain how each helps. [4]
Show answer
  1. (a) Any two of: hardware failure of the disk; accidental deletion/overwriting; physical damage (fire, flood, dropping it); theft/loss of the disk; power cut while writing corrupts data.

  2. (b) Explain why a computer with up-to-date anti-virus software can still be infected. [2]

(a) It scans files (on access or on a schedule) and compares their code with a database of known virus signatures; heuristic checking looks for virus-like behaviour in unknown files; a suspicious file is quarantined (isolated) or deleted, and the user is alerted; the signature database must be updated regularly.

Q10Security threats & protection · Standard · Paper 3 style · 6 marks
  1. (a) Ayesha wants to send a confidential file to Bilal using asymmetric encryption so that only Bilal can read it. State which key Ayesha uses to encrypt the file and which key Bilal uses to decrypt it. [2]
  2. (b) Explain why a person who intercepts the file cannot read it, even though Bilal's public key is freely available. [2]
  3. (c) Bilal replies with a message that Ayesha must be sure came from him. Describe how keys are used so that Ayesha can be sure of this. [2]
Show answer
  1. (a) Ayesha encrypts with Bilal's public key; Bilal decrypts with his own private key.
    B1 Bilal's public key. B1 Bilal's private key.
  2. (b) The file can only be decrypted with the matching private key, which only Bilal holds and never shares; the public key cannot be used to decrypt it (and the private key cannot practically be worked out from the public key).
    1 mark: only the private key can decrypt. 1 mark: only Bilal has the private key / it is never transmitted.
  3. (c) Bilal encrypts (a digest of) the message with his own private key; Ayesha decrypts it with Bilal's public key – if it decrypts correctly it must have come from Bilal, because only he has the private key.
    1 mark: Bilal uses his private key. 1 mark: Ayesha uses Bilal's public key, proving the sender.
Q11Security threats & protection · Standard · Paper 3 style · 6 marks
  1. (a) A software company in Bengaluru signs every update it releases with a digital signature. Describe how the digital signature is produced. [3]
  2. (b) Describe how a user's computer checks the signature before installing the update. [3]
Show answer
  1. (a) A hashing algorithm is applied to the update file to produce a message digest. The digest is encrypted with the company's private key. The encrypted digest (the digital signature) is attached to/sent with the file.
    1 mark each: hash/digest of the file; digest encrypted with the sender's private key; signature sent with the file.
  2. (b) It decrypts the signature using the company's public key to recover the original digest. It applies the same hashing algorithm to the received file to make a new digest. If the two digests match, the file is genuine and unaltered; if not, it is rejected.
    1 mark each: decrypt signature with company's public key; re-hash the received file with the same algorithm; compare digests – match means authentic and unchanged.

Q14Security threats & protection · Challenge · Paper 3 style · 8 marks
  1. (a) An online university portal uses a digital certificate. Describe how the university obtains its digital certificate. [3]
  2. (b) State three items of information that a digital certificate contains. [3]
  3. (c) Explain how a student's browser uses the certificate to decide whether to trust the portal. [2]
Show answer
  1. (a) The university generates a public/private key pair and sends a request containing its public key and identity details to a Certificate Authority (CA). The CA checks the university's identity. The CA issues the certificate containing the public key and details, signed with the CA's own private key.
    1 mark each for any three of: applies to a Certificate Authority; supplies public key and identification details; CA verifies identity; CA creates certificate and signs it with the CA's private key; certificate issued with expiry date.
  2. (b) Any three of: the owner's (subject's) name/domain; the owner's public key; the name of the issuing CA; the CA's digital signature; serial number; validity (start and expiry) dates; algorithm used.
    1 mark each for any three.
  3. (c) The browser checks the CA's signature on the certificate using the CA's public key (which it already trusts); it also checks the certificate has not expired/been revoked and that the domain name matches the site. If all checks pass, it trusts the public key in the certificate.
    1 mark: verifies CA signature with CA's public key. 1 mark: checks validity dates/domain/revocation.
Q15Security threats & protection · Challenge · Paper 3 style · 7 marks
  1. (a) Describe the main steps of a TLS handshake between a browser and a web server. [5]
  2. (b) Explain why TLS uses asymmetric encryption only during the handshake and symmetric encryption for the data that follows. [2]
Show answer
  1. (a) The client sends a 'hello' listing the TLS versions and cipher suites it supports. The server replies, choosing the version/cipher suite, and sends its digital certificate. The client checks the certificate with the CA's public key. The client and server then agree a session key – e.g. the client creates a secret and encrypts it with the server's public key, and only the server can decrypt it with its private key. Both sides derive the same symmetric session key and confirm the handshake is finished; data is then encrypted with that key.
    1 mark each for any five of: client hello with supported versions/ciphers; server hello choosing cipher; server sends certificate/public key; client verifies certificate (via CA); key exchange using server's public key (or key-agreement method); server uses private key; both generate same session key; 'finished' messages / encrypted data transfer begins.
  2. (b) Asymmetric encryption solves the problem of sharing a key securely but is slow/processor-intensive; symmetric encryption is much faster, so it is used for the bulk of the data once the session key has been shared safely.
    1 mark: asymmetric allows secure key exchange (no shared secret needed in advance). 1 mark: symmetric is faster/less processing for large amounts of data.
Q16Security threats & protection · Challenge · Paper 3 style · 6 marks
  1. (a) A student says: 'A digital signature is made by encrypting the whole document with the sender's private key.' Explain why a hash (message digest) is signed instead of the whole document. [2]
  2. (b) A contract file signed by a lawyer in Faisalabad has one figure changed in transit. Explain how the receiver detects this. [2]
  3. (c) Explain why a digital signature on its own does not prove that the public key used really belongs to the lawyer, and state what solves this problem. [2]
Show answer
  1. (a) The digest is short and of fixed length, so encrypting it with the private key is much quicker than encrypting a large document; it still identifies the document uniquely because any change to the document gives a different digest.
    1 mark: digest is small/fixed length – faster to encrypt and send. 1 mark: digest still detects any change to the document.
  2. (b) The receiver hashes the received (altered) file and gets a new digest; this does not match the digest recovered by decrypting the signature with the lawyer's public key, so the file is shown to have been altered.
    1 mark: new hash computed from received file differs. 1 mark: compared with digest from decrypted signature – mismatch shows tampering.
  3. (c) Anyone could create a key pair and claim the public key is the lawyer's; a digital certificate issued and signed by a trusted Certificate Authority links the public key to the lawyer's identity.
    1 mark: public key could belong to an impostor. 1 mark: digital certificate from a CA.
Q17Security threats & protection · Challenge · Paper 3 style · 5 marks
  1. (a) A research group of 12 scientists in different countries each wants to exchange private messages with every other member. Calculate how many different secret keys are needed if symmetric encryption is used with a separate key for each pair of members. [2]
  2. (b) Calculate how many keys in total are needed if asymmetric encryption is used instead. [1]
  3. (c) Apart from the number of keys, explain one other problem with symmetric encryption that asymmetric encryption solves. [2]
Show answer
  1. (a) 66 keys
    M1 number of pairs = n(n − 1) ÷ 2. A1 12 × 11 ÷ 2 = 66.
  2. (b) 24 keys (one public and one private key for each of the 12 members)
    B1 12 × 2 = 24.
  3. (c) The key distribution problem: the shared secret key must first be sent to the other person, and if it is intercepted in transit the messages can be read. With asymmetric encryption the public key can be sent openly and the private key never leaves its owner.
    1 mark: secret key has to be shared/transmitted and could be intercepted. 1 mark: asymmetric public key can be shared openly; private key never sent.
Q18Validation & verification · Core · Paper 1 style · 6 marks
  1. (a) Explain the difference between validation and verification. [2]
  2. (b) Describe two methods of verification that could be used when a clerk types customers' names into a utility company's system. [4]
Show answer
  1. (a) Validation is an automatic check by the computer that data is reasonable/sensible and follows set rules (it cannot tell if the data is actually correct). Verification checks that data has been copied or entered accurately, i.e. it matches the original.

  2. (b) Double entry: the name is typed twice (possibly by two people) and the computer compares the two versions; if they differ the clerk is asked to re-enter. Visual check (proof-reading): the clerk compares the data on screen with the original paper form before confirming.
    For each method: 1 mark for the name, 1 mark for a description.

Q21Validation & verification · Standard · Paper 1 style · 5 marks

Q23Validation & verification · Standard · Paper 1 style · 5 marks
  1. (a) A block of five bytes is sent with a checksum. The checksum is calculated by adding the denary values of the bytes and taking the remainder when the total is divided by 256. The bytes have the denary values 58, 127, 196, 21 and 155. Calculate the checksum. [2]
  2. (b) Describe how the receiving computer uses the checksum. [3]
Show answer
  1. (a) 45
    M1 58 + 127 + 196 + 21 + 155 = 557. A1 557 MOD 256 = 45.
  2. (b) The receiver recalculates the checksum from the bytes it has received using the same algorithm. It compares its value with the checksum sent with the block. If they are the same the data is accepted; if they differ an error has occurred and the block is requested again.
    1 mark each: recalculates using same algorithm; compares with transmitted checksum; mismatch → error, request re-transmission.
Q24Validation & verification · Standard · Paper 1 style · 5 marks
  1. (a) A clinic in Hyderabad uses double entry to verify patients' phone numbers. Describe how double entry works and explain one limitation of it. [3]
  2. (b) The clinic also applies a length check that only accepts phone numbers of exactly 11 digits. Explain why using both validation and verification is better than using only one of them. [2]
Show answer
  1. (a) The number is entered twice (by the same or a different person) and the computer compares the two entries; if they do not match, the user is asked to re-enter. Limitation: if the same mistake is made both times (e.g. reading the number wrongly from a badly written form), the wrong number is accepted.

    1 mark: validation catches unreasonable data but not wrong-but-sensible data. 1 mark: verification catches transcription errors that validation would miss.
Q25Validation & verification · Challenge · Paper 1 style · 6 marks
  1. (a) Four bytes and a parity byte are sent using even parity (parity bit is the most significant bit of each byte; the parity byte gives even parity for each bit column). The block received is:Byte 1: 01011010Byte 2: 00110011Byte 3: 01100001Byte 4: 10001110Parity byte: 10000010Identify the byte and the bit position (1 = leftmost, 8 = rightmost) that contains the error. Explain how you found it. [3]
  2. (b) Write the corrected value of the byte containing the error. [1]
  3. (c) Explain the advantage of a parity block over a parity check on each byte alone. [2]
Show answer
  1. (a) Byte 3, bit position 6.
    M1 byte 3 has three 1s – odd, so the error is in byte 3 (all other bytes have an even number of 1s). M1 column 6 (bytes 1–4 plus parity byte) has an odd number of 1s – all other columns even. A1 byte 3, bit 6.
  2. (b) 01100101
    B1 bit 6 of byte 3 changed from 0 to 1.
  3. (c) A parity check on bytes only shows which byte is wrong; the parity block (column check) also identifies which bit, so a single-bit error can be located and corrected automatically without re-transmission.
    1 mark: identifies exact bit position (row and column). 1 mark: error can be corrected without resending.

Q27Validation & verification · Challenge · Paper 2 style · 8 marks
  1. (a) Six-digit library card numbers at a university in Quetta are given a modulo-11 check digit using weights 7, 6, 5, 4, 3, 2 (left to right). Check digit = (11 − (weighted sum MOD 11)), with 11 written as 0 and 10 written as 'X'.Calculate the check digit for the card number 481305. [2]
  2. (b) Write a pseudocode function CheckDigit(CardNo : STRING) RETURNS STRING that takes a six-digit card number as a string and returns its check digit as a one-character string ('0'–'9' or 'X'). You may use MID(), STR_TO_NUM() and NUM_TO_STR(). [6]
Show answer
  1. (a) 7
    M1 4×7 + 8×6 + 1×5 + 3×4 + 0×3 + 5×2 = 28 + 48 + 5 + 12 + 0 + 10 = 103; 103 MOD 11 = 4. A1 11 − 4 = 7.
  2. (b) FUNCTION CheckDigit(CardNo : STRING) RETURNS STRING DECLARE Index, Total, Digit, Result : INTEGER Total ← 0 FOR Index ← 1 TO 6 Digit ← STR_TO_NUM(MID(CardNo, Index, 1)) Total ← Total + Digit * (8 - Index) NEXT Index Result ← 11 - (Total MOD 11) IF Result = 11 THEN Result ← 0 ENDIF IF Result = 10 THEN RETURN "X" ELSE RETURN NUM_TO_STR(Result) ENDIFENDFUNCTION

Q28Privacy & integrity · Core · Paper 1 style · 5 marks
  1. (a) Explain the difference between data privacy and data integrity. [2]
  2. (b) Many countries have data protection laws. State three requirements that such laws usually place on organisations that hold personal data. [3]
Show answer
  1. (a) Data privacy means keeping personal data confidential so only authorised people can see it and it is used only for the agreed purpose. Data integrity means the data is accurate, complete and consistent, and has not been changed in an unauthorised or accidental way.
    1 mark: privacy – restricting who can access/see personal data. 1 mark: integrity – accuracy/consistency of the data.
  2. (b) Any three of: data must be collected and processed fairly and lawfully; used only for the stated purpose; adequate, relevant and not excessive; kept accurate and up to date; not kept longer than necessary; kept secure; not transferred abroad without adequate protection; individuals can see/correct their data.
    1 mark each for any three.
