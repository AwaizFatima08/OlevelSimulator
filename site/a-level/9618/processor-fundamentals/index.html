Q2Assembly language & addressing · Core · Paper 1 style · 6 marks
  1. (a) Describe immediate addressing and direct addressing. Give an example instruction for each. [4]
  2. (b) Describe relative addressing and give one advantage of using it. [2]
Show answer
  1. (a) Immediate: the operand is the actual value to be used, e.g. LDM #25. Direct: the operand is the address that holds the value to be used, e.g. LDD 25.
    1 mark each: immediate – operand is the data/value itself; example e.g. LDM #25; direct – operand is the address of the data; example e.g. LDD 25 / ADD 40.
  2. (b) The address used is found by adding the operand (an offset) to a base address, usually the address of the current instruction in the program counter. Advantage: the program can be loaded anywhere in memory and still work (relocatable code).
    B1: operand is an offset added to the current/base address (e.g. contents of PC). B1: code is relocatable / jumps still work wherever the program is loaded.

Q4Assembly language & addressing · Core · Paper 1 style · 5 marks

A processor uses 16-bit machine code instructions. Each instruction has a 6-bit opcode followed by a 10-bit operand. The operand is an unsigned binary number.

  1. (a) Explain the meaning of the terms opcode and operand. [2]
  2. (b) Calculate the maximum number of different opcodes. [1]
  3. (c) Calculate the highest memory address that can be given in the operand when direct addressing is used. [1]
  4. (d) Give the value in the operand of the instruction LDM #300 as a 10-bit binary number. [1]
Show answer
  1. (a) Opcode: the part of the instruction that says which operation to perform (e.g. load, add). Operand: the part that holds the data, or the address of the data, that the operation uses.
    B1 opcode = operation/instruction code; B1 operand = data value or address used by the operation.
  2. (b) 64
    B1: 2⁶ = 64.
  3. (c) 1023
    B1: 2¹⁰ − 1 = 1023.
  4. (d) 0100101100
    B1: 300 = 256 + 32 + 8 + 4 = 0100101100.

  2. (b) Describe the role of the arithmetic logic unit (ALU) and the control unit (CU). [2]
  3. (c) Explain why the address bus is unidirectional. [1]
Show answer
  1. (a) Address bus: carries memory addresses from the processor to memory/devices; one direction (unidirectional).     B1 each, with direction.

    B1.

Q29Fetch-execute cycle & interrupts · Standard · Paper 1 style · 7 marks
  1. (a) Give two different sources of an interrupt. [2]
  2. (b) Describe how a processor detects and handles an interrupt. [5]
Show answer
  1. (a) e.g. a printer running out of paper (hardware), a timer signal, a division by zero (software error), a key being pressed.
    1 mark each for two different sources.
  2. (b) At the end of each fetch-execute cycle the processor checks for interrupts. Q30Fetch-execute cycle & interrupts · Challenge · Paper 1 style · 7 marks

The program counter (PC) contains 310. Memory address 310 holds the instruction LDD 452 and address 452 holds the value 87.

  1. (a) Give the contents of the PC, MAR, MDR, CIR and ACC after the instruction has been fetched and executed. Give the final values only. [5]
  2. (b) While LDD 452 is being executed, a keyboard interrupt arrives. Explain why the processor does not deal with it immediately. [2]
Show answer
  1. (a) PC 311, MAR 452, MDR 87, CIR LDD 452, ACC 87
    B1 each. During the fetch MAR = 310 and MDR = LDD 452; during execution the operand 452 is copied to MAR and 87 is read into MDR, then copied to ACC.
  2. (b) The processor checks for interrupts only at the end of each fetch-execute cycle, so it completes LDD 452 first; this means the instruction is not left half-finished and the register values can be saved in a consistent state.
