Q1Writing pseudocode algorithms · Core · Paper 2 style · 5 marks

A language-learning app for children in Malaysia counts vowels in words.

  1. (a) Write pseudocode for the function CountVowels(Word : STRING) RETURNS INTEGER. The function returns the number of vowels (a, e, i, o, u) in Word. Vowels may be upper or lower case. [5]
Show answer
  1. (a) FUNCTION CountVowels(Word : STRING) RETURNS INTEGER DECLARE Count, Index : INTEGER DECLARE Ch : CHAR Count ← 0 FOR Index ← 1 TO LENGTH(Word) Ch ← LCASE(MID(Word, Index, 1)) IF Ch = 'a' OR Ch = 'e' OR Ch = 'i' OR Ch = 'o' OR Ch = 'u' THEN Count ← Count + 1 ENDIF NEXT Index RETURN CountENDFUNCTION
    1 mark each: function header and ENDFUNCTION with Count initialised to 0; loop from 1 to LENGTH(Word); extract each character with MID; correct test for all five vowels in both cases (e.g. using LCASE); increment count and RETURN Count (not OUTPUT).

Q6Writing pseudocode algorithms · Standard · Paper 2 style · 7 marks

A water-quality sensor at a treatment plant in Johannesburg logs pH readings to a text file.

  1. (a) Write pseudocode for the function CopyHigh(Limit : REAL) RETURNS INTEGER. The function reads every line of the text file "Readings.txt". Each line holds one reading as a string. Show answer
  1. (a) FUNCTION CopyHigh(Limit : REAL) RETURNS INTEGER DECLARE Line : STRING DECLARE Count : INTEGER Count ← 0 OPENFILE "Readings.txt" FOR READ OPENFILE "High.txt" FOR WRITE WHILE NOT EOF("Readings.txt") READFILE "Readings.txt", Line IF STR_TO_NUM(Line) > Limit THEN WRITEFILE "High.txt", Line Count ← Count + 1 ENDIF ENDWHILE CLOSEFILE "Readings.txt" CLOSEFILE "High.txt" RETURN CountENDFUNCTION
    1 mark each: open Readings.txt FOR READ; open High.txt FOR WRITE; loop WHILE NOT EOF("Readings.txt"); READFILE each line into a variable; convert with STR_TO_NUM and compare with the parameter Limit; WRITEFILE and increment counter (initialised to 0); close both files and RETURN Count. Do not credit INPUT of Limit.

  1. (a) FUNCTION BillAmount(Units : INTEGER) RETURNS INTEGER DECLARE Cost : INTEGER IF Units <= 100 THEN Cost ← Units * 10 ELSE IF Units <= 300 THEN Cost ← 1000 + (Units - 100) * 15 ELSE Cost ← 1000 + 3000 + (Units - 300) * 22 ENDIF ENDIF RETURN CostENDFUNCTION

    1 mark each (350: 100×10 + 200×15 + 50×22 = 1000 + 3000 + 1100).

Q11Writing pseudocode algorithms · Challenge · Paper 2 style · 8 marks

A security club at a school in Rawalpindi is learning about simple ciphers.

  1. (a) Write pseudocode for the function Encrypt(Message : STRING, Shift : INTEGER) RETURNS STRING. Each upper-case letter is replaced by the letter Shift places later in the alphabet, wrapping from Z back to A. Shift is from 1 to 25. All other characters are copied unchanged. [7]
  2. (b) State the value returned by Encrypt("ZEBRA 9", 3). [1]
Show answer
  1. (a) FUNCTION Encrypt(Message : STRING, Shift : INTEGER) RETURNS STRING DECLARE Result : STRING DECLARE Index, Code : INTEGER DECLARE Ch : CHAR Result ← "" FOR Index ← 1 TO LENGTH(Message) Ch ← MID(Message, Index, 1) IF Ch >= 'A' AND Ch <= 'Z' THEN Code ← ASC(Ch) - ASC('A') Code ← MOD(Code + Shift, 26) Ch ← CHR(Code + ASC('A')) ENDIF Result ← Result & Ch NEXT Index RETURN ResultENDFUNCTION
    1 mark each: initialise result to empty string; loop through each character with MID; test for upper-case letter; convert to 0–25 using ASC; add Shift and wrap with MOD 26 (or IF > 'Z' subtract 26); convert back with CHR; concatenate every character (changed or not) and RETURN the result.
  2. (b) "CHEUD 9"
    B1.

A warehouse in Gwadar keeps sorted lists of product codes.

  1. (a) Write pseudocode for the function RemoveDuplicates(Size : INTEGER) RETURNS INTEGER. The first Size elements of the global array Codes[1:500] OF INTEGER are in ascending order and may contain repeated values. The function moves the elements so that each value appears once, at the start of the array, keeping ascending order, and returns the number of distinct values. For example, if Size is 7 and the elements are 3, 3, 5, 8, 8, 8, 9, then afterwards the first four elements are 3, 5, 8, 9 and 4 is returned. [7]
Show answer
  1. (a) FUNCTION RemoveDuplicates(Size : INTEGER) RETURNS INTEGER DECLARE ReadPos, WritePos : INTEGER IF Size = 0 THEN RETURN 0 ENDIF WritePos ← 1 FOR ReadPos ← 2 TO Size IF Codes[ReadPos] <> Codes[WritePos] THEN WritePos ← WritePos + 1 Codes[WritePos] ← Codes[ReadPos] ENDIF NEXT ReadPos RETURN WritePosENDFUNCTION
    1 mark each: header/ENDFUNCTION; handle Size = 0 (or Size < 2); write position starts at 1; loop from 2 to Size; compare current element with the last kept element; increment write position and copy the element; RETURN the number of distinct values.
Q13Writing pseudocode algorithms · Challenge · Paper 2 style · 8 marks

A teacher in Mombasa keeps test scores in a text file.

  1. (a) Write pseudocode for the procedure AboveAverage(). The text file "Scores.txt" has one line per student in the form StudentID,Score, for example "S0412,67". Score is an integer from 0 to 100 and StudentID is always 5 characters. The procedure must calculate the average score, then write the StudentID of every student whose score is above the average to the file "Above.txt", and finally output the average. Assume the file contains at least one line. [8]
Show answer
  1. (a) PROCEDURE AboveAverage() DECLARE Line : STRING DECLARE Total, Count, Score : INTEGER DECLARE Average : REAL Total ← 0 Count ← 0 OPENFILE "Scores.txt" FOR READ WHILE NOT EOF("Scores.txt") READFILE "Scores.txt", Line Score ← STR_TO_NUM(MID(Line, 7, LENGTH(Line) - 6)) Total ← Total + Score Count ← Count + 1 ENDWHILE CLOSEFILE "Scores.txt" Average ← Total / Count OPENFILE "Scores.txt" FOR READ OPENFILE "Above.txt" FOR WRITE WHILE NOT EOF("Scores.txt") READFILE "Scores.txt", Line Score ← STR_TO_NUM(MID(Line, 7, LENGTH(Line) - 6)) IF Score > Average THEN WRITEFILE "Above.txt", LEFT(Line, 5) ENDIF ENDWHILE CLOSEFILE "Scores.txt" CLOSEFILE "Above.txt" OUTPUT "Average score: ", AverageENDPROCEDURE
    Level-style marking, 1 mark each to max 8: open Scores.txt for READ; loop until EOF; READFILE each line; extract the score after the comma (MID/RIGHT and STR_TO_NUM); total and count, then average calculated after the first pass; close and reopen the file (second pass) or store the data in arrays; open Above.txt for WRITE and write LEFT(Line, 5) when Score > Average; close all files and output the average.

Q17Searching & sorting · Standard · Paper 2 style · 9 marks

A quiz website in Turkey ranks the scores of 100 players.

  1. (a) Write pseudocode for the procedure SortScores() which uses an efficient bubble sort to put the global array Scores[1:100] OF INTEGER into descending order (highest first). The sort must stop as soon as a complete pass makes no swaps. [7]
  2. (b) Explain why reducing the upper bound of the inner loop after each pass makes the algorithm more efficient. [2]
Show answer
  1. (a) PROCEDURE SortScores() DECLARE Index, Temp, Last : INTEGER DECLARE Swapped : BOOLEAN Last ← 99 REPEAT Swapped ← FALSE FOR Index ← 1 TO Last IF Scores[Index] < Scores[Index + 1] THEN Temp ← Scores[Index] Scores[Index] ← Scores[Index + 1] Scores[Index + 1] ← Temp Swapped ← TRUE ENDIF NEXT Index Last ← Last - 1 UNTIL Swapped = FALSE OR Last = 0ENDPROCEDURE
    1 mark each: outer conditional loop; flag reset to FALSE at the start of each pass; inner loop 1 to 99 (or reducing upper bound); compare adjacent elements with < for descending order; swap using a temporary variable; set flag TRUE when a swap happens; outer loop ends when no swaps (reducing the bound is credit-worthy but not required).
  2. (b) After each pass the smallest remaining value has moved to its final position at the end, so it does not need to be compared again; fewer comparisons are made.
    1 mark last element is in its correct place after each pass; 1 mark so fewer comparisons/iterations are needed.
