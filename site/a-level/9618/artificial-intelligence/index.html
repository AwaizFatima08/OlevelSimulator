Q9Graphs, Dijkstra & A* · Standard · Paper 3 style · 6 marks
  1. (a) Describe two differences between Dijkstra's algorithm and the A* algorithm. [4]
  2. (b) Suggest a suitable heuristic for A* in a road-navigation app and explain why it is suitable. [2]
Show answer
  1. (a) Dijkstra chooses the next node using only the distance from the start (g); A* uses f = g + h, adding a heuristic estimate of the distance to the goal. Dijkstra explores in all directions and can find shortest paths from the start to every node; A* is directed towards one goal and usually expands fewer nodes, so it is faster for a single destination. A* needs a heuristic (e.g. straight-line distance) to be available; Dijkstra does not.
    2 marks per difference (both sides stated), any two.
  2. (b) Straight-line (as-the-crow-flies) distance from the node to the destination, calculated from GPS coordinates; a road can never be shorter than the straight line, so it never overestimates (admissible).
    1 mark straight-line/Euclidean distance; 1 mark never overestimates / easy to calculate.

Q22Machine learning & neural networks · Standard · Paper 3 style · 5 marks

A single artificial neuron in a fire-alarm system has three inputs x₁, x₂, x₃ (each 0 or 1) with weights 0.6, −0.4 and 0.3, and a bias of −0.5. It outputs 1 if the weighted sum (including the bias) is ≥ 0, and 0 otherwise.

  1. (a) Calculate the weighted sum and the output of the neuron for the inputs x₁ = 1, x₂ = 0, x₃ = 1. [2]
  2. (b) Calculate the weighted sum and the output for x₁ = 0, x₂ = 1, x₃ = 1. [2]

Q23Machine learning & neural networks · Standard · Paper 3 style · 4 marks
  1. (a) Describe how back propagation of errors is used to train an artificial neural network. [4]
Show answer
  1. (a) Training data is passed forward through the network to give an output. The output is compared with the expected (labelled) output to find the error. The error is passed backwards through the network, layer by layer, to work out how much each weight contributed to it. Each weight is adjusted (e.g. by gradient descent) to reduce the error, and the process is repeated over many examples/epochs until the error is acceptably small.
    1 mark each to max 4: forward pass; compare with expected output to calculate error; error sent backwards from output layer through hidden layers; weights adjusted in proportion to their contribution; repeated many times until error minimised.

Q27Machine learning & neural networks · Challenge · Paper 3 style · 6 marks

Show answer
  1. (a) Collect a large set of leaf photos labelled by experts with the disease (or healthy). Split into training and test sets. Q29Machine learning & neural networks · Challenge · Paper 3 style · 6 marks

A perceptron has two inputs with weights w₁ = 0.2 and w₂ = −0.5, and a bias of 0.1 (treated as a weight on a constant input of 1). It outputs 1 if the weighted sum ≥ 0, otherwise 0. The training rule is: new weight = old weight + η × (target − output) × input, with learning rate η = 0.1. A training example has inputs (1, 1) and target output 1.

  1. (a) Calculate the output of the perceptron before training for the input (1, 1). [2]
  2. (b) Use the training rule to calculate the new values of w₁, w₂ and the bias. [3]
  3. (c) Show that the perceptron now gives the target output for this input. [1]
Show answer
  1. (a) Output 0
    M1: 0.2 × 1 + (−0.5) × 1 + 0.1 = −0.2; A1: < 0 so output 0.
  2. (b) w₁ = 0.3, w₂ = −0.4, bias = 0.2
    Error = 1 − 0 = 1. M1: change = 0.1 × 1 × input. A1: w₁ = 0.2 + 0.1 = 0.3, w₂ = −0.5 + 0.1 = −0.4; A1: bias = 0.1 + 0.1 = 0.2.
  3. (c) 0.3 − 0.4 + 0.2 = 0.1 ≥ 0, so output 1 = target.
    B1.

  2. (b) Explain the difference between exploration and exploitation in reinforcement learning, and why the agent needs both. [3]
Show answer
