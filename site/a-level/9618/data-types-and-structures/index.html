Q11Stacks, queues & linked lists · Core · Paper 2 style · 4 marks
  1. (a) Describe the difference between a stack and a queue. [2]
  2. (b) Give one use of a stack and one use of a queue in a computer system. [2]
Show answer
  1. (a) A stack is LIFO — the last item added is the first removed, and items are added/removed at the same end (top). A queue is FIFO — items are added at the rear and removed from the front.
    1 mark each.
  2. (b) Stack: e.g. storing return addresses for procedure calls / undo feature / evaluating expressions. Queue: e.g. print jobs waiting / keyboard buffer / processes waiting for the CPU.
    1 mark each.
