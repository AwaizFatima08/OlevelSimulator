Q12Iteration · Challenge · Paper 3 style · 9 marks

The positive constant a is such that ∫₁ᵃ ln x dx = 2.

  1. (a) Show that a = e^(1 + 1/a). [4]
  2. (b) Show by calculation that a lies between 3 and 4. [2]
  3. (c) Use an iterative formula based on the equation in part (a), with a₁ = 3.5, to find a correct to 3 decimal places. Give the result of each iteration to 4 decimal places. [3]
Show answer
  1. (a) a ln a − a + 1 = 2, so ln a = 1 + 1/a
    By parts: ∫ ln x dx = x ln x − x (M1 A1). [x ln x − x] from 1 to a = a ln a − a + 1 = 2 (M1). ln a = (a + 1)/a = 1 + 1/a, so a = e^(1 + 1/a) (A1).
  2. (b) g(a) = a − e^(1+1/a): g(3) < 0, g(4) > 0
    g(3) = −0.794, g(4) = 0.51 (M1). Sign change (A1).
  3. (c) a = 3.591
    aₙ₊₁ = e^(1 + 1/aₙ). Iterates (a in place of x): x1 = 3.5, x2 = 3.6173, x3 = 3.5839, x4 = 3.5931, x5 = 3.5906, x6 = 3.5913 (M1 A1). a = 3.591 (A1).
Q13Iteration · Challenge · Paper 3 style · 6 marks

The curve y = x² cos x has a stationary point at x = α, where 0 < α < ½π.

  1. (a) Show that α satisfies the equation α = tan⁻¹(2/α). [3]
  2. (b) Use the iterative formula xₙ₊₁ = tan⁻¹(2/xₙ), with x₁ = 1, to find α correct to 3 decimal places. Give the result of each iteration to 4 decimal places. [3]
Show answer

  2. (b) α = 1.077
    Iterates: x1 = 1, x2 = 1.1071, x3 = 1.0652, x4 = 1.0814, x5 = 1.0751, x6 = 1.0776, x7 = 1.0766, x8 = 1.0770 (M1 A1). α = 1.077 (A1).
Q14Iteration · Challenge · Paper 2 style · 7 marks

The equation x³ − 6x + 2 = 0 has a root α between 2 and 2.5. Two rearrangements are suggested:A: xₙ₊₁ = (xₙ³ + 2)/6B: xₙ₊₁ = ∛(6xₙ − 2)

  1. (a) Starting with x₁ = 2.3, find x₂, x₃, x₄ and x₅ using formula A, giving answers to 4 decimal places, and describe what happens. [2]
  2. (b) Use formula B with x₁ = 2.3 to find α correct to 2 decimal places, giving each iteration to 4 decimal places. [3]
  3. (c) By considering the gradient of each iteration function near x = 2.26, explain why B converges but A does not. [2]
Show answer
  1. (a) 2.3000, 2.3612, 2.5273, 3.0237, 4.9409; the values move away from α (diverge)
    Values 2.3000, 2.3612, 2.5273, 3.0237, 4.9409 (M1). They increase rapidly away from the root, so A does not converge to α (A1).
  2. (b) α = 2.26
    Iterates: x1 = 2.3, x2 = 2.2766, x3 = 2.2676, x4 = 2.2641, x5 = 2.2627 (M1 A1). α = 2.26 (A1).
  3. (c) |g′| > 1 for A, |g′| < 1 for B
    A: g′(x) = x²/2 ≈ 2.56 > 1 (B1). B: g′(x) = 2/(6x − 2)^(2/3) ≈ 0.39 < 1, so B converges (B1).

Q16Iteration · Challenge · Paper 2 style · 7 marks

The sequence defined by xₙ₊₁ = (2xₙ³ + 5)/(3xₙ² + 1), with x₁ = 1.5, converges to α.

  1. (a) Show that α is a root of the equation x³ + x − 5 = 0. [2]
  2. (b) Show that x³ + x − 5 = 0 has only one real root. [2]
  3. (c) Use the iteration to find α correct to 4 decimal places, giving each iteration to 5 decimal places. [3]
Show answer
  1. (a) α(3α² + 1) = 2α³ + 5 gives α³ + α − 5 = 0
    α = (2α³ + 5)/(3α² + 1) (M1). 3α³ + α = 2α³ + 5, so α³ + α − 5 = 0 (A1).
  2. (b) Derivative 3x² + 1 > 0, so the function is increasing
    d/dx(x³ + x − 5) = 3x² + 1 > 0 for all x (M1), so the curve crosses the x-axis once only (A1).
  3. (c) α = 1.5160
    Iterates: x1 = 1.5, x2 = 1.51613, x3 = 1.51598, x4 = 1.51598 (M1 A1). α = 1.5160 (A1).

Q19Locating a root (graphs/sign change) · Core · Paper 2 style · 4 marks
  1. (a) By sketching the graphs of y = ln x and y = 3 − x on the same axes, state the number of roots of the equation ln x = 3 − x. [2]
  2. (b) Show by calculation that this root lies between 2 and 3. [2]
Show answer
  1. (a) One root
    ln x is increasing for x > 0, 3 − x is decreasing (B1); the graphs cross once (B1).
  2. (b) f(x) = ln x + x − 3: f(2) = −0.307, f(3) = 1.1
    f(2) = −0.307 < 0, f(3) = 1.1 > 0 (M1). Sign change (A1).

  1. (a) By sketching the graphs of y = cos x and y = x², where x is in radians, state the number of real roots of the equation cos x = x². [2]
  2. (b) Show by calculation that the positive root lies between 0.8 and 0.9. [2]
Show answer
  1. (a) Two roots (one positive, one negative)
    Both graphs are symmetrical about the y-axis (B1); they cross once for x > 0 and once for x < 0 (B1).
  2. (b) f(x) = cos x − x²: f(0.8) = 0.0567, f(0.9) = −0.188
    f(0.8) = 0.0567 > 0, f(0.9) = −0.188 < 0 (M1). Sign change (A1).

  2. (b) Show that the root lies between 0.8 and 0.9. [2]
Show answer
  1. (a) For x < 0, 2/x < 0 < eˣ, no root; for x > 0, eˣ increases and 2/x decreases, so exactly one crossing
    Sketch shape of both graphs (B1). No intersection for x < 0 since eˣ > 0 > 2/x (B1). One intersection for x > 0 (B1).
  2. (b) f(x) = x eˣ − 2: f(0.8) = −0.22, f(0.9) = 0.214
    f(0.8) = −0.22 < 0, f(0.9) = 0.214 > 0 (M1). Sign change (A1).
Q22Locating a root (graphs/sign change) · Standard · Paper 3 style · 5 marks
  1. (a) By sketching the graphs of y = ln(x + 1) and y = 4 − x² for x > −1, show that the equation ln(x + 1) = 4 − x² has exactly one root. [3]
  2. (b) Show by calculation that the root lies between 1.7 and 1.8. [2]
Show answer
  1. (a) ln(x + 1) is increasing from −∞; 4 − x² is a ∩ parabola; they cross once, for some x > 0
    Correct shape of y = ln(x + 1) with asymptote x = −1 (B1). Correct parabola (B1). Near x = −1 the log graph is below the parabola, and they cross once for x > 0 (B1).
  2. (b) f(x) = ln(x + 1) + x² − 4: f(1.7) = −0.117, f(1.8) = 0.27
    f(1.7) = −0.117 < 0, f(1.8) = 0.27 > 0 (M1). Sign change (A1).
Q23Locating a root (graphs/sign change) · Standard · Paper 3 style · 5 marks

The curve y = x sin x, for 0 < x < π, has a maximum point at x = α.

  1. (a) Show that α satisfies the equation tan α = −α. [3]
  2. (b) Show by calculation that α lies between 2 and 2.1. [2]
Show answer
  1. (a) dy/dx = sin x + x cos x = 0 gives tan x = −x
    dy/dx = sin x + x cos x (M1 A1). = 0, divide by cos x: tan x = −x (A1).
  2. (b) sin x + x cos x: at 2 it is 0.077, at 2.1 it is −0.197
    g(x) = sin x + x cos x: g(2) = 0.077 > 0, g(2.1) = −0.197 < 0 (M1). Sign change, so dy/dx = 0 between 2 and 2.1 (A1).
Q24Locating a root (graphs/sign change) · Standard · Paper 2 style · 4 marks
  1. (a) Show that the equation x³ + 2x − 7 = 0 has exactly one real root. [2]
  2. (b) Show that the root lies between 1.5 and 1.6. [2]
Show answer
  1. (a) f′(x) = 3x² + 2 > 0, so f is increasing
    f′(x) = 3x² + 2 (M1), always positive, so f is increasing and crosses the axis once (A1).
  2. (b) f(1.5) = −0.625, f(1.6) = 0.296
    f(1.5) = 3.375 + 3 − 7 = −0.625, f(1.6) = 4.096 + 3.2 − 7 = 0.296 (M1). Sign change (A1).

f(x) = 2x³ − 3x² − 1.

  1. (a) Show that the equation f(x) = 0 has a root α between 1.6 and 1.7. [2]
  2. (b) By calculating f(1.65), state whether α is closer to 1.6 or to 1.7. [2]
Show answer
  1. (a) f(1.6) = −0.488, f(1.7) = 0.156
    f(1.6) = −0.488 < 0, f(1.7) = 0.156 > 0 (M1). Sign change (A1).
  2. (b) f(1.65) = −0.183 < 0, so α lies between 1.65 and 1.7: closer to 1.7

Q26Locating a root (graphs/sign change) · Challenge · Paper 2 style · 5 marks
  1. (a) By considering the graphs of y = sec x and y = 3 − x² for 0 ≤ x < ½π, show that the equation sec x = 3 − x² has exactly one root in this interval. [3]
  2. (b) Show that this root lies between 1 and 1.1. [2]
Show answer
  1. (a) At x = 0, sec x = 1 < 3; sec x increases (to ∞) while 3 − x² decreases, so one crossing
    sec 0 = 1 below 3 − 0 = 3 (B1). sec x is increasing and tends to infinity as x → ½π (B1); 3 − x² decreases, so they cross exactly once (B1).
  2. (b) f(x) = sec x − 3 + x²: f(1) = −0.149, f(1.1) = 0.415
    f(1) = −0.149 < 0, f(1.1) = 0.415 > 0 (M1). Sign change (A1).
Q27Locating a root (graphs/sign change) · Challenge · Paper 3 style · 5 marks

The curves y = 4 − x² and y = e^(−x) meet at two points, with x-coordinates α and β, where α < 0 < β.

  1. (a) Show that β lies between 1.9 and 2. [2]
  2. (b) Find an interval of width 0.1, with ends that are multiples of 0.1, which contains α. Justify your answer. [3]
Show answer
  1. (a) f(x) = 4 − x² − e^(−x): f(1.9) = 0.24, f(2) = −0.135
    f(1.9) = 0.24 > 0, f(2) = −0.135 < 0 (M1). Sign change (A1).
  2. (b) −1.1 < α < −1.0, since f(−1.1) = −0.214 < 0 and f(−1) = 0.282 > 0
    Trial values, e.g. f(−1.2) = −0.76, f(−1.1) = −0.214 (M1), f(−1) = 0.282 (M1). Sign change between −1.1 and −1.0 (A1).
Q28Locating a root (graphs/sign change) · Challenge · Paper 3 style · 5 marks

f(x) = tan x − 2, where x is in radians.

  1. (a) A student finds that f(1.5) > 0 and f(1.6) < 0 and says that the equation f(x) = 0 has a root between 1.5 and 1.6. Explain why the student is wrong. [2]
  2. (b) Show by calculation that the equation has a root between 1 and 1.2, and state its exact value. [3]
Show answer
  1. (a) tan x has a vertical asymptote at x = ½π ≈ 1.571 in this interval, so f is not continuous there
    ½π ≈ 1.571 lies in (1.5, 1.6) (B1); f is discontinuous there, so the sign change comes from the asymptote, not a root (B1).
  2. (b) f(1) = −0.443, f(1.2) = 0.572; root x = tan⁻¹ 2
    f(1) = −0.443 < 0, f(1.2) = 0.572 > 0 (M1 A1). Exact root tan⁻¹ 2 ≈ 1.107 (B1).
Q29Locating a root (graphs/sign change) · Challenge · Paper 2 style · 6 marks
  1. (a) By sketching the graphs of y = ln x and y = x − 2, show that the equation ln x = x − 2 has two roots. [2]
  2. (b) Show that one root lies between 0.1 and 0.2 and the other between 3 and 4. [4]
Show answer
  1. (a) The line y = x − 2 cuts the curve y = ln x twice: once for 0 < x < 1 and once for x > 1
    Correct sketches (B1). For small x, ln x is below x − 2; at x = 1, ln x = 0 > −1; for large x the line is above again, so two intersections (B1).
  2. (b) f(x) = ln x − x + 2: f(0.1) = −0.403, f(0.2) = 0.191, f(3) = 0.0986, f(4) = −0.614
    f(0.1) = −0.403 < 0, f(0.2) = 0.191 > 0 (M1 A1). f(3) = 0.0986 > 0, f(4) = −0.614 < 0 (M1 A1).
Q30Setting up the equation · Challenge · Paper 3 style · 7 marks

A circle has centre O and radius r cm. Points A and B lie on the circle, and angle AOB = x radians, where 0 < x < π. The area of triangle AOB is two thirds of the area of the sector OAB.

  1. (a) Show that x satisfies the equation x = 1.5 sin x. [2]
  2. (b) Show by calculation that the root lies between 1.4 and 1.6. [2]
  3. (c) Use the iterative formula xₙ₊₁ = 1.5 sin xₙ, with x₁ = 1.5, to find x correct to 3 decimal places. Give each iteration to 4 decimal places. [3]
Show answer
  1. (a) ½r² sin x = (2/3)(½r²x) gives x = 1.5 sin x
    Triangle ½r² sin x, sector ½r²x (B1). ½r² sin x = ⅔ × ½r²x, so sin x = ⅔x, x = 1.5 sin x (B1).
  2. (b) g(x) = 1.5 sin x − x: g(1.4) = 0.0782, g(1.6) = −0.101
    g(1.4) = 0.0782 > 0, g(1.6) = −0.101 < 0 (M1). Sign change (A1).
  3. (c) x = 1.496
    Iterates: x1 = 1.5, x2 = 1.4962, x3 = 1.4958, x4 = 1.4958 (M1 A1). x = 1.496 (A1).
