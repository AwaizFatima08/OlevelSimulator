  2. (b) 2.57
    B1 2e^0.25 = 2.568…
Q2Separable differential equation · Core · Paper 3 style · 6 marks
  1. (a) Given that dy/dx = e^(2x − y) and y = 0 when x = 0, show that y = ln(½(e^(2x) + 1)). [5]
  2. (b) Find the value of y when x = 1, giving your answer correct to 3 significant figures. [1]
Show answer
  1. (a) eʸ = ½e^(2x) + ½, so y = ln(½(e^(2x) + 1))
    M1 write as eʸ dy/dx = e^(2x) and separate. A1 eʸ = ½e^(2x) + c. M1 use initial condition. A1 c = ½. A1 given answer correctly obtained.
  2. (b) 1.43
    B1 ln((e² + 1)/2) = 1.43.
Q3Separable differential equation · Core · Paper 3 style · 6 marks
  1. (a) The variables x and y are related by 2y dy/dx = 3x² + 2, where y > 0, and y = 4 when x = 0. Find y² in terms of x. [3]
  2. (b) Find the exact value of y when x = 2. [1]
  3. (c) Find the value of x for which y = 2√3, giving your answer correct to 3 significant figures. [2]
Show answer
  1. (a) y² = x³ + 2x + 16
    M1 ∫2y dy = ∫(3x² + 2) dx. A1 y² = x³ + 2x + c. A1 c = 16.
  2. (b) 2√7
    B1 y² = 8 + 4 + 16 = 28, y = 2√7 (≈ 5.29).
  3. (c) −1.18
    M1 x³ + 2x + 16 = 12, i.e. x³ + 2x + 4 = 0, solved numerically. A1 x = −1.18.
Q4Separable differential equation · Core · Paper 3 style · 6 marks
  1. (a) In a chemical reaction in a laboratory in Karachi, the mass x grams of product formed after t seconds satisfies dx/dt = 0.02(50 − x), and x = 0 when t = 0. Solve the differential equation to show that x = 50(1 − e^(−0.02t)). [4]
  2. (b) Find the time taken for 40 grams of product to form, correct to 3 significant figures. [2]
Show answer
  1. (a) −ln(50 − x) = 0.02t + c with c = −ln 50, giving x = 50(1 − e^(−0.02t))
    M1 ∫1/(50 − x) dx = ∫0.02 dt. A1 −ln(50 − x) = 0.02t + c. M1 c = −ln 50. A1 given answer.
  2. (b) 80.5 s
    M1 e^(−0.02t) = 0.2. A1 t = 50 ln 5 = 80.5 s.

Show answer

    M1 ∫v⁻² dv = −∫0.02 dt. A1 −1/v = −0.02t + c. M1 c = −0.1. A1 given answer.
  2. (b) 2.5 m s⁻¹; 7.5 s
    B1 50/20 = 2.5. B1 t + 5 = 12.5, t = 7.5.
Q7Separable differential equation · Core · Paper 3 style · 7 marks
  1. (a) The variables x and y satisfy dy/dx = e^(x + y), and y = 0 when x = 0. Find y in terms of x. [5]
  2. (b) Find y when x = 0.5, correct to 3 significant figures, and state the exact value that x approaches as y tends to infinity. [2]
Show answer
  1. (a) y = −ln(2 − eˣ)
    M1 ∫e^(−y) dy = ∫eˣ dx. A1 −e^(−y) = eˣ + c. M1 c = −2. A1 e^(−y) = 2 − eˣ. A1 y = −ln(2 − eˣ).
  2. (b) y = 1.05; x approaches ln 2
    B1 −ln(2 − e^0.5) = 1.05. B1 y → ∞ as 2 − eˣ → 0, i.e. x → ln 2 (≈ 0.693).

Q9Separable differential equation · Standard · Paper 3 style · 8 marks
  1. (a) A cup of chai at 90 °C is left in a room at 25 °C. Its temperature θ °C after t minutes satisfies dθ/dt = −k(θ − 25), where k is a positive constant. Solve the differential equation to find θ in terms of k and t. [4]
  2. (b) After 5 minutes the temperature is 60 °C. Find the value of k correct to 3 significant figures. [2]
  3. (c) Find the temperature of the chai after 12 minutes, correct to the nearest degree. [2]
Show answer
  1. (a) θ = 25 + 65e^(−kt)
    M1 ∫1/(θ − 25) dθ = −∫k dt. A1 ln(θ − 25) = −kt + c. M1 t = 0, θ = 90: c = ln 65. A1 θ = 25 + 65e^(−kt).
  2. (b) 0.124
    M1 35 = 65e^(−5k). A1 k = (1/5) ln(13/7) = 0.124.
  3. (c) 40 °C
    M1 25 + 65e^(−12k). A1 39.7 → 40 °C.
Q10Separable differential equation · Standard · Paper 3 style · 7 marks
  1. (a) The variables x and y satisfy dy/dx = y² sin x, and y = 0.5 when x = 0. Solve the differential equation, giving y in terms of x. [5]
  2. (b) Find the exact value of y when x = π/3. [1]
  3. (c) State what happens to y as x approaches π. [1]
Show answer
  1. (a) y = 1/(1 + cos x)
    M1 ∫y⁻² dy = ∫sin x dx. A1 −1/y = −cos x + c. M1 x = 0, y = 0.5: −2 = −1 + c. A1 c = −1. A1 y = 1/(1 + cos x).
  2. (b) 2/3
    B1 1/(1 + ½) = 2/3.
  3. (c) y increases without limit (y → ∞)
    B1 1 + cos x → 0, so y → ∞.

Q13Separable differential equation · Standard · Paper 3 style · 7 marks

Q18Separable differential equation · Standard · Paper 3 style · 8 marks
  1. (a) The population P of goats on a farm in Balochistan at time t years is modelled by dP/dt = 0.1P − 20, and P = 300 when t = 0. Show that P = 200 + 100e^(0.1t). [5]

  2. (b) 13.9 years
    M1 100e^(0.1t) = 400. A1 t = 10 ln 4 = 13.9.

    B1 dP/dt = 0 so P remains 200.
Q19Separable differential equation · Challenge · Paper 3 style · 10 marks
  1. (a) The number of fish, N, in a pond at time t months is modelled by dN/dt = 0.0005N(800 − N). When t = 0, N = 100. Using partial fractions, solve the differential equation to show that N = 800/(1 + 7e^(−0.4t)). [6]
  2. (b) Find the number of fish after 5 months. [1]
  3. (c) Find the time taken for the number of fish to reach 600, giving your answer correct to 3 significant figures, and state what happens to N in the long term. [3]
Show answer
  1. (a) ln(N/(800 − N)) = 0.4t − ln 7, giving N = 800/(1 + 7e^(−0.4t))
    M1 separate. M1 1/(N(800 − N)) = (1/800)(1/N + 1/(800 − N)). A1 (1/800)(ln N − ln(800 − N)) = 0.0005t + c. M1 use t = 0, N = 100. A1 ln(N/(800 − N)) = 0.4t + ln(1/7). A1 rearranged to the given form.
  2. (b) 411
    B1 800/(1 + 7e^(−2)) = 410.8 → 411.
  3. (c) 7.61 months; N approaches 800
    M1 1 + 7e^(−0.4t) = 4/3. A1 t = (ln 21)/0.4 = 7.61. B1 N → 800.
Q20Separable differential equation · Challenge · Paper 3 style · 9 marks
  1. (a) The variables x and y satisfy x dy/dx = y² − 1, for x > 0, y > 1, and y = 3 when x = 1. Show that y = (2 + x²)/(2 − x²). [7]
  2. (b) Find the value of y when x = 1.2, correct to 3 significant figures, and explain why the solution is valid only for x < √2. [2]
Show answer
  1. (a) ½ ln((y − 1)/(y + 1)) = ln x + ½ ln ½, so (y − 1)/(y + 1) = ½x², giving y = (2 + x²)/(2 − x²)
    M1 separate: ∫1/(y² − 1) dy = ∫1/x dx. M1 partial fractions ½(1/(y − 1) − 1/(y + 1)). A1 ½ ln(y − 1) − ½ ln(y + 1). A1 = ln x + c. M1 c = ½ ln(1/2). M1 remove logs: (y − 1)/(y + 1) = ½x². A1 rearrange to given answer.
  2. (b) y = 6.14; at x = √2 the denominator is zero (y → ∞)
    B1 3.44/0.56 = 6.14. B1 denominator 2 − x² → 0.

  1. (a) The number of users P of a ride-hailing app in a city increases at a rate proportional to P. At a certain time, when P = 2000, P is increasing at 100 users per day. Write down a differential equation relating P and t (days) and find the constant of proportionality. [2]
  2. (b) Taking t = 0 when P = 2000, solve the differential equation and find P when t = 10, to the nearest whole number. [4]
Show answer
  1. (a) dP/dt = kP with k = 0.05
    B1 dP/dt = kP. B1 k = 100/2000 = 0.05.
  2. (b) P = 2000e^(0.05t); P = 3297
    M1 ∫(1/P) dP = ∫0.05 dt. A1 ln P = 0.05t + c. A1 P = 2000e^(0.05t). A1 3297.
Q28Forming a differential equation · Standard · Paper 3 style · 8 marks
  1. (a) A metal casting at a foundry in Gujranwala cools so that the rate of decrease of its temperature θ °C is proportional to the difference between θ and the surrounding temperature of 30 °C. Initially θ = 200 and the temperature is falling at 8.5 °C per minute. Form a differential equation and find the constant of proportionality. [3]
  2. (b) Solve the differential equation and find the temperature after 20 minutes. [3]
  3. (c) Find the time taken for the temperature to fall to 50 °C. [2]
Show answer
  1. (a) dθ/dt = −k(θ − 30), k = 0.05
    B1 dθ/dt = −k(θ − 30). M1 8.5 = k × 170. A1 k = 0.05.
  2. (b) θ = 30 + 170e^(−0.05t); 92.5 °C
    M1 ln(θ − 30) = −0.05t + c. A1 θ = 30 + 170e^(−0.05t). A1 30 + 170e^(−1) = 92.5.
  3. (c) 42.8 minutes
    M1 e^(−0.05t) = 20/170. A1 t = 20 ln 8.5 = 42.8.
Q29Forming a differential equation · Challenge · Paper 3 style · 8 marks
  1. (a) A container is filled with water. When the depth of water is h cm, the volume is V = 4h³ cm³. Water leaks out through a small hole at a rate of 2√h cm³ per second. Show that dh/dt = −1/(6h^(3/2)). [3]
  2. (b) Initially the depth is 16 cm. Solve the differential equation and find the time taken for the container to empty, giving your answer in minutes correct to 3 significant figures. [5]
Show answer
  1. (a) dV/dt = 12h² dh/dt = −2√h, so dh/dt = −2√h/(12h²) = −1/(6h^(3/2))
    B1 dV/dh = 12h². M1 chain rule dV/dt = (dV/dh)(dh/dt) with dV/dt = −2√h. A1 given answer.
  2. (b) (2/5)h^(5/2) = 409.6 − t/6; empties after 2460 s = 41.0 minutes
    M1 ∫h^(3/2) dh = −∫(1/6) dt. A1 (2/5)h^(5/2) = −t/6 + c. A1 c = (2/5) × 1024 = 409.6. M1 h = 0: t = 6 × 409.6. A1 2457.6 s = 41.0 minutes.
Q30Forming a differential equation · Challenge · Paper 3 style · 7 marks
  1. (a) Gas escapes from a spherical balloon so that the rate of decrease of its volume is proportional to its radius r cm. Show that r dr/dt = −c, where c is a positive constant. [The volume of a sphere is (4/3)πr³.] [3]
  2. (b) Initially r = 10, and after 6 seconds r = 8. Solve the differential equation to show that r² = 100 − 6t. [3]
  3. (c) Find the time at which the balloon has completely deflated, according to this model, correct to 3 significant figures. [1]
Show answer
  1. (a) dV/dt = 4πr² dr/dt = −kr, so r dr/dt = −k/(4π) = −c
    B1 dV/dr = 4πr². M1 4πr² dr/dt = −kr. A1 r dr/dt = −c with c = k/(4π).
  2. (b) ½r² = −ct + 50; 32 = 50 − 6c gives c = 3, so r² = 100 − 6t
    M1 ∫r dr = −∫c dt. A1 ½r² = −ct + 50. A1 c = 3 and given answer.
  3. (c) 16.7 s
    B1 100/6 = 16.7.
