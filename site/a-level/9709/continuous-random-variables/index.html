Q1Median / mean of a pdf · Core · Paper 6 style · 5 marks

The random variable X has probability density function given byf(x) = (3/8)x² for 0 ≤ x ≤ 2,f(x) = 0 otherwise.

  1. (a) Find E(X). [2]
  2. (b) Find Var(X). [3]
Show answer
  1. (a) 3/2
    M1 ∫₀² (3/8)x³ dx; A1 3/2.
  2. (b) 3/20
    M1 E(X²) = ∫₀² (3/8)x⁴ dx = 12/5; M1 12/5 − (3/2)²; A1 3/20.
Q2Median / mean of a pdf · Core · Paper 6 style · 5 marks

The random variable X has probability density function given byf(x) = x/8 for 0 ≤ x ≤ 4,f(x) = 0 otherwise.

  1. (a) Find the median of X, giving your answer in exact form. [3]
  2. (b) Find E(X). [2]
Show answer
  1. (a) 2√2 (≈ 2.83)
    M1 ∫₀^m x/8 dx = ½; A1 m²/16 = ½; A1 m = 2√2.
  2. (b) 8/3
    M1 ∫₀⁴ x²/8 dx; A1 8/3.

Q9Median / mean of a pdf · Standard · Paper 6 style · 6 marks

The time, T minutes, that a customer waits to be served at a bank counter has probability density functionf(t) = (10 − t)/50 for 0 ≤ t ≤ 10,f(t) = 0 otherwise.

  1. (a) Find the mean waiting time. [2]
  2. (b) Find the median waiting time, correct to 3 significant figures. [4]
Show answer
  1. (a) 10/3 minutes
    M1 (1/50)∫₀¹⁰ (10t − t²) dt; A1 (1/50)(500 − 1000/3) = 10/3.
  2. (b) 2.93 minutes
    M1 (1/50)(10m − m²/2) = ½; A1 m² − 20m + 50 = 0; M1 m = 10 ± √50; A1 m = 10 − √50 = 2.93 (other root > 10).
Q10Median / mean of a pdf · Standard · Paper 6 style · 8 marks

The random variable X has probability density function given byf(x) = 4x³ for 0 ≤ x ≤ 1,f(x) = 0 otherwise.

  1. (a) Find E(X) and Var(X). [4]
  2. (b) Hence find E(3X + 2) and Var(3X + 2). [2]
  3. (c) Find the median of X, correct to 3 significant figures. [2]
Show answer
  1. (a) E(X) = 4/5, Var(X) = 2/75
    M1 ∫₀¹ 4x⁴ dx = 4/5; A1; M1 E(X²) = 4/6 and subtract (4/5)²; A1 2/75.
  2. (b) 4.4 and 0.24
    B1 3(4/5) + 2 = 4.4; B1 9 × 2/75 = 0.24.
  3. (c) 0.841
    M1 m⁴ = ½; A1 0.841.
Q11Median / mean of a pdf · Standard · Paper 6 style · 8 marks

The random variable X has probability density function given byf(x) = kx²(1 − x) for 0 ≤ x ≤ 1,f(x) = 0 otherwise.

  1. (a) Show that k = 12. [2]
  2. (b) Find P(X < ½). [2]
  3. (c) Find E(X) and Var(X). [4]
Show answer
  1. (a) Shown
    M1 k(1/3 − 1/4) = 1; A1.
  2. (b) 5/16
    M1 12[x³/3 − x⁴/4]₀^½ = 12(1/24 − 1/64); A1 5/16.
  3. (c) E(X) = 3/5, Var(X) = 1/25
    M1 12∫₀¹ (x³ − x⁴) dx; A1 3/5; M1 E(X²) = 12(1/5 − 1/6) = 2/5; A1 Var = 2/5 − 9/25 = 1/25.
Q12Median / mean of a pdf · Challenge · Paper 6 style · 8 marks

The random variable X has probability density function given byf(x) = kx(4 − x²) for 0 ≤ x ≤ 2,f(x) = 0 otherwise.

  1. (a) Find the value of k. [2]
  2. (b) Show that the median m satisfies m⁴ − 8m² + 8 = 0, and hence find m correct to 3 significant figures. [4]
  3. (c) Find E(X). [2]
Show answer
  1. (a) k = 1/4
    M1 k[2x² − x⁴/4]₀² = 4k = 1; A1.
  2. (b) m = 1.08
    M1 ¼(2m² − m⁴/4) = ½; A1 m⁴ − 8m² + 8 = 0; M1 m² = 4 − 2√2 (reject 4 + 2√2 as m > 2); A1 m = 1.08.
  3. (c) 16/15
    M1 ¼∫₀² (4x² − x⁴) dx; A1 16/15.
Q13Median / mean of a pdf · Challenge · Paper 6 style · 7 marks

The random variable X has probability density function given byf(x) = k(x − 1)(5 − x) for 1 ≤ x ≤ 5,f(x) = 0 otherwise.

  1. (a) Find the value of k. [2]
  2. (b) State the mean and the median of X. [1]
  3. (c) Show that the upper quartile q satisfies u³ − 12u + 8 = 0, where u = q − 3, and find q correct to 3 significant figures. [4]
Show answer
  1. (a) k = 3/32
    M1 ∫₁⁵ k(x − 1)(5 − x) dx = 32k/3 = 1; A1.
  2. (b) Both equal 3
    B1 by symmetry about x = 3.
  3. (c) q = 3.69
    M1 with u = x − 3, f = (3/32)(4 − u²); M1 ∫₀^u (3/32)(4 − t²) dt = ¼; A1 4u − u³/3 = 8/3, so u³ − 12u + 8 = 0; A1 u = 0.695 (root between 0 and 2), q = 3.69.

Q15Median / mean of a pdf · Challenge · Paper 6 style · 7 marks

The time, X hours after 2 pm, at which a power cut ends on a particular afternoon is modelled by the probability density functionf(x) = kx²(3 − x) for 0 ≤ x ≤ 3,f(x) = 0 otherwise.

  1. (a) Find the value of k. [2]
  2. (b) Find E(X). [2]
  3. (c) Show that the median of X lies between E(X) and 2. [3]
Show answer
  1. (a) k = 4/27
    M1 k[x³ − x⁴/4]₀³ = 27k/4 = 1; A1.
  2. (b) 9/5
    M1 (4/27)∫₀³ (3x³ − x⁴) dx; A1 (4/27)(243/20) = 9/5.
  3. (c) F(1.8) = 0.475 < 0.5 and F(2) = 0.593 > 0.5
    M1 F(x) = (4/27)(x³ − x⁴/4); A1 F(1.8) = 0.475; A1 F(2) = 16/27 = 0.593, so 1.8 < median < 2.
