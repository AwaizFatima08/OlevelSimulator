Q26Solving cubic equations · Challenge · Paper 1 style · 5 marks

Q27Solving cubic equations · Challenge · Paper 2 style · 8 marks

Let f(x) = 6x³ − 11x² − 3x + 2.

  1. (a) Show that f(x) = (x − 2)(3x − 1)(2x + 1). [3]

Q60Factor and remainder theorems · Challenge · Paper 1 style · 6 marks

Let f(x) = x³ − 2x² + kx − 2k, where k is a constant.

  1. (a) Show that (x − 2) is a factor of f(x) for all values of k, and factorise f(x) fully. [3]
  2. (b) Find the set of values of k for which f(x) = 0 has exactly one real root. [3]
Show answer
  1. (a) f(2) = 8 − 8 + 2k − 2k = 0 for every k, so (x − 2) is a factor. f(x) = (x − 2)(x² + k).
    M1 substitute x = 2 and simplify to 0 for all k; M1 divide to get x² + k; A1 f(x) = (x − 2)(x² + k).
  2. (b) k > 0
    For k > 0, x² = −k has no real solutions, so x = 2 is the only real root. For k = 0, x² = 0 gives x = 0 as well, so there are two roots. For k < 0, x² = −k gives two real roots ±√(−k), so there are at least two distinct real roots. So the required set is k > 0. M1 consider x² = −k, A1 k > 0 gives no further roots, A1 reject k = 0 and k < 0.
