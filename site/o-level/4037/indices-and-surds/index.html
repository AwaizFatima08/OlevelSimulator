Q29Surds · Challenge · Paper 2 style · 7 marks

Show answer

Show answer

    Let t = x^(1/2), so x^(−1/2) = 1/t. The equation becomes t + 1/t = 5/2, so 2t² − 5t + 2 = 0, i.e. (2t − 1)(t − 2) = 0. t = ½ gives x = ¼; t = 2 gives x = 4. M1 substitute t, M1 form the quadratic, M1 factorise, A1 t = ½ or 2, A1 x = ¼ or 4.

Q60Indices and equations with indices · Challenge · Paper 2 style · 4 marks

Let 2^x = 3^y = 6^z, where x, y and z are non-zero.

  1. (a) Show that 1/z = 1/x + 1/y. [4]
Show answer
  1. (a) Let N be the common value. Then x = ln N/ln 2, y = ln N/ln 3 and z = ln N/ln 6. So 1/x + 1/y = (ln 2 + ln 3)/ln N = ln 6/ln N = 1/z.
    M1 take logarithms of each expression to write x, y and z in terms of ln N; M1 write 1/x and 1/y using ln 2 and ln 3; M1 add and use ln 2 + ln 3 = ln 6; A1 conclude 1/z = 1/x + 1/y.
