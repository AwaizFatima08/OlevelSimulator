Q1Graphs of functions · Core · Paper 1 style · no calculator · 5 marks
  1. (a) Complete the table of values for y = x² − 2x − 3.x: −2, −1, 0, 1, 2, 3, 4y: …, 0, −3, …, −3, 0, … [2]
  2. (b) By solving an equation, find the x-coordinates of the points where the curve y = x² − 2x − 3 crosses the x-axis. [2]
  3. (c) Write down the coordinates of the turning point of the curve. [1]
Show answer
  1. (a) x = −2: y = 5; x = 1: y = −4; x = 4: y = 5
    B2 for all three correct (B1 for two).
  2. (b) x = −1 and x = 3
    x² − 2x − 3 = 0, (x + 1)(x − 3) = 0 M1; x = −1, 3 A1.
  3. (c) (1, −4)
    B1 (from symmetry of the table).
Q2Graphs of functions · Core · Paper 2 style · calculator · 6 marks
  1. (a) Complete the table of values for y = 12/x.x: 1, 1.5, 2, 3, 4, 6y: 12, …, 6, …, …, 2 [2]
  2. (b) Write down the equations of the two asymptotes of the curve y = 12/x. [2]
  3. (c) The line y = 3x meets the curve y = 12/x at a point in the first quadrant. Find the coordinates of this point. [2]
Show answer
  1. (a) x = 1.5: y = 8; x = 3: y = 4; x = 4: y = 3
    B2 all three correct (B1 for two).
  2. (b) x = 0 and y = 0
    B1 each.
  3. (c) (2, 6)
    3x = 12/x, x² = 4 M1; x = 2, y = 6 A1.

  2. (b) Write down the equation of the line of symmetry of the curve. [1]

Q4Graphs of functions · Core · Paper 2 style · calculator · 6 marks
  1. (a) Complete the table for y = 3 × 2ˣ.x: −2, −1, 0, 1, 2, 3y: …, 1.5, …, 6, …, 24 [2]
  2. (b) Write down the coordinates of the point where the curve crosses the y-axis. [1]
  3. (c) Use trial and improvement to find the value of x for which y = 10. Give your answer correct to 2 decimal places. [3]
Show answer
  1. (a) x = −2: y = 0.75; x = 0: y = 3; x = 2: y = 12
    B2 all three (B1 for two).
  2. (b) (0, 3)
    B1.
  3. (c) x = 1.74
    3 × 2ˣ = 10 M1; trials e.g. x = 1.73 → 9.95, x = 1.74 → 10.02, x = 1.735 → 9.99 M1; x = 1.74 A1.
Q5Graphs of functions · Core · Paper 1 style · no calculator · 4 marks
  1. (a) Four curves are described by equations:P: y = x³ Q: y = 5/x R: y = 2ˣ S: y = 4 − x²Write down the letter of the curve that(i) has a maximum point,(ii) never crosses either axis,(iii) passes through (0, 1),(iv) passes through the origin. [4]
Show answer
  1. (a) (i) S (ii) Q (iii) R (iv) P
    B1 each. S is an upside-down parabola with maximum (0, 4); y = 5/x has asymptotes on both axes; 2⁰ = 1; 0³ = 0.
Q6Graphs of functions · Standard · Paper 2 style · calculator · 7 marks
  1. (a) The table shows some values of y = x³ − 4x + 1.x: −3, −2, −1, 0, 1, 2, 3y: …, 1, …, 1, −2, …, 16Complete the table. [2]
  2. (b) Find the gradient of the straight line joining the points on the curve where x = 1 and x = 3. [2]
  3. (c) The line y = 2x + 1 meets the curve y = x³ − 4x + 1 at three points. Show that the x-coordinates satisfy x³ − 6x = 0 and find all three values. Give non-integer answers correct to 2 decimal places. [3]
Show answer
  1. (a) x = −3: y = −14; x = −1: y = 4; x = 2: y = 1
    B2 for all three correct (B1 for two).
  2. (b) 9
    (16 − (−2)) ÷ (3 − 1) M1; = 9 A1.
  3. (c) x = 0, x = 2.45, x = −2.45
    x³ − 4x + 1 = 2x + 1 ⇒ x³ − 6x = 0 M1; x(x² − 6) = 0 M1; 0, ±√6 = ±2.45 A1.
Q7Graphs of functions · Standard · Paper 2 style · calculator · 6 marks

  2. (b) Show that x = 1 is a solution of x³ − 3x² + 2 = 0. [1]
  3. (c) Given that x³ − 3x² + 2 = (x − 1)(x² − 2x − 2), find the other two solutions of x³ − 3x² + 2 = 0. Give your answers correct to 2 decimal places. [3]
Show answer
  1. (a) x = −1: y = −2; x = 1: y = 0; x = 3: y = 2
    B2 all three (B1 for two).
  2. (b) 1 − 3 + 2 = 0
    B1 substitution shown.
  3. (c) x = 2.73 or x = −0.73
    x = (2 ± √(4 + 8))/2 M1 A1; 2.73, −0.73 A1.
