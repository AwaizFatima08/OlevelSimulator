Q2Validation and verification · Core · Paper 2 style · 4 marks
  1. (a) Explain the difference between validation and verification. [2]
  2. (b) Describe two methods of verification that could be used when a new customer's details are typed into a shop's computer. [2]
Show answer
  1. (a) Validation is an automatic check by the computer that data is reasonable/sensible and meets set rules before it is accepted; verification checks that data has been accurately copied or entered, i.e. it matches the original source. (Verification does not check that the data is sensible.)
    1 mark for validation, 1 mark for verification.
  2. (b) Double entry: the data is entered twice and the computer compares the two entries, accepting it only if they match. Visual check: the user (or customer) reads the data on screen and compares it with the original document before confirming.
    1 mark for each method described.

Q4Validation and verification · Standard · Paper 2 style · 5 marks
  1. (a) A warehouse uses 4-digit product codes followed by a check digit. The check digit is calculated as follows:- multiply the 1st, 2nd, 3rd and 4th digits by 4, 3, 2 and 1 respectively- add the results- the check digit is the remainder when the total is divided by 10.Calculate the check digit for the code 3706. Show your working. [2]
  2. (b) A worker types the code 52816. Show whether this code is valid. [2]
  3. (c) The worker meant to type 52186. Explain how the check digit detects this kind of error. [1]
Show answer
  1. (a) 4×3 + 3×7 + 2×0 + 1×6 = 12 + 21 + 0 + 6 = 39; 39 MOD 10 = 9. Check digit = 9 (full code 37069).
    M1 for correct weighted sum 39, A1 for 9.
  2. (b) 4×5 + 3×2 + 2×8 + 1×1 = 20 + 6 + 16 + 1 = 43; 43 MOD 10 = 3, but the check digit entered is 6, so the code is invalid.
    M1 for weighted sum 43 and remainder 3, A1 for stating invalid because 3 ≠ 6.
  3. (c) Two digits (1 and 8) were swapped (transposition error). For the correct code 5218 the weighted sum is 4×5 + 3×2 + 2×1 + 1×8 = 36, giving check digit 6, which matches. Because the digits have different weights, swapping them changes the total to 43 and the calculated check digit to 3, which does not match the 6 entered, so the error is detected.
    1 mark: swapped digits are multiplied by different weights, so the calculated check digit changes and no longer matches the one entered.

    1 mark: records whether any swap happened in a pass. 1 mark: loop ends when a pass has no swaps / avoids unnecessary passes.
  3. (c) After each pass the largest remaining name is in its correct place at the end, so it does not need to be compared again.
    1 mark.

Q27Program development life cycle, decomposition and design methods · Challenge · Paper 2 style · 6 marks
  1. (a) A team is writing software for a parcel-delivery company. Explain why the team decomposes the problem into sub-systems before coding. [3]
  2. (b) The team uses a structure diagram, a flowchart and pseudocode during design. Describe what each of these shows. [3]
Show answer
  1. (a) Each sub-system is a smaller, simpler problem that is easier to understand and solve; different programmers can work on different sub-systems at the same time; each part can be tested separately, making errors easier to find; sub-programs/modules can be reused.
    1 mark each for any three points.
  2. (b) Structure diagram: the system broken down hierarchically into sub-systems and smaller modules. Flowchart: the steps of an algorithm and the order/flow between them using standard symbols and arrows. Pseudocode: the algorithm written in structured English-like statements, close to program code but not in a specific language.
    1 mark for each description.

Q30Test data · Challenge · Paper 2 style · 5 marks
  1. (a) A weather station program accepts temperatures from −10.0 °C to 45.0 °C inclusive, given to one decimal place. State the type of test data (normal, abnormal, extreme or boundary) for each value and whether it should be accepted or rejected.(i) 23.4(ii) −10.0(iii) 45.1(iv) hot [4]
  2. (b) Explain why boundary testing uses values on both sides of each limit. [1]
