Q1Programming languages, translators and IDEs · Core · Paper 1 style · 3 marks
  1. (a) A games studio in Lahore writes most of its code in a high-level language. State two differences between a high-level language and a low-level language. [2]
  2. (b) Give one reason why a programmer at the studio might still write a small part of the game in a low-level language. [1]
Show answer
  1. (a) Any two, e.g. high-level uses English-like statements, low-level uses mnemonics or binary; high-level is machine independent, low-level is specific to one processor; one high-level statement may become many machine code instructions, one assembly instruction becomes one machine code instruction.
    1 mark each for any two differences, both sides of the comparison needed (or clearly implied). Do not accept 'high-level is harder'.
  2. (b) To directly control/manipulate the hardware (e.g. specific registers or memory locations), or to produce code that runs faster / uses less memory.
    1 mark for any one valid reason.

Q15Programming languages, translators and IDEs · Challenge · Paper 1 style · 5 marks
  1. (a) A drone's flight controller has a small amount of memory and must respond to its sensors very quickly. Explain why its designers might write parts of the control program in assembly language instead of a high-level language. [4]
  2. (b) Explain why the same assembly language program could not be used on a drone that has a different type of processor. [1]
Show answer
  1. (a) Assembly gives direct control of the hardware (registers, memory addresses, ports), needed to read the sensors and drive the motors; each instruction translates to one machine code instruction, so the code can be written to be compact, which suits the small memory; the programmer can optimise the code so it executes faster, which suits the need for quick response.
    Up to 4 marks: 1 for each point and 1 for each linked expansion (direct hardware control; compact code for small memory; fast execution for quick response).
  2. (b) Assembly language is specific to a processor's instruction set, so a different processor would need a rewritten program.
    1 mark.
Q16Programming languages, translators and IDEs · Challenge · Paper 1 style · 4 marks
  1. (a) A student's program contains two syntax errors, one on line 14 and one on line 30. Describe what happens when the program is translated with an interpreter. [2]
  2. (b) Describe what happens when the same program is translated with a compiler. [2]
Show answer
  1. (a) Lines 1 to 13 are translated and executed; the interpreter stops at line 14 and reports that error; the error on line 30 is not reported until line 14 has been corrected and the program is re-run to that point.
    1 mark: runs until line 14 then stops and reports it. 1 mark: line 30 error only found after correcting line 14 and running again.
  2. (b) The compiler attempts to translate the whole program; it reports both errors (lines 14 and 30) in an error list at the end; no executable file is produced, so none of the program runs.
    1 mark: both errors reported together after translation. 1 mark: no executable produced / program does not run.

Q20Programming languages, translators and IDEs · Challenge · Paper 1 style · 4 marks
  1. (a) A program contains a loop that is repeated 1 000 000 times. Explain why the program runs more slowly when it is interpreted than when it is compiled. [3]
  2. (b) Give one reason why the programmer may still prefer to use the interpreter while developing this program. [1]
Show answer
  1. (a) An interpreter translates and executes one statement at a time, every time it is reached, so the statements in the loop are translated 1 000 000 times. A compiler translates the whole program once into machine code before it runs, so the loop runs as machine code with no translation during execution.

  2. (b) It stops at the first error and reports it immediately, so errors can be found and corrected one at a time; the program can be run without translating it all first.
    1 mark.

Q35System and application software, operating system functions · Challenge · Paper 1 style · 6 marks
  1. (a) A computer has 4 GiB of RAM. A student opens several large programs at once. Explain how the operating system manages the processes and memory so the student can keep working. [4]
  2. (b) The student notices that the computer slows down a lot when very many programs are open. Explain why. [2]
Show answer
  1. (a) The OS allocates memory to each process and keeps a record of which memory each uses; when RAM is full it can move data/pages not currently needed to virtual memory on secondary storage; it swaps them back into RAM when needed; it schedules processor time between the processes (multitasking) so each makes progress; it frees memory when a program is closed.
    1 mark each for any four points.
  2. (b) RAM is full so more data is held in virtual memory; data must be repeatedly swapped between RAM and secondary storage, which is much slower than RAM (disk thrashing).
    1 mark: virtual memory/secondary storage used. 1 mark: swapping data is slow compared with RAM.

Q48Interrupts · Standard · Paper 1 style · 5 marks

Show answer

Show answer

Q55Interrupts · Challenge · Paper 1 style · 6 marks
  1. (a) Asad is listening to music on his computer while a document prints. At the same moment he presses a key and the printer runs out of paper. Explain how the processor uses interrupts to deal with both events without the music stopping for long. [4]
  2. (b) Explain why using interrupts is more efficient than the processor repeatedly checking every device to see whether it needs attention. [2]
Show answer
  1. (a) Each device sends an interrupt signal; the interrupts are queued according to priority; at the end of each FDE cycle the processor checks the queue; it saves the state of the current task, runs the ISR for the highest-priority interrupt, then for the next one (e.g. shows an out-of-paper message, reads the key press); after each ISR the saved state is restored so the music program continues; this happens so fast the music continues smoothly.
    1 mark each for any four points applied to the scenario.
  2. (b) The processor does not waste time checking devices that do not need attention; it can carry on with other processing and only responds when a device sends an interrupt.

Q56Interrupts · Challenge · Paper 1 style · 5 marks
  1. (a) A computer is running a long calculation when two interrupts arrive at almost the same time: 'paper jam' from a printer and 'data received' from the network card, which has a higher priority. Explain how the processor deals with both interrupts and the calculation. [5]
Show answer
  1. (a) Both interrupts are placed in the interrupt queue in priority order. At the end of the current fetch-decode-execute cycle the processor finds that the network interrupt has a higher priority than the calculation, so it saves the calculation's state (register contents) and runs the network ISR. It then checks the queue again and services the paper-jam interrupt (or restores the calculation if that has higher priority). When the ISRs are finished, the saved state is restored and the calculation continues from where it stopped.
    1 mark each for any five: queue in priority order; checked at end of cycle; network handled first; state saved; ISR run; paper jam handled next/after; state restored; calculation resumes where it stopped.
Q57Interrupts · Challenge · Paper 1 style · 4 marks
  1. (a) Explain why the processor saves the contents of its registers before running an interrupt service routine, and what would happen if it did not. [4]
Show answer
  1. (a) The registers (e.g. program counter, accumulator) hold the current state of the task that was interrupted. The ISR uses the same registers, so it would overwrite these values. Saving them lets the processor restore them afterwards, so the original task continues from exactly where it stopped. Without saving, the task would resume at the wrong instruction or with wrong data, giving wrong results or crashing.
    1 mark: registers hold the current task's state/PC holds next instruction; 1 mark: ISR overwrites registers; 1 mark: restored after ISR so the task resumes correctly; 1 mark: consequence of not saving.
Q58Interrupts · Challenge · Paper 1 style · 4 marks
  1. (a) A cheap electronic toy checks its single button every few milliseconds instead of using interrupts (this is called polling). Explain why polling is acceptable for the toy, and why interrupts are essential for a laptop. [4]
Show answer
  1. (a) The toy has only one input and one simple task, so checking it constantly wastes little and the toy has nothing else to do. A laptop has many devices (keyboard, mouse, network, disk, printer) and runs many programs; checking each device constantly would waste processor time, and urgent events could be missed or delayed. Interrupts let devices signal only when they need attention, so the processor can do useful work in between and respond to the most urgent first.
    1 mark: toy – few devices/single task so polling cost is small; 1 mark: laptop – many devices; 1 mark: polling wastes processor time; 1 mark: interrupts give a quick response with priorities.
