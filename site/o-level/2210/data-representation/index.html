  1. (a) 3.27 times
    M1 (96 000 × 24) ÷ (44 100 × 16); A1 3.27.
  2. (b) Benefit: more samples per second and more precise amplitudes, so the sound is more accurate/higher quality. Drawback: much larger files need more storage and take longer to download/transfer.

Q75Representing text, sound and images · Challenge · Paper 1 style · 5 marks
  1. (a) A program sorts words by comparing the character codes of their letters. The ASCII code of 'B' is 66 and of 'a' is 97. Explain why the program puts 'Banana' before 'apple'. [2]
  2. (b) Suggest how the program could sort the words in true alphabetical order. [1]
  3. (c) Explain why a character set must be agreed between computers that exchange text messages. [2]
Show answer
  1. (a) It compares the first characters: 'B' has code 66, which is smaller than 97 for 'a', so 'Banana' is placed first, even though 'a' comes before 'b' in the alphabet; all capital letters have smaller codes than lower-case letters.
    1 mark: compares codes 66 and 97. 1 mark: capitals have lower codes than lower case.
  2. (b) Convert all letters to the same case (e.g. capitals) before comparing them.
    1 mark.
  3. (c) Text is stored as binary codes; if the sending and receiving computers use different character sets, the same code would be shown as a different character, so the message would be wrong/unreadable.
    1 mark: characters are stored as codes. 1 mark: different sets would give different characters.
