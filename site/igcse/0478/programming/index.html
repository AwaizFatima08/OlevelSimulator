Q1Extended programming task (15-mark scenario) · Core · Paper 2 style · 15 marks

A cricket academy in Sialkot records the runs scored by its 20 players in each of 10 matches. The program uses:• a one-dimensional array PlayerName[1:20] of type STRING, already holding the players' names• a two-dimensional array Runs[1:20, 1:10] of type INTEGERRequirements:• allow the runs for every player in every match to be input, rejecting any value below 0 or above 300• calculate each player's total and average runs (average rounded to 1 decimal place) and output the name, total and average• find and output the name of the player with the highest total.You may answer in pseudocode or a high-level programming language. Use meaningful identifiers and add comments.

  1. (a) Write the section of the program that inputs and validates the runs for every player in every match. [5]
  2. (b) Write the section that calculates and outputs each player's total and average. [5]
  3. (c) Write the section that finds and outputs the name of the player with the highest total. (You may store each total in an array Totals[1:20] in part (b).) [5]
Show answer
  1. (a) FOR Player ← 1 TO 20 FOR Match ← 1 TO 10 OUTPUT "Enter runs for ", PlayerName[Player], " in match ", Match INPUT Runs[Player, Match] WHILE Runs[Player, Match] < 0 OR Runs[Player, Match] > 300 DO OUTPUT "Invalid: runs must be 0 to 300. Re-enter" INPUT Runs[Player, Match] ENDWHILE NEXT MatchNEXT Player
    1 mark each: outer loop for 20 players; inner loop for 10 matches; prompt and input into Runs[Player, Match]; validation condition < 0 OR > 300; re-input with error message inside a loop.
  2. (b) DECLARE Total : INTEGERDECLARE Average : REALFOR Player ← 1 TO 20 Total ← 0 FOR Match ← 1 TO 10 Total ← Total + Runs[Player, Match] NEXT Match Average ← ROUND(Total / 10, 1) OUTPUT PlayerName[Player], " total: ", Total, " average: ", AverageNEXT Player
    1 mark each: loop through players; total reset to 0 for each player; inner loop adds Runs[Player, Match]; average = total / 10 rounded to 1 d.p.; output name, total and average with messages.
  3. (c) // assumes Totals[Player] ← Total was added inside the loop in (b)DECLARE Highest : INTEGERDECLARE BestPlayer : INTEGERHighest ← Totals[1]BestPlayer ← 1FOR Player ← 2 TO 20 IF Totals[Player] > Highest THEN Highest ← Totals[Player] BestPlayer ← Player ENDIFNEXT PlayerOUTPUT "Highest scorer: ", PlayerName[BestPlayer], " with ", Highest, " runs"
    1 mark each: totals stored in an array (or recalculated); highest initialised to first total (or −1); loop compares each total with highest; highest and index updated together; output name of best player using the stored index with message.
Q2Extended programming task (15-mark scenario) · Core · Paper 2 style · 15 marks

A power company calculates monthly bills for 50 households. Each household's meter reading at the start and end of the month is input. Units used = end reading − start reading.Charges:• the first 100 units cost Rs 10 each• units from 101 to 300 cost Rs 15 each• every unit above 300 costs Rs 25The program uses arrays HouseID[1:50] (STRING, already filled) and Bill[1:50] (REAL).Requirements:• input both readings for each house; the end reading must not be less than the start reading• calculate and store each bill, and output the house ID with its units and bill• output the total of all bills and the number of households that used more than 300 units.You may answer in pseudocode or a high-level programming language. Use meaningful identifiers and add comments.

  1. (a) Write the section that inputs and validates both readings for one household and calculates the units used. [4]
  2. (b) Write the section that calculates the bill for one household from Units and stores it in Bill[House]. [5]
  3. (c) Write the rest of the program: the loop for all 50 households, initialising the counters, and outputting the total of all bills and the count of households above 300 units. (Use your sections from (a) and (b).) [5]
  4. (d) Calculate the bill for a household that uses 350 units. [1]
Show answer
  1. (a) OUTPUT "Start reading for ", HouseID[House]INPUT StartReadingOUTPUT "End reading for ", HouseID[House]INPUT EndReadingWHILE EndReading < StartReading DO OUTPUT "End reading cannot be less than start reading. Re-enter end reading" INPUT EndReadingENDWHILEUnits ← EndReading − StartReading
    1 mark each: inputs with prompts; validation condition EndReading < StartReading; loop with error message and re-input; units calculated.
  2. (b) IF Units <= 100 THEN Bill[House] ← Units * 10ELSE IF Units <= 300 THEN Bill[House] ← 100 * 10 + (Units − 100) * 15 ELSE Bill[House] ← 100 * 10 + 200 * 15 + (Units − 300) * 25 Over300 ← Over300 + 1 ENDIFENDIFOUTPUT HouseID[House], " units: ", Units, " bill: Rs ", Bill[House]
    1 mark each for any five of: correct first band (≤ 100 × 10); correct condition for second band; second band = 1000 + (Units − 100) × 15; third band = 1000 + 3000 + (Units − 300) × 25; count of households over 300 incremented; output of ID, units and bill.
  3. (c) DECLARE TotalBills : REALDECLARE Over300 : INTEGERTotalBills ← 0Over300 ← 0FOR House ← 1 TO 50 // section (a) // section (b) TotalBills ← TotalBills + Bill[House]NEXT HouseOUTPUT "Total of all bills: Rs ", TotalBillsOUTPUT "Households using more than 300 units: ", Over300
    1 mark each: totals and counter initialised to 0 before the loop; loop 1 to 50 around (a) and (b); running total updated inside the loop; total output after the loop; count output after the loop with message.
  4. (d) Rs 5250
    100 × 10 + 200 × 15 + 50 × 25 = 1000 + 3000 + 1250 = 5250.

Q4Extended programming task (15-mark scenario) · Core · Paper 2 style · 15 marks

A fitness club in Kuala Lumpur gives each member a step counter. For one member, the steps taken each day for 4 weeks are stored in a two-dimensional array Steps[1:4, 1:7] of INTEGER (week, day).Requirements:• input the steps for every day; a value must be between 0 and 60 000• output the total steps for each week and the week with the most steps• output the number of days on which the member reached the target of 10 000 steps, and the percentage of days (to 1 decimal place).You may answer in pseudocode or a high-level programming language. Use meaningful identifiers and add comments.

  1. (a) Write the section that inputs and validates the steps. [4]
  2. (b) Write the section that outputs each week's total and the week with the most steps. [6]
  3. (c) Write the section that outputs the number and percentage of days on which 10 000 steps were reached. [4]
  4. (d) The member reached the target on 17 days. State the percentage your program outputs. [1]
Show answer
  1. (a) FOR Week ← 1 TO 4 FOR Day ← 1 TO 7 OUTPUT "Steps for week ", Week, " day ", Day INPUT Steps[Week, Day] WHILE Steps[Week, Day] < 0 OR Steps[Week, Day] > 60000 DO OUTPUT "Must be 0 to 60000, re-enter" INPUT Steps[Week, Day] ENDWHILE NEXT DayNEXT Week
    1 mark each: nested loops 4 × 7; input into Steps[Week, Day]; range check; re-input loop with message.
  2. (b) BestWeek ← 1BestTotal ← -1FOR Week ← 1 TO 4 WeekTotal ← 0 FOR Day ← 1 TO 7 WeekTotal ← WeekTotal + Steps[Week, Day] NEXT Day OUTPUT "Week ", Week, " total: ", WeekTotal IF WeekTotal > BestTotal THEN BestTotal ← WeekTotal BestWeek ← Week ENDIFNEXT WeekOUTPUT "Most steps in week ", BestWeek
    1 mark each: week total reset to 0 each week; inner loop totals 7 days; week total output; best total initialised; comparison updates best total and week; output best week.
  3. (c) TargetDays ← 0FOR Week ← 1 TO 4 FOR Day ← 1 TO 7 IF Steps[Week, Day] >= 10000 THEN TargetDays ← TargetDays + 1 ENDIF NEXT DayNEXT WeekOUTPUT "Target reached on ", TargetDays, " days"OUTPUT "Percentage: ", ROUND(TargetDays / 28 * 100, 1), "%"
    1 mark each: counter initialised; condition >= 10000 counted over all 28 days; percentage = count / 28 × 100 rounded to 1 d.p.; outputs with messages.
  4. (d) 60.7%
    17 ÷ 28 × 100 = 60.71… → 60.7.
Q5Extended programming task (15-mark scenario) · Standard · Paper 2 style · 15 marks

A cinema in Hyderabad has 8 rows (A to H, numbered 1 to 8 in the program) with 12 seats in each row. The program uses a two-dimensional Boolean array Booked[1:8, 1:12], where TRUE means the seat is taken. A ticket costs Rs 900, but seats in rows 1 and 2 cost Rs 600.Requirements:• at the start, set every seat to not booked• repeatedly let a customer choose a row and seat number; validate both; if the seat is free, book it and add the price to the takings, otherwise output a message• stop when the customer enters 0 for the row• at the end, output the total takings and the number of empty seats in each row.You may answer in pseudocode or a high-level programming language. Use meaningful identifiers and add comments.

  1. (a) Write the section that sets every seat to not booked and initialises the takings. [3]
  2. (b) Write the section that handles bookings until 0 is entered for the row. [7]
  3. (c) Write the section that outputs the total takings and the number of empty seats in each row. [5]
Show answer
  1. (a) DECLARE Booked : ARRAY[1:8, 1:12] OF BOOLEANDECLARE Takings : INTEGERTakings ← 0FOR Row ← 1 TO 8 FOR Seat ← 1 TO 12 Booked[Row, Seat] ← FALSE NEXT SeatNEXT Row
    1 mark each: nested loops over 8 rows and 12 seats; each element set to FALSE; takings initialised to 0.
  2. (b) OUTPUT "Enter row number (1-8), or 0 to finish"INPUT RowWHILE Row <> 0 DO IF Row < 1 OR Row > 8 THEN OUTPUT "Invalid row" ELSE OUTPUT "Enter seat number (1-12)" INPUT Seat WHILE Seat < 1 OR Seat > 12 DO OUTPUT "Invalid seat, re-enter (1-12)" INPUT Seat ENDWHILE IF Booked[Row, Seat] = TRUE THEN OUTPUT "Sorry, that seat is already booked" ELSE Booked[Row, Seat] ← TRUE IF Row <= 2 THEN Takings ← Takings + 600 ELSE Takings ← Takings + 900 ENDIF OUTPUT "Seat booked" ENDIF ENDIF OUTPUT "Enter row number (1-8), or 0 to finish" INPUT RowENDWHILE
    1 mark each: condition-controlled loop ending when row = 0; row validated (1–8); seat input and validated (1–12); check Booked[Row, Seat] before booking; seat set to TRUE; correct price added (600 for rows 1–2, otherwise 900); messages for taken seat/invalid input and re-input of row inside the loop.
  3. (c) OUTPUT "Total takings: Rs ", TakingsFOR Row ← 1 TO 8 Empty ← 0 FOR Seat ← 1 TO 12 IF Booked[Row, Seat] = FALSE THEN Empty ← Empty + 1 ENDIF NEXT Seat OUTPUT "Row ", Row, ": ", Empty, " empty seats"NEXT Row
    1 mark each: takings output with message; loop through rows; counter reset for each row; counts seats that are FALSE; outputs row number and count.
Q6Extended programming task (15-mark scenario) · Standard · Paper 2 style · 15 marks

A public library in Peshawar records returned books. For each of 30 returns in a day, the librarian inputs the member ID (exactly 6 characters) and the number of days late (0 to 60). The fine is Rs 20 per day for the first 7 days late and Rs 50 per day after that; the maximum fine is Rs 2000.The program uses arrays MemberID[1:30] (STRING) and Fine[1:30] (INTEGER).Requirements:• input and validate the member ID (length check) and days late (range check)• calculate and store each fine and output it• output the total fines, the average fine of the members who paid a fine (rounded to 2 decimal places), and the member ID with the largest fine.You may answer in pseudocode or a high-level programming language. Use meaningful identifiers and add comments.

  1. (a) Write the section that inputs and validates the data for return number Count. [4]
  2. (b) Write the section that calculates and stores the fine for return number Count. [4]
  3. (c) Write the section that outputs the total, the average fine of members who paid a fine, and the member with the largest fine. [5]
  4. (d) Calculate the fines for members who are 20 days late and 45 days late. [2]
Show answer
  1. (a) OUTPUT "Enter 6-character member ID"INPUT MemberID[Count]WHILE LENGTH(MemberID[Count]) <> 6 DO OUTPUT "ID must be exactly 6 characters. Re-enter" INPUT MemberID[Count]ENDWHILEOUTPUT "Enter days late (0-60)"INPUT DaysLateWHILE DaysLate < 0 OR DaysLate > 60 DO OUTPUT "Days late must be 0 to 60. Re-enter" INPUT DaysLateENDWHILE
    1 mark each for any four of: ID input into array; length check using LENGTH() <> 6; re-input loop with message; days late input; range check 0–60 with re-input loop.
  2. (b) IF DaysLate <= 7 THEN Fine[Count] ← DaysLate * 20ELSE Fine[Count] ← 7 * 20 + (DaysLate − 7) * 50ENDIFIF Fine[Count] > 2000 THEN Fine[Count] ← 2000ENDIFOUTPUT "Fine for ", MemberID[Count], ": Rs ", Fine[Count]
    1 mark each for any four of: condition DaysLate <= 7; fine = days × 20; fine = 140 + (days − 7) × 50; capped at 2000; output of fine with ID.
  3. (c) Total ← 0Payers ← 0MaxIndex ← 1FOR Count ← 1 TO 30 Total ← Total + Fine[Count] IF Fine[Count] > 0 THEN Payers ← Payers + 1 ENDIF IF Fine[Count] > Fine[MaxIndex] THEN MaxIndex ← Count ENDIFNEXT CountOUTPUT "Total fines: Rs ", TotalIF Payers > 0 THEN OUTPUT "Average fine: Rs ", ROUND(Total / Payers, 2)ELSE OUTPUT "No fines today"ENDIFOUTPUT "Largest fine: ", MemberID[MaxIndex], " Rs ", Fine[MaxIndex]
    1 mark each: total accumulated; payers counted only when fine > 0; average = total / payers rounded to 2 d.p. (division by zero avoided); index of largest fine tracked; outputs with messages.
  4. (d) Rs 790 and Rs 2000
    20 days: 140 + 13 × 50 = 790. 45 days: 140 + 38 × 50 = 2040, capped at 2000.
