Q1Primary, secondary, virtual and cloud storage · Core · Paper 1 style · 4 marks
  1. (a) State two differences between RAM and ROM. [2]
  2. (b) A washing machine sold in Lahore stores its wash programs in ROM. Explain why ROM is used for this. [2]
Show answer
  1. (a) RAM is volatile, ROM is non-volatile; RAM can be read from and written to, ROM is (normally) read-only.
    1 mark each for any two of: RAM volatile / ROM non-volatile; RAM read and write / ROM read only; RAM stores data and programs currently in use / ROM stores the start-up instructions (bootstrap/BIOS); RAM contents change while the computer runs / ROM contents are fixed.
  2. (b) The wash programs must not be lost when the machine is switched off, and they must not be changed by the user.
    1 mark: ROM is non-volatile so the programs are kept when power is off. 1 mark: ROM cannot be written to/changed so the programs cannot be accidentally altered or deleted.
Q2Primary, secondary, virtual and cloud storage · Core · Paper 1 style · 4 marks
  1. (a) Ayesha stores her photographs on a solid-state drive (SSD) in her laptop. Identify whether an SSD is primary or secondary storage. [1]
  2. (b) Give three reasons why an SSD is more suitable than a magnetic hard disk drive for a laptop that is carried to school every day. [3]
Show answer
  1. (a) Secondary storage.
    B1 secondary (non-volatile, not directly accessed by the CPU).
  2. (b) No moving parts so more robust/less likely to be damaged if dropped; lighter and thinner; uses less power so the battery lasts longer (also faster access, silent).
    1 mark each for any three of: no moving parts / more durable if knocked; lighter; smaller/thinner; lower power consumption so longer battery life; faster read/write access; runs cooler; silent.
Q3Primary, secondary, virtual and cloud storage · Core · Paper 1 style · 6 marks
  1. (a) Define cloud storage. [2]
  2. (b) A football club in Manchester is deciding whether to keep its match videos on cloud storage or on its own local server. Give two benefits and two drawbacks of using cloud storage. [4]
Show answer
  1. (a) Storing data on remote servers (owned by a third party) that are accessed over the internet.
    1 mark: data stored on (remote/off-site) servers. 1 mark: accessed using the internet / managed by a third-party company.
  2. (b) Benefits: can be accessed from anywhere with an internet connection; provider handles backups/maintenance; storage can be increased easily; no need to buy hardware. Drawbacks: needs an internet connection; monthly fees; security depends on a third party; data could be lost if the provider fails; uploads/downloads may be slow.
    2 marks for benefits, any two of: access from any location/device with internet; easy to share files; provider backs up data and maintains hardware; scalable; no hardware purchase or maintenance cost. 2 marks for drawbacks, any two of: requires internet access; ongoing subscription cost; data security/privacy controlled by third party; risk of provider outage or closure; slow transfer of large files.
Q4Primary, secondary, virtual and cloud storage · Standard · Paper 1 style · 6 marks
  1. (a) Describe how data is stored on a magnetic hard disk drive. [4]
  2. (b) A video-editing studio in Karachi keeps 40 TB of archived footage. Explain why magnetic storage is still often chosen for this instead of solid-state storage. [2]
Show answer
  1. (a) Platters coated in magnetic material spin; a read/write head moves across the surface on an actuator arm; it magnetises tiny areas in one of two directions to represent 1 and 0; data is stored in tracks and sectors.
    1 mark each for any four of: uses (rotating) platters; surface coated with a magnetisable material; read/write head on an actuator arm moves across the platter; tiny areas (domains) are magnetised; magnetised in one of two directions to represent 1 or 0; platter divided into tracks and sectors; head reads by detecting the direction of magnetisation.
  2. (b) Magnetic storage has a lower cost per gigabyte and is available in very large capacities, and the archive does not need very fast access.
    1 mark: cheaper per unit of storage / large capacity at low cost. 1 mark: speed of access is less important for archive data / data is accessed rarely.
Q5Primary, secondary, virtual and cloud storage · Standard · Paper 1 style · 6 marks
  1. (a) Explain what is meant by virtual memory. [2]
  2. (b) Describe how virtual memory is used when a student opens many large applications at once. [3]
  3. (c) State one drawback of relying heavily on virtual memory. [1]
Show answer
  1. (a) Part of secondary storage (e.g. the hard disk or SSD) is used as if it were extra RAM when RAM is full.
    1 mark: an area of secondary storage is used as (an extension of) RAM. 1 mark: used when RAM is full / to hold pages of data or programs not currently needed.
  2. (b) When RAM becomes full, data/pages that are not currently being used are moved from RAM to virtual memory on secondary storage, freeing RAM for the data needed now; when those pages are needed again they are swapped back into RAM.
    1 mark each for: RAM fills up; pages/data not currently in use are transferred to virtual memory (secondary storage); space in RAM is then used for the new data/application; pages are swapped back into RAM when needed.
  3. (c) It is much slower than RAM, so the computer slows down (disk thrashing).
    B1 slower access than RAM / disk thrashing / extra wear on an SSD.
Q6Primary, secondary, virtual and cloud storage · Standard · Paper 1 style · 6 marks
  1. (a) Describe how a solid-state drive stores data. [3]
  2. (b) Describe how data is stored on an optical disc such as a DVD. [3]
Show answer
  1. (a) It uses flash memory made of transistors (NAND/NOR); electric charge is trapped in a floating gate (control gate and floating gate) to represent a 1 or 0; there are no moving parts, and the charge stays when power is removed.
    1 mark each for any three of: uses flash memory / semiconductor chips; made of transistors; control gate and floating gate; electrons/charge trapped in the floating gate; presence or absence of charge represents 1 or 0; non-volatile – charge remains without power; no moving parts.
  2. (b) A laser burns/creates pits and lands on a spiral track on the disc surface; to read, a laser is shone on the track and the reflection differs between pits and lands, representing 1s and 0s.
    1 mark each for any three of: laser used to write and read; pits and lands; on a single spiral track; reflected light is detected; pits scatter light / lands reflect it; the difference represents binary 1 and 0.
Q7Primary, secondary, virtual and cloud storage · Challenge · Paper 1 style · 8 marks
  1. (a) A hospital in Islamabad needs storage for three purposes. For each, name the most suitable type of storage (magnetic, optical, solid state or cloud) and justify your choice.(i) The start-up instructions of a heart-rate monitor's control board.(ii) A portable device carried by doctors on ward rounds to record notes.(iii) Off-site copies of patient records so they survive a fire in the building. [6]
  2. (b) The hospital's computers have 8 GiB of RAM. Explain why adding more RAM can make a computer run faster when many programs are open. [2]
Show answer
  1. (a) (i) ROM / solid state (flash) in the device – non-volatile and must not be changed. (ii) Solid state – no moving parts so robust if dropped, small, low power. (iii) Cloud storage – stored off-site on remote servers, so it is not destroyed by a fire at the hospital, and can be accessed from anywhere.
    For each part: 1 mark for a suitable storage type, 1 mark for a matching justification. (i) ROM/flash: non-volatile, instructions fixed. (ii) Solid state: durable, light, low power, fast. (iii) Cloud (or magnetic tape/disk stored off-site): physically separate location, protected from local disaster; accept magnetic with off-site justification.
  2. (b) More data and programs can be held in RAM at once, so less virtual memory (slow secondary storage) is needed and less time is spent swapping pages.
    1 mark: more instructions/data can be stored in RAM. 1 mark: less need to use virtual memory / fewer slow transfers to and from secondary storage.
Q8Primary, secondary, virtual and cloud storage · Challenge · Paper 1 style · 6 marks
  1. (a) Explain why a computer needs both primary storage and secondary storage. [4]
  2. (b) A student says: 'If my laptop had 2 TB of RAM I would not need an SSD at all.' Give two reasons why the student is wrong. [2]
Show answer
  1. (a) Primary storage (RAM) is directly accessible by the CPU and fast, so it holds the data and instructions currently being used, but RAM is volatile and relatively expensive. Secondary storage is non-volatile and has large capacity at lower cost, so it keeps files and programs permanently when the power is off.
    1 mark each for: primary storage is directly accessed by the CPU; RAM holds data/programs currently in use and is fast; RAM is volatile so contents lost when power off; secondary storage is non-volatile/permanent; secondary storage offers large capacity at lower cost.
  2. (b) RAM is volatile, so all files and the operating system would be lost when the laptop is switched off; RAM is far more expensive per byte, so 2 TB would be extremely costly.
    1 mark each for any two of: RAM is volatile – data lost when power off; nothing to load the OS from on start-up; RAM cost per GB much higher; ROM only holds the bootstrap so files still need permanent storage.

Q12CPU components and the fetch-decode-execute cycle · Standard · Paper 1 style · 6 marks
  1. (a) Describe the fetch stage of the fetch-decode-execute cycle. Refer to the registers and buses used. [5]
  2. (b) State what happens in the decode stage. [1]
Show answer
  1. (a) The address in the PC is copied into the MAR; the address is sent along the address bus to memory; a read signal is sent on the control bus; the instruction at that address is sent along the data bus to the MDR; the instruction is copied from the MDR into the CIR; the PC is incremented by 1.
    1 mark each for any five of: PC holds address of next instruction; address copied from PC to MAR; address sent via address bus; control unit sends read signal on control bus; instruction transferred via data bus; instruction stored in MDR; instruction copied to CIR; PC incremented.
  2. (b) The control unit decodes (interprets) the instruction in the CIR.
    B1 instruction in the CIR is decoded/interpreted by the control unit.
Q13CPU components and the fetch-decode-execute cycle · Standard · Paper 1 style · 4 marks
  1. (a) Explain why the address bus is unidirectional but the data bus is bidirectional. [2]
  2. (b) State the purpose of the accumulator (ACC). [1]
  3. (c) During one cycle the PC contains 52. State the value in the PC after the fetch stage has finished, assuming instructions are stored one per address and no jump occurs. [1]
Show answer
  1. (a) Addresses only travel from the CPU to memory, whereas data must travel both from memory to the CPU (reading) and from the CPU to memory (writing).
    1 mark: address bus carries addresses only from CPU (MAR) to memory. 1 mark: data bus carries data to and from the CPU (read and write).
  2. (b) It temporarily stores the result of calculations carried out by the ALU.
    B1 holds intermediate/final results of ALU operations.
  3. (c) 53
    B1 53 – the PC is incremented by 1 during the fetch stage.
Q14CPU components and the fetch-decode-execute cycle · Challenge · Paper 1 style · 8 marks
  1. (a) An instruction is stored at memory address 200 and the next instruction is at address 201. The instruction at 200 tells the CPU to add the value stored at address 350 to the accumulator.Describe, step by step, how the CPU fetches and executes this instruction, naming each register and bus involved. [6]
  2. (b) Explain why the PC is incremented during the fetch stage instead of after the instruction has been executed. [2]
Show answer
  1. (a) Fetch: 200 is copied from PC to MAR; sent on address bus with a read signal on the control bus; instruction travels on data bus to MDR; copied to CIR; PC becomes 201. Decode: CU decodes the instruction in CIR. Execute: 350 is placed in the MAR; value at address 350 is read via the data bus into the MDR; the ALU adds the MDR value to the ACC; result is stored in the ACC.
    1 mark each for any six of: PC (200) → MAR; address bus used; read signal via control bus; instruction to MDR via data bus; MDR → CIR; PC incremented to 201; CU decodes instruction; operand address 350 → MAR; data at 350 loaded into MDR; ALU performs addition; result stored in ACC.
  2. (b) So that it already holds the address of the next instruction, ready for the next cycle; if the instruction is a jump, the execute stage can then overwrite the PC with the new address.
    1 mark: PC then points to the next instruction ready for the next fetch. 1 mark: a jump/branch instruction can replace the PC value during execute.
Q15CPU components and the fetch-decode-execute cycle · Challenge · Paper 1 style · 6 marks

  3. (c) Describe what is held in the MAR and the MDR at the moment an instruction is being read from address 75, if the instruction stored there is 10110011. [2]
Show answer
  1. (a) The ALU does not decode instructions; the control unit decodes the instruction (the ALU only carries out arithmetic and logic during execute).
    1 mark: identifies that the ALU does not decode. 1 mark: correction – the CU decodes the instruction; ALU used only during execution of arithmetic/logic.
  2. (b) The clock sends out regular pulses that synchronise all CPU operations; each step of the cycle happens in time with the clock pulses.
    1 mark: produces timing signals/pulses at a fixed rate. 1 mark: synchronises the components so each step of the FDE cycle occurs on a pulse.
  3. (c) MAR holds the address 75; MDR receives/holds the instruction 10110011.
    1 mark: MAR = 75 (address). 1 mark: MDR = 10110011 (contents of that address).

Q23CPU performance, cores, cache and embedded systems · Standard · Paper 1 style · 5 marks
  1. (a) Explain how increasing the size of the cache can improve the performance of a CPU. [3]
  2. (b) Hassan says that a quad-core processor will always run his programs four times faster than a single-core processor of the same clock speed. Explain why he is wrong. [2]

  1. (a) A games company compares two CPUs:CPU X: 4 cores, 2.8 GHz, 6 MB cacheCPU Y: 2 cores, 3.6 GHz, 3 MB cacheThe company's game engine runs many tasks in parallel. Recommend one CPU for the company and justify your choice by referring to all three factors. [4]

    1 mark: recommends X. 1 mark: more cores allow tasks to run in parallel. 1 mark: larger cache, fewer accesses to RAM. 1 mark: acknowledges Y has higher clock speed/more cycles per second but this advantage is outweighed (accept a well-justified Y only if it uses all three factors, max 3).
  2. (b) Other parts of the system, such as RAM, buses and storage, may not keep up, so the CPU waits for data; higher speed also causes more heat, which may lead to the CPU slowing itself down.
    1 mark each for any two of: bottleneck in memory/bus/storage speed; CPU waits for data; overheating causes throttling; program may be limited by input/output.

Q26Sensors and microprocessor control · Standard · Paper 1 style · 6 marks
  1. (a) A greenhouse in Murree uses a temperature sensor and a microprocessor to control a heater and a window motor. The temperature should stay between 18 °C and 26 °C.Describe how the system keeps the temperature in this range. [6]
Show answer
  1. (a) The temperature sensor continually sends readings; they are converted from analogue to digital by an ADC; the microprocessor compares each reading with the stored values 18 and 26; if the reading is below 18 the microprocessor sends a signal to switch the heater on (and close the window); if the reading is above 26 it switches the heater off and sends a signal to the actuator/motor to open the window; if it is in range, heater off and window closed (no change); the process repeats continuously.
    1 mark each for any six of: sensor sends readings to microprocessor; ADC converts analogue to digital; preset values stored; reading compared with 18 and 26; below 18 → heater on / window closed; above 26 → heater off, signal to actuator to open window; between → no action/heater off; the loop continues/readings taken at intervals.
Q27Sensors and microprocessor control · Standard · Paper 1 style · 6 marks
  1. (a) A car has a parking-assist system that uses sensors and a microprocessor. When the car is closer than 50 cm to an object, a buzzer beeps.Name a suitable sensor for this system. [1]
  2. (b) Explain how the microprocessor uses data from the sensor to control the buzzer. [4]
  3. (c) Suggest one improvement so that the driver gets more information as the car gets closer. [1]
Show answer
  1. (a) Proximity sensor (accept ultrasonic/infrared distance sensor).
    B1 proximity sensor.
  2. (b) The sensor continuously sends data; the data is converted to digital; the microprocessor compares the distance with the stored value 50 cm; if it is less than 50 cm it sends a signal to switch the buzzer on, otherwise the buzzer is off; this repeats continuously.
    1 mark each for any four of: sensor sends readings; ADC converts to digital; compared with stored value (50 cm); less than 50 → signal to turn buzzer on; otherwise buzzer off; process repeats continuously.
  3. (c) The microprocessor makes the beeps faster (or louder) as the distance decreases.
    B1 frequency/rate of beeping increases as distance falls / a continuous tone below a second threshold / display showing distance.
Q28Sensors and microprocessor control · Challenge · Paper 1 style · 8 marks
  1. (a) A water-treatment plant in Faisalabad must keep the pH of drinking water between 6.5 and 8.5. If the pH falls below 6.5 an alkali valve is opened; if it rises above 8.5 an acid valve is opened. An alarm sounds if the pH is outside 6.0–9.0.Describe how a microprocessor-controlled system with a pH sensor would work. [6]
  2. (b) Give two reasons for using a microprocessor-controlled system instead of a worker who tests the water by hand. [2]
Show answer
  1. (a) The pH sensor sends readings continuously; ADC converts to digital; the microprocessor compares the reading with stored values; below 6.5 → signal to actuator to open the alkali valve; above 8.5 → open the acid valve; between 6.5 and 8.5 → both valves closed; if below 6.0 or above 9.0 the microprocessor also sends a signal to sound the alarm; the readings are checked again in a continuous loop.
    1 mark each for any six of: pH sensor sends data; analogue to digital conversion; comparison with stored values; < 6.5 opens alkali valve via actuator; > 8.5 opens acid valve; otherwise valves closed; < 6.0 or > 9.0 triggers alarm; continuous loop/regular intervals.
  2. (b) Readings are taken continuously, including at night; responses are faster and more accurate; no human error or fatigue; safer for workers near chemicals.
    1 mark each for any two of: works 24/7; faster response; more accurate/consistent; no human error; safer; cheaper in the long term.
Q29Network hardware and addressing (NIC, MAC, IP, router) · Standard · Paper 1 style · 6 marks
  1. (a) State the purpose of a network interface card (NIC). [1]
  2. (b) A MAC address is shown as 3C-5A-B4-0E-71-D2. Describe the structure of a MAC address. [3]
  3. (c) State two differences between an IPv4 address and an IPv6 address. [2]
Show answer
  1. (a) It allows a device to connect to a network.
    B1 provides a connection to a (wired or wireless) network; contains the MAC address.
  2. (b) It is 48 bits (12 hexadecimal digits / 6 pairs); the first half identifies the manufacturer; the second half is the serial number of the device.
    1 mark each: 48-bit / 12 hex digits; first 6 hex digits (first half) = manufacturer code; last 6 hex digits = device serial number.
  3. (c) IPv4 is 32 bits, IPv6 is 128 bits; IPv4 written as four denary numbers separated by dots, IPv6 as eight groups of hexadecimal separated by colons; IPv6 allows far more addresses.
    1 mark each for any two: 32 vs 128 bits; denary with dots vs hex with colons; IPv6 gives many more unique addresses.
Q30Network hardware and addressing (NIC, MAC, IP, router) · Challenge · Paper 1 style · 8 marks
  1. (a) A home in Rawalpindi has a router connecting a laptop, two phones and a smart TV to the internet. Describe the role of the router. [3]
  2. (b) Explain the difference between a static IP address and a dynamic IP address, and suggest why a web server would use a static IP address. [3]
  3. (c) Explain why a device has both a MAC address and an IP address. [2]
Show answer
  1. (a) It connects the home network to the internet; it receives data packets and forwards them to the correct device using the IP address; it assigns local IP addresses to devices (DHCP).
    1 mark each for any three of: connects local network to the internet/other networks; receives and forwards packets; reads destination IP address; uses routing table to choose route; assigns IP addresses to devices.
  2. (b) A static IP address does not change; a dynamic IP address is assigned each time a device connects and may change. A web server needs a static address so that DNS records stay correct and users can always find it.
    1 mark: static is permanent/does not change. 1 mark: dynamic is assigned (by the router/ISP) each connection and can change. 1 mark: server needs a fixed address so it can always be located / DNS maps to it reliably.
  3. (c) The MAC address is fixed by the manufacturer and identifies the device on the local network; the IP address identifies the device's location on a network/the internet and is used to route data between networks.
    1 mark: MAC identifies the device physically / unique, set by manufacturer. 1 mark: IP is a logical address that identifies where the device is on the internet, used for routing.
