Q6Error detection (parity, checksum, echo check, check digit, ARQ) · Standard · Paper 1 style · 7 marks
  1. (a) Describe how a checksum is used to detect errors in transmitted data. [4]
  2. (b) A device calculates its checksum as the total of the data values MOD 256. It sends these values: 156, 201, 77, 98, 240. Calculate the checksum. Show your working. [2]
  3. (c) The receiver gets 156, 201, 77, 89, 240 and the checksum 4. Explain whether the error will be detected. [1]
Show answer
  1. (a) Before sending, a value (checksum) is calculated from the data using an agreed algorithm; the checksum is sent with the data; the receiver recalculates the checksum from the data it receives using the same algorithm; if the two checksums are different an error has occurred and the data is requested again.
    1 mark each for: checksum calculated from the block of data before sending; transmitted with the data; recalculated by the receiver using the same algorithm; compared – if they do not match, an error is detected / retransmission requested.
  2. (b) 4
    M1 156 + 201 + 77 + 98 + 240 = 772; A1 772 MOD 256 = 4.
  3. (c) Yes – the receiver's total is 763, and 763 MOD 256 = 251, which does not match 4.
    B1 detected because recalculated checksum 251 ≠ 4.

Q12Error detection (parity, checksum, echo check, check digit, ARQ) · Challenge · Paper 1 style · 6 marks
  1. (a) A satellite sends large blocks of scientific data to a ground station in Pakistan. It takes the signal a long time to travel. Compare the suitability of an echo check and a checksum for this link. [4]
  2. (b) Explain why a parity check on each byte would be less reliable than a checksum for this data. [2]
Show answer
  1. (a) An echo check doubles the transmission (all the data must be sent back), which would be very slow over a long-delay link; the error could also occur on the return journey. A checksum adds only a small value to each block, so little extra data is sent; the ground station can check each block itself and request only the faulty blocks again. So a checksum (with ARQ) is more suitable.
    1 mark each for any four of: echo check sends all data back – doubles traffic/time; long delay makes echo check slow; error may occur on return so ambiguous; checksum adds little extra data; receiver can check without returning data; only faulty blocks resent; conclusion that checksum is more suitable.
  2. (b) A parity check cannot detect an even number of bit errors in a byte, and with noisy signals several bits may change; a checksum based on the whole block is more likely to detect such errors.
    1 mark: parity misses errors where an even number of bits change. 1 mark: checksum covers the whole block / more likely to detect multiple errors.

Q17Transmission methods (serial/parallel, simplex/duplex, USB) · Standard · Paper 1 style · 5 marks
  1. (a) Explain why serial transmission is used for long-distance connections even though parallel transmission sends more bits at once. [4]
  2. (b) Give one situation where parallel transmission is suitable. [1]
Show answer
  1. (a) In parallel transmission the bits travel along separate wires and can arrive at slightly different times (skewing), which becomes worse over long distances and corrupts the data; serial transmission uses one wire so bits arrive in order with no skew; it is also cheaper because fewer wires are needed and suffers less interference (crosstalk).
    1 mark each for any four of: parallel bits can become skewed / arrive out of sync; skew increases with distance; serial has no skew – bits arrive in order; serial needs fewer wires so cheaper; less crosstalk/interference with one wire; serial more reliable over distance.
  2. (b) Over very short distances, such as inside the computer between the CPU and memory (internal buses).
    B1 internal buses / within an integrated circuit / very short connection.

    1 mark: encryption does not stop interception. 1 mark: intercepted data cannot be understood without the key.

(a) Each packet can take a different route through the network, depending on congestion, so some arrive sooner than others; the receiver uses the packet numbers in the headers to put them in order 1–6; it notices packet 4 is missing (by the packet numbers/total) and sends a request for it to be resent (or waits for a timeout); the file is reassembled when all packets have arrived.
    1 mark each for: different routes/traffic cause different arrival times; packet numbers used to reorder; missing packet identified from packet numbers; request for retransmission of packet 4 / timeout then resend.
  2. (b) If one route is congested or broken, packets can be sent another way; only lost/corrupted packets need resending, not the whole file; the network capacity is shared efficiently.
    1 mark each for any two of: avoids busy/broken routes; more reliable; only faulty packets resent; efficient use of network; no need for a dedicated line.
