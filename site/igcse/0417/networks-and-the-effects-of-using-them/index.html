Q1Passwords and authentication · Core · Paper 1 style · 6 marks

Ayesha uses the password ayesha2009 for her school email account.

  1. (a) Explain why this is a weak password. [2]
  2. (b) Give two features of a strong password. [2]
  3. (c) State two other actions Ayesha should take to keep her password secure. [2]
Show answer
  1. (a) It is easy to guess because it uses her own name and probably her year of birth, and it has no capital letters or symbols.
    1 mark each for any two of: contains personal information (her name) | number looks like a birth year/date, easily found | no upper-case letters | no special characters/symbols | all lower case so fewer combinations to try | could be cracked quickly by software trying names/dates.
  2. (b) At least 8 characters long; a mix of upper case, lower case, digits and symbols (and no personal information or dictionary words).
    1 mark each for any two of: at least 8 (or more) characters | mixes upper and lower case letters | includes numbers | includes special characters such as # or ! | not a dictionary word | no personal details such as names or dates.
  3. (c) Change it regularly; never tell it to anyone or write it down (and use a different password for each account).
    1 mark each for any two of: change it regularly | do not share it | do not write it down / store it where others can see | use a different password for each account | log out on shared computers | do not let browser remember it on a shared device | watch for shoulder surfing when typing it.
Q2Passwords and authentication · Core · Paper 1 style · 4 marks
  1. (a) A bank's mobile app asks a customer for a password and then sends a six-digit code by text message to the customer's phone. State the name of this method of authentication. [1]
  2. (b) Explain why this method is more secure than using a password alone. [3]
Show answer
  1. (a) Two-factor authentication (2FA).
    B1 two-factor authentication / two-step verification / multi-factor authentication.
  2. (b) Two different factors are needed: something the user knows (password) and something they have (the phone). A hacker who has stolen the password still cannot log in without the phone, and the code changes every time and expires quickly.
    1 mark each for any three of: needs two separate pieces of evidence | something you know plus something you have | stolen/guessed password alone is not enough | code is sent only to the registered phone | code is one-time / changes every login | code expires after a short time | user is alerted if a code arrives that they did not request.
Q3Passwords and authentication · Standard · Paper 1 style · 6 marks

A hospital in Karachi wants staff to use biometric methods instead of passwords to unlock the computers that hold patient records.

  1. (a) Name two biometric methods the hospital could use. [2]
  2. (b) Describe two advantages of biometric methods over passwords for the hospital staff. [2]
  3. (c) Describe two disadvantages of biometric methods in a hospital. [2]
Show answer
  1. (a) Fingerprint recognition; face (facial) recognition.
    1 mark each for any two of: fingerprint | facial recognition | retina scan | iris scan | voice recognition | hand/palm vein recognition.
  2. (b) Staff cannot forget or lose their fingerprint/face, so no resets are needed; biometrics are unique and very hard to copy or share, so only authorised staff can open records.
    1 mark each for any two expanded points: cannot be forgotten | cannot be lost or left behind | unique to each person so harder to fake | cannot be shared with or lent to a colleague | faster to log in during emergencies | no need to remember many passwords | stops shoulder surfing of a typed password.
  3. (c) Gloves, masks or injuries (cuts, dirty hands) can stop the fingerprint or face being recognised; the scanners are expensive to buy and set up, and the biometric data is personal data that must be protected.
    1 mark each for any two of: surgical gloves/masks may block recognition | cuts, burns or dirt on fingers cause rejection | false rejections delay staff | expensive hardware | data is very personal – privacy concerns | if the stored biometric data is stolen it cannot be changed like a password | takes time to enrol every member of staff.
Q4Passwords and authentication · Standard · Paper 1 style · 6 marks

A company gives each employee a small physical token. When pressed, it shows a number that changes every 30 seconds. Employees type this number after their password to log in from home.

  1. (a) Describe how the physical token and the company's system make sure the number is accepted only once. [3]
  2. (b) Compare a physical token with an electronic token (an authenticator app on a smartphone). [3]
Show answer
  1. (a) The token and the server share a secret and both run the same algorithm using the current time, so they generate the same number; the server checks the typed number matches the one it calculates for that time period, and once used (or after 30 seconds) it is no longer valid.
    1 mark each for any three of: token generates a one-time password (OTP) | token and server use the same algorithm/secret key | the number is linked to the time / changes every 30 s | server generates the same number and compares | if they match access is granted | the number expires and cannot be reused.
  2. (b) Both generate one-time codes used as a second factor and both must be in the user's possession. A physical token is a separate device that can be lost and costs money to issue, whereas the electronic token is software on a phone the user already owns, so it costs less, but it depends on the phone being charged and secure.
    1 mark for a similarity: both create one-time passcodes / both are 'something you have' / both used for two-factor authentication. Up to 2 marks for differences: physical is extra hardware vs app on existing phone | physical costs the company to buy/replace vs app is free/cheap | physical has no network or battery dependence on phone vs app needs a working phone | phone can be infected with malware whereas token is a closed device.
Q5Passwords and authentication · Challenge · Paper 1 style · 8 marks

A school is choosing a way for students to log on to the library computers. The options are: (1) user ID and password, (2) a smart card with a PIN, (3) zero login using face recognition.

  1. (a) Explain what is meant by zero login. [2]
  2. (b) Evaluate the use of smart cards with a PIN for the students rather than user IDs and passwords. [6]
Show answer
  1. (a) The system authenticates the user without them typing anything, by using biometrics and behaviour (for example face, location or how they use the device) to recognise them automatically.
    1 mark each for: no username or password is entered | user is recognised automatically by biometrics / behavioural patterns / known device or location.
  2. (b) Smart cards are quick and need two factors, but cards can be lost, forgotten or swapped and cost money; passwords cost nothing but are often weak or shared. Conclusion: smart cards with PINs are more secure if the school can afford the readers and replacement cards.
    Up to 4 marks for benefits/drawbacks, max 4 on one side; 1–2 marks for a reasoned conclusion. Benefits: two factors (card + PIN) so a stolen card alone is useless | chip data is hard to copy | short PIN easier to remember than complex password | quicker log on | card can also be used for library loans/ID. Drawbacks: cards lost/forgotten so students cannot log on | cost of cards and readers | students may share card and PIN | PIN can be seen by shoulder surfing | replacement takes time. Passwords: no extra cost but often weak/written down/shared. Conclusion must weigh security against cost/convenience.
Q6Passwords and authentication · Challenge · Paper 1 style · 6 marks
  1. (a) A user receives a message that says their online account has been locked after three wrong password attempts. Explain why systems lock an account after a small number of failed attempts. [2]
  2. (b) Magnetic stripe cards and smart cards (chip cards) are both used to authenticate users. Describe two reasons why smart cards are more secure. [2]
  3. (c) Give two reasons why a user should not use the same password for every online account. [2]
Show answer
  1. (a) To stop a hacker using software to try thousands of possible passwords (a brute-force attack); locking after a few attempts makes guessing impractical and alerts the real owner.
    1 mark each for: prevents repeated guessing / brute-force attacks by programs | limits the number of tries so the chance of guessing is tiny / alerts the owner and administrator.
  2. (b) The chip data is encrypted and much harder to copy (clone) than a magnetic stripe; a smart card normally needs a PIN as well, and the chip can create a different code for each transaction.
    1 mark each for any two of: chip data is encrypted | magnetic stripe data is easily read and cloned (skimming) | chip used with a PIN = two factors | chip can generate a unique code each use | magnetic stripe can be damaged by magnets / easier to tamper with.
  3. (c) If one website is hacked and passwords are leaked, criminals can use that password to get into all the user's other accounts; one stolen password then exposes everything (email, bank, social media).
    1 mark each for any two of: a data breach at one site exposes all accounts | criminals try leaked passwords on other sites | the email account could be used to reset other passwords | damage from one phishing attack is multiplied.

Q8Cloud computing and file sharing · Core · Paper 1 style · 5 marks

Bilal is a university student in Lahore. He saves all his assignments to a cloud storage service instead of his laptop's hard disk.

  1. (a) Give three advantages to Bilal of using cloud storage. [3]
  2. (b) Give two disadvantages to Bilal of using cloud storage. [2]
Show answer
  1. (a) He can open his files from any device with internet access, e.g. a university computer; his files are backed up on the provider's servers so they are safe if his laptop is lost or damaged; he can easily share files with classmates.
    1 mark each for any three of: access from anywhere / any device with internet | no need to carry a storage device | automatic backup by provider | files safe if laptop is lost/stolen/broken | easy sharing and collaborating on the same file | extra storage can be bought as needed | files synchronise across devices.
  2. (b) He cannot reach his files without an internet connection; his data is held by a third party, so it could be hacked or lost if the provider has problems.
    1 mark each for any two of: needs an internet connection | slow upload/download on a poor connection | security risk – provider could be hacked | he loses control of his data | provider could go out of business / service outage | ongoing subscription cost for more space | uses mobile data allowance.
Q9Cloud computing and file sharing · Standard · Paper 1 style · 8 marks

A small architecture firm in Islamabad has eight employees. It is deciding whether to use a public cloud service or to keep a server in its own office.

  1. (a) Describe the difference between a public cloud and a private cloud. [2]
  2. (b) Discuss the advantages and disadvantages to the firm of using a public cloud service rather than a server in its office. [6]
Show answer
  1. (a) A public cloud is run by a third-party provider and its servers are shared by many customers over the internet; a private cloud is used by one organisation only, often behind its own firewall and controlled by that organisation.
    1 mark for public: third-party provider / storage shared by many customers / accessed over the internet. 1 mark for private: dedicated to one organisation / controlled by the organisation / behind its firewall.
  2. (b) Public cloud: no server to buy or maintain, provider handles backups and security updates, staff can work from site visits and home, storage can grow easily; but monthly fees continue, a fast reliable internet connection is essential, large drawing files are slow to upload, the firm depends on the provider and client data is held by a third party. Conclusion based on cost and connectivity.
    Max 4 marks for one side; 6th mark for a reasoned conclusion. Advantages: no hardware purchase | no IT staff needed for maintenance | backups done by provider in several locations | access from anywhere (site visits) | easy to increase storage | software/security updated by provider. Disadvantages: needs reliable internet | large CAD files slow to transfer | ongoing subscription | less control over data security | provider outage stops work | legal concerns about where client data is stored.
Q10Cloud computing and file sharing · Standard · Paper 1 style · 6 marks
  1. (a) Three students are writing a group report. They each edit the same document saved in cloud storage at the same time. Describe two benefits of working this way compared with emailing copies of the file to each other. [4]
  2. (b) State two security precautions the students should take when sharing the file. [2]
Show answer
  1. (a) Everyone works on one up-to-date copy, so there is no confusion about which version is newest and no need to merge changes; edits appear immediately and the version history lets them see who changed what and restore earlier versions.
    Two benefits, each 1 mark for identification + 1 mark for expansion: single shared copy – no conflicting versions to merge | real-time editing – see each other's changes instantly | version history – can undo/restore and see who edited | no attachment size limits | comments can be added for discussion.
  2. (b) Share only with named people (not 'anyone with the link'), giving view-only access where editing is not needed; use strong passwords with two-factor authentication on their cloud accounts.
    1 mark each for any two of: share with specific accounts only | set appropriate permissions (view/comment/edit) | do not post the share link publicly | strong passwords on accounts | two-factor authentication | log out on shared computers.
Q11Cloud computing and file sharing · Challenge · Paper 1 style · 6 marks

A manufacturing company keeps its customer database on servers in its own building but stores its marketing videos and staff training files with a cloud provider. Both systems are linked so staff can reach either from the same software.

  1. (a) Identify the type of cloud storage the company is using and justify your answer. [2]
  2. (b) Explain why the company may have chosen to keep the customer database on its own servers. [2]
  3. (c) Explain why public cloud storage is suitable for the videos and training files. [2]
Show answer
  1. (a) Hybrid cloud – it combines a private cloud (the customer database on its own servers) with a public cloud (videos and training files at a provider).
    B1 hybrid. B1 justification: mixture of private (in-house, sensitive data) and public (third party, less sensitive data) linked together.
  2. (b) The customer data is personal and sensitive; keeping it in-house gives the company full control over security and access and helps it meet data protection laws.
    1 mark each for any two of: personal/sensitive data | full control of security | less risk from a third party being hacked | meets data protection rules about where data is held | fast access on the local network without depending on internet.
  3. (c) These files are large and not sensitive, so the provider can store them cheaply and staff in any branch or at home can stream them over the internet without the company buying extra storage.
    1 mark each for any two of: large files would need expensive in-house storage | not confidential, so lower risk | accessible by staff anywhere | provider scales storage as more videos are added | provider handles backups.
Q12Cloud computing and file sharing · Challenge · Paper 1 style · 6 marks
  1. (a) A freelance graphic designer in Dubai syncs her work folder between her laptop and a cloud service. Explain what happens when she edits a file on her laptop while it is offline and then reconnects. [3]
  2. (b) Explain why cloud storage on its own should not be her only backup. [3]
Show answer
  1. (a) The change is saved locally first; when the laptop reconnects the sync software detects the file has changed and uploads the new version to the cloud servers; other synced devices then download the updated version (if the file was also changed elsewhere, a conflict copy may be created).
    1 mark each for any three of: edit stored on the local copy | sync software monitors for changes | on reconnection the new version is uploaded | cloud copy is replaced/updated (old version kept in history) | other devices download the update | if edited in two places a conflicted copy is made.
  2. (b) Syncing copies mistakes too: if she deletes or corrupts a file, or ransomware encrypts it, the damaged version is synced to the cloud. The provider could also suffer an outage or close her account, so she should keep a separate backup, for example on an external drive.
    1 mark each for any three of: deletions/corruption are synced across | ransomware-encrypted files overwrite good copies | provider outage or account lock-out means no access | provider could close / lose data | needs internet to recover | a second, independent backup (external drive/another service) is good practice.

Q15Network devices · Standard · Paper 1 style · 5 marks
  1. (a) Explain the difference between a hub and a switch. [3]
  2. (b) State what is meant by a MAC address. [2]
Show answer
  1. (a) Both connect devices in a LAN. A hub sends every data packet it receives to all connected devices, whereas a switch reads the MAC address of the destination and sends the packet only to that device, so a switch reduces unnecessary traffic and is more secure.
    1 mark for a similarity: both connect devices on a LAN. 1 mark: hub broadcasts packets to all devices. 1 mark: switch uses MAC addresses / a lookup table to send only to the intended device. (Max 3; accept 'switch is more secure / less traffic' as expansion.)
  2. (b) A unique identifier given to a network interface card by the manufacturer, normally written as 12 hexadecimal digits (48 bits).
    1 mark each for any two of: unique number identifying a device/NIC | set by the manufacturer | made up of 48 bits / 12 hexadecimal digits / 6 pairs | part identifies manufacturer, part identifies device.
Q16Network devices · Standard · Paper 1 style · 5 marks

A school computer room has 30 desktop computers connected by cables. The network technician says the room needs a switch, and each computer needs a NIC.

  1. (a) Explain why each computer needs a NIC. [2]
  2. (b) The school wants students' laptops to join the same network without cables. Name the extra device needed and describe what it does. [3]
Show answer
  1. (a) The NIC is the hardware that physically connects the computer to the network (cable or wireless) and gives it a unique MAC address so data can be sent to it.
    1 mark each for: provides the connection/interface to the network | has a unique MAC address so the device can be identified.
  2. (b) A wireless access point (WAP); it connects to the wired network (for example to the switch) and sends and receives data to and from devices by radio waves (Wi-Fi), so wireless devices become part of the LAN.
    B1 wireless access point. Then 1 mark each for any two of: connects to the wired LAN/switch | transmits/receives data using radio waves/Wi-Fi | allows wireless devices to join the LAN | can require a password/encryption key.
Q17Network devices · Challenge · Paper 1 style · 6 marks

A company has two office buildings in different cities. Each building has its own LAN of about 50 computers connected through switches.

  1. (a) Explain how a document sent from a computer in the first office reaches a computer in the second office. Refer to switches and routers in your answer. [4]
  2. (b) The company replaced its old hubs with switches. Give two benefits of doing this. [2]
Show answer
  1. (a) The document is split into packets. The switch in the first office reads the MAC address and forwards the packets to the router. The router reads the destination IP address and sends the packets out over the internet/WAN, where other routers pass them on. The router at the second office receives them and passes them to its switch, which uses the MAC address to deliver them only to the destination computer, where they are reassembled.
    1 mark each for any four of: data split into packets | switch forwards packets within the LAN using MAC addresses | router connects the LAN to the WAN/internet | router uses IP address to route the packets | packets may travel different routes via other routers | receiving router passes packets to its LAN | switch sends to correct computer | packets reassembled in order.
  2. (b) Less network traffic, because data goes only to the intended computer so the network is faster; better security, because other computers do not receive data meant for someone else.
    1 mark each for any two of: less unnecessary traffic | fewer collisions / faster network | more secure as data not broadcast to all | better performance as more devices are added.

A coffee shop in Karachi offers free internet to customers through a WLAN.

Q24Network types (LAN, WLAN, WAN) · Standard · Paper 1 style · 6 marks
  1. (a) A bank has 400 branches across Pakistan. Each branch has its own LAN. Explain why the bank also needs a WAN. [2]
  2. (b) Compare a LAN with a WAN. [4]
Show answer
  1. (a) The branches are spread over a large area, so a WAN is needed to link all the branch LANs to each other and to head office, so customer account data can be shared and updated everywhere.
    1 mark each for: branches far apart / large geographical area | WAN connects the separate LANs so data (customer accounts) can be shared/accessed centrally.
  2. (b) Both connect computers so they can share data and resources. A LAN covers a small area such as one building, whereas a WAN covers a large area such as a country. A LAN normally uses the organisation's own cables and equipment, but a WAN uses leased lines, telephone networks or satellites owned by other companies. LANs usually have faster data transfer than WANs.
    1 mark for a similarity (both share data/resources / both can use routers/switches). Up to 3 marks for linked differences: small area vs large area | own cables/equipment vs public/leased links | faster vs slower | cheaper vs more expensive to run | fewer vs very many connected devices. Comparisons must state both sides.
Q25Network types (LAN, WLAN, WAN) · Challenge · Paper 1 style · 6 marks

A hospital is replacing its cabled LAN on the wards with a WLAN so doctors can use tablet computers at patients' bedsides.

  1. (a) Evaluate the decision to use a WLAN on the wards. [6]
Show answer
  1. (a) Benefits: doctors can update patient records at the bedside immediately, no trailing cables, tablets can be moved between wards, cheaper to add new devices. Drawbacks: signals may be intercepted so strong encryption is needed for confidential data, interference from medical equipment or thick walls may cause dead spots, slower than cable for large scans, tablets need charging and can be lost or stolen. Q26Wi-fi and Bluetooth · Core · Paper 1 style · 4 marks
  1. (a) Give two similarities between Wi-Fi and Bluetooth. [2]
  2. (b) Give two differences between Wi-Fi and Bluetooth. [2]
Show answer
  1. (a) Both are wireless technologies that send data using radio waves; both can be secured using encryption/passwords.
    1 mark each for any two of: both wireless | both use radio waves (both can use the 2.4 GHz band) | both use encryption/security keys | both connect devices without cables | both have limited range.
  2. (b) Wi-Fi has a greater range (up to about 100 m) than Bluetooth (about 10–30 m); Wi-Fi has a faster data transfer rate, so it suits larger files and internet access, while Bluetooth suits a small number of nearby devices.
    1 mark each for any two differences, both sides stated: Wi-Fi longer range vs Bluetooth shorter | Wi-Fi faster vs Bluetooth slower | Wi-Fi connects many devices to a network/internet vs Bluetooth pairs a few devices directly (WPAN) | Bluetooth uses less power.
Q27Wi-fi and Bluetooth · Standard · Paper 1 style · 6 marks

Zainab wants to send a photo from her smartphone to her friend's phone, which is next to her, using Bluetooth.

  1. (a) Describe the steps involved in connecting the two phones using Bluetooth. [4]
  2. (b) Explain why Bluetooth uses spread-spectrum frequency hopping. [2]
Show answer
  1. (a) Turn Bluetooth on in both phones; set the friend's phone to be discoverable; Zainab's phone searches for nearby devices and selects her friend's phone; a pairing code/PIN is shown and confirmed on both phones; the phones are paired and the photo can be sent.
    1 mark each for any four of: switch Bluetooth on on both devices | make receiving device discoverable/visible | sending device searches/scans for devices | select the device from the list | pairing code/PIN is displayed/entered | code confirmed on both devices (matching) | devices paired and connection made | file sent and accepted.
  2. (b) Bluetooth changes randomly between many channels (79) many times a second, which reduces interference from other devices using the same frequencies and makes the transmission harder to intercept.
    1 mark each for: channel/frequency is changed rapidly/randomly among many channels | reduces interference from other devices / makes eavesdropping more difficult.

Q29Internet, intranet and extranet · Standard · Paper 1 style · 6 marks
  1. (a) Describe what is meant by an intranet. [2]
  2. (b) Give three differences between the internet and an intranet. [3]
  3. (c) State one example of information a school might put on its intranet. [1]
Show answer
  1. (a) A private network used inside one organisation, which uses internet technologies such as web pages, and can only be accessed by the organisation's staff (with a login).
    1 mark each for any two of: private network | belongs to one organisation | uses the same protocols/technology as the internet (web pages, browsers) | only accessible by authorised members/employees | usually behind a firewall.
  2. (b) The internet is public and can be used by anyone, an intranet only by members of the organisation; internet information is not controlled and may be unreliable, intranet content is checked and relevant to the organisation; the internet is a worldwide network of networks, an intranet is usually within one organisation's buildings.
    1 mark each for any three linked differences: public vs private | open to anyone vs needs login/authorised | worldwide vs organisation-only | information not moderated vs controlled/policed | huge amount of general information vs company-specific information | intranet more secure/behind firewall.
  3. (c) Homework timetables and class notes for students.
    B1 any suitable internal item: timetables, homework, staff notices, policies, internal forms, exam schedules.
Q30Internet, intranet and extranet · Challenge · Paper 1 style · 8 marks

A car manufacturer allows its parts suppliers to log in to part of its private network to check stock levels and place delivery schedules.

  1. (a) Identify the type of network the suppliers are using and explain your answer. [2]
  2. (b) Discuss the benefits and drawbacks to the manufacturer of giving suppliers this access. [6]
Show answer
  1. (a) An extranet – it is part of the company's intranet that has been opened to authorised people outside the organisation (the suppliers) through a secure login.
    B1 extranet. B1 explanation: private network extended to selected outside users / suppliers given restricted access via login.
  2. (b) Benefits: suppliers see stock levels in real time so parts arrive just in time, fewer phone calls and emails, fewer ordering errors, faster reordering. Drawbacks: security risk if a supplier's login is stolen, cost of setting up secure access and firewalls, must limit what each supplier can see, competitors' information must be protected, dependence on the system working. Conclusion: beneficial if access is controlled and monitored.
    Max 4 for one side; 1–2 marks for conclusion. Benefits: real-time stock information | automatic/just-in-time deliveries | lower admin cost/time | fewer errors | stronger supplier relationship | available 24/7. Drawbacks: unauthorised access/hacking via supplier accounts | set-up and maintenance cost | need strict permissions | confidential data could leak to rival suppliers | downtime stops ordering.
