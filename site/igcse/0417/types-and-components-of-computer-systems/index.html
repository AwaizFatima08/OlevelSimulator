Q1Operating systems and user interfaces · Core · Paper 1 style · 3 marks
  1. (a) State three functions of an operating system. [3]
Show answer
  1. (a) Any three: manages memory; manages the processor/multitasking; manages input and output devices (peripherals) using drivers; manages files and folders (file management); provides a user interface; handles security/user accounts and passwords; handles interrupts and errors; loads/runs application software.
    1 mark each.

Q5Operating systems and user interfaces · Core · Paper 1 style · 2 marks

A railway ticket kiosk in Lahore shows passengers a list of options on the screen, such as 'Buy ticket', 'Check timetable' and 'Cancel'. Choosing an option opens a new list of options. Passengers choose by touching the option on the screen.

  1. (a) Name the type of user interface described. [1]
  2. (b) Give one advantage of this interface for a passenger who has never used a computer. [1]
Show answer
  1. (a) Menu-driven interface
    1 mark. The screen shows lists of options that lead to further lists; there are no windows or commands to type.
  2. (b) Any one: the options are shown on screen so no commands need to be remembered; each choice leads to a clear next step; very little typing is needed.
    1 mark for one valid advantage linked to the passenger.
Q6Operating systems and user interfaces · Standard · Paper 1 style · 6 marks
  1. (a) Describe a command line interface. [2]
  2. (b) Give two advantages and two disadvantages of a command line interface compared with a graphical user interface. [4]
Show answer
  1. (a) The user types instructions/commands using a keyboard at a prompt; commands must be in an exact format/syntax and the computer responds with text output.
    1 mark: typed commands. 1 mark: exact syntax/text-only display.
  2. (b) Advantages: the user can access/configure everything directly, giving more control; uses less memory and processing power; commands can be combined/run as scripts to automate tasks; faster for expert users. Disadvantages: many commands must be learnt/remembered; commands must be typed exactly so errors are easy to make; difficult for beginners; no pictures/icons so less intuitive.
    1 mark each for two advantages and two disadvantages.
Q7Operating systems and user interfaces · Standard · Paper 1 style · 4 marks
  1. (a) A car has a dialogue-based interface for controlling the radio, phone and satnav. Describe how a dialogue-based interface works. [2]
  2. (b) Give one advantage and one disadvantage of using this interface while driving. [2]
Show answer
  1. (a) The user speaks commands into a microphone; voice recognition software compares the words with stored commands and carries out the action, often replying with speech.
    1 mark: spoken commands via microphone. 1 mark: recognised/compared with stored commands and action carried out.
  2. (b) Advantage: the driver keeps hands on the wheel and eyes on the road, so it is safer. Disadvantage: background noise or accents may not be recognised; limited set of commands; the driver may still be distracted.
    1 mark each.
Q8Operating systems and user interfaces · Standard · Paper 1 style · 4 marks
  1. (a) Describe one advantage and one disadvantage of a gesture-based interface on a smart television. [4]
Show answer
  1. (a) Advantage: no remote control is needed so it cannot be lost; natural/intuitive movements so easy for young children; hygienic as nothing is touched.     1 mark for each advantage/disadvantage, 1 mark each for its expansion (2 + 2).
Q9Operating systems and user interfaces · Standard · Paper 1 style · 3 marks

A school network uses a server. Before a pupil can open the shared folders, the server checks the pupil's user name and password.

  1. (a) Name the operating system function that checks user names and passwords and controls which folders each user can open. [1]
  2. (b) Describe one other function that the operating system on the server performs. [2]
Show answer
  1. (a) User management (user accounts and access rights / security)
    1 mark. Accept 'security' if the answer refers to login and access rights.
  2. (b) Any one, e.g. file management: it stores, names and organises files on the server's storage; memory management: it allocates RAM to the programs that are running; peripheral management: it handles printing requests from the network.
    1 mark for naming a valid function. 1 mark for a description that relates to the server.
Q10Operating systems and user interfaces · Standard · Paper 1 style · 4 marks

A driver in Sindh uses a satellite navigation (satnav) system that responds to spoken commands such as 'Navigate to Hyderabad' while both hands stay on the steering wheel.

  1. (a) Describe how a voice-controlled user interface works. [2]
  2. (b) Give two drawbacks of this interface for a driver on a busy road. [2]
Show answer
  1. (a) The user speaks a command into a microphone; the software converts the speech into text and recognises the command; the system carries out the command and responds, for example with speech or a message on the screen.
    1 mark: the user speaks a command that is picked up by a microphone. 1 mark: software recognises and interprets the speech, then carries out the command.
  2. (b) Any two: background noise (traffic or radio) can cause commands to be misheard; the driver may be distracted by speaking and listening rather than watching the road; commands must be said in the exact form the system expects; a strong accent may be misunderstood.
    1 mark for each valid drawback with a reason.
Q11Operating systems and user interfaces · Challenge · Paper 1 style · 5 marks
  1. (a) Compare a dialogue-based interface with a gesture-based interface. [5]
Show answer
  1. (a) Similarities: both are natural/intuitive ways to give commands without a keyboard or mouse; both allow hands-free or touch-free control (e.g. of a smart TV or car system); both rely on software to recognise the input and compare it with stored commands; both can misinterpret input and have a limited set of commands that must be learnt. Differences: a dialogue-based interface uses spoken commands picked up by a microphone, whereas a gesture-based interface uses body/hand movements detected by a camera or motion sensors; a dialogue-based interface is affected by background noise and accents, whereas a gesture-based interface is affected by poor lighting or the user being out of the camera's view; a dialogue-based interface lets the user keep hands on another task (e.g. driving), whereas gestures need the hands/body to move; gestures can be used in noisy places or where speaking is unsuitable, whereas speech cannot.
    1 mark per valid comparative point, up to 5; at least one similarity and one difference needed for full marks. Points must link the two interfaces, not be two separate lists.
Q12Operating systems and user interfaces · Challenge · Paper 1 style · 6 marks
  1. (a) A technician manages 300 computers on a school network. She can use either a command line interface or a graphical user interface. Discuss which type of interface would be better for her work. [6]
Show answer
  1. (a) CLI: can write scripts to carry out the same task (e.g. installing updates, creating user accounts) on all 300 computers automatically; direct access to system settings; uses fewer resources so works on remote/low-powered machines; faster for an expert; but she must remember exact commands and a typing error could damage many machines. GUI: easier to learn and see the effects; fewer errors through choosing from menus; visual tools can show the network clearly; but repetitive tasks on 300 machines are slow, needs more memory, some settings may not be available. Conclusion: CLI is likely better for an experienced technician doing repetitive network tasks, perhaps with GUI tools for occasional jobs.
    Max 4 if only one interface discussed. 1 mark per expanded point applied to the scenario; 1 mark for a reasoned conclusion.
Q13Operating systems and user interfaces · Challenge · Paper 1 style · 4 marks
  1. (a) Smartphones use a post-WIMP interface. Explain how the interface of a smartphone differs from the WIMP interface of a desktop computer. [4]
Show answer
  1. (a) A smartphone uses a touch screen, so fingers replace the mouse pointer; actions are made with gestures such as tap, swipe, pinch to zoom and rotate, which WIMP does not use; there are usually no overlapping windows — apps fill the whole screen; icons are larger so they can be pressed with a finger; menus are often hidden or replaced by on-screen buttons.
    1 mark each for any four valid explained differences.
Q14Operating systems and user interfaces · Challenge · Paper 1 style · 6 marks

An Islamabad bank is choosing a user interface for 150 cashiers. Each cashier uses the same five transactions all day: deposit, withdrawal, balance enquiry, transfer and print statement.

  1. (a) Discuss whether a command line interface, a graphical user interface (GUI) or a menu-driven interface is the most suitable for the cashiers. [6]
Show answer
  1. (a) Sample points. Command line: fast for expert users, but cashiers would have to memorise commands and typing errors are easy to make. GUI: icons and windows are easy to learn, but each transaction may need several clicks and screens and it uses more processing power. Menu-driven: each of the five transactions is one option, quick to learn, and only valid options are shown, so fewer errors; less flexible if new transactions are added. Conclusion: a menu-driven interface (or a simple GUI with large buttons for the five transactions) is most suitable because the work is repetitive, the choices are limited and staff must learn quickly.
    Up to 6 marks: 2 marks for clear points on each interface type linked to this work (command line, GUI and menu-driven, given with reasons), and 2 marks for a balanced conclusion that is justified. Points that describe an interface without linking to cashiers or the five transactions score at most half marks.
Q15Operating systems and user interfaces · Challenge · Paper 1 style · 4 marks

A shared laser printer in an office is used by twelve computers on a network. Several people send print jobs at almost the same time.

  1. (a) Explain the role of the operating system in managing these print jobs. [4]
Show answer
  1. (a) The operating system (with the print spooler) stores each job in a print queue; jobs are printed in order, first in first out; the next job is sent when the printer is ready; status and error messages are shown; users can pause or delete their own waiting jobs; the printer is handled as a peripheral through its driver.
    1 mark each for any four: jobs stored in a queue; queue order is kept; next job sent when printer is free; status or error messages; a job can be paused or deleted; the printer is controlled through the operating system and its driver.

Q21Types of computer · Standard · Paper 1 style · 4 marks
  1. (a) Compare a phablet with a smartphone. [4]
Show answer
  1. (a) Similarities: both can make calls and send messages; both have touch screens, internet access, cameras and run apps; both are portable and use mobile networks. Q28Types of computer · Challenge · Paper 1 style · 7 marks

A hospital keeps all patient records on a central server. Forty computers in the wards and offices access the records through the hospital network.

  1. (a) Name this type of computer and explain one benefit of storing the records centrally. [3]
  2. (b) Describe two risks of storing all the records on one central server, and one way to reduce each risk. [4]
Show answer
  1. (a) Server. Benefit: all staff see the same up-to-date copy of each record; there is only one copy, so no conflicting versions; backups and security can be managed from one place.
    1 mark for 'server'. 2 marks for a benefit that is explained (1 mark for the benefit, 1 for the explanation).
  2. (b) Any two risks with a reduction: if the server fails, records may be lost or unavailable, so use regular backups and a second server; hackers could reach every record, so use passwords, encryption and a firewall; the network could fail and staff cannot reach the records, so use a backup connection.
    1 mark per valid risk and 1 mark per matching way to reduce it (4 marks maximum).
Q29Types of computer · Challenge · Paper 1 style · 6 marks

Q31Internal components and memory · Core · Paper 1 style · 3 marks
  1. (a) Name the type of internal memory that holds the operating system, programs and data currently in use. [1]
  2. (b) A student's computer becomes slow when several programs are open at the same time. Explain why adding more RAM could make the computer run faster. [2]
Show answer
  1. (a) RAM (random access memory)
    1 mark.
  2. (b) More programs and data can be held in RAM at the same time, so less data has to be moved between RAM and backing storage (e.g. the hard disk), which is much slower to access.
    1 mark: more programs/data can be stored in RAM at once. 1 mark: less swapping to/from slower backing storage.
Q32Internal components and memory · Core · Paper 1 style · 4 marks

A student is revising the parts of the central processing unit (CPU) of a computer.

  1. (a) Name the part of the CPU that carries out arithmetic and logic operations. [1]
  2. (b) State the purpose of the control unit. [2]
  3. (c) Name one other part of the CPU that temporarily holds data or instructions. [1]
Show answer
  1. (a) Arithmetic logic unit (ALU)
    1 mark.
  2. (b) It controls and co-ordinates the operation of the CPU: it fetches instructions from memory, decodes them and sends control signals to the other parts of the computer.
    1 mark for controls or co-ordinates the operations. 1 mark for a valid detail (fetches and decodes instructions, or sends control signals).
  3. (c) Registers (accept: cache memory).
    1 mark. Accept 'registers' or 'cache' as a small store on or very close to the CPU.
Q33Internal components and memory · Core · Paper 1 style · 3 marks

  1. (a) Name two components that are normally fixed to the motherboard. [2]
  2. (b) Describe one function of the motherboard. [1]
Show answer
  1. (a) Any two of: the CPU socket or processor; RAM slots; the chipset; expansion slots; the BIOS/ROM chip.
    1 mark each for a valid component. Accept 'CPU' and 'RAM' only if they are described as sockets or slots on the motherboard.
  2. (b) It connects the components so that they can communicate, for example carrying data and signals between the CPU, memory and other devices.
    1 mark for a valid function.
Q34Internal components and memory · Core · Paper 1 style · 4 marks

A processor has a small amount of cache memory.

  1. (a) State what is meant by cache memory. [2]
  2. (b) Explain why cache memory is faster than RAM. [2]
Show answer
  1. (a) A small and very fast memory, inside or very close to the CPU, that holds frequently used data or instructions so that the CPU does not have to wait for the slower RAM.
    1 mark: small and very fast memory. 1 mark: holds data or instructions the CPU needs often, avoiding waits for RAM.
  2. (b) Cache is on or close to the CPU, so data travels a shorter distance; it uses faster (more expensive) memory technology than RAM.
    1 mark for being closer to the CPU or on the CPU. 1 mark for faster technology or shorter distance explained.

(iii) processes image data and sends the output to the monitor/screen. (iv) the main circuit board that connects all components together and allows them to communicate.
    1 mark each.
Q36Internal components and memory · Standard · Paper 1 style · 3 marks
  1. (a) A washing machine contains a microprocessor and a small amount of ROM. Explain why the washing programmes (cycles) are stored in ROM. [2]
  2. (b) The washing machine also has some RAM. Suggest what might be stored in the RAM. [1]
Show answer
  1. (a) The programmes must not be lost when the machine is switched off, so non-volatile ROM is needed; the user should not be able to change/erase them accidentally, so read-only memory is suitable.
    1 mark: non-volatile. 1 mark: cannot be altered.
  2. (b) e.g. the current settings chosen by the user (temperature, spin speed, delay time); the current stage of the cycle/time remaining; sensor readings such as water level or temperature.
    1 mark.

    1 mark each for any four: minimum requirements not met; not enough RAM or processor speed; the OS version is too old or not supported; the graphics hardware or drivers do not support the software.
Q75Hardware and software · Challenge · Paper 1 style · 5 marks

A company uses a database application, a spreadsheet application and a utility that backs up its files every night.

  1. (a) Explain why the company should use a utility that backs up its data automatically, and why the backups should be kept in a different location from the computers. [5]
Show answer
  1. (a) Automatic backup means backups are not forgotten, so little work is lost if a fault happens; a separate location protects the backups from fire, flood, theft or malware on the main computers; a backup kept in another building is still usable if the main site is destroyed; regular test restores check the backups actually work.
    Up to 5 marks, 1 mark each for: automatic backup is reliable and regular; backup is up to date so little data is lost; separate location protects against fire, flood or theft; backups are not infected by malware on the main computers; backups must be checked or restorable.
