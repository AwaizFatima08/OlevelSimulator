Practice questions

Original questions written by HomiLabs in the style of the exam, with answers and mark schemes. They are not Cambridge past paper questions and have not been reviewed by Cambridge. Try each one before opening the answer.

Q1Operating systems and user interfaces · Core · Paper 1 style · 3 marks
  1. (a) State three functions of an operating system. [3]
Show answer
  1. (a) Any three: manages memory; manages the processor/multitasking; manages input and output devices (peripherals) using drivers; manages files and folders (file management); provides a user interface; handles security/user accounts and passwords; handles interrupts and errors; loads/runs application software.
    1 mark each.
Q2Operating systems and user interfaces · Core · Paper 1 style · 4 marks
  1. (a) Name the type of user interface described in each statement.(i) The user types commands such as copy report.txt backup at a prompt.(ii) The user clicks icons and chooses options from menus using a pointer.(iii) The user says 'call home' to a phone, which carries out the action.(iv) The user waves a hand in front of a smart TV's camera to change the channel. [4]
Show answer
  1. (a) (i) command line interface (CLI) (ii) graphical user interface (GUI) (iii) dialogue-based interface (iv) gesture-based interface
    1 mark each.
Q3Operating systems and user interfaces · Core · Paper 1 style · 3 marks
  1. (a) A graphical user interface is often called a WIMP interface. State what each letter of WIMP stands for. [2]
  2. (b) Give one reason why a GUI is suitable for a young child using a computer for the first time. [1]
Show answer
  1. (a) Windows, Icons, Menus, Pointer (or pointing device)
    2 marks all four; 1 mark for two or three.
  2. (b) The child does not need to learn/type commands — they can click/tap pictures (icons) that are easy to recognise.
    1 mark.
Q4Operating systems and user interfaces · Standard · Paper 1 style · 6 marks
  1. (a) Describe a command line interface. [2]
  2. (b) Give two advantages and two disadvantages of a command line interface compared with a graphical user interface. [4]
Show answer
  1. (a) The user types instructions/commands using a keyboard at a prompt; commands must be in an exact format/syntax and the computer responds with text output.
    1 mark: typed commands. 1 mark: exact syntax/text-only display.
  2. (b) Advantages: the user can access/configure everything directly, giving more control; uses less memory and processing power; commands can be combined/run as scripts to automate tasks; faster for expert users. Disadvantages: many commands must be learnt/remembered; commands must be typed exactly so errors are easy to make; difficult for beginners; no pictures/icons so less intuitive.
    1 mark each for two advantages and two disadvantages.
Q5Operating systems and user interfaces · Standard · Paper 1 style · 4 marks
  1. (a) A car has a dialogue-based interface for controlling the radio, phone and satnav. Describe how a dialogue-based interface works. [2]
  2. (b) Give one advantage and one disadvantage of using this interface while driving. [2]
Show answer
  1. (a) The user speaks commands into a microphone; voice recognition software compares the words with stored commands and carries out the action, often replying with speech.
    1 mark: spoken commands via microphone. 1 mark: recognised/compared with stored commands and action carried out.
  2. (b) Advantage: the driver keeps hands on the wheel and eyes on the road, so it is safer. Disadvantage: background noise or accents may not be recognised; limited set of commands; the driver may still be distracted.
    1 mark each.
Q6Operating systems and user interfaces · Standard · Paper 1 style · 4 marks
  1. (a) Describe one advantage and one disadvantage of a gesture-based interface on a smart television. [4]
Show answer
  1. (a) Advantage: no remote control is needed so it cannot be lost; natural/intuitive movements so easy for young children; hygienic as nothing is touched. Disadvantage: unintended movements may be read as commands; the user must learn/remember the gestures; may not work well in poor light or if the user is out of the camera's view; can be tiring to use.
    1 mark for each advantage/disadvantage, 1 mark each for its expansion (2 + 2).
Q7Operating systems and user interfaces · Challenge · Paper 1 style · 5 marks
  1. (a) Compare a dialogue-based interface with a gesture-based interface. [5]
Show answer
  1. (a) Similarities: both are natural/intuitive ways to give commands without a keyboard or mouse; both allow hands-free or touch-free control (e.g. of a smart TV or car system); both rely on software to recognise the input and compare it with stored commands; both can misinterpret input and have a limited set of commands that must be learnt. Differences: a dialogue-based interface uses spoken commands picked up by a microphone, whereas a gesture-based interface uses body/hand movements detected by a camera or motion sensors; a dialogue-based interface is affected by background noise and accents, whereas a gesture-based interface is affected by poor lighting or the user being out of the camera's view; a dialogue-based interface lets the user keep hands on another task (e.g. driving), whereas gestures need the hands/body to move; gestures can be used in noisy places or where speaking is unsuitable, whereas speech cannot.
    1 mark per valid comparative point, up to 5; at least one similarity and one difference needed for full marks. Points must link the two interfaces, not be two separate lists.
Q8Operating systems and user interfaces · Challenge · Paper 1 style · 6 marks
  1. (a) A technician manages 300 computers on a school network. She can use either a command line interface or a graphical user interface. Discuss which type of interface would be better for her work. [6]
Show answer
  1. (a) CLI: can write scripts to carry out the same task (e.g. installing updates, creating user accounts) on all 300 computers automatically; direct access to system settings; uses fewer resources so works on remote/low-powered machines; faster for an expert; but she must remember exact commands and a typing error could damage many machines. GUI: easier to learn and see the effects; fewer errors through choosing from menus; visual tools can show the network clearly; but repetitive tasks on 300 machines are slow, needs more memory, some settings may not be available. Conclusion: CLI is likely better for an experienced technician doing repetitive network tasks, perhaps with GUI tools for occasional jobs.
    Max 4 if only one interface discussed. 1 mark per expanded point applied to the scenario; 1 mark for a reasoned conclusion.
Q9Operating systems and user interfaces · Challenge · Paper 1 style · 4 marks
  1. (a) Smartphones use a post-WIMP interface. Explain how the interface of a smartphone differs from the WIMP interface of a desktop computer. [4]
Show answer
  1. (a) A smartphone uses a touch screen, so fingers replace the mouse pointer; actions are made with gestures such as tap, swipe, pinch to zoom and rotate, which WIMP does not use; there are usually no overlapping windows — apps fill the whole screen; icons are larger so they can be pressed with a finger; menus are often hidden or replaced by on-screen buttons.
    1 mark each for any four valid explained differences.
Q10Types of computer · Core · Paper 1 style · 2 marks
  1. (a) Give two advantages of a desktop computer compared with a laptop for a family's home use. [2]
Show answer
  1. (a) Any two: usually cheaper for the same specification; easier to upgrade/repair parts; full-size keyboard and larger monitor are more comfortable; less likely to be stolen or dropped; better cooling so less overheating; often more powerful.
    1 mark each.
Q11Types of computer · Core · Paper 1 style · 3 marks
  1. (a) Give three uses of a smartphone other than making phone calls. [3]
Show answer
  1. (a) Any three: sending text/instant messages; accessing the internet/browsing; sending emails; taking photos/videos; using satnav/maps; online banking/payments; social media; playing games/music; video calling; using apps such as a calculator or calendar.
    1 mark each.
Q12Types of computer · Core · Paper 1 style · 3 marks
  1. (a) Name the type of computer described in each statement.(i) A large, powerful computer with a separate monitor, keyboard and mouse that stays in one place.(ii) A thin, portable device with only a touch screen, larger than a phone, usually without a physical keyboard.(iii) A device that combines the features of a smartphone and a tablet, with a screen larger than a typical phone. [3]
Show answer
  1. (a) (i) desktop computer (ii) tablet (iii) phablet
    1 mark each.
Q13Types of computer · Standard · Paper 1 style · 4 marks
  1. (a) Compare a phablet with a smartphone. [4]
Show answer
  1. (a) Similarities: both can make calls and send messages; both have touch screens, internet access, cameras and run apps; both are portable and use mobile networks. Differences: a phablet has a larger screen than a smartphone (between a phone and a tablet); a phablet is easier for reading and watching video; a smartphone is smaller and lighter so fits in a pocket more easily; a phablet usually has a bigger battery but uses more power; a phablet is harder to use with one hand.
    1 mark per valid comparative point up to 4; at least one similarity and one difference for full marks.
Q14Types of computer · Standard · Paper 1 style · 4 marks
  1. (a) Census workers in rural Sindh use tablet computers to record household information. Give two advantages and two disadvantages of using tablets for this work. [4]
Show answer
  1. (a) Advantages: light and portable, easy to carry between houses; long battery life; touch screen with on-screen forms that can validate data; data can be sent to the central database immediately via mobile network; built-in camera/GPS records location. Disadvantages: touch screen typing slower than a keyboard; small screen; can be stolen or damaged; battery may run out with no charging point; poor mobile signal in remote areas prevents sending data.
    1 mark each for two advantages and two disadvantages applied to the scenario.
Q15Types of computer · Standard · Paper 1 style · 4 marks
  1. (a) Describe two features of a laptop computer that make it suitable for a salesperson who travels between cities. [2]
  2. (b) Give two disadvantages of laptops for the salesperson. [2]
Show answer
  1. (a) Any two: lightweight and portable with a built-in keyboard, screen and touchpad (all in one unit); runs on a rechargeable battery so it can be used on trains/in hotels without mains power; built-in Wi-fi to connect to networks; built-in webcam for video conferencing.
    1 mark each.
  2. (b) Any two: easily stolen or lost when travelling; battery needs recharging/runs out; can be damaged if dropped; can overheat; small keyboard/screen can cause strain over long periods.
    1 mark each.
Q16Types of computer · Challenge · Paper 1 style · 6 marks
  1. (a) A secondary school in Islamabad plans to replace the desktop computers in its computer room with laptops that students can also take to other classrooms. Discuss the advantages and disadvantages of this plan. [6]
Show answer
  1. (a) Advantages: laptops can be used in any classroom, so ICT can be used in other subjects; take up less space; use less electricity; can work during power cuts using batteries; can connect wirelessly to the network; students can work in groups anywhere. Disadvantages: more expensive for the same performance; easier to steal or drop/damage; batteries wear out and need charging/charging trolleys; smaller screens and keyboards may cause poor posture; harder to upgrade/repair; Wi-fi may be slower than wired connections; can overheat. Conclusion.
    Max 4 for one side only. 1 mark per expanded point; 1 mark for a reasoned conclusion.
Q17Types of computer · Challenge · Paper 1 style · 5 marks
  1. (a) A university student is deciding whether to buy a tablet or a laptop for writing assignments and attending online lectures. Compare a tablet with a laptop for this student. [5]
Show answer
  1. (a) Similarities: both portable with batteries; both can connect to Wi-fi to attend online lectures; both have screens, cameras and microphones for video calls. Differences: a laptop has a physical keyboard and touchpad so typing long assignments is quicker, whereas a tablet relies on an on-screen keyboard; a tablet is lighter and smaller so easier to carry; a laptop usually has more storage and processing power and runs full versions of software; a tablet usually has longer battery life; a laptop has more ports (USB) for connecting devices.
    1 mark per valid comparative point up to 5; at least one similarity and one difference; points must relate the two devices.
Q18Internal components and memory · Core · Paper 1 style · 3 marks
  1. (a) Name the type of internal memory that holds the operating system, programs and data currently in use. [1]
  2. (b) A student's computer becomes slow when several programs are open at the same time. Explain why adding more RAM could make the computer run faster. [2]
Show answer
  1. (a) RAM (random access memory)
    1 mark.
  2. (b) More programs and data can be held in RAM at the same time, so less data has to be moved between RAM and backing storage (e.g. the hard disk), which is much slower to access.
    1 mark: more programs/data can be stored in RAM at once. 1 mark: less swapping to/from slower backing storage.
Q19Internal components and memory · Standard · Paper 1 style · 4 marks
  1. (a) State the purpose of each internal component.(i) Central processing unit (CPU)(ii) Network interface card (NIC)(iii) Graphics card(iv) Motherboard [4]
Show answer
  1. (a) (i) processes instructions/carries out calculations and controls the computer. (ii) allows the computer to connect to a network. (iii) processes image data and sends the output to the monitor/screen. (iv) the main circuit board that connects all components together and allows them to communicate.
    1 mark each.
Q20Internal components and memory · Standard · Paper 1 style · 3 marks
  1. (a) A washing machine contains a microprocessor and a small amount of ROM. Explain why the washing programmes (cycles) are stored in ROM. [2]
  2. (b) The washing machine also has some RAM. Suggest what might be stored in the RAM. [1]
Show answer
  1. (a) The programmes must not be lost when the machine is switched off, so non-volatile ROM is needed; the user should not be able to change/erase them accidentally, so read-only memory is suitable.
    1 mark: non-volatile. 1 mark: cannot be altered.
  2. (b) e.g. the current settings chosen by the user (temperature, spin speed, delay time); the current stage of the cycle/time remaining; sensor readings such as water level or temperature.
    1 mark.
Q21Internal components and memory · Challenge · Paper 1 style · 6 marks
  1. (a) Compare RAM and ROM. [4]
  2. (b) Explain why the instructions used to start up a computer are stored in ROM rather than RAM. [2]
Show answer
  1. (a) Similarities: both are internal memory/directly accessed by the CPU; both are solid-state chips on the motherboard; both store data/instructions. Differences: RAM is volatile while ROM is non-volatile; RAM is read/write while ROM is read-only; RAM holds the OS, programs and data currently in use while ROM holds the boot program/BIOS; RAM is usually much larger in capacity.
    1 mark per valid comparative point; at least one similarity and one difference for full marks.
  2. (b) ROM is non-volatile so the instructions are still there when the computer is switched on (RAM is empty at start-up); ROM is read-only so the instructions cannot be accidentally erased or changed.
    1 mark each.
Q22Internal components and memory · Challenge · Paper 1 style · 4 marks
  1. (a) A journalist is typing a news report in a word processor when there is a power cut. She had last saved the report 20 minutes earlier. Explain what happens to her work and why. [3]
  2. (b) Give one way she could reduce the amount of work lost in future. [1]
Show answer
  1. (a) While she types, the word processor and the open document are held in RAM; RAM is volatile, so its contents are lost when the power is cut; the work typed in the last 20 minutes is lost and only the version saved to backing storage (which is non-volatile) remains.
    1 mark: document being edited is in RAM. 1 mark: RAM is volatile/contents lost. 1 mark: only saved copy on backing storage kept/last 20 minutes lost.
  2. (b) e.g. save more often / turn on the autosave (autorecover) option; use an uninterruptible power supply (UPS); use cloud software that saves continuously; use a laptop with a charged battery.
    1 mark.
Q23Emerging technologies · Core · Paper 1 style · 3 marks
  1. (a) Describe the difference between virtual reality (VR) and augmented reality (AR). [2]
  2. (b) Give one example of a use of AR. [1]
Show answer
  1. (a) VR creates a completely computer-generated 3D environment that replaces the real world, usually seen through a headset. AR overlays computer-generated images/information onto the user's view of the real world, e.g. through a phone camera or glasses.
    1 mark: VR = fully artificial environment replacing reality. 1 mark: AR = digital content added to the real world.
  2. (b) e.g. seeing how furniture would look in a room through a phone app; games such as catching virtual creatures in real places; showing directions on a car windscreen (head-up display); showing labels on museum exhibits; virtual try-on of glasses/clothes.
    1 mark.
Q24Emerging technologies · Standard · Paper 1 style · 4 marks
  1. (a) An airline trains its pilots using virtual reality. Give three advantages of using VR for this training. [3]
  2. (b) Give one disadvantage of VR training. [1]
Show answer
  1. (a) Any three: dangerous situations (engine failure, bad weather) can be practised safely; no risk to aircraft or passengers; cheaper than using real aircraft/no fuel used; scenarios can be repeated as many times as needed; the trainee's performance can be recorded and reviewed; training can take place at any time regardless of weather.
    1 mark each.
  2. (b) e.g. headsets can cause motion sickness/headaches/eye strain; equipment is expensive; it may not feel exactly like the real situation.
    1 mark.
Q25Emerging technologies · Standard · Paper 1 style · 4 marks
  1. (a) Artificial intelligence (AI) is used in many everyday applications. Describe two examples of AI being used in everyday life. [4]
Show answer
  1. (a) Any two, described: chatbots on websites answer customers' questions by understanding their messages; voice assistants recognise speech and answer questions/carry out commands; streaming and shopping websites recommend films or products based on what the user has watched/bought before; self-driving or driver-assist cars use sensors and AI to recognise road signs, lanes and obstacles; email spam filters learn to recognise spam; facial recognition to unlock phones.
    For each example: 1 mark for naming a valid use, 1 mark for describing how AI is involved.
Q26Emerging technologies · Challenge · Paper 1 style · 6 marks
  1. (a) A furniture shop in Karachi is planning an augmented reality app that lets customers see how its sofas and tables would look in their own homes. Discuss the benefits and drawbacks of this app for the shop. [6]
Show answer
  1. (a) Benefits: customers can see the size, colour and fit of furniture in their own room before buying, so fewer returns; more confidence leads to more online sales; customers who cannot visit the shop can still choose; modern image attracts younger customers; fewer display models needed in the showroom. Drawbacks: expensive to develop and maintain the app and 3D models of every product; customers need a suitable smartphone; the app may show sizes or colours inaccurately, causing complaints; customers cannot feel the comfort or material; the app must be updated when stock changes. Conclusion.
    Max 4 for one side only. 1 mark per expanded point applied to the shop; 1 mark for a reasoned conclusion.
Q27Hardware and software · Core · Paper 1 style · 4 marks
  1. (a) Explain the difference between hardware and software. [2]
  2. (b) Classify each of these as internal hardware or external hardware: motherboard, printer, RAM, monitor. [2]
Show answer
  1. (a) Hardware is the physical parts of a computer system that can be touched, e.g. keyboard, processor. Software is the programs/instructions that tell the computer what to do, e.g. an operating system, a word processor.
    1 mark: hardware = physical components. 1 mark: software = programs/instructions.
  2. (b) Internal: motherboard, RAM. External: printer, monitor.
    2 marks all four; 1 mark for two or three.
Q28Hardware and software · Core · Paper 1 style · 3 marks
  1. (a) State whether each item is system software or application software:(i) spreadsheet(ii) compiler(iii) photo editing software(iv) device driver(v) operating system(vi) video editing software [3]
Show answer
  1. (a) System: compiler, device driver, operating system. Application: spreadsheet, photo editing software, video editing software.
    3 marks all six correct; 2 marks four or five; 1 mark two or three.
Q29Hardware and software · Standard · Paper 1 style · 5 marks
  1. (a) Describe the purpose of each type of system software.(i) Device driver(ii) Compiler(iii) Utility software [3]
  2. (b) Give two examples of utility software. [2]
Show answer
  1. (a) (i) allows the operating system to communicate with/control a hardware device such as a printer. (ii) translates a whole program written in a high-level language into machine code so it can be run. (iii) carries out specific tasks to maintain/look after the computer, e.g. anti-virus, backup, defragmentation, compression.
    1 mark each.
  2. (b) Any two: anti-virus; anti-spyware; backup; disk defragmenter; file compression; disk formatter; file management/security (encryption) software.
    1 mark each.
Q30Hardware and software · Challenge · Paper 1 style · 6 marks
  1. (a) Compare system software with application software. [4]
  2. (b) Explain why a new computer needs an operating system before the user can run a word processor. [2]
Show answer
  1. (a) Similarities: both are programs/instructions stored on the computer; both are needed for the user to do useful work. Differences: system software controls and manages the computer hardware and provides a platform for other software, whereas application software lets the user carry out specific tasks (e.g. writing letters); application software cannot run without system software (an operating system) but system software can run without applications; system software usually runs in the background, whereas the user interacts directly with application software; examples: operating system/compiler vs word processor/spreadsheet.
    1 mark per valid comparative point; at least one similarity and one difference for full marks.
  2. (b) The word processor relies on the operating system to manage memory, the processor, files and devices (e.g. keyboard, printer) and to provide the user interface; without the operating system the word processor cannot load or communicate with the hardware.
    1 mark: OS manages hardware/resources for the application. 1 mark: application cannot be loaded/run or use devices without it.
