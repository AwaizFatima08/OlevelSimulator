Q1Formulas and functions · Core · Paper 1 style · 4 marks
  1. (a) Explain the difference between a formula and a function in a spreadsheet. [2]
  2. (b) Give one example of each, using cell references. [2]
Show answer
  1. (a) A formula is a calculation entered by the user, using cell references, values and operators, e.g. =B2*C2. A function is a predefined/built-in named operation in the software that carries out a calculation on given arguments/a range, e.g. =SUM(B2:B10).
    1 mark: formula = user-written calculation with operators/cell references. 1 mark: function = built-in/predefined named routine. Examples alone not enough.
  2. (b) Formula e.g. =D4-E4 or =B3*1.17; function e.g. =AVERAGE(C2:C20) or =MAX(B2:B9).
    1 mark for a valid formula; 1 mark for a valid function.
