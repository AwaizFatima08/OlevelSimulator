Q1Direct data entry devices (bar codes, RFID, QR) · Core · Paper 1 style · 3 marks
  1. (a) A public library in Lahore is replacing the bar code labels in its books with RFID tags. State two advantages to the library of using RFID tags rather than bar codes. [2]
  2. (b) State one disadvantage to the library of using RFID tags. [1]
Show answer
  1. (a) Any two, e.g. several books can be read at the same time; no line of sight is needed so books need not be turned to face the reader; tags can be read through covers/bags; tags are harder to damage than printed labels; data on the tag can be changed/updated.
    1 mark each for any two distinct advantages. Do not accept 'faster' alone without a reason.
  2. (b) Any one, e.g. tags cost more than bar code labels; tags can be read by unauthorised readers nearby; signals can be blocked/jammed by metal or interference; tags on adjacent books may be read by mistake.
    1 mark for one valid disadvantage.

Q3Direct data entry devices (bar codes, RFID, QR) · Core · Paper 1 style · 4 marks
  1. (a) Describe the steps that take place when a cashier scans the bar code on a tin of beans at a supermarket checkout. [4]
Show answer
  1. (a) The reader shines (red/laser) light on the bar code; the light is reflected from the white spaces, not the black bars; the reflections are converted into a number (product code); the code is looked up in the stock database/file; the price and description are sent back to the till and shown/printed on the receipt; the stock level for the item is reduced by 1.
    1 mark per step, max 4.
Q4Direct data entry devices (bar codes, RFID, QR) · Core · Paper 1 style · 4 marks

A hotel in Murree gives each guest a plastic key card with a magnetic stripe. The guest swipes the card through a reader on the room door.

  1. (a) Describe how the data on the key card is read when it is swiped. [2]
  2. (b) Give two disadvantages of magnetic stripe key cards compared with key cards that contain a chip. [2]
Show answer
  1. (a) The stripe passes the read head of a magnetic stripe reader; the head detects the pattern of magnetised areas and converts it to digital data (the room code), which the door's microprocessor checks.
    1 mark: stripe swiped past read head / magnetic stripe reader detects magnetised data. 1 mark: data converted to digital and compared with the code stored for the door.
  2. (b) Any two, e.g. the stripe is easily damaged by magnets/phones/scratches; the data can be copied (cloned) easily; stripe wears out with repeated swiping; must be swiped in the correct direction.
    1 mark each for any two valid disadvantages.
Q5Direct data entry devices (bar codes, RFID, QR) · Core · Paper 1 style · 5 marks
  1. (a) Give two differences between a QR code and a one-dimensional bar code. [2]
  2. (b) A fruit stall in Quetta displays a QR code so that customers can pay with a mobile banking app. Describe how a customer pays using the QR code. [3]
Show answer
  1. (a) Any two, e.g. a QR code is two-dimensional (squares in a grid) while a bar code is a row of lines; a QR code holds much more data (e.g. a whole web address); a QR code can be read from any angle; a QR code can be read by a smartphone camera without a dedicated scanner; a QR code still reads if partly damaged.
    1 mark per valid difference (must compare both).
  2. (b) The customer opens the banking app and uses the phone camera to scan the QR code; the app reads the stall's account details from the code; the customer types the amount and confirms with a PIN/fingerprint; the money is transferred and both see a confirmation.
    1 mark each for any three: scan with phone camera/app; account details decoded from code; amount entered and authorised (PIN/biometric); payment transferred and confirmation shown.
Q6Direct data entry devices (bar codes, RFID, QR) · Standard · Paper 1 style · 6 marks
  1. (a) A warehouse in Karachi stores boxes of spare parts. It is deciding whether to label the boxes with bar codes or with RFID tags. Compare the use of bar code readers and RFID readers for identifying the boxes. [6]
Show answer
  1. (a) Similarities and differences written as linked comparisons, e.g. both read data without typing so reduce errors; both identify the box and look up its record in the stock file. RFID reads by radio waves while a bar code reader uses light reflected from the code; RFID needs no line of sight but a bar code must face the reader; RFID can read many boxes at once whereas bar codes are scanned one at a time; RFID tags can be read from further away; RFID tag data can be rewritten but a printed bar code cannot be changed; RFID tags cost more than printed labels; bar codes are easily damaged/dirtied, RFID tags are more robust.
    1 mark per valid point, max 6. At least one similarity needed for full marks. Points must compare the two (e.g. 'RFID…whereas bar code…'); a list of separate features in two columns max 4.
Q7Direct data entry devices (bar codes, RFID, QR) · Standard · Paper 1 style · 6 marks
  1. (a) A museum in Istanbul places a QR code next to each exhibit. Describe how a visitor uses the QR code to see more information about an exhibit. [3]
  2. (b) Give two advantages to the museum of using QR codes rather than printed information boards. [2]
  3. (c) Give one disadvantage of QR codes for visitors. [1]
Show answer
  1. (a) Visitor opens the camera/QR app on their smartphone; points the camera at the QR code; the app decodes the pattern (into a URL/text); the phone opens the web page/shows the information or plays a video/audio guide.
    1 mark each for any three steps in a sensible order.
  2. (b) Any two, e.g. information can be updated online without reprinting; can link to video/audio/multiple languages; QR code takes very little wall space; cheap to produce; can store more data than a bar code.
    1 mark each for any two.
  3. (c) Any one, e.g. visitor needs a smartphone with a camera; needs internet access/mobile data to open the page; a QR code can be replaced by a fake one linking to a malicious site.
    1 mark.
Q8Direct data entry devices (bar codes, RFID, QR) · Standard · Paper 1 style · 5 marks
  1. (a) A national survey in Pakistan uses printed forms. Part of each form has answer boxes that people shade in with a pencil. Another part asks people to write their address in capital letters. Explain why an optical mark reader (OMR) is used for the shaded boxes. [2]
  2. (b) Explain why the addresses are read using a scanner with optical character recognition (OCR) software and not an OMR. [2]
  3. (c) State one disadvantage of using OCR to read the addresses. [1]
Show answer
  1. (a) OMR detects the position of the marks in set positions; very fast so thousands of forms are processed quickly; more accurate than a person typing the answers.
    1 mark for how it works/what it detects, 1 mark for a linked benefit.
  2. (b) OMR can only detect whether a box is shaded, not read letters; OCR converts the scanned image of the handwriting/characters into editable text that can be stored in the database.
    1 mark for why OMR is unsuitable, 1 mark for what OCR does.
  3. (c) Handwriting may be unclear so characters are misread/errors need checking; poor-quality forms are rejected.
    1 mark.
Q9Direct data entry devices (bar codes, RFID, QR) · Standard · Paper 1 style · 5 marks
  1. (a) A customer in a restaurant in Dubai pays by inserting a chip and PIN card into a hand-held card reader. Describe the steps involved in making this payment. [5]
Show answer
  1. (a) The waiter enters the amount; the card is inserted into the reader; the customer types the PIN on the keypad; the PIN is checked against the one stored on the chip; if correct, the card details are sent to the bank (securely/encrypted); the bank checks the account has enough funds; the payment is authorised and the money is transferred; the reader displays 'approved' and a receipt is printed; if the PIN is wrong the transaction is rejected (after limited attempts card locked).
    1 mark per valid step in order, max 5.
Q10Direct data entry devices (bar codes, RFID, QR) · Standard · Paper 1 style · 5 marks

Cars using a motorway have an RFID tag stuck on the inside of the windscreen. When a car passes through the toll plaza, the barrier lifts without the car stopping and the toll is taken from the driver's prepaid account.

  1. (a) Describe how the RFID system identifies the car and charges the toll. [3]
  2. (b) Give one advantage of this system for drivers and one advantage for the motorway company. [2]
Show answer
  1. (a) A reader at the toll plaza sends out radio waves; the tag's antenna picks them up and the tag sends back its unique ID; the computer looks up the ID in the database of accounts, deducts the toll from that account and opens the barrier.
    1 mark each: reader sends radio waves / tag responds; unique tag ID transmitted; ID matched to account in database and toll deducted (and barrier raised).
  2. (b) Drivers: no need to stop/queue or carry cash, so journeys are faster. Company: fewer toll staff needed / fewer cash-handling errors / traffic flows faster with less congestion.
    1 mark for a driver advantage; 1 mark for a company advantage.
Q11Direct data entry devices (bar codes, RFID, QR) · Standard · Paper 1 style · 5 marks

Many smartphones can make contactless payments using near field communication (NFC).

  1. (a) Describe how a customer pays for groceries using NFC on a smartphone. [3]
  2. (b) Explain why paying with a smartphone can be more secure than tapping a contactless bank card. [2]
Show answer
  1. (a) The cashier enters the total on the card reader; the customer unlocks the payment app with fingerprint/face/PIN; the phone is held close to (within a few cm of) the reader; the payment details are sent by NFC radio and the payment is authorised.
    1 mark each for any three: amount entered on reader; customer authenticates on phone; phone held very close to reader; data passed by short-range radio/NFC and payment approved.
  2. (b) The phone must be unlocked with a fingerprint/face/PIN before paying, so a thief who steals it cannot easily use it; the phone sends a one-time code (token) instead of the real card number, so intercepted data is useless.
    1 mark each for two explained points (biometric/PIN check before every payment; real card number not transmitted / token used).
Q12Direct data entry devices (bar codes, RFID, QR) · Challenge · Paper 1 style · 6 marks
  1. (a) A café in Islamabad accepts contactless card payments for amounts up to a set limit. Describe how a contactless payment is made. [4]
  2. (b) Explain two security concerns about contactless payments. [2]
Show answer
  1. (a) Total is entered on the card reader/till; customer holds the card (or phone) close to the reader; data is sent by radio waves (RFID/NFC) from the chip; the transaction is encrypted; the card details are checked with the bank and the payment is authorised; reader shows that the payment is accepted (beep/green light) and a receipt can be given. No PIN is needed below the limit.
    1 mark per point, max 4.
  2. (b) Any two explained, e.g. a stolen card can be used without knowing the PIN (up to the limit); a criminal with a hidden reader close by could read card data (skimming/eavesdropping); a customer might pay twice by mistake if the card is near the reader again.
    1 mark each for any two explained concerns.
Q13Direct data entry devices (bar codes, RFID, QR) · Challenge · Paper 1 style · 6 marks
  1. (a) A dairy farm near Sahiwal puts a passive RFID tag in each cow's ear. Describe how the reader obtains the data from a passive RFID tag. [3]
  2. (b) Explain three reasons why RFID tags are more suitable than bar code labels for identifying the cows. [3]
Show answer
  1. (a) The reader sends out radio waves; the tag's antenna picks up the radio signal, which provides the energy to power the tag (no battery); the tag sends back its stored data (unique ID) as radio waves; the reader receives the data and passes it to the computer (where the cow's record is looked up).
    1 mark per point, max 3.
  2. (b) Cows move, and RFID needs no line of sight so the cow does not need to be held still; many cows can be read at once as they pass through a gate; a tag works when covered in mud/dirt whereas a bar code would become unreadable; tags are tough/waterproof; data on the tag (e.g. vaccination date) can be updated.
    1 mark for each explained reason, max 3.
Q14Direct data entry devices (bar codes, RFID, QR) · Challenge · Paper 1 style · 6 marks
  1. (a) An international airport is planning to attach RFID tags to all checked-in luggage instead of using printed bar code labels. Evaluate this plan. [6]
Show answer
  1. (a) Benefits: bags read automatically as they pass on conveyors without line of sight, so fewer lost/misrouted bags; many bags read at once speeds up sorting; tags readable at longer range and when label is creased/torn; passengers could track bags; data can be updated along the route. Drawbacks: tags cost more per bag than paper labels; all airports on the route need RFID readers or bags still need bar codes; radio signals can be blocked by metal/liquids in bags; tags may be read by unauthorised readers (privacy); setup costs of new readers and staff training. Conclusion with a justified judgement.
    Level marking: 5–6 marks: benefits and drawbacks both well developed with a reasoned conclusion; 3–4 marks: both sides with some development; 1–2 marks: one side or list-like points. Up to 1 mark per developed point, max 6.
Q15Direct data entry devices (bar codes, RFID, QR) · Challenge · Paper 1 style · 6 marks

A hospital in Karachi plans to give each patient a wristband with a bar code. Nurses will scan the wristband and the bar code on each medicine packet before giving a dose.

  1. (a) Evaluate the use of bar codes on patient wristbands and medicine packets in this hospital. [6]
Show answer
  1. (a) Benefits: correct patient is identified, reducing the risk of giving the wrong medicine; the system can check that the medicine and dose match the prescription and warn the nurse; doses are recorded automatically with the time, so records are accurate and complete; faster than writing notes. Drawbacks: cost of scanners, printers and software; bar codes can be damaged/wet/smudged and fail to scan, so manual entry may be needed; nurses need training; if the system fails, a backup paper method is needed; a scan must be in line of sight, which may disturb a sleeping patient. Conclusion: likely worthwhile because patient safety improves.
    Up to 4 marks for benefits/drawbacks explained in context (max 4 if only one side); 1 mark for balance of both sides; 1 mark for a reasoned conclusion.

Q22Input devices · Standard · Paper 1 style · 4 marks
  1. (a) A doctor in a clinic is choosing between a keyboard and a microphone with speech recognition software to enter patient notes. Compare these two input methods for this task. [4]
Show answer
  1. (a) Both enter text into the patient record. Q28Input devices · Challenge · Paper 1 style · 5 marks
  1. (a) Explain why ATMs use a numeric keypad rather than a full keyboard. [2]
  2. (b) Describe two problems customers may have when using the numeric keypad at an ATM. [2]
  3. (c) Suggest one feature of the keypad that helps a customer who is blind or partially sighted. [1]

Q29Input devices · Challenge · Paper 1 style · 6 marks

A photographer's digital camera takes photos that are 6000 pixels wide and 4000 pixels high. Each pixel uses 3 bytes. Use 1 MB = 1 048 576 bytes and 1 GB = 1024 MB.

  1. (a) Calculate the size of one uncompressed photo in MB. Give your answer correct to 2 decimal places. [2]
  2. (b) The camera saves each photo as a .jpg with an average size of 8 MB. Calculate how many photos fit on a 64 GB memory card. [2]
  3. (c) Explain why a high number of pixels is useful when the photo will be printed as a large poster. [2]
Show answer
  1. (a) 68.66 MB
    M1: 6000 × 4000 × 3 = 72 000 000 bytes. A1: ÷ 1 048 576 = 68.66 MB.
  2. (b) 8192 photos
    M1: 64 × 1024 = 65 536 MB. A1: 65 536 ÷ 8 = 8192.
  3. (c) More pixels means more detail; the image can be enlarged to poster size without the pixels becoming visible (pixelation/blurring).
    1 mark: more detail/higher resolution. 1 mark: can be printed large without pixelation.
Q30Input devices · Challenge · Paper 1 style · 6 marks

Zubair has a condition that makes it very difficult for him to control the fine movements of his hands. He wants to write essays and use the internet on his computer.

  1. (a) Discuss the suitability of a microphone with speech-recognition software, a trackerball and a large-key keyboard as input devices for Zubair. [6]
Show answer
  1. (a) Microphone with speech recognition: he can dictate essays and commands without using his hands, much faster than typing; but software must be trained to his voice, errors need correcting, background noise causes mistakes. Trackerball: the ball is moved with the thumb/palm while the device stays still, so less precise movement is needed than a mouse and it cannot be knocked off the desk; but still needs some hand control and clicking. Large-key keyboard: bigger keys are easier to hit, fewer typing errors; but typing remains slow and tiring. Q57Output devices · Challenge · Paper 1 style · 6 marks
  1. (a) Describe the steps a laser printer goes through to print a page. [5]
  2. (b) Explain why a laser printer is suitable for printing a large number of copies of the same page. [1]
Show answer
  1. (a) The page data is sent to the printer and stored in its memory/buffer; the drum is given a (positive) electrostatic charge; a laser beam scans the drum, removing the charge where the image will be (or vice versa), forming an electrostatic image; the drum is coated with charged toner, which sticks only to the charged/image areas; the paper is given an opposite charge and the toner is transferred to it as it passes the drum; the fuser heats and presses the toner so it melts onto the paper; the drum is discharged/cleaned for the next page.
    1 mark per step, max 5.
  2. (b) The whole page image is formed on the drum at once so pages are printed very quickly/the toner lasts for many pages.
    1 mark.

Q59Output devices · Challenge · Paper 1 style · 6 marks

A lecture theatre in Faisalabad must choose between an LCD projector and a DLP (digital light processing) projector.

  1. (a) Compare LCD and DLP projectors. [6]
Show answer
  1. (a) Both project a large image from a computer and use a bright lamp.
