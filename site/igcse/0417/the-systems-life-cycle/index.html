Q1Design: data capture forms and file structures · Core · Paper 1 style · 3 marks
  1. (a) A systems analyst is designing an on-screen data capture form for new members of a sports club in Abbottabad. Give three features of a well-designed on-screen form. [3]
Show answer
  1. (a) Any three, e.g. a clear title so users know the purpose; clear instructions/labels for each field; drop-down lists or radio buttons for fixed choices; tick boxes for yes/no answers; boxes of a suitable size for the data; fields in a logical order; navigation buttons (next/back/submit); no unnecessary fields/uncluttered layout; consistent font and colours; help/error messages.
    1 mark each for any three distinct features.

  1. (a) State what is meant by a primary key in a database table. [1]
  2. (b) A car hire company in Sharjah stores these fields about each car: Make, Model, Colour, RegistrationNumber, Seats. State which field should be the primary key. [1]
Show answer
  1. (a) A field that uniquely identifies each record in the table.
    1 mark.
  2. (b) RegistrationNumber.
    1 mark.
Q3Design: data capture forms and file structures · Core · Paper 1 style · 4 marks
  1. (a) An on-screen booking form for a youth hostel in Naran is being designed. For each field, name the most suitable form control.(i) RoomType: one of Single, Double or Dormitory(ii) GuestName(iii) BreakfastIncluded: yes or no(iv) HomeCity: one of 35 cities in a fixed list [4]

  1. (a) (i) Radio buttons (option buttons) (ii) Text box (iii) Check box (iv) Drop-down list (combo box)

Q4Design: data capture forms and file structures · Core · Paper 1 style · 4 marks
  1. (a) A blood donation camp in Multan uses a paper form that donors fill in by hand. The data is later typed into a computer. Give two features of the paper form that would help the data to be typed in accurately. [2]
  2. (b) Explain why the order of the fields on the paper form should match the order of the fields on the data entry screen. [2]
Show answer
  1. (a) Any two, e.g. one box for each character; tick boxes for yes/no or multiple-choice answers; clear instructions such as 'write in CAPITAL letters'; date shown as DD/MM/YYYY boxes; fields in the same order as the input screen.
    1 mark each for any two features, each linked to accuracy. Do not accept 'nice colours' or 'easy to read' without a reason.
  2. (b) The typist can work down the form and the screen together without searching, so it is faster and fields are less likely to be missed or typed into the wrong box.
    1 mark: typist moves through both in the same sequence / no need to search. 1 mark: fewer transcription errors or fields skipped / faster entry.
Q5Design: data capture forms and file structures · Core · Paper 1 style · 2 marks
  1. (a) A cricket club stores whether each member has paid this year's fee. The analyst chooses a Boolean (Yes/No) field rather than a text field. Give two reasons for this choice. [2]
Show answer
  1. (a) Any two, e.g. only two values are possible so invalid entries such as 'Yse' or 'paid' cannot be stored; uses less storage; searching for unpaid members is simpler and more reliable; can be shown as a check box on the form.
    1 mark each for any two valid reasons.

Q7Design: data capture forms and file structures · Standard · Paper 1 style · 4 marks
  1. (a) In a file of customer details, the analyst stores telephone numbers such as 03001234567 in a text field, not a numeric field. Explain why. [2]
  2. (b) The analyst stores each customer's date of birth rather than their age. Explain why. [2]
Show answer
  1. (a) A numeric field would remove the leading zero; telephone numbers may contain + or spaces/dashes; no calculations are carried out on them.
    1 mark each for any two points.
  2. (b) Age changes every year so the stored value would become wrong/need updating; age can always be calculated from the date of birth and today's date.
    1 mark each.

Q9Design: data capture forms and file structures · Standard · Paper 1 style · 5 marks
  1. (a) A mobile phone repair shop in Rawalpindi stores details of each repair job. Sample data: JobNo R00412; IMEI 356938035643809 (always 15 digits); DateReceived 14/09/2026; RepairCost 3500.00; Collected No.For each field, state a suitable data type and, where relevant, a field length. [5]
Show answer
  1. (a) JobNo: text/alphanumeric, length 6. IMEI: text, length 15. DateReceived: date/time (format DD/MM/YYYY). RepairCost: currency (or real/decimal, 2 decimal places). Collected: Boolean (Yes/No).

Q10Design: data capture forms and file structures · Standard · Paper 1 style · 4 marks
  1. (a) A courier company stores the destination city for each of its 40 000 parcel records. City names are on average 9 characters long. The analyst replaces each name with a 3-character code, for example LHE for Lahore. Each character uses 1 byte.Calculate how many bytes are saved. Then give the saving in kilobytes, correct to 1 decimal place (1 KB = 1024 bytes). [2]
  2. (b) Name a validation check that should be used on the city code field and explain how it works. [2]
Show answer
  1. (a) 240 000 bytes; 234.4 KB
    M1: (9 − 3) × 40 000 = 240 000 bytes. A1: 240 000 ÷ 1024 = 234.375 → 234.4 KB.
  2. (b) Lookup check: the code entered is compared with the stored list of valid city codes (e.g. LHE, KHI, ISB) and is accepted only if it is in the list.
    1 mark: lookup check. 1 mark: compared with a stored list of valid codes / rejected if not in the list. Accept length check (exactly 3 characters) for 1 mark only if explained.
Q11Design: data capture forms and file structures · Standard · Paper 1 style · 4 marks
  1. (a) A sports academy in Islamabad designs a file of member records. Each record has these fields and sizes:MemberID 6 bytes; FullName 30 bytes; Phone 11 bytes; JoinDate 8 bytes; Balance 4 bytes; Active 1 byte.Calculate the size of one record in bytes. [1]
  2. (b) There will be 2500 members. The analyst adds 10% to allow for extra data stored by the software. Calculate the estimated file size in kilobytes, correct to 1 decimal place (1 KB = 1024 bytes). [2]
  3. (c) Explain why the analyst needs to estimate the file size during design. [1]
Show answer
  1. (a) 60 bytes
    6 + 30 + 11 + 8 + 4 + 1 = 60.
  2. (b) 161.1 KB
    M1: 60 × 2500 = 150 000 bytes; × 1.1 = 165 000 bytes. A1: 165 000 ÷ 1024 = 161.13 → 161.1 KB.
  3. (c) So that backing storage of a large enough capacity (with room for growth) can be chosen/bought for the new system.
    1 mark for linking file size to choosing storage capacity.

The data needed is: full name, gender, date of birth, blood group (one of 8 types), telephone number and whether the patient has any allergies. Describe how the form should be designed to make data entry quick and accurate. Refer to the fields listed. [6]
Show answer
  1. (a) Title such as 'New patient registration' and short instructions; full name in a text box large enough for long names, perhaps split into first name/family name; gender chosen with radio buttons; date of birth entered with a date picker or set format dd/mm/yyyy; blood group from a drop-down list of the 8 types so it cannot be mistyped; telephone number in a text box with a set format/input mask; allergies as a yes/no tick box with a text box for details only if yes; fields in a logical order; validation on fields with clear error messages; submit/clear/next buttons; consistent layout, no clutter.
    1 mark per feature linked to a field or explained, max 6. Generic features without reference to the scenario max 3.

Q16Testing and test data · Core · Paper 1 style · 3 marks
  1. (a) Describe what is meant by each type of test data.(i) Normal data(ii) Abnormal data(iii) Extreme data [3]
Show answer
  1. (a) (i) Data within the acceptable range/of the correct type that should be accepted.(ii) Data outside the range or of the wrong type that should be rejected.(iii) Data on the boundaries of the acceptable range (the largest and smallest acceptable values) that should be accepted.
    1 mark each.

Q24Testing and test data · Standard · Paper 1 style · 4 marks
  1. (a) A new payroll system for 250 staff is tested using last month's live data, which was already processed by the old system. Explain how this test shows whether the new system calculates pay correctly. [2]
  2. (b) Explain why the new system must still be tested with abnormal and extreme data as well as live data. [2]
Show answer
  1. (a) The correct results (each payslip and the total paid) are already known from the old system, so the new system's outputs can be compared with them; if they match, the new calculations are correct.
    1 mark: results already known from the old system. 1 mark: compare the new outputs with these known results.
  2. (b) Live data is mostly normal data that has already been checked, so it may contain no invalid or boundary values; without abnormal and extreme data the validation rules and error messages would not be tested.
    1 mark: live data contains few or no invalid/boundary values. 1 mark: so validation rules/error handling would not be tested.

Q29Testing and test data · Challenge · Paper 1 style · 4 marks
  1. (a) A recruitment system should accept ages from 18 to 65 inclusive. During testing, the extreme value 18 was rejected, but 65 was accepted. The rule used was:>18 AND <=65Explain why 18 was rejected. [2]
  2. (b) Write the corrected rule. [1]
  3. (c) Explain why using only normal data would not have found this error. [1]
Show answer
  1. (a) The rule uses > (greater than) for the lower limit, so 18 itself fails the test because 18 is not greater than 18.
    1 mark: identifies the > operator. 1 mark: 18 is not greater than 18 so it is outside the rule.
  2. (b) >=18 AND <=65
    1 mark. Accept 'Between 18 And 65'.
  3. (c) Normal values such as 30 lie well inside the range and pass both versions of the rule; only a boundary value shows the difference.
    1 mark.

Q87Documentation · Challenge · Paper 1 style · 6 marks
  1. (a) Compare user documentation and technical documentation. [4]
  2. (b) Explain why user documentation often includes a troubleshooting section. [2]
Show answer
  1. (a) Both describe the system and both include hardware/software requirements. User documentation is written for people who use the system, whereas technical documentation is for people who maintain/develop it; user documentation explains how to carry out tasks (save, print, search) in plain language, while technical documentation includes program code, file structures and validation rules; user documentation has tutorials/FAQs/troubleshooting, technical documentation has algorithms/flowcharts/test results.
    1 mark per comparison point, max 4; at least one similarity for full marks.
  2. (b) Users can solve common problems/error messages themselves without needing a technician; this saves time and support costs and the user can continue working.
    1 mark each.
Q88Documentation · Challenge · Paper 1 style · 6 marks
  1. (a) A company in Karachi hires a new programmer to update a stock system written five years ago by someone who has since left. Explain how the technical documentation will help the programmer. Refer to three items in the documentation. [6]
Show answer
  1. (a) e.g. Program listing and comments show how the code works so the programmer can find where to make changes. File structures show the fields, data types and sizes so new fields can be added without damaging data. Test plan and results let the programmer re-test after changes to make sure the system still works. (Also accept list of variables, flowcharts/algorithms, validation routines, known bugs.)
    For each of three items: 1 mark for naming the item, 1 mark for explaining how it helps the update.
Q89Documentation · Challenge · Paper 1 style · 3 marks
  1. (a) A troubleshooting section is being written for a school fees system used by office staff. Write three entries, each giving a problem the user might meet and the action to take. [3]
Show answer
  1. (a) e.g. 'Receipt does not print' – check the printer is switched on, has paper and is selected, then click Reprint. 'Error: student ID not found' – check the ID was typed correctly; search by name instead. 'Cannot log in' – check Caps Lock is off; after three failed attempts ask the administrator to reset the password.
    1 mark for each entry that gives a realistic problem with a sensible, specific action. Vague actions such as 'ask for help' alone are not enough.
Q90Documentation · Challenge · Paper 1 style · 6 marks
  1. (a) A wholesale company is deciding whether to give its shopkeeper customers a printed user manual or a set of short video tutorials for its new ordering app. Many of the shopkeepers have little experience of computers. Evaluate the two options and give a recommendation. [6]
Show answer
  1. (a) Videos: show exactly what to tap and in which order, easier for beginners and for people less confident reading; can be watched again; but need internet/data, cannot easily find one small detail, may be hard to watch while using the app on the same phone. Printed manual: can be read beside the phone while using the app, no internet needed, easy to flick to a page; but can be lost, costs money to print and post, may be hard to follow without pictures and becomes out of date when the app changes. Recommendation, e.g. short videos plus a simple printed quick-start card, because users have little experience.
    Up to 2 marks for points about videos, up to 2 marks for points about the manual, 1 mark for relating to the users' inexperience, 1 mark for a justified recommendation. Max 6.
