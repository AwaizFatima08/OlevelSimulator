Q2Web development layers and HTML · Core · Paper 1 style · 4 marks
  1. (a) State the purpose of the head section and the body section of a web page. [2]
  2. (b) Give two items that are placed in the head section. [2]
Show answer
  1. (a) The head contains information about the page that is not displayed in the page itself, such as the title, metatags and links to stylesheets; the body contains the content shown in the browser window, such as text, images, tables and links.
    1 mark: head – page information/metadata/title/stylesheet links not displayed in the page. 1 mark: body – the visible content.
  2. (b) The page title; the link to an external stylesheet.
    1 mark each for any two of: title | meta tags (charset, keywords, description, author, viewport) | link to external CSS | internal <style> | base target | scripts.

Q12Web development layers and HTML · Standard · Paper 1 style · 5 marks
  1. (a) Explain why the presentation layer should be kept separate from the content layer by using an external stylesheet. [4]
  2. (b) Explain why the <link> to an external stylesheet is placed in the head section. [1]
Show answer
  1. (a) One stylesheet can be attached to every page, so all pages look consistent; changing one rule in the stylesheet updates every page at once; the HTML files are smaller and easier to read and edit because they contain only content; and different stylesheets can be used for different devices or for printing without changing the content.
    1 mark each for any four of: consistency across pages/house style | change once – updates all pages | saves time when restyling | HTML simpler/shorter/easier to maintain | faster loading – CSS cached once | different styles for different devices/print | developers and designers can work separately.
  2. (b) The link is information about the page rather than content to display, so it belongs in the head; the head is read before the body is shown, so the styles are ready and the page is displayed correctly formatted from the start.
    B1: head holds information about the page/resources, not displayed content | loaded before the body so styles are applied when the page is shown.

Q24Web development layers and HTML · Challenge · Paper 1 style · 4 marks
  1. (a) Compare a CSS class with an inline style for formatting part of a web page. [4]
Show answer
  1. (a) Both change the appearance of elements. A class is defined once in a stylesheet (e.g. .warning { color: #FF0000; }) and can be applied to many elements with class="warning", so changing the class definition updates all of them; an inline style is written inside one element's tag with the style attribute and affects only that element. Inline styles override class rules, but they mix presentation with content and are harder to maintain.
    1 mark for a similarity (both apply formatting/CSS properties). Up to 3 for differences: class defined once and reused vs inline applies to one element | class in stylesheet vs style attribute in tag | changing class updates all vs edit each inline style | inline has higher priority | class keeps content and presentation separate.
