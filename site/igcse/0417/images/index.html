Practice questions

Original practice questions written by HomiLabs in the exam style. They are not Cambridge past paper questions. Try each one before opening the answer.

Q1Editing images · Core · Paper 2 style · 3 marks
  1. (a) A newsletter for a cricket club in Sialkot contains a photograph that is 15 cm wide and 10 cm high. It must be resized so that it is 6 cm wide and the aspect ratio is maintained. Calculate the new height of the photograph. [1]
  2. (b) Explain why the aspect ratio of the photograph should be maintained when it is resized. [2]
Show answer
  1. (a) 4 cm
    B1: 10 × 6 ÷ 15 = 4 cm.
  2. (b) So that the image is not distorted/stretched or squashed; the proportions of the people and objects stay correct so the image still looks realistic/professional.
    1 mark: image not distorted (stretched/squashed). 1 mark: proportions (width to height) stay the same / people and objects keep their correct shape.
Q2Editing images · Core · Paper 2 style · 3 marks
  1. (a) A student is editing an image of a market stall for a school magazine. Describe the difference between cropping the image and resizing the image. [2]
  2. (b) State one reason why the student might crop the image. [1]
Show answer
  1. (a) Cropping removes unwanted parts from the edges of the image, so some content is lost and the remaining part is unchanged in scale. Resizing changes the size/dimensions of the whole image but keeps all of its content.
    1 mark: cropping cuts away/removes part of the image (from the edges). 1 mark: resizing makes the whole image bigger or smaller with all content kept.
  2. (b) e.g. to remove an unwanted person/object at the edge; to focus attention on the main subject (the stall); to change its shape to fit a space.
    1 mark for one valid reason.
Q3Editing images · Core · Paper 2 style · 3 marks
  1. (a) A word-processed leaflet for a dental clinic in Peshawar contains a paragraph about opening hours. Describe the steps needed to place the image clinic.jpg so that it is aligned with the right margin and the text of the paragraph wraps around it. [3]
Show answer
  1. (a) Place the cursor in the paragraph and insert the image from file (Insert → Picture → clinic.jpg); select the image and set text wrapping to square (or tight); drag/position the image so its right edge is aligned with the right margin (or set horizontal alignment: right, relative to margin).
    1 mark: insert the picture from the file. 1 mark: set text wrapping to square/tight. 1 mark: align/position image to the right margin.
Q4Editing images · Core · Paper 1 style · 3 marks
  1. (a) A travel agent in Lahore wants to reduce the file size of the photographs on her website. State three ways the file size of an image can be reduced. [3]
Show answer
  1. (a) Any three: reduce the resolution/number of pixels (resize it smaller); crop unwanted areas; reduce the colour depth; compress the image (e.g. save as a compressed .jpg at a lower quality).
    1 mark each for any three distinct methods.
Q5Editing images · Core · Paper 3 style · 2 marks
  1. (a) An image is 1080 pixels wide and 720 pixels high. It is rotated 90° clockwise. State the width and height of the rotated image. [1]
  2. (b) State one reason why an image taken with a phone might need to be rotated before it is used. [1]
Show answer
  1. (a) 720 pixels wide and 1080 pixels high
    B1: width and height swap.
  2. (b) e.g. the phone was held sideways so the image appears on its side; to change it from landscape to portrait to fit a space.
    1 mark.
Q6Editing images · Core · Paper 3 style · 3 marks
  1. (a) The image fort.jpg is 900 pixels wide and 600 pixels high. On a web page it must be displayed 300 pixels wide with its aspect ratio kept. Calculate the height at which it must be displayed. [1]
  2. (b) Write the HTML to display the image at this size, with the alternative text 'Lahore Fort'. [2]
Show answer
  1. (a) 200 pixels
    B1: 600 × 300 ÷ 900 = 200.
  2. (b) <img src="fort.jpg" width="300" height="200" alt="Lahore Fort">
    1 mark: img element with src="fort.jpg". 1 mark: width="300" and height="200" and alt="Lahore Fort". Accept the size given with a style attribute.
Q7Editing images · Core · Paper 2 style · 3 marks
  1. (a) Describe the steps needed to insert the image bus.png into a document so that it is exactly 5 cm wide, with its height in proportion, and placed at the top left of the first page below the header. [3]
Show answer
  1. (a) Position the cursor at the start of the document (top left, below the header) and insert the picture from the file bus.png; with aspect ratio locked, set the width to 5 cm (the height changes automatically); check the image is aligned with the left margin/top of the text area.
    1 mark: insert picture from file at start of document. 1 mark: lock aspect ratio and set width to 5 cm. 1 mark: align to left margin at top of page.
Q8Editing images · Core · Paper 1 style · 2 marks
  1. (a) State what is meant by the aspect ratio of an image. [1]
  2. (b) An image is 640 pixels wide and 480 pixels high. Give its aspect ratio in its simplest form. [1]
Show answer
  1. (a) The ratio of the width of the image to its height.
    1 mark.
  2. (b) 4 : 3
    B1: 640 : 480 = 4 : 3.
Q9Editing images · Core · Paper 2 style · 2 marks
  1. (a) A scanned map has been inserted into a sports day flyer upside down: the north arrow and the labels point towards the bottom of the page. Name the image edit, including the angle, that will correct it. [1]
  2. (b) State one other edit, apart from resizing and cropping, that can be applied to an image in a document. [1]
Show answer
  1. (a) Rotate the image through 180°.
    1 mark: rotate 180°. Do not accept flip/reflect vertically (this would leave the labels as a mirror image).
  2. (b) e.g. rotate; change brightness; change contrast; change colour depth/recolour; apply text wrapping.
    1 mark.
Q10Editing images · Core · Paper 3 style · 2 marks
  1. (a) A photograph of a wedding was taken outdoors in strong sunlight and looks too light, with faded colours. State which adjustment should be made. [1]
  2. (b) State one reason why the original photograph should be kept before editing. [1]
Show answer
  1. (a) Decrease the brightness (accept: also increase the contrast).
    1 mark.
  2. (b) So the edits can be undone / the original can be used again if the edit is not suitable, because some edits cannot be reversed once saved.
    1 mark.
Q11Editing images · Standard · Paper 3 style · 4 marks
  1. (a) A digital photograph of the Badshahi Mosque is 1600 pixels wide and 1200 pixels high. It is to be reduced to 480 pixels wide for a web page, keeping the aspect ratio. Calculate the new height in pixels. [1]
  2. (b) Each pixel is stored using 3 bytes and the image is not compressed. Calculate the file size, in bytes, of the original image and of the reduced image. [2]
  3. (c) Explain why the reduced image is more suitable for the web page. [1]
Show answer
  1. (a) 360 pixels
    B1: 1200 × 480 ÷ 1600 = 360.
  2. (b) Original 5 760 000 bytes; reduced 518 400 bytes
    B1: 1600 × 1200 × 3 = 5 760 000. B1: 480 × 360 × 3 = 518 400.
  3. (c) It has a much smaller file size so the page loads/downloads faster and uses less bandwidth.
    1 mark: smaller file → faster loading.
Q12Editing images · Standard · Paper 2 style · 3 marks
  1. (a) An image of a horse facing right is placed in a document. Explain the difference between reflecting the image horizontally and rotating it through 180°. [2]
  2. (b) The horse must face towards the text on the left of the page. State which of the two edits should be used. [1]
Show answer
  1. (a) Reflecting (flipping) horizontally makes a mirror image so the horse faces left but stays the right way up. Rotating through 180° turns the image so the horse faces left and is also upside down.
    1 mark: reflect = mirror image, horse now faces left, still upright. 1 mark: rotate 180° = horse upside down (and facing left).
  2. (b) Reflect (flip) horizontally.
    1 mark.
Q13Editing images · Standard · Paper 2 style · 3 marks
  1. (a) An image in a report is 9.3 cm wide and 12.4 cm high. It must be resized to exactly 8 cm high with the aspect ratio maintained. Calculate the new width, in centimetres. [2]
  2. (b) Describe how the student can make sure the aspect ratio is maintained when entering the new height in the software. [1]
Show answer
  1. (a) 6 cm
    M1: 9.3 × 8 ÷ 12.4. A1: 6.0 cm.
  2. (b) Tick/select the 'lock aspect ratio' (keep proportions) option before typing the new height, so the width changes automatically.
    1 mark.
Q14Editing images · Standard · Paper 3 style · 3 marks
  1. (a) An image of the Karakoram mountains is 2000 pixels wide and 1500 pixels high. It is cropped by removing 250 pixels from the left and 250 pixels from the right, and 150 pixels from the top and 150 pixels from the bottom. Calculate the dimensions of the cropped image. [2]
  2. (b) Give the aspect ratio of the cropped image in its simplest form, width : height. [1]
Show answer
  1. (a) 1500 pixels wide × 1200 pixels high
    B1: width 2000 − 2 × 250 = 1500. B1: height 1500 − 2 × 150 = 1200.
  2. (b) 5 : 4
    B1: 1500 : 1200 = 5 : 4.

For each image, name the most suitable text wrapping setting.(i) A logo that must sit on its own line above the title, with no text on either side.(ii) A photograph in the middle of a paragraph, with the text running down both sides close to the outline of an irregular-shaped object.(iii) A small icon that must move with the words in a line of text as if it were a character. [3]
Show answer
  1. (a) (i) Top and bottom; (ii) Tight (or through); (iii) In line with text.
    1 mark each.
Q16Editing images · Standard · Paper 3 style · 3 marks
  1. (a) A graphic designer is preparing images for a charity website. State the most suitable generic file format for each image and give a reason.(i) A colour photograph of a flood relief camp.(ii) A logo that must have a transparent background so the page colour shows through.(iii) A small, simple animated 'Donate' banner. [3]
Show answer
  1. (a) (i) .jpg — compressed format suited to photographs with many colours (small file). (ii) .png — supports transparency (and lossless compression keeps sharp edges). (iii) .gif — supports simple animation (limited colours suit a simple banner).
    1 mark each: correct format with reason.
Q17Editing images · Standard · Paper 2 style · 3 marks
  1. (a) In a poster for a science fair, a photograph of a student has been made wider without changing its height. The student's face now looks stretched. Explain why this has happened and describe how to correct it. [3]
Show answer
  1. (a) The aspect ratio was not maintained, so the width was increased by a different factor from the height. To correct it: reset the image size (or undo), lock the aspect ratio, then resize by dragging a corner handle (or changing one dimension) so both dimensions change in proportion.
    1 mark: aspect ratio not maintained / width changed but not height. 1 mark: reset or undo the distortion. 1 mark: lock aspect ratio / use corner handle so width and height change proportionally.
Q18Editing images · Standard · Paper 3 style · 4 marks
  1. (a) A photograph is to be printed 6 inches wide and 4 inches high at 300 dots (pixels) per inch. Calculate the number of pixels needed across and down the image. [2]
  2. (b) The photographer only has a version 900 pixels wide. Calculate the number of pixels per inch it would give if printed 6 inches wide, and explain the effect on the printed photograph. [2]
Show answer
  1. (a) 1800 pixels across and 1200 pixels down
    B1: 6 × 300 = 1800. B1: 4 × 300 = 1200.
  2. (b) 150 pixels per inch; the photograph would look less sharp/blurred or pixelated because each pixel is printed larger.
    B1: 900 ÷ 6 = 150. B1: less sharp / pixelated with reason.
Q19Editing images · Standard · Paper 2 style · 3 marks
  1. (a) A table in a recipe booklet has a column that is 4.5 cm wide. A picture of a mango, 7.5 cm wide and 5 cm high, must fit exactly across the width of one cell with its aspect ratio maintained. Calculate the height of the resized picture. [2]
  2. (b) State one reason why the picture should be resized in the document rather than stretched by dragging a side handle. [1]
Show answer
  1. (a) 3 cm
    M1: 5 × 4.5 ÷ 7.5. A1: 3 cm.
  2. (b) Dragging a side handle changes only one dimension so the picture is distorted; entering the size with the ratio locked keeps proportions and gives an exact width.
    1 mark.
Q20Editing images · Standard · Paper 3 style · 3 marks
  1. (a) Complete the statements: the maximum number of different colours that can be represented with a colour depth of(i) 1 bit(ii) 4 bits(iii) 8 bits(iv) 16 bits. [2]
  2. (b) Explain why a photograph stored with a colour depth of 24 bits has a larger file size than the same photograph stored with 8 bits. [1]
Show answer
  1. (a) (i) 2 (ii) 16 (iii) 256 (iv) 65 536
    2 marks for all four correct; 1 mark for two or three correct (2ⁿ).
  2. (b) Each pixel needs 24 bits instead of 8, so three times as much data is stored for the same number of pixels.
    1 mark.
Q21Editing images · Standard · Paper 1 style · 4 marks
  1. (a) Explain why images placed on web pages are usually compressed. [2]
  2. (b) Describe the difference between lossy and lossless compression of an image. [2]
Show answer
  1. (a) Compression reduces the file size so the image downloads faster and the web page loads more quickly; it also uses less bandwidth/storage on the server.
    1 mark: smaller file size. 1 mark: faster loading / less bandwidth or storage.
  2. (b) Lossy compression permanently removes some image data (detail the eye may not notice), so the original cannot be fully restored but the file is much smaller. Lossless compression reduces the file size without losing any data, so the original image can be restored exactly.
    1 mark: lossy removes data permanently. 1 mark: lossless — no data lost / original restored exactly.
Q22Editing images · Standard · Paper 3 style · 2 marks
  1. (a) A page from an old school register has been scanned. The scanned image is tilted about 3° anticlockwise and has white triangles at its corners after it is straightened. Describe the two edits needed to produce a neat, straight rectangular image. [2]
Show answer
  1. (a) Rotate the image about 3° clockwise so the text lines are horizontal; then crop the image to remove the empty/white triangles at the corners.
    1 mark: rotate 3° clockwise. 1 mark: crop to remove the corners/edges.
Q23Editing images · Challenge · Paper 3 style · 4 marks
  1. (a) An uncompressed image is 800 pixels wide and 600 pixels high. Its colour depth is 24 bits per pixel. Calculate its file size in bytes. [1]
  2. (b) The colour depth is reduced to 8 bits per pixel. Calculate the new file size in bytes and the number of different colours that can now be shown. [2]
  3. (c) Describe one effect on the appearance of the image of reducing the colour depth. [1]
Show answer
  1. (a) 1 440 000 bytes
    B1: 800 × 600 × 24 ÷ 8 = 1 440 000.
  2. (b) 480 000 bytes; 256 colours
    B1: 800 × 600 × 8 ÷ 8 = 480 000. B1: 2⁸ = 256.
  3. (c) Fewer colours are available so smooth changes of colour (e.g. a sky) appear as bands/blocks of colour and some detail/realism is lost.
    1 mark: fewer colours → banding / less realistic / loss of quality.
Q24Editing images · Challenge · Paper 3 style · 4 marks
  1. (a) A photograph taken inside a dimly lit museum looks dark and dull: the dark areas and light areas look very similar. Explain the difference between adjusting the brightness and adjusting the contrast of an image. [2]
  2. (b) State which adjustments should be made to improve this photograph, giving a reason for each. [2]
Show answer
  1. (a) Brightness makes every pixel in the whole image lighter (or darker) by the same amount. Contrast changes the difference between the light and dark areas: increasing it makes light areas lighter and dark areas darker.
    1 mark: brightness = whole image lighter/darker. 1 mark: contrast = difference between light and dark parts.
  2. (b) Increase the brightness so that the details in the dark image can be seen; increase the contrast so that the light and dark areas are more clearly different/the image looks less dull.
    1 mark: increase brightness + reason. 1 mark: increase contrast + reason.
Q25Editing images · Challenge · Paper 1 style · 6 marks
  1. (a) A school in Multan is putting hundreds of photographs of school events on its website. The web designer plans to reduce the resolution of every photograph before uploading it. Discuss the benefits and drawbacks of reducing the resolution of the photographs. [6]
Show answer
  1. (a) Benefits: smaller file sizes so pages load faster, especially on mobile data; uses less storage space on the web server; uses less bandwidth so hosting may cost less; quicker to upload; less data used by visitors. Drawbacks: image quality/detail is lost; images may look pixelated if enlarged or viewed on large high-resolution screens; visitors cannot download good-quality versions to print; the reduction cannot be undone unless the originals are kept; it takes time to edit hundreds of photographs. Conclusion e.g. benefits outweigh drawbacks for a web page if originals are kept.
    Max 4 marks for one side only. 1 mark per expanded point from: faster loading; less server storage; less bandwidth/cost; faster upload; loss of detail; pixelation when enlarged; poor for printing; cannot undo/originals must be kept; time taken. 1 mark for a reasoned conclusion. Answers in prose comparing both sides needed for full marks.
Q26Editing images · Challenge · Paper 3 style · 5 marks
  1. (a) An image 2400 pixels wide and 1800 pixels high is scaled to 35% of its width and 35% of its height. Calculate the new dimensions. [2]
  2. (b) The image is uncompressed. Calculate the new file size as a percentage of the original file size. [2]
  3. (c) A student says 'scaling to 35% makes the file 35% of its original size'. Explain why the student is wrong. [1]
Show answer
  1. (a) 840 pixels × 630 pixels
    B1: 2400 × 0.35 = 840. B1: 1800 × 0.35 = 630.
  2. (b) 12.25%
    M1: (840 × 630) ÷ (2400 × 1800) or 0.35². A1: 12.25%.
  3. (c) Both the width and the height are reduced, so the number of pixels is multiplied by 0.35 twice (0.35 × 0.35), not once.
    1 mark.
Q27Editing images · Challenge · Paper 3 style · 4 marks
  1. (a) A profile photograph is 1200 pixels wide and 900 pixels high. It must become a square image 250 pixels wide for a membership card, showing the person's face in the centre. Describe, with dimensions, the two edits needed and the order in which they should be done. [3]
  2. (b) Explain why resizing the original image straight to 250 × 250 pixels would not be suitable. [1]
Show answer
  1. (a) First crop the image to a square 900 × 900 pixels by removing 150 pixels from each side (left and right), keeping the face central. Then resize the square image, with aspect ratio locked, to 250 × 250 pixels.
    1 mark: crop to 900 × 900 (remove 300 pixels of width). 1 mark: 150 pixels from each side to keep face centred. 1 mark: then resize to 250 × 250 with aspect ratio kept.
  2. (b) The original is 4 : 3, not square, so forcing it to 250 × 250 would distort/squash the face.
    1 mark.
Q28Editing images · Challenge · Paper 3 style · 4 marks
  1. (a) An uncompressed image uses 3 bytes per pixel and has an aspect ratio of 4 : 3. Its file size must be no more than 600 KB, where 1 KB = 1024 bytes. Its width must be a multiple of 4 pixels. Calculate the largest possible width and height, and the file size in bytes at that size. [4]
Show answer
  1. (a) Width 520 pixels, height 390 pixels, file size 608 400 bytes
    M1: limit 600 × 1024 = 614 400 bytes. M1: w × (3w/4) × 3 ≤ 614 400 → w² ≤ 273 066.7 → w ≤ 522.5. A1: w = 520 (largest multiple of 4), h = 390. A1: 520 × 390 × 3 = 608 400 bytes (≤ 614 400). (524 × 393 × 3 = 617 796 is too big.)
Q29Editing images · Challenge · Paper 2 style · 3 marks
  1. (a) A newsletter is set on A4 portrait paper (21 cm wide). The left and right margins are each 2 cm. The page has two columns of equal width with 1 cm spacing between them. Calculate the width of each column. [2]
  2. (b) An image 12 cm wide and 9 cm high must fill the full width of one column with its aspect ratio maintained. Calculate the new height. [1]
Show answer
  1. (a) 8 cm
    M1: (21 − 2 − 2 − 1) ÷ 2. A1: 8 cm.
  2. (b) 6 cm
    B1: 9 × 8 ÷ 12 = 6 cm.
Q30Editing images · Challenge · Paper 2 style · 4 marks
  1. (a) A student has inserted a photograph into a two-column report. The teacher notes these problems:• the photograph looks squashed;• it overlaps the right margin by 1 cm;• the text stops above the photograph and starts again below it, leaving large empty spaces at the sides;• the top of the photograph covers part of the header.For each problem, describe how the student should correct it. [4]
Show answer
  1. (a) Squashed: reset the size and resize with the aspect ratio locked (drag a corner handle). Overlaps margin: reduce the width (in proportion) or move it so it fits within the column/margins. Empty spaces: change text wrapping from top and bottom to square/tight. Covers header: move the image down into the body of the page (below the header) / anchor it in the text.
    1 mark per correct fix for each problem (4).
