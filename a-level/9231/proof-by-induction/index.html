Q8Sequences & inequalities · Standard · Paper 1 style · 6 marks
  1. (a) Prove by mathematical induction that 2ⁿ > n² for all integers n ≥ 5. [5]
  2. (b) State the values of n, with 1 ≤ n ≤ 4, for which 2ⁿ > n² is false. [1]
Show answer
  1. (a) Proof by induction (see working).
    B1: n = 5: 2⁵ = 32 > 25.M1: assume 2ᵏ > k² for some k ≥ 5; then 2^(k+1) = 2 × 2ᵏ > 2k².M1: 2k² − (k + 1)² = k² − 2k − 1 = (k − 1)² − 2 > 0 for k ≥ 5 (indeed for k ≥ 3).A1: so 2^(k+1) > (k + 1)².A1: true for n = 5 and true for k + 1 whenever true for k ≥ 5, so true for all n ≥ 5.
  2. (b) n = 2, 3, 4
    B1: 2² = 4 = 4, 2³ = 8 < 9, 2⁴ = 16 = 16 (n = 1: 2 > 1 is true).

  2. (b) Hence find M¹² when θ = π/6. [2]
Show answer

Show answer
  1. (a) Proof by induction (see working).

Q59Matrix powers · Challenge · Paper 1 style · 8 marks
  1. (a) The matrix X is (2 1; 1 2). Prove by mathematical induction that Xⁿ = ½(3ⁿ + 1 3ⁿ − 1; 3ⁿ − 1 3ⁿ + 1) for all positive integers n. [6]
  2. (b) Hence find n for which the top-left entry of Xⁿ equals 365. [2]
Show answer
  1. (a) Proof by induction (see working).

Q60Matrix powers · Challenge · Paper 1 style · 8 marks
  1. (a) The matrix Y is (0 1; −2 3). Prove by mathematical induction that Yⁿ = (2 − 2ⁿ 2ⁿ − 1; 2 − 2ⁿ⁺¹ 2ⁿ⁺¹ − 1) for all positive integers n. [6]
  2. (b) Hence find Y⁵. [2]
Show answer
  1. (a) Proof by induction (see working).
    Base case n = 1: (2 − 2 2 − 1; 2 − 4 4 − 1) = (0 1; −2 3) = Y. M1. Assume Yᵏ has entries a, b, c, d as in the formula. Then YᵏY = (−2b a + 3b; −2d c + 3d).
