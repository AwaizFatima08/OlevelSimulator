Q1Second order: constant coefficients · Core · Paper 2 style · 5 marks
  1. (a) Find the general solution of the differential equation d²y/dx² − 5 dy/dx + 6y = 0. [2]
  2. (b) Given that y = 2 and dy/dx = 5 when x = 0, find the particular solution. [3]
Show answer
  1. (a) y = Ae²ˣ + Be³ˣ
    M1 auxiliary equation m² − 5m + 6 = 0; A1 m = 2, 3 and y = Ae²ˣ + Be³ˣ.
  2. (b) y = e²ˣ + e³ˣ
    M1 A + B = 2; M1 2A + 3B = 5; A1 A = 1, B = 1.
Q2Second order: constant coefficients · Core · Paper 2 style · 6 marks
  1. (a) Find the general solution of d²y/dx² + 4 dy/dx + 13y = 0. [3]
  2. (b) Find the particular solution for which y = 1 and dy/dx = 0 when x = 0. [3]
Show answer
  1. (a) y = e⁻²ˣ(A cos 3x + B sin 3x)
    M1 m² + 4m + 13 = 0; A1 m = −2 ± 3i; A1 y = e⁻²ˣ(A cos 3x + B sin 3x).
  2. (b) y = e⁻²ˣ(cos 3x + (2/3) sin 3x)
    B1 A = 1; M1 differentiate: dy/dx at 0 = −2A + 3B = 0; A1 B = 2/3.
Q3Second order: constant coefficients · Core · Paper 2 style · 5 marks
  1. (a) Find the general solution of the differential equation d²y/dx² + 6 dy/dx + 9y = 18. [4]
  2. (b) State the limit of y as x → ∞. [1]
Show answer
  1. (a) y = (A + Bx)e⁻³ˣ + 2
    M1 m² + 6m + 9 = 0, repeated root m = −3; A1 complementary function (A + Bx)e⁻³ˣ; M1 particular integral y = k gives 9k = 18; A1 y = (A + Bx)e⁻³ˣ + 2.
  2. (b) 2
    B1 (A + Bx)e⁻³ˣ → 0 so y → 2.
Q4Second order: constant coefficients · Core · Paper 2 style · 5 marks
  1. (a) Find the complementary function for the differential equation d²y/dx² − dy/dx − 2y = 4x. [2]
  2. (b) Find a particular integral of the form y = px + q, and hence write down the general solution. [3]
Show answer
  1. (a) Ae²ˣ + Be⁻ˣ
    M1 m² − m − 2 = 0; A1 m = 2, −1.
  2. (b) y = Ae²ˣ + Be⁻ˣ − 2x + 1
    M1 substitute: −p − 2(px + q) = 4x; A1 p = −2, q = 1; A1 general solution y = Ae²ˣ + Be⁻ˣ − 2x + 1.
Q5Second order: constant coefficients · Standard · Paper 2 style · 10 marks
  1. (a) Find the particular solution of the differential equation d²y/dx² + 2 dy/dx + 5y = 10 cos x, given that y = 0 and dy/dx = 0 when x = 0. [10]
Show answer
  1. (a) y = e⁻ˣ(−2 cos 2x − (3/2) sin 2x) + 2 cos x + sin x
    M1 auxiliary equation m² + 2m + 5 = 0; A1 m = −1 ± 2i, CF e⁻ˣ(A cos 2x + B sin 2x); M1 PI p cos x + q sin x; M1 substitute and compare: 4p + 2q = 10, 4q − 2p = 0; A1 p = 2, q = 1; B1 general solution y = e⁻ˣ(A cos 2x + B sin 2x) + 2 cos x + sin x; M1 y(0) = 0: A + 2 = 0; A1 A = −2; M1 y′(0) = −A + 2B + 1 = 0; A1 B = −3/2.
Q6Second order: constant coefficients · Standard · Paper 2 style · 8 marks
  1. (a) The displacement x metres of a model boat on a wave tank at time t seconds satisfies d²x/dt² + 4x = 8t². Find the general solution. [5]
  2. (b) When t = 0, x = 0 and dx/dt = 2. Find x in terms of t. [3]
Show answer
  1. (a) x = A cos 2t + B sin 2t + 2t² − 1
    M1 m² + 4 = 0, m = ±2i; A1 CF A cos 2t + B sin 2t; M1 PI at² + bt + c: 2a + 4(at² + bt + c) = 8t²; A1 a = 2, b = 0, c = −1; A1 general solution.
  2. (b) x = cos 2t + sin 2t + 2t² − 1
    M1 A − 1 = 0 so A = 1; M1 dx/dt = −2A sin 2t + 2B cos 2t + 4t, so 2B = 2; A1 B = 1.
Q7Second order: constant coefficients · Standard · Paper 2 style · 8 marks

Show answer

Q8Second order: constant coefficients · Standard · Paper 2 style · 6 marks
  1. (a) Explain why a particular integral of d²y/dx² + dy/dx − 6y = 10e²ˣ cannot be of the form ke²ˣ. [1]
  2. (b) Using a particular integral of the form kxe²ˣ, find the general solution. [5]
Show answer
  1. (a) e²ˣ is part of the complementary function (m = 2 is a root of the auxiliary equation).
    B1 auxiliary equation m² + m − 6 = 0 has root 2, so ke²ˣ gives zero on the left side.
  2. (b) y = Ae²ˣ + Be⁻³ˣ + 2xe²ˣ
    B1 CF Ae²ˣ + Be⁻³ˣ; M1 y = kxe²ˣ, y′ = ke²ˣ(1 + 2x), y″ = ke²ˣ(4 + 4x); M1 substitute: ke²ˣ(4 + 4x + 1 + 2x − 6x) = 10e²ˣ; A1 5k = 10, k = 2; A1 general solution.
Q9Second order: constant coefficients · Standard · Paper 2 style · 10 marks
  1. (a) Find the solution of 4 d²y/dx² + 4 dy/dx + y = 3x + 2 for which y = 0 and dy/dx = 0 when x = 0. [8]
  2. (b) Show that, for large positive x, the graph of y approaches a straight line, and state its equation. [2]
Show answer
  1. (a) y = (10 + 2x)e^(−x/2) + 3x − 10
    M1 4m² + 4m + 1 = 0; A1 m = −1/2 repeated, CF (A + Bx)e^(−x/2); M1 PI px + q: 4p + px + q = 3x + 2; A1 p = 3, q = −10; M1 y(0) = 0 gives A = 10; M1 differentiate and use y′(0) = 0: B − A/2 + 3 = 0; A1 B = 2; A1 final answer.
  2. (b) y = 3x − 10
    M1 (10 + 2x)e^(−x/2) → 0 as x → ∞; A1 y ≈ 3x − 10.
Q10Second order: constant coefficients · Challenge · Paper 2 style · 8 marks
  1. (a) Show that y = −x cos 3x is a particular integral of d²y/dx² + 9y = 6 sin 3x. [3]
  2. (b) Find the solution for which y = 0 and dy/dx = 1 when x = 0. [4]
  3. (c) Describe the behaviour of y as x becomes large. [1]
Show answer
  1. (a) Shown
    M1 y′ = −cos 3x + 3x sin 3x; M1 y″ = 6 sin 3x + 9x cos 3x; A1 y″ + 9y = 6 sin 3x.
  2. (b) y = (2/3) sin 3x − x cos 3x
    B1 CF A cos 3x + B sin 3x; M1 y(0) = 0 gives A = 0; M1 y′(0) = 3B − 1 = 1; A1 B = 2/3.
  3. (c) y oscillates with amplitude that grows without bound (roughly proportional to x).
    B1 the term −x cos 3x dominates: oscillations of increasing amplitude.
Q11Second order: constant coefficients · Challenge · Paper 2 style · 11 marks
  1. (a) The variable x satisfies d²x/dt² + 2 dx/dt + 2x = 4e⁻ᵗ, with x = 0 and dx/dt = 1 when t = 0. Find x in terms of t. [9]
  2. (b) Find the exact value of x when t = π, and give it correct to 3 significant figures. [2]
Show answer
  1. (a) x = e⁻ᵗ(4 − 4 cos t + sin t)
    M1 m² + 2m + 2 = 0; A1 m = −1 ± i, CF e⁻ᵗ(A cos t + B sin t); M1 PI ke⁻ᵗ: k − 2k + 2k = 4; A1 k = 4; M1 x(0) = 0: A + 4 = 0; A1 A = −4; M1 differentiate, dx/dt at 0 = −A + B − 4 = 1; A1 B = 1; A1 final answer.
  2. (b) 8e^(−π) ≈ 0.346
    M1 e^(−π)(4 + 4 + 0); A1 8e^(−π) = 0.346.
Q12Second order: constant coefficients · Challenge · Paper 2 style · 8 marks
  1. (a) Find a particular integral of d²y/dx² − 4 dy/dx + 4y = 8x² of the form ax² + bx + c. [3]
  2. (b) Show that kx²e²ˣ is a particular integral of d²y/dx² − 4 dy/dx + 4y = e²ˣ for a suitable constant k, and find k. [3]
  3. (c) Hence write down the general solution of d²y/dx² − 4 dy/dx + 4y = 8x² + e²ˣ. [2]
Show answer
  1. (a) 2x² + 4x + 3
    M1 2a − 4(2ax + b) + 4(ax² + bx + c) = 8x²; M1 compare: 4a = 8, 4b − 8a = 0, 2a − 4b + 4c = 0; A1 a = 2, b = 4, c = 3.
  2. (b) k = 1/2
    M1 y′ = ke²ˣ(2x + 2x²), y″ = ke²ˣ(2 + 8x + 4x²); M1 substitute: ke²ˣ(2 + 8x + 4x² − 8x − 8x² + 4x²) = 2ke²ˣ; A1 k = 1/2.
  3. (c) y = (A + Bx)e²ˣ + (1/2)x²e²ˣ + 2x² + 4x + 3
    B1 CF (A + Bx)e²ˣ; B1 sum of both particular integrals.

Q16First order: integrating factor · Core · Paper 2 style · 6 marks

Q18First order: integrating factor · Standard · Paper 2 style · 10 marks
  1. (a) Find the solution of dy/dx + 2xy/(x² + 1) = 4x for which y = 3 when x = 0. Show that it can be written as y = x² + 1 + 2/(x² + 1). [7]
  2. (b) By writing u = x² + 1, find the least value of y, giving your answer in exact form. [3]
Show answer
  1. (a) y = x² + 1 + 2/(x² + 1)
    M1 integrating factor e^(ln(x² + 1)) = x² + 1; A1 d((x² + 1)y)/dx = 4x(x² + 1); M1 integrate: (x² + 1)y = x⁴ + 2x² + c; A1 correct; M1 y(0) = 3 gives c = 3; A1 y = (x⁴ + 2x² + 3)/(x² + 1); A1 = ((x² + 1)² + 2)/(x² + 1) = x² + 1 + 2/(x² + 1).
  2. (b) 2√2
    M1 y = u + 2/u with u ≥ 1; M1 dy/du = 1 − 2/u² = 0 gives u = √2 (≥ 1, so attainable); A1 least value √2 + 2/√2 = 2√2.

Q22First order: integrating factor · Challenge · Paper 2 style · 8 marks

A tank initially holds 100 litres of pure water. Salt solution with concentration 0.2 kg per litre flows in at 3 litres per minute, and the well-mixed solution flows out at 2 litres per minute. The tank does not overflow during the time considered. The mass of salt in the tank after t minutes is S kg.

  1. (a) Show that dS/dt + 2S/(100 + t) = 0.6. [2]
  2. (b) Solve the differential equation to find S in terms of t. [5]
  3. (c) Find the mass of salt in the tank after 50 minutes, correct to 3 significant figures. [1]
Show answer
  1. (a) Shown
    M1 inflow 3 × 0.2 = 0.6 kg/min; volume at time t is 100 + t litres, outflow 2 × S/(100 + t); A1 rearrange to given form.
  2. (b) S = 0.2(100 + t) − 200 000/(100 + t)²
    M1 integrating factor (100 + t)²; A1 d(S(100 + t)²)/dt = 0.6(100 + t)²; M1 S(100 + t)² = 0.2(100 + t)³ + c; M1 S = 0 at t = 0 gives c = −200 000; A1 S = 0.2(100 + t) − 200 000/(100 + t)².
  3. (c) 21.1 kg
    B1 30 − 200 000/22 500 = 21.1 kg.
Q23First order: integrating factor · Challenge · Paper 2 style · 11 marks
  1. (a) Find the solution of x dy/dx − y = x³eˣ, for x > 0, given that y = 2 when x = 1. [7]
  2. (b) Find the exact value of y when x = 2. [1]
  3. (c) Show that dy/dx > 0 for all x > 0. [3]
Show answer
  1. (a) y = x(x − 1)eˣ + 2x
    M1 divide by x: dy/dx − y/x = x²eˣ; A1 integrating factor 1/x; M1 d(y/x)/dx = xeˣ; M1 integrate by parts: y/x = (x − 1)eˣ + c; A1 correct; M1 use (1, 2): c = 2; A1 y = x(x − 1)eˣ + 2x.
  2. (b) 2e² + 4
    B1 2(1)e² + 4 = 2e² + 4.
  3. (c) Shown
    M1 dy/dx = (x² + x − 1)eˣ + 2; M1 for x ≥ 0.62 (where x² + x − 1 ≥ 0) every term is non-negative and 2 > 0; A1 for 0 < x < 0.62, x² + x − 1 > −1 and eˣ < 1.86, so (x² + x − 1)eˣ > −1.86 and dy/dx > 0.
Q24Substitution to reduce a DE · Core · Paper 2 style · 7 marks
  1. (a) Use the substitution y = vx to show that the differential equation dy/dx = (x² + y²)/(xy), x > 0, reduces to x dv/dx = 1/v. [3]
  2. (b) Hence find y² in terms of x, given that y = 2 when x = 1. [4]
Show answer
  1. (a) Shown
    M1 dy/dx = v + x dv/dx; M1 right side = (1 + v²)/v = 1/v + v; A1 x dv/dx = 1/v.
  2. (b) y² = 2x²(ln x + 2)
    M1 separate: v dv = dx/x; A1 v²/2 = ln x + c; M1 x = 1, v = 2: c = 2; A1 y² = 2x²(ln x + 2).
Q25Substitution to reduce a DE · Standard · Paper 2 style · 8 marks
  1. (a) Show that the substitution x = eᵗ transforms the differential equation x² d²y/dx² − 3x dy/dx + 3y = 6 into d²y/dt² − 4 dy/dt + 3y = 6. [4]
  2. (b) Hence find the general solution for y in terms of x. [4]
Show answer
  1. (a) Shown
    M1 dy/dx = e⁻ᵗ dy/dt, so x dy/dx = dy/dt; M1 d²y/dx² = e⁻²ᵗ(d²y/dt² − dy/dt); A1 x² d²y/dx² = d²y/dt² − dy/dt; A1 substitute: d²y/dt² − dy/dt − 3 dy/dt + 3y = 6.
  2. (b) y = Ax + Bx³ + 2
    M1 m² − 4m + 3 = 0, m = 1, 3; A1 CF Aeᵗ + Be³ᵗ; B1 PI y = 2; A1 y = Ax + Bx³ + 2.
Q26Substitution to reduce a DE · Standard · Paper 2 style · 8 marks
  1. (a) Show that the substitution z = 1/y transforms dy/dx + y/x = xy² into dz/dx − z/x = −x. [3]
  2. (b) Hence find y in terms of x, given that y = 1/2 when x = 1. [5]
Show answer
  1. (a) Shown
    M1 dy/dx = −(1/z²) dz/dx; M1 substitute: −(1/z²) dz/dx + 1/(xz) = x/z²; A1 multiply by −z²: dz/dx − z/x = −x.
  2. (b) y = 1/(3x − x²)
    M1 integrating factor 1/x; A1 d(z/x)/dx = −1; M1 z/x = −x + c; M1 z = 2 at x = 1 gives c = 3; A1 y = 1/(3x − x²).
Q27Substitution to reduce a DE · Challenge · Paper 2 style · 9 marks
  1. (a) Show that the substitution y = u/x transforms the differential equation x d²y/dx² + 2 dy/dx + 4xy = 0 into d²u/dx² + 4u = 0. [4]
  2. (b) Find y in terms of x, given that y = 2/π when x = π/4 and y = 0 when x = π/2. [5]
Show answer
  1. (a) Shown
    M1 dy/dx = u′/x − u/x²; M1 d²y/dx² = u″/x − 2u′/x² + 2u/x³; M1 substitute: (u″ − 2u′/x + 2u/x²) + (2u′/x − 2u/x²) + 4u; A1 u″ + 4u = 0.
  2. (b) y = sin 2x/(2x)
    M1 u = A cos 2x + B sin 2x; A1 y = (A cos 2x + B sin 2x)/x; M1 x = π/2: −A/(π/2) = 0, A = 0; M1 x = π/4: B/(π/4) = 2/π; A1 B = 1/2, y = sin 2x/(2x).
Q28Substitution to reduce a DE · Challenge · Paper 2 style · 8 marks
  1. (a) Show that the substitution u = y² transforms the differential equation dy/dx − y = xe²ˣ/y into du/dx − 2u = 2xe²ˣ. [3]
  2. (b) Given that y = 3 when x = 0 and y > 0, find y in terms of x. [5]
Show answer
  1. (a) Shown
    M1 du/dx = 2y dy/dx; M1 multiply the equation by 2y: 2y dy/dx − 2y² = 2xe²ˣ; A1 du/dx − 2u = 2xe²ˣ.
  2. (b) y = eˣ√(x² + 9)
    M1 integrating factor e⁻²ˣ; A1 d(ue⁻²ˣ)/dx = 2x; M1 ue⁻²ˣ = x² + c; M1 u = 9 at x = 0, c = 9; A1 y² = (x² + 9)e²ˣ so y = eˣ√(x² + 9).
Q29Long-term behaviour · Standard · Paper 2 style · 9 marks
  1. (a) The displacement x of a damped oscillator at time t satisfies d²x/dt² + 3 dx/dt + 2x = 4 sin 2t. Find the general solution. [6]
  2. (b) Describe the motion for large values of t, and find the amplitude of this motion in exact form. [3]
Show answer
  1. (a) x = Ae⁻ᵗ + Be⁻²ᵗ − (3/5) cos 2t − (1/5) sin 2t
    M1 m² + 3m + 2 = 0; A1 CF Ae⁻ᵗ + Be⁻²ᵗ; M1 PI p cos 2t + q sin 2t; M1 compare: −2p + 6q = 0, −6p − 2q = 4; A1 p = −3/5, q = −1/5; A1 general solution.
  2. (b) x ≈ −(3/5) cos 2t − (1/5) sin 2t: oscillation with period π and amplitude √10/5 ≈ 0.632
    M1 exponential terms → 0, so x approaches the particular integral; A1 oscillation of period π; A1 amplitude √((3/5)² + (1/5)²) = √10/5.
Q30Long-term behaviour · Challenge · Paper 2 style · 11 marks
  1. (a) Find the solution of d²y/dx² + 2 dy/dx + 10y = 20 + 18e⁻ˣ for which y = 0 and dy/dx = 0 when x = 0. [9]
  2. (b) State what happens to y as x → ∞, and explain why the answer does not depend on the initial conditions. [2]
Show answer
  1. (a) y = e⁻ˣ(−4 cos 3x − (2/3) sin 3x) + 2 + 2e⁻ˣ
    M1 m² + 2m + 10 = 0; A1 m = −1 ± 3i; M1 PI a + be⁻ˣ; A1 10a = 20, a = 2; A1 b(1 − 2 + 10) = 18, b = 2; M1 y(0): A + 2 + 2 = 0, A = −4; M1 y′(0) = −A + 3B − 2 = 0; A1 B = −2/3; A1 final answer.
  2. (b) y → 2
    B1 y → 2; B1 every other term contains the factor e⁻ˣ, which tends to 0 whatever the values of the arbitrary constants.
