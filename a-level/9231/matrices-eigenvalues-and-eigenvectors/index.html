Q1Diagonalisation · Core · Paper 2 style · 6 marks

Matrices are written row by row, with rows separated by semicolons; for example (1 2; 3 4) has first row 1, 2 and second row 3, 4. Column vectors are written as (x, y, z)ᵀ.

  1. (a) The matrices P = (1 1 0; 0 1 1; 0 0 1) and D = diag(2, −1, 3). Find P⁻¹. [2]
  2. (b) Hence find the matrix A = PDP⁻¹. [2]
  3. (c) State the eigenvalues of A and an eigenvector corresponding to the eigenvalue 3. [2]
Show answer
  1. (a) P⁻¹ = (1 −1 1; 0 1 −1; 0 0 1)
    M1 det P = 1 and cofactors; A1.
  2. (b) A = (2 −3 3; 0 −1 4; 0 0 3)
    M1 correct order of multiplication; A1.
  3. (c) 2, −1, 3; (0, 1, 1)ᵀ
    B1 eigenvalues are the entries of D; B1 third column of P.

  2. (b) Use the Cayley-Hamilton theorem to express A⁻¹ in the form pA + qI, and hence find A⁻¹. [3]
Show answer

    M1 A² − 6A + 5I = 0; M1 multiply by A⁻¹: A − 6I + 5A⁻¹ = 0; A1.

    M1 det = 1(−2 − k) − 2(4 − 3k) + 1(2 + 3) = 5k − 5; A1 k = 1.
  2. (b) m = 7; if m ≠ 7 the planes form a triangular prism (no common point, no two planes parallel)
    M1 equation 3 left side = equation 1 + equation 2; A1 m = 4 + 3 = 7; B1 triangular prism, normals not parallel.
  3. (c) r = (−1, 0, 5)ᵀ + t(3, 1, −5)ᵀ
    M1 subtract: x − 3y = −1; M1 parameter y = t; A1 x = 3t − 1, z = 5 − 5t.
Q25Systems of equations & geometric meaning · Challenge · Paper 2 style · 8 marks
  1. (a) Consider the systemx + ky + z = 1x + y + kz = 1kx + y + z = 1Show that the determinant of the matrix of coefficients is (1 − k)²(k + 2). [3]
  2. (b) Find the unique solution when k ≠ 1 and k ≠ −2. [2]
  3. (c) Describe the geometric arrangement of the planes when k = 1 and when k = −2. [3]
Show answer
  1. (a) Shown
    M1 expand: 1(1 − k) − k(1 − k²) + 1(1 − k); M1 (1 − k)(2 − k − k²); A1 (1 − k)(1 − k)(k + 2) (AG).
  2. (b) x = y = z = 1/(k + 2)
    M1 by symmetry or subtracting equations x = y = z; A1 (k + 2)x = 1.
  3. (c) k = 1: all three equations are x + y + z = 1, the same plane (infinitely many solutions); k = −2: adding the equations gives 0 = 3, inconsistent, and no two planes are parallel, so they form a triangular prism
    B1 k = 1 coincident planes; M1 sum of equations for k = −2; A1 prism.

Q28Eigenvalues & eigenvectors · Standard · Paper 2 style · 7 marks

Matrices are written row by row, with rows separated by semicolons; for example (1 2; 3 4) has first row 1, 2 and second row 3, 4. Column vectors are written as (x, y, z)ᵀ.

  1. (a) The matrix A = (1 1 0; 1 0 1; 0 1 1). Show that the characteristic equation of A is λ³ − 2λ² − λ + 2 = 0. [3]
  2. (b) Hence find the eigenvalues of A and a corresponding eigenvector for each. [4]
Show answer
  1. (a) Shown
    M1 det(A − λI) = (1 − λ)[−λ(1 − λ) − 1] − 1(1 − λ); A1 simplification; A1 −(λ³ − 2λ² − λ + 2) = 0 (AG).
  2. (b) λ = 2: (1, 1, 1)ᵀ; λ = 1: (1, 0, −1)ᵀ; λ = −1: (1, −2, 1)ᵀ
    B1 eigenvalues 2, 1, −1; A1 A1 A1 eigenvectors.
Q29Eigenvalues & eigenvectors · Standard · Paper 2 style · 8 marks

Matrices are written row by row, with rows separated by semicolons; for example (1 2; 3 4) has first row 1, 2 and second row 3, 4. Column vectors are written as (x, y, z)ᵀ.

  1. (a) The matrix A = (2 1; 4 −1). Find the eigenvalues of A and corresponding eigenvectors. [4]
  2. (b) Show that if e is an eigenvector of A with eigenvalue λ, then e is an eigenvector of A² + 2A with eigenvalue λ² + 2λ. [2]
  3. (c) Hence state the eigenvalues of A² + 2A and deduce the value of det(A² + 2A). [2]
Show answer
  1. (a) λ = 3: (1, 1)ᵀ; λ = −2: (1, −4)ᵀ
    M1 λ² − λ − 6 = 0; A1 3, −2; A1 A1 eigenvectors.
  2. (b) Shown
    M1 A²e = A(λe) = λ²e; A1 (A² + 2A)e = (λ² + 2λ)e (AG).
  3. (c) 15 and 0; det = 0
    B1 9 + 6 and 4 − 4; B1 product 0.
Q30Eigenvalues & eigenvectors · Challenge · Paper 2 style · 8 marks

Matrices are written row by row, with rows separated by semicolons; for example (1 2; 3 4) has first row 1, 2 and second row 3, 4. Column vectors are written as (x, y, z)ᵀ.

  1. (a) The matrix A = (2 a 0; 1 1 1; 0 1 2), where a is a constant. Show that the characteristic equation of A is (λ − 2)(λ² − 3λ + 1 − a) = 0. [3]
  2. (b) Given that 4 is an eigenvalue of A, find a and the other eigenvalues. [3]
  3. (c) Find an eigenvector corresponding to the eigenvalue 4. [2]
Show answer
  1. (a) Shown
    M1 expand det(A − λI) along the first row: (2 − λ)[(1 − λ)(2 − λ) − 1] − a(2 − λ); M1 take out factor (2 − λ); A1 (2 − λ)(λ² − 3λ + 1 − a) = 0 (AG).
  2. (b) a = 5; eigenvalues 2 and −1
    M1 16 − 12 + 1 − a = 0; A1 a = 5; A1 λ² − 3λ − 4 = 0 gives 4, −1, plus 2.
  3. (c) (5, 2, 1)ᵀ
    M1 (A − 4I)x = 0; A1.
