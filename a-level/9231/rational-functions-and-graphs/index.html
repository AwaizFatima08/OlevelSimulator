Q1Stationary points & range · Core · Paper 1 style · 7 marks
  1. (a) The curve C has equation y = (x² + 3)/(x − 1). Find the coordinates of the stationary points of C. [4]
  2. (b) Determine the nature of each stationary point and hence state the set of values that y cannot take. [3]
Show answer
  1. (a) (−1, −2) and (3, 6)
    M1 quotient rule: dy/dx = (2x(x − 1) − (x² + 3))/(x − 1)²; A1 = (x² − 2x − 3)/(x − 1)²; M1 set numerator = 0: (x − 3)(x + 1) = 0; A1 (−1, −2) and (3, 6).
  2. (b) (−1, −2) is a maximum, (3, 6) is a minimum; y cannot take values with −2 < y < 6
    M1 sign of dy/dx either side (or second derivative); A1 max at (−1, −2), min at (3, 6); B1 −2 < y < 6 excluded (the two branches lie either side of x = 1).
Q2Stationary points & range · Core · Paper 1 style · 6 marks
  1. (a) The curve C has equation y = (x − 2)/(x² + 5). By considering a quadratic equation in x, show that −1/2 ≤ y ≤ 1/10 for all real x. [4]
  2. (b) Hence find the coordinates of the turning points of C. [2]
Show answer
  1. (a) −1/2 ≤ y ≤ 1/10
    M1 rearrange: yx² − x + (5y + 2) = 0; M1 real x requires discriminant ≥ 0: 1 − 4y(5y + 2) ≥ 0; A1 20y² + 8y − 1 ≤ 0, i.e. (10y − 1)(2y + 1) ≤ 0; A1 −1/2 ≤ y ≤ 1/10.
  2. (b) (5, 1/10) and (−1, −1/2)
    M1 at the extreme values the quadratic has a repeated root x = 1/(2y); A1 y = 1/10 gives x = 5, y = −1/2 gives x = −1.

  2. (b) Hence find the coordinates of the turning points of C. [2]
Show answer
  1. (a) −1 ≤ y ≤ 1 (shown)

Q6Stationary points & range · Standard · Paper 1 style · 8 marks
  1. (a) The curve C has equation y = (x² + x + 1)/(x² − x + 1). Explain why C has no vertical asymptotes and state the equation of its horizontal asymptote. [2]
  2. (b) Show that 1/3 ≤ y ≤ 3 for all real x. [4]
  3. (c) Find the coordinates of the stationary points of C. [2]
Show answer
  1. (a) x² − x + 1 = (x − 1/2)² + 3/4 > 0, so the denominator is never zero; horizontal asymptote y = 1
    B1 completing the square (or discriminant −3 < 0); B1 y = 1.
  2. (b) 1/3 ≤ y ≤ 3
    M1 (y − 1)x² − (y + 1)x + (y − 1) = 0; M1 discriminant (y + 1)² − 4(y − 1)² ≥ 0; A1 (3 − y)(3y − 1) ≥ 0; A1 1/3 ≤ y ≤ 3 (y = 1 also gives real x = 0).
  3. (c) (1, 3) maximum and (−1, 1/3) minimum
    M1 repeated root x = (y + 1)/(2(y − 1)); A1 (1, 3) and (−1, 1/3).

Q8Stationary points & range · Standard · Paper 1 style · 6 marks
  1. (a) The function f is defined for all real x by f(x) = (x² − 3x)/(x² + 3). Find the range of f. [5]
  2. (b) State the x-coordinate at which f takes its greatest value. [1]
Show answer
  1. (a) −1/2 ≤ f(x) ≤ 3/2
    M1 y(x² + 3) = x² − 3x gives (y − 1)x² + 3x + 3y = 0; M1 discriminant 9 − 12y(y − 1) ≥ 0; A1 4y² − 4y − 3 ≤ 0; M1 (2y − 3)(2y + 1) ≤ 0; A1 −1/2 ≤ y ≤ 3/2.
  2. (b) x = −3
    B1 x = −3/(2(y − 1)) with y = 3/2 gives x = −3 (check: f(−3) = 18/12 = 3/2).

  2. (b) Find the exact x-coordinate at which f takes its greatest value. [2]
Show answer
  1. (a) 3 − √5 ≤ f(x) ≤ 3 + √5
    M1 (y − 1)x² − 2x + (y − 5) = 0; M1 discriminant 4 − 4(y − 1)(y − 5) ≥ 0; A1 y² − 6y + 4 ≤ 0; A1 3 − √5 ≤ y ≤ 3 + √5 (y = 1 is attained at x = −2, inside the interval).

Q11Stationary points & range · Standard · Paper 1 style · 7 marks
  1. (a) The curve C has equation y = (x² + 3x)/(x − 1). Show that the line y = k meets C at two distinct points if and only if (k − 1)(k − 9) > 0. [4]
  2. (b) Deduce the coordinates of the stationary points of C. [3]
Show answer
  1. (a) (k − 1)(k − 9) > 0 (shown)
    M1 x² + 3x = k(x − 1) ⇒ x² + (3 − k)x + k = 0; M1 discriminant (3 − k)² − 4k > 0; A1 k² − 10k + 9 > 0; A1 (k − 1)(k − 9) > 0 (and x = 1 is never a root since 1 + 3 − k + k ≠ 0).
  2. (b) (−1, 1) and (3, 9)
    M1 tangent when k = 1 or k = 9, repeated root x = (k − 3)/2; A1 k = 1 ⇒ (−1, 1); A1 k = 9 ⇒ (3, 9).
Q12Stationary points & range · Challenge · Paper 1 style · 9 marks
  1. (a) The curve C has equation y = (ax + 1)/(x² + 1), where a is a positive constant. Show that the set of values taken by y is (1 − √(1 + a²))/2 ≤ y ≤ (1 + √(1 + a²))/2. [4]
  2. (b) Given that the greatest value of y is 3, find the exact value of a and the least value of y. [3]
  3. (c) Find the exact x-coordinates of the stationary points of C for this value of a. [2]
Show answer
  1. (a) (1 − √(1 + a²))/2 ≤ y ≤ (1 + √(1 + a²))/2
    M1 yx² − ax + (y − 1) = 0; M1 discriminant a² − 4y(y − 1) ≥ 0; A1 4y² − 4y − a² ≤ 0; A1 roots y = (1 ± √(1 + a²))/2, so y lies between them.
  2. (b) a = 2√6; least value −2
    M1 (1 + √(1 + a²))/2 = 3 gives √(1 + a²) = 5; A1 a² = 24, a = 2√6; A1 least value (1 − 5)/2 = −2.
  3. (c) x = √6/3 (maximum) and x = −√6/2 (minimum)
    M1 repeated root x = a/(2y); A1 y = 3 gives x = 2√6/6 = √6/3, y = −2 gives x = −2√6/4 = −√6/2.
Q13Stationary points & range · Challenge · Paper 1 style · 9 marks
  1. (a) The curve C has equation y = (x² − 2x + λ)/(x − 3), where λ is a constant and λ ≠ −3. Show that C has two stationary points if and only if λ > −3. [4]
  2. (b) For λ = 1, find the coordinates of the stationary points and state the set of values of y for which the line y = k does not meet C. [4]
  3. (c) Explain why, for λ = 1, the curve touches the x-axis. [1]
Show answer
  1. (a) Stationary points exist iff λ > −3
    M1 dy/dx = ((2x − 2)(x − 3) − (x² − 2x + λ))/(x − 3)²; A1 numerator x² − 6x + 6 − λ; M1 two distinct roots iff 36 − 4(6 − λ) > 0; A1 12 + 4λ > 0 so λ > −3 (and x = 3 is not a root since λ ≠ −3).
  2. (b) (1, 0) maximum and (5, 8) minimum; 0 < k < 8
    M1 x² − 6x + 5 = 0; A1 x = 1, 5; A1 (1, 0) and (5, 8); B1 the line misses C for 0 < k < 8.
  3. (c) The numerator is (x − 1)², so y = 0 only at x = 1, which is a stationary point
    B1 repeated root of the numerator at the maximum point (1, 0).
Q14Stationary points & range · Challenge · Paper 1 style · 10 marks
  1. (a) The curve C has equation y = (x − a)/((x − 1)(x − 4)), where a is a constant with a ≠ 1 and a ≠ 4. Show that every value of y taken by C satisfies 9y² + (10 − 4a)y + 1 ≥ 0. [4]
  2. (b) In the case a = 0, find the set of values that y cannot take and the coordinates of the stationary points of C. [4]
  3. (c) Find the set of values of a for which C has no stationary points. [2]
Show answer
  1. (a) 9y² + (10 − 4a)y + 1 ≥ 0 (shown)
    M1 yx² − (5y + 1)x + (4y + a) = 0; M1 discriminant (5y + 1)² − 4y(4y + a) ≥ 0; A1 25y² + 10y + 1 − 16y² − 4ay ≥ 0; A1 9y² + (10 − 4a)y + 1 ≥ 0.

    M1 no gap in range iff discriminant of the quadratic in y is negative: (10 − 4a)² − 36 < 0; A1 |10 − 4a| < 6 ⇒ 1 < a < 4.

  3. (c) In the case k = 1, find the exact set of values of y for which C does not exist. [4]
Show answer
  1. (a) k = 4; C is the line y = x + 2 with the point (−2, 0) removed
