Q1Symmetric functions & power sums · Core · Paper 1 style · 4 marks

The equation 2x³ − 5x² + 3x − 7 = 0 has roots α, β and γ.

  1. (a) Find the value of α² + β² + γ². [2]
  2. (b) Find the value of 1/α + 1/β + 1/γ. [2]
Show answer
  1. (a) 13/4
    M1 α² + β² + γ² = (Σα)² − 2Σαβ with Σα = 5/2, Σαβ = 3/2; A1 25/4 − 3 = 13/4.
  2. (b) 3/7
    M1 Σ1/α = Σαβ/αβγ with αβγ = 7/2; A1 (3/2)/(7/2) = 3/7.
Q2Symmetric functions & power sums · Core · Paper 1 style · 5 marks

The equation x³ + 4x² − 2x + 9 = 0 has roots α, β and γ.

  1. (a) Show that α²β² + β²γ² + γ²α² = (αβ + βγ + γα)² − 2αβγ(α + β + γ), and hence find its value. [3]
  2. (b) Hence find the value of 1/α² + 1/β² + 1/γ². [2]
Show answer
  1. (a) −68
    M1 expand (Σαβ)² = Σα²β² + 2αβγΣα; B1 Σα = −4, Σαβ = −2, αβγ = −9; A1 4 − 2(−9)(−4) = −68.
  2. (b) −68/81
    M1 Σ1/α² = Σα²β²/(αβγ)²; A1 (−68)/81 = −68/81.
Q3Symmetric functions & power sums · Core · Paper 1 style · 5 marks

The equation 3x³ − x² + 6x + 2 = 0 has roots α, β and γ.

  1. (a) Find the value of (α + 1)(β + 1)(γ + 1). [2]
  2. (b) Find the value of α² + β² + γ². [2]
  3. (c) Explain what your answer to part (b) tells you about the roots of the equation. [1]
Show answer
  1. (a) 8/3
    M1 expand: αβγ + Σαβ + Σα + 1 with Σα = 1/3, Σαβ = 2, αβγ = −2/3; A1 8/3.
  2. (b) −35/9
    M1 (1/3)² − 2(2); A1 −35/9.
  3. (c) Not all roots are real: one real root and two non-real (complex conjugate) roots.
    B1 sum of squares of real numbers cannot be negative, so the roots are not all real; real coefficients so exactly one real root and a conjugate pair.
Q4Symmetric functions & power sums · Core · Paper 1 style · 6 marks

The equation x⁴ − 3x³ + 5x − 2 = 0 has roots α, β, γ and δ.

  1. (a) Write down the values of Σα, Σαβ, Σαβγ and αβγδ. [2]
  2. (b) Find the value of α² + β² + γ² + δ². [2]
  3. (c) Find the value of 1/α + 1/β + 1/γ + 1/δ. [2]
Show answer
  1. (a) Σα = 3, Σαβ = 0, Σαβγ = −5, αβγδ = −2
    B2 all four correct (B1 for two or three correct).
  2. (b) 9
    M1 (Σα)² − 2Σαβ; A1 9 − 0 = 9.
  3. (c) 5/2
    M1 Σαβγ/αβγδ; A1 (−5)/(−2) = 5/2.

  2. (b) Find the values of S₂, S₃ and S₄. [4]

Q9Symmetric functions & power sums · Standard · Paper 1 style · 8 marks

The equation 2x⁴ + x³ − 4x² + 3x − 6 = 0 has roots α, β, γ and δ.

  1. (a) Find the value of α² + β² + γ² + δ². [2]
  2. (b) Find the value of α³ + β³ + γ³ + δ³. [3]
  3. (c) Find the value of 1/α² + 1/β² + 1/γ² + 1/δ². [3]
Show answer
  1. (a) 17/4
    B1 Σα = −1/2, Σαβ = −2; A1 1/4 + 4 = 17/4.
  2. (b) −61/8
    M1 Σα³ = (Σα)³ − 3(Σα)(Σαβ) + 3Σαβγ, with Σαβγ = −3/2; M1 correct substitution; A1 −1/8 − 3 − 9/2 = −61/8.
  3. (c) −13/12
    M1 Σ1/α = Σαβγ/αβγδ = (−3/2)/(−3) = 1/2; M1 Σ1/(αβ) = Σαβ/αβγδ = 2/3; A1 Σ1/α² = 1/4 − 4/3 = −13/12.
Q10Symmetric functions & power sums · Standard · Paper 1 style · 6 marks

The roots of the equation x³ − 14x² + kx − 64 = 0, where k is a real constant, are real and in geometric progression.

  1. (a) By writing the roots as a/r, a and ar, show that a = 4. [2]
  2. (b) Find the value of k and the three roots. [4]
Show answer
  1. (a) a = 4
    M1 product of roots a³ = 64; A1 a = 4 (real).
  2. (b) k = 56; roots 2, 4, 8
    M1 substitute x = 4: 64 − 224 + 4k − 64 = 0; A1 k = 56; M1 other two roots have sum 14 − 4 = 10 and product 64/4 = 16; A1 roots 2, 4, 8.
Q11Symmetric functions & power sums · Standard · Paper 1 style · 7 marks

The equation 2x³ − 9x² + kx − 3 = 0, where k is a constant, has three real roots in arithmetic progression.

  1. (a) By writing the roots as a − d, a and a + d, find the value of a. [2]
  2. (b) Find the value of k. [2]
  3. (c) Find the exact values of the other two roots. [3]
Show answer
  1. (a) a = 3/2
    M1 sum of roots 3a = 9/2; A1 a = 3/2.
  2. (b) k = 11
    M1 substitute x = 3/2: 27/4 − 81/4 + 3k/2 − 3 = 0; A1 k = 11.
  3. (c) (3 − √5)/2 and (3 + √5)/2
    M1 product of roots (3/2)(a² − d²) = 3/2 so a² − d² = 1; M1 d² = 9/4 − 1 = 5/4; A1 roots 3/2 ± √5/2.
Q12Symmetric functions & power sums · Standard · Paper 1 style · 6 marks

The equation x³ − 3x² + 4x − 5 = 0 has roots α, β and γ.

  1. (a) Find the value of α³ + β³ + γ³. [3]
  2. (b) The matrix M has rows (α, β, γ), (β, γ, α) and (γ, α, β). Show that det M = 3αβγ − (α³ + β³ + γ³) and hence find the value of det M. [3]
Show answer
  1. (a) 6
    B1 Σα = 3, Σαβ = 4, αβγ = 5; M1 Σα³ = (Σα)³ − 3ΣαΣαβ + 3αβγ; A1 27 − 36 + 15 = 6.
  2. (b) 9
    M1 expand det M = α(γβ − α²) − β(β² − αγ) + γ(αβ − γ²); A1 = 3αβγ − Σα³; A1 15 − 6 = 9.

The equation x³ + 5x² − 3x + 2 = 0 has roots α, β and γ.

  1. (a) Show that α²β + α²γ + β²α + β²γ + γ²α + γ²β = (α + β + γ)(αβ + βγ + γα) − 3αβγ, and find its value. [3]
  2. (b) Hence find the value of α/β + β/α + β/γ + γ/β + γ/α + α/γ. [2]

  1. (a) 21
    M1 expand (Σα)(Σαβ) to get the six terms plus 3αβγ; A1 shown; A1 (−5)(−3) − 3(−2) = 21.

    M1 common denominator αβγ gives (sum in (a))/αβγ; A1 21/(−2) = −21/2.
Q14Symmetric functions & power sums · Standard · Paper 1 style · 7 marks

The numbers α, β and γ satisfy α + β + γ = 3, α² + β² + γ² = 17 and α³ + β³ + γ³ = 27.

  1. (a) Find the values of αβ + βγ + γα and αβγ. [4]
  2. (b) Hence find a cubic equation with integer coefficients whose roots are α, β and γ, and solve it. [3]
Show answer
  1. (a) αβ + βγ + γα = −4, αβγ = −12
    M1 Σαβ = ((Σα)² − Σα²)/2 = (9 − 17)/2; A1 −4; M1 Σα³ = (Σα)³ − 3ΣαΣαβ + 3αβγ: 27 = 27 + 36 + 3αβγ; A1 αβγ = −12.
  2. (b) x³ − 3x² − 4x + 12 = 0; roots 3, 2, −2
    B1 x³ − 3x² − 4x + 12 = 0; M1 factorise x²(x − 3) − 4(x − 3) = (x − 3)(x² − 4); A1 3, 2, −2.
Q15Symmetric functions & power sums · Standard · Paper 1 style · 7 marks

The equation x³ + 2x² − x + 3 = 0 has roots α, β and γ.

  1. (a) Find the value of α² + β² + γ². [2]
  2. (b) By writing α + β = −2 − γ, or otherwise, find the value of (α + β)² + (β + γ)² + (γ + α)². [3]
  3. (c) Find the value of (α + β)(β + γ)(γ + α). [2]
Show answer
  1. (a) 6
    M1 (−2)² − 2(−1); A1 6.
  2. (b) 10
    M1 Σ(−2 − γ)² = 12 + 4Σγ + Σγ²; M1 = 12 − 8 + 6; A1 10.
  3. (c) 5
    M1 Π(−2 − γ) = −Π(2 + γ) = −(8 + 4Σγ + 2Σαβ + αβγ) with αβγ = −3; A1 5.
Q16Symmetric functions & power sums · Challenge · Paper 1 style · 8 marks

The equation x³ − x + 4 = 0 has roots α, β and γ.

  1. (a) Find the value of α⁴ + β⁴ + γ⁴. [3]
  2. (b) Show that the equation whose roots are 1/α, 1/β, 1/γ is 4y³ − y² + 1 = 0. [2]
  3. (c) Hence find the value of 1/α³ + 1/β³ + 1/γ³. [3]
Show answer
  1. (a) 2
    M1 α⁴ = α² − 4α from x³ = x − 4; M1 Σα⁴ = Σα² − 4Σα with Σα = 0, Σα² = 0 − 2(−1) = 2; A1 2.
  2. (b) Shown
    M1 substitute x = 1/y: 1/y³ − 1/y + 4 = 0; A1 multiply by y³: 4y³ − y² + 1 = 0.
  3. (c) −47/64
    M1 for the new equation Σ1/α = 1/4, Σ1/(αβ) = 0, Π1/α = −1/4; M1 Σy³ = (Σy)³ − 3ΣyΣyz + 3Πy; A1 1/64 − 3/4 = −47/64.

The equation x⁴ + 2x³ − 3x² + x + 5 = 0 has roots α, β, γ and δ. Let Sₙ = αⁿ + βⁿ + γⁿ + δⁿ.

  1. (a) Find the values of S₂ and S₃. [4]
  2. (b) By summing the equation over all four roots after multiplying it by suitable powers of x, find S₄. [3]

  1. (a) S₂ = 10, S₃ = −29
    B1 Σα = −2, Σαβ = −3, Σαβγ = −1, αβγδ = 5; A1 S₂ = 4 + 6 = 10; M1 S₃ = (Σα)³ − 3ΣαΣαβ + 3Σαβγ; A1 −8 − 18 − 3 = −29.

    M1 x⁴ = −2x³ + 3x² − x − 5 so S₄ = −2S₃ + 3S₂ − S₁ − 5S₀ with S₀ = 4, S₁ = −2; M1 substitution: 58 + 30 + 2 − 20; A1 70.
Q18Symmetric functions & power sums · Challenge · Paper 1 style · 7 marks

The equation x³ + ax² + bx − 6 = 0, where a and b are real constants, has roots α, β and γ. It is given that α² + β² + γ² = 14 and 1/α + 1/β + 1/γ = 11/6.

  1. (a) Show that αβ + βγ + γα = 11. [2]
  2. (b) Find the two possible values of a. [3]
  3. (c) Given also that all three roots are positive, find the roots. [2]
Show answer
  1. (a) Shown
    M1 1/α + 1/β + 1/γ = Σαβ/αβγ; A1 Σαβ = (11/6)(6) = 11.
  2. (b) a = −6 or a = 6
    M1 (Σα)² = Σα² + 2Σαβ = 14 + 22 = 36; A1 Σα = ±6; A1 a = −Σα so a = −6 or 6.
  3. (c) 1, 2, 3
    M1 positive roots so Σα = 6, a = −6: x³ − 6x² + 11x − 6 = 0; A1 (x − 1)(x − 2)(x − 3) = 0 so 1, 2, 3.
Q19Symmetric functions & power sums · Challenge · Paper 1 style · 6 marks

The equation x³ + 3x² − 2x − 1 = 0 has roots α, β and γ.

  1. (a) Show that the sum of the products in pairs of αβ, βγ and γα is αβγ(α + β + γ), and write down the product αβ·βγ·γα in terms of αβγ. [2]
  2. (b) Hence find the value of (αβ)³ + (βγ)³ + (γα)³. [4]
Show answer
  1. (a) αβ·βγ + βγ·γα + γα·αβ = αβγ(α + β + γ); product = (αβγ)²
    B1 each pair product contains αβγ times one root; B1 (αβγ)².
  2. (b) −23
    B1 Σα = −3, Σαβ = −2, αβγ = 1; M1 for u = αβ etc: Σu = −2, Σuv = 1 × (−3) = −3, Πu = 1; M1 Σu³ = (Σu)³ − 3ΣuΣuv + 3Πu; A1 −8 − 18 + 3 = −23.
Q20Symmetric functions & power sums · Challenge · Paper 1 style · 7 marks

The equation x³ − 2x² + 3x − 4 = 0 has roots α, β and γ.

  1. (a) Find the values of α² + β² + γ² and α²β² + β²γ² + γ²α². [3]
  2. (b) Hence find the value of (α² + 1)(β² + 1)(γ² + 1). [2]
  3. (c) Verify your answer to part (b) by considering p(i)p(−i), where p(x) = x³ − 2x² + 3x − 4 and i² = −1. [2]
Show answer
  1. (a) α² + β² + γ² = −2, α²β² + β²γ² + γ²α² = −7
    B1 Σα = 2, Σαβ = 3, αβγ = 4; A1 Σα² = 4 − 6 = −2; A1 Σα²β² = 9 − 2(4)(2) = −7.
  2. (b) 8
    M1 expand: α²β²γ² + Σα²β² + Σα² + 1; A1 16 − 7 − 2 + 1 = 8.
  3. (c) p(i) = −2 + 2i, p(−i) = −2 − 2i, product 8
    M1 p(x) = Π(x − α) so p(i)p(−i) = Π(i − α)(−i − α) = Π(α² + 1); A1 (−2 + 2i)(−2 − 2i) = 8.

The equation x³ − 4x + 1 = 0 has roots α, β and γ. Let Sₙ = αⁿ + βⁿ + γⁿ.

Q22Symmetric functions & power sums · Challenge · Paper 1 style · 8 marks

The equation x⁴ + x² + 2x + 6 = 0 has roots α, β, γ and δ.

  1. (a) Find the value of α² + β² + γ² + δ² and deduce that the equation has at least two non-real roots. [3]
  2. (b) Find the value of α³ + β³ + γ³ + δ³. [2]
  3. (c) Find the value of α⁴ + β⁴ + γ⁴ + δ⁴. [3]
Show answer
  1. (a) −2; at least two non-real roots
    B1 Σα = 0, Σαβ = 1; B1 Σα² = −2; B1 a negative sum of squares means not all roots are real, and with real coefficients non-real roots come in conjugate pairs, so at least two.
  2. (b) −6
    M1 Σα³ = (Σα)³ − 3ΣαΣαβ + 3Σαβγ with Σαβγ = −2; A1 −6.
  3. (c) −22
    M1 α⁴ = −α² − 2α − 6; M1 Σα⁴ = −Σα² − 2Σα − 24; A1 2 − 0 − 24 = −22.

Q25Transformed equations · Core · Paper 1 style · 6 marks

The equation x³ + 2x² − 3x + 1 = 0 has roots α, β and γ.

  1. (a) Using the substitution y = x − 1, find the cubic equation whose roots are α − 1, β − 1 and γ − 1. [3]
  2. (b) Hence find the value of (α − 1)(β − 1)(γ − 1) and of 1/(α − 1) + 1/(β − 1) + 1/(γ − 1). [3]
Show answer
  1. (a) y³ + 5y² + 4y + 1 = 0

    B1 product of new roots = −1; M1 sum of reciprocals = (sum of products in pairs)/(product) = 4/(−1); A1 −4.
Q26Transformed equations · Standard · Paper 1 style · 6 marks

The equation x³ − 4x² + x + 3 = 0 has roots α, β and γ.

  1. (a) Using the substitution y = x², show that the equation whose roots are α², β², γ² is y³ − 14y² + 25y − 9 = 0. [4]
  2. (b) Hence find the value of α⁴ + β⁴ + γ⁴. [2]
Show answer
  1. (a) Shown
    M1 x³ + x = 4x² − 3, i.e. x(x² + 1) = 4x² − 3; M1 square both sides: x²(x² + 1)² = (4x² − 3)²; M1 replace x² by y: y(y + 1)² = (4y − 3)²; A1 y³ − 14y² + 25y − 9 = 0.
  2. (b) 146
    M1 Σy² = 14² − 2(25); A1 146.
Q27Transformed equations · Standard · Paper 1 style · 5 marks

The equation x³ + x² − 2x + 5 = 0 has roots α, β and γ.

  1. (a) Explain why β + γ = −1 − α. [1]
  2. (b) Hence find the cubic equation with roots β + γ, γ + α and α + β. [3]
  3. (c) Hence write down the value of (α + β)(β + γ)(γ + α). [1]
Show answer
  1. (a) α + β + γ = −1 (sum of roots)
    B1 Σα = −b/a = −1.
  2. (b) y³ + 2y² − y − 7 = 0
    M1 y = −1 − x, so substitute x = −1 − y; M1 expand (−1 − y)³ + (−1 − y)² − 2(−1 − y) + 5 = 0; A1 y³ + 2y² − y − 7 = 0.
  3. (c) 7
    B1 product of roots of the new equation = 7.
Q28Transformed equations · Standard · Paper 1 style · 6 marks

The equation 3x³ − 2x² + x − 4 = 0 has roots α, β and γ.

  1. (a) Show that if y = x/(x + 1) then x = y/(1 − y). [1]
  2. (b) Find the cubic equation, with integer coefficients, whose roots are α/(α + 1), β/(β + 1) and γ/(γ + 1). [4]
  3. (c) Hence find the value of α/(α + 1) + β/(β + 1) + γ/(γ + 1). [1]
Show answer
  1. (a) Shown
    B1 y(x + 1) = x so x(1 − y) = y.
  2. (b) 10y³ − 16y² + 13y − 4 = 0
    M1 substitute x = y/(1 − y); M1 multiply by (1 − y)³: 3y³ − 2y²(1 − y) + y(1 − y)² − 4(1 − y)³ = 0; M1 expand; A1 10y³ − 16y² + 13y − 4 = 0.
  3. (c) 8/5
    B1 sum of roots = 8/5.
Q29Transformed equations · Challenge · Paper 1 style · 6 marks

The equation x³ − 2x + 4 = 0 has roots α, β and γ.

  1. (a) Explain why αβ = −4/γ. [1]
  2. (b) Hence show that the equation whose roots are αβ, βγ and γα is y³ + 2y² − 16 = 0. [3]
  3. (c) Hence find the value of α²β² + β²γ² + γ²α². [2]
Show answer
  1. (a) αβγ = −4
    B1 product of roots = −d/a = −4.
  2. (b) Shown
    M1 the new roots are −4/x for each root x, so substitute x = −4/y; M1 −64/y³ + 8/y + 4 = 0; A1 multiply by y³/4: y³ + 2y² − 16 = 0.
  3. (c) 4
    M1 Σu² = (Σu)² − 2Σuv with Σu = −2, Σuv = 0; A1 4.
Q30Transformed equations · Challenge · Paper 1 style · 6 marks

The equation x³ + x − 3 = 0 has roots α, β and γ.

  1. (a) Show that α³ = 3 − α. [1]
  2. (b) Hence find the cubic equation whose roots are α³, β³ and γ³. [3]
  3. (c) Hence find the value of α⁶ + β⁶ + γ⁶. [2]
Show answer
  1. (a) Shown
    B1 α satisfies α³ + α − 3 = 0.
  2. (b) y³ − 9y² + 28y − 27 = 0
    M1 y = 3 − x, so substitute x = 3 − y; M1 (3 − y)³ + (3 − y) − 3 = 0; A1 y³ − 9y² + 28y − 27 = 0.
  3. (c) 25
    M1 Σy² = 9² − 2(28); A1 25.
