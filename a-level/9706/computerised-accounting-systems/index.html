Q2Computerised systems and data security · Core · Paper 1 style · 1 mark
  1. (a) What is the main purpose of making regular backup copies of accounting data? [1]
Show answer
  1. (a) B to allow the data to be restored if it is lost or corrupted
    A backup is a copy kept so that lost or damaged data can be recovered. It does not stop unauthorised reading (A, which needs encryption/passwords) or check accuracy (C).

  1. (a) Which input control checks that a compulsory field, such as a customer code, has been filled in? [1]
Show answer

Q15Computerised systems and data security · Core · Paper 2 style · 4 marks

A business backs up its accounting data every night.

  1. (a) Describe the difference between a full backup and an incremental backup. [2]
  2. (b) State one advantage of each type of backup. [2]
Show answer
  1. (a) A full backup copies all the data each time. An incremental backup copies only the data that has changed since the last backup (of any type).
    1 mark for full backup copying everything; 1 mark for incremental copying only changes since the last backup.
  2. (b) Full backup: restoring the data needs only one set of copies, so it is quicker and simpler. Incremental backup: it takes less time and storage to make each day.
    1 mark for a valid advantage of full backups; 1 mark for a valid advantage of incremental backups.

Q26Computerised systems and data security · Standard · Paper 2 style · 4 marks

A garment exporter in Sialkot has received emails that appear to come from its bank, asking staff to confirm the company's online banking log-in details. Last month another firm in the city had its accounting files locked by ransomware.

  1. (a) Explain what is meant by 'phishing' and suggest one way to protect the business against it. [2]
  2. (b) Explain what is meant by 'ransomware' and suggest one way to protect the business against it. [2]
Show answer
  1. (a) Phishing is a fraudulent message pretending to be from a trusted organisation to trick staff into revealing passwords or bank details. Protection: train staff never to give log-in details by email and to check messages with the bank directly.

  2. (b) Ransomware is malicious software that encrypts or locks files and demands payment to release them. Protection: keep regular backups stored separately so files can be restored without paying, and keep antivirus software and updates current.
    1 mark explanation; 1 mark protection (separate backups, antivirus, updates, not opening unknown attachments).

Q28Computerised systems and data security · Standard · Paper 2 style · 4 marks

Show answer

Q44Computerised systems and data security · Challenge · Paper 2 style · 6 marks

Show answer

Q45Computerised systems and data security · Challenge · Paper 2 style · 7 marks

Margalla Engineering Ltd is replacing its old accounting software with a new system. The finance director must choose between direct changeover (switching completely on one day) and parallel running (running both systems together for three months).

  2. (b) Advise the finance director which method to use. Justify your answer. [6]
Show answer
  1. (a) Operating the old and new systems at the same time, with the same data, so their results can be compared before the old system is dropped.
    B1.
  2. Q49Computerised systems and data security · Challenge · Paper 2 style · 6 marks

Show answer
  1. (a) Partly true: the software keeps debits equal to credits, posts to ledgers and control accounts automatically and removes arithmetic errors, so some manual checks are no longer needed.
