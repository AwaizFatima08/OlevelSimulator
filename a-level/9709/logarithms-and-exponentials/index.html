Q1Linearisation (ln graphs) · Core · Paper 2 style · 4 marks
  1. (a) The variables x and y satisfy y = Kxⁿ, where K and n are constants. The graph of ln y against ln x is a straight line passing through the points (0.5, 2.1) and (2.5, 0.9). Find the values of n and K, giving K correct to 3 significant figures. [4]
Show answer
  1. (a) n = −0.6, K = 11.0
    B1 ln y = ln K + n ln x; M1 gradient (0.9 − 2.1)/(2.5 − 0.5) = −0.6; M1 ln K = 2.1 + 0.6 × 0.5 = 2.4; A1 K = e^{2.4} = 11.0.

  1. (a) The table gives values of x and y. x: 1, 2, 3, 4; y: 6, 12, 24, 48. Show that ln y is a linear function of x, and find the gradient and the intercept on the ln y axis, each correct to 3 significant figures. [4]

Show answer
  1. (a) gradient 0.693, intercept 1.10
    ln y = 1.792, 2.485, 3.178, 3.871. Equal steps of 0.693 for each unit increase in x, so linear (M1, A1). Gradient = ln 2 = 0.693 (A1). Intercept = ln 6 − ln 2 = ln 3 = 1.10 (A1).

    Gradient ln b = ln 2 gives b = 2; intercept ln A = ln 3 gives A = 3 (M1, A1).

  2. (b) Calculate the values of ln N for the table, correct to 2 decimal places, and use them to estimate k and N₀. [4]
  3. (c) Use the model to estimate the number of bacteria after 10 hours, correct to 2 significant figures, and comment on the reliability of this estimate. [2]
Show answer
  1. (a) ln N = ln N₀ + kt; gradient k, intercept ln N₀
    M1 take ln of both sides; A1 gradient k, vertical intercept ln N₀.

    B1 ln N values; M1 gradient (8.32 − 5.52)/8; A1 k = 0.35; A1 N₀ = e^{5.52} ≈ 250.

Q13Linearisation (ln graphs) · Standard · Paper 1 style · 8 marks
  1. (a) The variable V volts satisfies V = 40e^(−0.15t), where t is the time in seconds. The table shows values of V for t = 0, 3, 6, 9: V: 40.0, 25.5, 16.3, 10.4. Complete the table of values of ln V, correct to 3 decimal places, and show that the points lie close to a straight line when ln V is plotted against t. [3]
  2. (b) Use the first and last points to find the gradient of the line, correct to 2 significant figures, and state the value of V when t = 0. [3]

Show answer

  1. (a) A machine part has power P watts at speed v m/s, where P = a × v^b. Two readings are (2, 4) and (4, 32). Show that the graph of ln P against ln v is a straight line, and find its gradient. [3]
  2. (b) Find the values of a and b. [2]
Show answer
  1. (a) gradient 3
    Taking logs: ln P = ln a + b ln v, a straight line in ln v (M1, A1). Gradient = (ln 32 − ln 4)/(ln 4 − ln 2) = ln 8/ln 2 = 3 (M1, A1).

Q15Linearisation (ln graphs) · Standard · Paper 1 style · 8 marks

  2. (b) The line of ln y against 1/x passes through the points (1/x, ln y) = (2, 3.0) and (4, 1.0). Find k, and A correct to 3 significant figures. [4]

Show answer
  1. (a) ln y = ln A + k(1/x)
    ln y = ln A + ln e^(k/x) = ln A + k/x, which is linear in 1/x with gradient k and intercept ln A (M1, A1).
  2. (b) k = −1, A = 148
    Gradient = (1.0 − 3.0)/(4 − 2) = −1, so k = −1 (M1, A1). Intercept: 3.0 = ln A + (−1)(2), so ln A = 5 and A = e⁵ = 148 (M1, A1).
  3. (c) 20.1
    1/x = 2, so ln y = 3 and y = e³ = 20.1 (M1, A1)

A sample of a radioactive substance used in a hospital has mass m grams after t years, where m = 40e^{−0.025t}.

  1. (a) Find the initial mass. [1]
  2. (b) Find the time taken for the mass to fall to 15 g, correct to 3 significant figures. [3]
  3. (c) Find the half-life of the substance, correct to 3 significant figures. [2]
Show answer
  1. (a) 40 g
    B1 t = 0 gives m = 40.
  2. (b) 39.2 years
    M1 e^{−0.025t} = 15/40; M1 −0.025t = ln 0.375; A1 t = 39.2.

Q32Log & exponential equations · Standard · Paper 1 style · 5 marks
  1. (a) Show that the equation ln x + ln(x − 3) = ln 10 can be written as x² − 3x − 10 = 0 for x > 3. [2]
  2. (b) Hence solve the equation ln x + ln(x − 3) = ln 10, giving the exact value of x. [3]
Show answer
  1. (a) x² − 3x − 10 = 0
    ln[x(x − 3)] = ln 10 gives x(x − 3) = 10, so x² − 3x − 10 = 0 (M1, A1).
  2. (b) x = 5
    (x − 5)(x + 2) = 0 gives x = 5 or x = −2 (M1, A1). x = −2 is rejected because ln(x − 3) and ln x need x > 3 (M1, A1).
Q33Log & exponential equations · Standard · Paper 1 style · 5 marks

Show answer

    Let y = 6ˣ: y² − 35y + 216 = 0, so (y − 8)(y − 27) = 0 (M1, A1). 6ˣ = 8 gives x = ln 8/ln 6 = 1.16 (M1, A1). 6ˣ = 27 gives x = ln 27/ln 6 = 1.84 (A1).

Q40Log & exponential equations · Challenge · Paper 1 style · 7 marks
  1. (a) Show that the equation log₂(x + 1) + log₄ x = 3 can be written as x(x + 1)² = 64, where x > 0. [3]
  2. (b) Hence find the value of x, correct to 3 significant figures. [4]
Show answer
  1. (a) x(x + 1)² = 64
    Write log₄ x = ½ log₂ x. Multiply by 2: 2 log₂(x + 1) + log₂ x = 6 (M1, M1). So log₂[x(x + 1)²] = 6 and x(x + 1)² = 64 (A1).
  2. (b) 3.36
    x³ + 2x² + x − 64 = 0. Test x = 3.3: 3.3 × 4.3² = 61.0; x = 3.4: 3.4 × 4.4² = 65.8, so root is between 3.3 and 3.4 (M1). x = 3.36: 3.36 × 4.36² = 63.9; x = 3.37: 3.37 × 4.37² = 64.4. Root x = 3.36 (M1, A1, A1).
