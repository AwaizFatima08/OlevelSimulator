    M1 common denominator 1 − cos² θA1 numerator sin θ(1 + cos θ − 1 + cos θ) = 2 sin θ cos θM1 1 − cos² θ = sin² θA1 2 cos θ/sin θ = 2/tan θ
  2. (b) θ = 21.80°, 201.80°

  1. (a) Prove the identity tan x + 1/tan x ≡ 1/(sin x cos x). [3]
  2. (b) By forming a quadratic equation in tan x, solve tan x + 1/tan x = 4 for 0° < x < 360°, giving exact answers. [4]
Show answer
  1. (a) Proof
    M1 sin x/cos x + cos x/sin xM1 (sin² x + cos² x)/(sin x cos x)A1 1/(sin x cos x)

Q28Trig graphs · Core · Paper 1 style · 6 marks
  1. (a) The function f is defined by f(x) = 3 − 2 cos x for 0 ≤ x ≤ 2π. State the range of f. [2]
  2. (b) Describe the shape of the graph of y = f(x), giving the coordinates of its maximum point and its end-points. [2]
  3. (c) Solve the equation f(x) = 4, giving exact answers. [2]
Show answer
  1. (a) 1 ≤ f(x) ≤ 5
    B1 least value 1 (at x = 0, 2π)B1 greatest value 5 (at x = π)
  2. (b) Cosine curve reflected and stretched; max (π, 5); ends (0, 1) and (2π, 1)
    B1 one 'hump' shape starting and ending at y = 1B1 maximum at (π, 5)
  3. (c) x = 2π/3, 4π/3
    M1 cos x = −1/2A1 2π/3, 4π/3
Q29Trig graphs · Standard · Paper 1 style · 7 marks
  1. (a) The graph of y = a + b sin x, for 0 ≤ x ≤ 2π, where a and b are constants and b > 0, has a maximum point at (π/2, 7) and a minimum point at (3π/2, −1). Find a and b. [2]
  2. (b) Find the x-coordinates of the points where the graph crosses the x-axis, giving answers correct to 3 decimal places. [3]
  3. (c) State the set of values of k for which the equation a + b sin x = k has exactly two solutions for 0 ≤ x ≤ 2π. [2]
Show answer
  1. (a) a = 3, b = 4
    M1 a + b = 7, a − b = −1A1 a = 3, b = 4
  2. (b) x = 3.990, 5.435
    M1 sin x = −3/4A1 π + 0.848 = 3.990A1 2π − 0.848 = 5.435
  3. (c) −1 < k < 7, k ≠ 3
    B1 −1 < k < 7B1 k ≠ 3 (three solutions 0, π, 2π when k = 3)

  2. (b) Find an expression for f⁻¹(x) and state its domain. [3]
  3. (c) Find the exact value of f⁻¹(0.5). [1]
Show answer

    B1 f(π/2) = −1B1 f(−π/2) = 5, range −1 ≤ f(x) ≤ 5

    B1 sin⁻¹(0.5) = π/6
