Q8Binomial probabilities · Core · Paper 5 style · 5 marks

Q10Binomial probabilities · Core · Paper 5 style · 5 marks

Each of 10 students in a class has probability 0.6 of passing a quiz, independently of the others. X is the number of students who pass.

  1. (a) Find the probability that the number passing is between 4 and 7 inclusive. Give your answer correct to 3 significant figures. [3]
  2. (b) Find the standard deviation of X, correct to 2 decimal places. [2]
Show answer
  1. (a) 0.778
    P(4 ≤ X ≤ 7) = Σ C(10,k) 0.6^k 0.4^(10−k) for k = 4, 5, 6, 7 = 0.7779, so 0.778.
  2. (b) 1.55
    Var(X) = npq = 10 × 0.6 × 0.4 = 2.4, so the standard deviation is √2.4 = 1.55 (2 d.p.).

Q20Binomial probabilities · Standard · Paper 5 style · 6 marks

A machine makes components, and each component is defective with probability 0.02, independently of the others. Let n be the number of components inspected.

  1. (a) Find the least number of components n such that P(at least one defective) ≥ 0.5. [4]
  2. (b) State two assumptions needed for the binomial model to be appropriate. [2]
Show answer
  1. (a) 35
    P(at least one defective) = 1 − 0.98ⁿ. For n = 34, 1 − 0.98³⁴ = 0.4968 < 0.5. For n = 35, 1 − 0.98³⁵ = 0.5069 ≥ 0.5. So n = 35.
  2. (b) Independence and a constant probability 0.02 for each component
    Each component is defective independently, and every component has the same probability 0.02 of being defective.
Q21Binomial probabilities · Standard · Paper 5 style · 5 marks

X ~ B(5, p), where p is a constant, and P(X = 1) = 0.4096.

  1. (a) Show that p = 0.2. [3]
  2. (b) Find P(X ≥ 4). [2]
Show answer
  1. (a) p = 0.2
    P(X = 1) = 5p(1 − p)⁴. Checking p = 0.2: 5 × 0.2 × 0.8⁴ = 0.4096. Differentiating, d/dp[p(1 − p)⁴] = (1 − p)³(1 − 5p), so p(1 − p)⁴ has its only maximum at p = 0.2, where it equals 0.4096. So p = 0.2 is the only solution.
  2. (b) 0.00672
    P(X ≥ 4) = P(X = 4) + P(X = 5) = 5 × 0.2⁴ × 0.8 + 0.2⁵ = 0.0064 + 0.00032 = 0.00672.

Q28Binomial probabilities · Challenge · Paper 5 style · 6 marks

Q29Binomial probabilities · Challenge · Paper 5 style · 6 marks

X ~ B(12, 0.3), with q = 1 − p.

  1. (a) Show that P(X = r + 1)/P(X = r) = (n − r)p/((r + 1)(1 − p)). [3]
  2. (b) Hence find the most likely value of X and the probability of this value, correct to 3 significant figures. [3]
Show answer
  1. (a) (n − r)p/((r + 1)(1 − p))
    P(X = r + 1)/P(X = r) = [C(n, r+1) p^(r+1) q^(n−r−1)]/[C(n, r) p^r q^(n−r)] = (n − r)/(r + 1) × p/q.
  2. (b) 3; 0.240
    Ratio for r = 2 → 3: (10 × 0.3)/(3 × 0.7) = 1.43 > 1; for r = 3 → 4: (9 × 0.3)/(4 × 0.7) = 0.96 < 1. So the most likely value is 3, with P(X = 3) = C(12,3) × 0.3³ × 0.7⁹ = 0.2397, so 0.240.

Q47Geometric distribution · Standard · Paper 5 style · 6 marks

  2. (b) Find the probability that the first head occurs on toss 3 or later. [2]
Show answer

Q57Geometric distribution · Challenge · Paper 5 style · 6 marks

X ~ Geo(p), where q = 1 − p.

  1. (a) Show that P(X is odd) = 1/(2 − p). [4]
  2. (b) Find P(X is odd) when p = 0.4. [2]
Show answer
  1. (a) 1/(2 − p)
    P(X odd) = p + pq² + pq⁴ + ... = p/(1 − q²) = p/((1 − q)(1 + q)) = p/(p(1 + q)) = 1/(1 + q) = 1/(2 − p).
  2. (b) 0.625
    P(X odd) = 1/(2 − 0.4) = 1/1.6 = 0.625.

  1. (a) Find the set of values of p for which the median of X is 3, giving the bounds correct to 3 significant figures. [5]
Show answer
  1. (a) 0.206 ≤ p < 0.293
    Median m: smallest m with P(X ≤ m) ≥ 0.5. Median = 3 needs P(X ≤ 2) < 0.5 and P(X ≤ 3) ≥ 0.5. So 1 − q² < 0.5, i.e. q > 0.7071, giving p < 0.2929; and 1 − q³ ≥ 0.5, i.e. q ≤ 0.7937, giving p ≥ 0.2063.

Q60Geometric distribution · Challenge · Paper 5 style · 6 marks

X ~ Geo(p), where P(X = 2) = 0.21.

  1. (a) Find both possible values of p. [4]
  2. (b) For each value of p, find P(X ≥ 4). [2]
Show answer
  1. (a) p = 0.7 or p = 0.3
    P(X = 2) = pq = p(1 − p) = 0.21, so p² − p + 0.21 = 0. Then p = (1 ± √0.16)/2 = (1 ± 0.4)/2, giving p = 0.7 or p = 0.3.
  2. (b) 0.027 (p = 0.7); 0.343 (p = 0.3)
    P(X ≥ 4) = q³. For p = 0.7, q = 0.3 and q³ = 0.027. For p = 0.3, q = 0.7 and q³ = 0.343.
