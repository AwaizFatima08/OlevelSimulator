Q1Probability distribution table · Core · Paper 5 style · 3 marks
  1. (a) The random variable X takes the values 1, 2, 3 and 4 only, and P(X = x) = kx, where k is a constant. Draw up the probability distribution table for X in terms of k and find the value of k. [2]
  2. (b) Find P(X ≥ 3). [1]
Show answer
  1. (a) k = 1/10; P(X = x) = 1/10, 2/10, 3/10, 4/10 for x = 1, 2, 3, 4
    M1 k + 2k + 3k + 4k = 1; A1 k = 1/10.
  2. (b) 7/10
    B1 3/10 + 4/10.

Q29E(X) and Var(X) · Challenge · Paper 5 style · 6 marks
  1. (a) The random variable X has the distribution shown, where a is a constant with a > 2.x: 0, 2, aP(X = x): 0.4, 0.4, 0.2Show that Var(X) = 0.16a² − 0.32a + 0.96. [3]
  2. (b) Given that Var(X) = 4.8, find the value of a. [3]
Show answer
  1. (a) E(X) = 0.8 + 0.2a; E(X²) = 1.6 + 0.2a²; Var(X) = 1.6 + 0.2a² − (0.8 + 0.2a)² = 0.16a² − 0.32a + 0.96
    B1 E(X); B1 E(X²); B1 expand and simplify.
  2. (b) a = 6
    M1 0.16a² − 0.32a − 3.84 = 0 ⇒ a² − 2a − 24 = 0; M1 (a − 6)(a + 4) = 0; A1 a = 6 (a > 2).
Q30E(X) and Var(X) · Challenge · Paper 5 style · 6 marks
  1. (a) A charity in Lahore runs a game in which a player pays Rs 100 to spin a wheel. The probability of landing on gold is 0.05 and the prize is Rs x; the probability of landing on silver is 0.2 and the prize is Rs 200; otherwise there is no prize. The charity wants an expected profit of Rs 25 per game. Find x. [3]
  2. (b) With this value of x, find the standard deviation of the prize money for one game, correct to 3 significant figures. [3]
Show answer
  1. (a) x = 700
    M1 expected prize = 100 − 25 = 75; M1 0.05x + 0.2 × 200 = 75; A1 x = 700.
  2. (b) Rs 164
    M1 E(P²) = 0.05 × 700² + 0.2 × 200² = 32500; M1 Var = 32500 − 75² = 26875; A1 √26875 = 163.9 ≈ 164.
