Q1Polynomials (factor/remainder) · Core · Paper 2 style · 6 marks
  1. (a) The polynomial p(x) is defined by p(x) = 2x³ + ax² − 13x + 6, where a is a constant. It is given that (x − 2) is a factor of p(x). Find the value of a. [2]
  2. (b) Hence factorise p(x) completely and solve the equation p(x) = 0. [4]
Show answer
  1. (a) a = 1
    p(2) = 16 + 4a − 26 + 6 = 0 M1; a = 1 A1
  2. (b) p(x) = (x − 2)(2x − 1)(x + 3); x = 2, ½, −3
    Divide by (x − 2) to get 2x² + 5x − 3 M1 A1; = (2x − 1)(x + 3) A1; x = 2, 1/2, −3 A1
Q2Polynomials (factor/remainder) · Core · Paper 2 style · 4 marks
  1. (a) Find the remainder when x⁴ − 3x³ + 2x − 5 is divided by (x + 2). [2]
  2. (b) Find the remainder when x⁴ − 3x³ + 2x − 5 is divided by (2x − 1). [2]
Show answer
  1. (a) 31
    f(−2) = 16 + 24 − 4 − 5 M1; = 31 A1
  2. (b) −69/16
    f(½) = 1/16 − 3/8 + 1 − 5 M1; = −69/16 A1
Q3Polynomials (factor/remainder) · Core · Paper 2 style · 7 marks
  1. (a) The polynomial x³ + ax² + bx − 8 has a factor (x + 1), and leaves a remainder of −12 when divided by (x − 2). Find the values of a and b. [4]
  2. (b) Factorise the polynomial and hence find the exact roots of the equation x³ + ax² + bx − 8 = 0. [3]
Show answer
  1. (a) a = 1, b = −8
    −1 + a − b − 8 = 0 M1; 8 + 4a + 2b − 8 = −12 M1; solve: a − b = 9, 2a + b = −6 M1; a = 1, b = −8 A1
  2. (b) (x + 1)(x² − 8); x = −1, ±2√2
    x²(x + 1) − 8(x + 1) M1; (x + 1)(x² − 8) A1; x = −1, 2√2, −2√2 A1
Q4Polynomials (factor/remainder) · Core · Paper 1 style · 2 marks
  1. (a) The polynomial f(x) = x³ + 5x² + px − 18, where p is a constant, leaves a remainder of 12 when divided by (x − 2). Find the value of p. [2]
Show answer
  1. (a) p = 1
    Remainder theorem: f(2) = 8 + 20 + 2p − 18 = 12 (M1); 2p = 2, so p = 1 (A1)
Q5Polynomials (factor/remainder) · Core · Paper 1 style · 5 marks
  1. (a) The polynomial p(x) = 2x³ − 3x² + ax − 6 has a factor (x − 2). Find the value of a. [2]
  2. (b) Factorise p(x) completely. [3]
Show answer
  1. (a) a = 1
    p(2) = 16 − 12 + 2a − 6 = 0 (M1), so 2a = 2 and a = 1 (A1)
  2. (b) (x − 2)(2x² + x + 3)
    Divide 2x³ − 3x² + x − 6 by (x − 2) to get 2x² + x + 3 (M1 for method, A1 for quotient); the quadratic has discriminant 1 − 24 < 0, so it does not factorise further (A1)
Q6Polynomials (factor/remainder) · Standard · Paper 2 style · 9 marks
  1. (a) The polynomial p(x) = 6x³ + ax² + bx + 2, where a and b are constants, has a factor (2x + 1) and leaves remainder −6 when divided by (x − 1). Find a and b. [4]
  2. (b) Factorise p(x) completely. [2]
  3. (c) Hence solve the equation 6e³ʸ − 11e²ʸ − 3eʸ + 2 = 0, giving your answers correct to 3 significant figures. [3]
Show answer
  1. (a) a = −11, b = −3
    p(−½) = −¾ + a/4 − b/2 + 2 = 0 M1; p(1) = 8 + a + b = −6 M1; a − 2b = −5 and a + b = −14 M1; a = −11, b = −3 A1
  2. (b) (2x + 1)(3x − 1)(x − 2)
    Divide by (2x + 1): 3x² − 7x + 2 M1; (2x + 1)(3x − 1)(x − 2) A1
  3. (c) y = -1.10, y = 0.693
    eʸ = −½ (rejected, eʸ > 0), ⅓, 2 M1 A1; y = ln(1/3) = −1.10, y = ln 2 = 0.693 A1
Q7Polynomials (factor/remainder) · Standard · Paper 2 style · 8 marks
  1. (a) The polynomial p(x) = x³ − 4x² + ax + b has a factor (x − 3). When p(x) is divided by (x − 2) the remainder is the same as when p(x) is divided by (x + 2). Find a and b. [4]
  2. (b) Find the remainder when p(x) is divided by (x − 2). [1]
  3. (c) Find the exact roots of p(x) = 0. [3]
Show answer
  1. (a) a = −4, b = 21
    p(3) = 0: 3a + b = 9 M1; p(2) = p(−2): 2a + b − 8 = b − 2a − 24 M1; a = −4 A1; b = 21 A1
  2. (b) 5
    8 − 16 − 8 + 21 = 5 B1
  3. (c) x = 3, x = (1 ± √29)/2
    p(x) = (x − 3)(x² − x − 7) M1 A1; x = 3, (1 ± √29)/2 A1
Q8Polynomials (factor/remainder) · Standard · Paper 3 style · 8 marks
  1. (a) The polynomial p(x) = 4x³ + ax² + bx − 3 has factors (2x − 1) and (x + 1). Find the values of a and b. [4]
  2. (b) Hence find the third factor of p(x). [1]
  3. (c) Solve the equation 4cos³θ + 8cos²θ + cos θ − 3 = 0 for 0° ≤ θ ≤ 360°. [3]
Show answer
  1. (a) a = 8, b = 1
    p(½) = ½ + a/4 + b/2 − 3 = 0 M1; p(−1) = −4 + a − b − 3 = 0 M1; a + 2b = 10, a − b = 7 M1; a = 8, b = 1 A1
  2. (b) (2x + 3)
    Compare constant terms / divide: (2x + 3) B1
  3. (c) θ = 60°, 180°, 300°
    cos θ = ½, −1, −3/2 M1; −3/2 has no solutions A1; θ = 60°, 300°, 180° A1
Q9Polynomials (factor/remainder) · Standard · Paper 1 style · 6 marks
  1. (a) The polynomial f(x) = x³ + ax² + bx − 6, where a and b are constants, has a factor (x − 1) and leaves a remainder of −12 when divided by (x + 2). Find the values of a and b. [4]
  2. (b) Hence factorise f(x) completely. [2]
Show answer
  1. (a) a = 2, b = 3
    f(1) = 0 gives a + b = 5 (M1 A1); f(−2) = −8 + 4a − 2b − 6 = −12 gives 2a − b = 1 (M1); solving gives a = 2 and b = 3 (A1)
  2. (b) (x − 1)(x² + 3x + 6)
    Divide f(x) = x³ + 2x² + 3x − 6 by (x − 1) to get x² + 3x + 6 (M1 A1); the discriminant of x² + 3x + 6 is 9 − 24 < 0, so it does not factorise further
Q10Polynomials (factor/remainder) · Standard · Paper 1 style · 6 marks
  1. (a) The polynomial q(x) = 3x³ + ax² − 5x + b, where a and b are constants, leaves a remainder of 9 when divided by (x + 2). It is also given that (x − 1) is a factor of q(x). Find the values of a and b. [4]
  2. (b) Hence factorise q(x) completely. [2]
Show answer
  1. (a) a = 7, b = −5
    q(−2) = −24 + 4a + 10 + b = 9, so 4a + b = 23 (M1 A1); q(1) = 3 + a − 5 + b = 0, so a + b = 2 (M1); solving gives a = 7, b = −5 (A1)
  2. (b) (x − 1)(3x² + 10x + 5)
    Divide q(x) = 3x³ + 7x² − 5x − 5 by (x − 1) (M1); the quadratic 3x² + 10x + 5 has no rational roots (A1)
Q11Polynomials (factor/remainder) · Challenge · Paper 3 style · 8 marks
  1. (a) The polynomial p(x) = x³ + ax² + bx + c leaves remainders 2, 5 and 14 when divided by (x − 1), (x − 2) and (x − 3) respectively. Find a, b and c. [5]
  2. (b) Show that the equation p(x) = 0 has exactly one real root, and state two consecutive integers between which it lies. [3]
Show answer
  1. (a) a = −3, b = 5, c = −1
    Three equations: a + b + c = 1, 4a + 2b + c = −3, 9a + 3b + c = −13 M1 A1; eliminate c: 3a + b = −4, 5a + b = −10 M1; a = −3, b = 5 A1; c = −1 A1
  2. (b) Exactly one real root, between 0 and 1
    p′(x) = 3x² − 6x + 5, discriminant 36 − 60 < 0 so p′(x) > 0 for all x and p is increasing M1 A1; p(0) = −1 < 0, p(1) = 2 > 0, so root between 0 and 1 B1
Q12Polynomials (factor/remainder) · Challenge · Paper 2 style · 9 marks
  1. (a) Given that (x − 3) is a factor of p(x) = 2x³ + ax² − 11x + 6, find a and factorise p(x) completely. [4]
  2. (b) Hence solve the equation 2|x|³ − 3x² − 11|x| + 6 = 0. [2]
  3. (c) Hence solve the equation 2(27ʸ) − 3(9ʸ) − 11(3ʸ) + 6 = 0, giving any non-exact answer correct to 3 significant figures. [3]
Show answer
  1. (a) a = −3; p(x) = (x − 3)(2x − 1)(x + 2)
    54 + 9a − 33 + 6 = 0 M1; a = −3 A1; quotient 2x² + 3x − 2 M1; (x − 3)(2x − 1)(x + 2) A1
  2. (b) x = ±3, ±½
    x² = |x|², so this is p(|x|) = 0 with |x| = 3 or ½ (|x| = −2 rejected) M1; x = ±3, ±½ A1
  3. (c) y = 1, y = -0.631
    3ʸ = 3, ½ (−2 rejected) M1; y = 1 A1; y = ln ½ / ln 3 = −0.631 A1
Q13Polynomials (factor/remainder) · Challenge · Paper 3 style · 7 marks
  1. (a) The polynomial p(x) = x³ + kx² − 4x − 4k, where k is a constant. Show that (x + k) is a factor of p(x) for all values of k. [2]
  2. (b) When p(x) is divided by (x − 3) the remainder is 30. Find k and factorise p(x) completely. [3]
  3. (c) Find the values of k for which the equation p(x) = 0 has exactly two distinct real roots. [2]
Show answer
  1. (a) p(−k) = 0 for all k
    p(−k) = −k³ + k³ + 4k − 4k M1; = 0, so (x + k) is a factor A1
  2. (b) k = 3; (x + 3)(x − 2)(x + 2)
    p(3) = 27 + 9k − 12 − 4k = 15 + 5k = 30 M1; k = 3 A1; p(x) = (x + 3)(x² − 4) = (x + 3)(x − 2)(x + 2) A1
  3. (c) k = 2 or k = −2
    p(x) = (x + k)(x − 2)(x + 2), so there is a repeated root when −k = 2 or −k = −2 M1; k = ±2 A1
Q14Polynomials (factor/remainder) · Challenge · Paper 1 style · 6 marks
  1. (a) The polynomial f(x) = x⁴ + px² + qx + 4, where p and q are constants, has (x + 1) and (x − 2) as factors. Find the values of p and q. [3]
  2. (b) Factorise f(x) completely. [2]
  3. (c) Find the remainder when f(x) is divided by (x − 3). [1]
Show answer
  1. (a) p = −5, q = 0
    f(−1) = 0 gives p − q = −5 (M1 A1); f(2) = 0 gives 4p + 2q = −20 (M1); solving gives p = −5, q = 0 (A1)
  2. (b) (x − 1)(x + 1)(x − 2)(x + 2)
    f(x) = x⁴ − 5x² + 4 = (x² − 1)(x² − 4) (M1); each bracket factorised (A1)
  3. (c) 40
    f(3) = 81 − 45 + 4 = 40
