Q1Discriminant / tangency · Core · Paper 1 style · 3 marks
  1. (a) Find the values of the constant k for which the equation 2x² + kx + 18 = 0 has two equal roots. [3]
Show answer
  1. (a) k = 12 or k = −12
    Equal roots: b² − 4ac = 0 (M1). k² − 4(2)(18) = 0 so k² = 144 (A1). k = ±12 (A1).
Q2Discriminant / tangency · Core · Paper 1 style · 4 marks
  1. (a) Show that the equation 3x² − 5x + 4 = 0 has no real roots. [2]
  2. (b) Find the set of values of the constant p for which the equation x² + 6x + p = 0 has two distinct real roots. [2]
Show answer
  1. (a) Discriminant = −23 < 0, so no real roots
    b² − 4ac = 25 − 48 = −23 (M1). Negative, so no real roots (A1).
  2. (b) p < 9
    36 − 4p > 0 (M1). p < 9 (A1).
Q3Discriminant / tangency · Core · Paper 1 style · 4 marks
  1. (a) The line y = 2x + c is a tangent to the curve y = x² − 4x + 7. Find the value of c and the coordinates of the point where the line touches the curve. [4]
Show answer
  1. (a) c = −2; point of contact (3, 4)
    x² − 4x + 7 = 2x + c gives x² − 6x + (7 − c) = 0 (M1). Tangent: 36 − 4(7 − c) = 0 (M1), c = −2 (A1). Then x² − 6x + 9 = 0, x = 3, y = 4 (A1).
Q4Discriminant / tangency · Core · Paper 1 style · 3 marks
  1. (a) The equation 4x² + (m − 1)x + 1 = 0 has equal roots. Find the possible values of the constant m. [3]
Show answer
  1. (a) m = 5 or m = −3
    Equal roots: b² − 4ac = 0 (M1). (m − 1)² − 4(4)(1) = 0, so (m − 1)² = 16 (M1). m − 1 = ±4, so m = 5 or m = −3 (A1).
Q5Discriminant / tangency · Core · Paper 1 style · 6 marks
  1. (a) Find the set of values of the constant c for which the line y = 3x + c does not meet the curve y = x² + x − 3. [3]
  2. (b) Show that c = −4 gives a line that touches the curve, and state the coordinates of the point of contact. [3]
Show answer
  1. (a) c < −4
    Equate: x² + x − 3 = 3x + c, so x² − 2x − (3 + c) = 0 (M1). No real solutions needs discriminant < 0: 4 + 4(3 + c) < 0 (M1), so 16 + 4c < 0 and c < −4 (A1).
  2. (b) (1, −1)
    With c = −4, x² − 2x + 1 = 0, so (x − 1)² = 0 and the discriminant is zero: the line is a tangent (M1). The repeated root is x = 1 (M1) and y = 3(1) − 4 = −1, so the point of contact is (1, −1) (A1).
Q6Discriminant / tangency · Standard · Paper 1 style · 4 marks
  1. (a) The equation kx² + (k + 3)x + 1 = 0 is a quadratic equation in x, where k is a non-zero constant. Show that its discriminant is k² + 2k + 9. [2]
  2. (b) By completing the square, show that the equation has two distinct real roots for every non-zero value of k. [2]
Show answer
  1. (a) (k + 3)² − 4k = k² + 2k + 9
    b² − 4ac = (k + 3)² − 4(k)(1) (M1) = k² + 6k + 9 − 4k = k² + 2k + 9 (A1).
  2. (b) k² + 2k + 9 = (k + 1)² + 8 ≥ 8 > 0
    (k + 1)² + 8 (M1). A square is never negative, so the discriminant is at least 8 > 0: two distinct real roots for every k ≠ 0 (A1).
Q7Discriminant / tangency · Standard · Paper 1 style · 4 marks
  1. (a) Find the set of values of the constant m for which the line y = mx − 1 does not meet the curve y = x² + 3x + 3. [4]
Show answer
  1. (a) −1 < m < 7
    x² + 3x + 3 = mx − 1 gives x² + (3 − m)x + 4 = 0 (M1). No intersection: (3 − m)² − 16 < 0 (M1). Critical values 3 − m = ±4, m = −1, 7 (A1). −1 < m < 7 (A1).
Q8Discriminant / tangency · Standard · Paper 1 style · 4 marks
  1. (a) The curve y = x² − 2kx + 3k + 4 lies completely above the x-axis. Find the set of possible values of the constant k. [4]
Show answer
  1. (a) −1 < k < 4
    No real roots of x² − 2kx + 3k + 4 = 0: 4k² − 4(3k + 4) < 0 (M1). k² − 3k − 4 < 0 (A1). (k − 4)(k + 1) < 0, critical values −1, 4 (M1). −1 < k < 4 (A1).
Q9Discriminant / tangency · Standard · Paper 1 style · 5 marks
  1. (a) Find the set of values of the constant k for which 2x² − 4kx + (k + 6) > 0 for all real values of x. [5]
Show answer
  1. (a) −3/2 < k < 2
    The graph is a positive quadratic, so it is above the x-axis for all x when the discriminant is negative (M1). (−4k)² − 4(2)(k + 6) < 0 gives 16k² − 8k − 48 < 0 (M1), so 2k² − k − 6 < 0 (A1). (2k + 3)(k − 2) < 0 (M1), so −3/2 < k < 2 (A1).
Q10Discriminant / tangency · Standard · Paper 1 style · 7 marks
  1. (a) The line y = mx + 2 is a tangent to the curve y = 3x² − 2x + 6. Find the two possible values of m, giving your answers in exact form. [4]
  2. (b) For the tangent with m = −2 + 4√3, find the exact coordinates of the point of contact. [3]
Show answer
  1. (a) m = −2 + 4√3 or m = −2 − 4√3
    Equate: 3x² − 2x + 6 = mx + 2, so 3x² − (2 + m)x + 4 = 0 (M1). Discriminant (2 + m)² − 4(3)(4) = 0 gives (2 + m)² = 48 (M1). 2 + m = ±4√3, so m = −2 ± 4√3 (A1, A1).
  2. (b) (2√3/3, 10 − 4√3/3)
    The repeated root is x = (2 + m)/6 = 4√3/6 = 2√3/3 (M1). y = mx + 2 = (−2 + 4√3)(2√3/3) + 2 = 10 − 4√3/3 (M1, A1).
Q11Discriminant / tangency · Challenge · Paper 1 style · 7 marks
  1. (a) The line y = mx + 5 is a tangent to the curve y = 2x² − 3x + 7. Find the two possible values of m. [4]
  2. (b) For each value of m, find the coordinates of the point of contact. [3]
Show answer
  1. (a) m = 1 or m = −7
    2x² − 3x + 7 = mx + 5 gives 2x² − (3 + m)x + 2 = 0 (M1). (3 + m)² − 16 = 0 (M1). 3 + m = ±4 (A1). m = 1 or −7 (A1).
  2. (b) m = 1: (1, 6); m = −7: (−1, 12)
    m = 1: 2x² − 4x + 2 = 0, x = 1, y = 6 (M1 A1). m = −7: 2x² + 4x + 2 = 0, x = −1, y = 12 (A1).
Q12Discriminant / tangency · Challenge · Paper 1 style · 7 marks
  1. (a) The equation kx² + 6x + (k − 8) = 0, where k ≠ 0, has two distinct real roots. Find the set of possible values of k. [4]
  2. (b) Find the value of k for which the equation has equal roots and that root is positive. State the root. [3]
Show answer
  1. (a) −1 < k < 9, k ≠ 0
    36 − 4k(k − 8) > 0 (M1). k² − 8k − 9 < 0 (A1). (k − 9)(k + 1) < 0 (M1). −1 < k < 9 with k ≠ 0 (A1).
  2. (b) k = −1, root x = 3
    Equal roots when k = −1 or 9 (B1). k = −1: −x² + 6x − 9 = 0, x = 3 (positive) (M1). k = 9: 9x² + 6x + 1 = 0, x = −1/3 (negative), so k = −1, root 3 (A1).
Q13Discriminant / tangency · Challenge · Paper 1 style · 6 marks
  1. (a) The line x + 2y = c is a tangent to the curve y = 4/x. Find the possible values of c, giving your answers in exact form. [4]
  2. (b) Find the coordinates of the point of contact for the positive value of c. [2]
Show answer
  1. (a) c = 4√2 or c = −4√2
    y = (c − x)/2, so (c − x)/2 = 4/x (M1). x² − cx + 8 = 0 (A1). Tangent: c² − 32 = 0 (M1). c = ±√32 = ±4√2 (A1).
  2. (b) (2√2, √2)
    x = c/2 = 2√2 (M1). y = 4/(2√2) = √2 (A1).
Q14Discriminant / tangency · Challenge · Paper 1 style · 6 marks
  1. (a) The line y = 2x + k meets the curve y = x² − 4x + 9 at two points P and Q. The x-coordinates of P and Q differ by 4. Find the value of k. [4]
  2. (b) Find the coordinates of P and Q. [2]
Show answer
  1. (a) k = 4
    x² − 4x + 9 = 2x + k gives x² − 6x + (9 − k) = 0 (M1). Roots α, β: α + β = 6 and αβ = 9 − k. (α − β)² = (α + β)² − 4αβ = 36 − 4(9 − k) = 4k (M1). (α − β)² = 16, so 4k = 16 and k = 4 (A1, A1).
  2. (b) P(1, 6) and Q(5, 14)
    With k = 4 the equation is x² − 6x + 5 = 0, so x = 1 or 5 (M1). y = 2x + 4 gives y = 6 or 14 (A1).
Q15Discriminant / tangency · Challenge · Paper 1 style · 6 marks
  1. (a) The curve y = x² − 1 has tangents through the point (0, −5). Each tangent has equation y = mx − 5 for some constant m. Show that m² = 16 for each tangent and state the two equations of the tangents. [4]
  2. (b) Find the coordinates of the point of contact of each tangent. [2]
Show answer
  1. (a) y = 4x − 5 and y = −4x − 5
    Equate x² − 1 = mx − 5, giving x² − mx + 4 = 0 (M1). Tangency: m² − 16 = 0 (M1), so m = ±4 (A1). Tangents: y = 4x − 5 and y = −4x − 5 (A1).
  2. (b) (2, 3) and (−2, 3)
    Repeated root x = m/2, so x = 2 for m = 4 and x = −2 for m = −4 (M1). y = x² − 1 = 3 in both cases (A1).

Q22Completing the square · Standard · Paper 1 style · 6 marks

  1. (a) Express g(x) in the form (ax + b)² + c, where a > 0. [3]
  2. (b) Hence explain why g(x) > 0 for all x, and find the range of the function h(x) = 1/g(x). [3]
Show answer
  1. (a) (2x − 3)² + 4
    a = 2 (B1), b = −3 (B1), c = 13 − 9 = 4 (B1).

Q23Completing the square · Standard · Paper 1 style · 5 marks

A farmer near Sahiwal has 60 m of fencing. She uses it for three sides of a rectangular goat pen; the fourth side is an existing brick wall. The two sides perpendicular to the wall each have length x m.

  1. (a) Show that the area A m² of the pen is given by A = 60x − 2x². [1]
  2. (b) Express A in the form p − q(x − r)² and hence find the greatest possible area and the value of x that gives it. [4]
Show answer
  1. (a) A = x(60 − 2x) = 60x − 2x²
    Side parallel to wall = 60 − 2x, so A = x(60 − 2x) (B1).
  2. (b) A = 450 − 2(x − 15)²; greatest area 450 m² when x = 15
    −2(x² − 30x) = −2[(x − 15)² − 225] (M1) = 450 − 2(x − 15)² (A1 A1). Maximum 450 m² at x = 15 (A1).

Q26Completing the square · Standard · Paper 1 style · 4 marks

  2. (b) Hence find the least possible value of x² + y², and the values of x and y at which it occurs. [2]
Show answer
  1. (a) x² + (20 − x)² = 2x² − 40x + 400 = 2(x − 10)² + 200
    Substitute y = 20 − x: x² + 400 − 40x + x² = 2x² − 40x + 400 (M1). Complete the square: 2(x² − 20x + 100) + 200 = 2(x − 10)² + 200 (M1).
  2. (b) Least value 200, when x = y = 10
    2(x − 10)² is least when x = 10, giving 200 (M1). Then y = 10 (A1).

Show answer

    Expand: 4 − (x² + 2x − 3) = −x² − 2x + 7 (M1). 8 − (x² + 2x + 1) = 7 − 2x − x² (A1).
  2. (b) Maximum (−1, 8); x = −1 + 2√2 and x = −1 − 2√2

  1. (a) The curve y = x² + kx + 2k, where k is a constant, crosses the x-axis at two distinct points. Find the set of values of k. [3]
  2. (b) Find the values of k for which the minimum point of the curve lies on the x-axis. [2]
Show answer
  1. (a) k < 0 or k > 8
    Discriminant k² − 4(2k) > 0 (M1), so k² − 8k > 0 (M1). k(k − 8) > 0 gives k < 0 or k > 8 (A1).
  2. (b) k = 0 or k = 8
    The minimum y-coordinate is 2k − k²/4 (M1). Setting it to zero: k(8 − k) = 0, so k = 0 or k = 8 (A1).

  1. (a) The curve C has equation y = x² − 4x + c and its vertex lies on the line y = 2x − 1. Find the value of c. [3]
  2. (b) For this value of c, explain how many points C has in common with the x-axis. [2]
Show answer
  1. (a) c = 7
    Vertex x-coordinate is 2 and y-coordinate is 4 − 8 + c = c − 4 (M1). On the line: c − 4 = 2(2) − 1 = 3 (M1), so c = 7 (A1).
  2. (b) None: discriminant 16 − 28 < 0
    The discriminant of x² − 4x + 7 is 16 − 28 = −12 < 0 (M1), so C does not meet the x-axis (A1).
Q74Sketching quadratics · Challenge · Paper 1 style · 6 marks
  1. (a) The equation |x² − 4| = k, where k is a constant, has real solutions. Find the number of real solutions when k = 2 and when k = 5. [4]
  2. (b) Find the set of values of k for which the equation has exactly four real solutions. [2]
Show answer
  1. (a) k = 2: 4 solutions; k = 5: 2 solutions
    For k = 2: x² − 4 = 2 gives x² = 6, and x² − 4 = −2 gives x² = 2; each positive value gives two values of x, so 4 solutions (M1, A1). For k = 5: x² − 4 = 5 gives x² = 9 (x = ±3); x² − 4 = −5 gives x² = −1 (no solutions), so 2 solutions (M1, A1).
  2. (b) 0 < k < 4
    Four solutions need x² = 4 + k and x² = 4 − k to be two different positive values, so 0 < k < 4 (M1). For k = 4 the value x² = 0 gives only 3 solutions, and for k = 0 only 2 (A1).
Q75Sketching quadratics · Challenge · Paper 1 style · 5 marks
  1. (a) The curve C has equation y = x² − 2x − 3. The curve C′ is the reflection of C in the x-axis. Find the equation of C′. [2]
  2. (b) Find the coordinates of the turning point of C′. [2]
  3. (c) Explain why C and C′ cross the x-axis at the same points. [1]
Show answer
  1. (a) y = −x² + 2x + 3
    Reflection in the x-axis replaces y by −y: −y = x² − 2x − 3 (M1). So y = −x² + 2x + 3 (A1).
  2. (b) (1, 4)
    C has turning point (1, −4) since x² − 2x − 3 = (x − 1)² − 4 (M1). Reflecting gives (1, 4) (A1).
  3. (c) The reflection maps points on the x-axis (y = 0) to themselves, so the x-intercepts are unchanged
    A point with y = 0 maps to (x, −0) = (x, 0), so every x-intercept of C is also one of C′ (B1).
