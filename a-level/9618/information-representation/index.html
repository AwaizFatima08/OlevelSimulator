Q1Bitmap & vector graphics · Core · Paper 1 style · 5 marks
  1. (a) Define the term pixel. [1]
  2. (b) Define the term image resolution. [1]
  3. (c) Define the term colour depth. [1]
  4. (d) A bitmap file has a file header. State two items of data that are stored in the file header. [2]
Show answer
  1. (a) The smallest addressable element (dot) of a bitmap image, which has a single colour.
    B1: smallest element / dot of a bitmap image that can be given a colour.
  2. (b) The number of pixels in the image, given as width × height in pixels.
    B1: number of pixels (wide × high) in the image. Do not accept screen resolution or 'pixels per inch of a screen'.
  3. (c) The number of bits used to store the colour of each pixel.
    B1: number of bits per pixel (used to represent its colour).
  4. (d) Any two of: image width in pixels, image height in pixels, colour depth (bits per pixel), file type / format, file size, compression type used.
    1 mark each for any two of: width; height (or resolution); colour depth; file type; file size; compression method; colour palette information.
Q2Bitmap & vector graphics · Core · Paper 1 style · 4 marks

A digital camera used by a wildlife survey team in the Margalla Hills takes bitmap photographs with a resolution of 1600 × 1200 pixels and a colour depth of 24 bits. Ignore any file header data.

  1. (a) Calculate the file size of the image in bytes. Show your working. [2]
  2. (b) Convert your answer to part (a) into mebibytes (MiB). Give your answer correct to 2 decimal places. [2]
Show answer
  1. (a) 5 760 000 bytes
    M1: 1600 × 1200 × 24 (= 46 080 000 bits); A1: ÷ 8 = 5 760 000 bytes.
  2. (b) 5.49 MiB
    M1: 5 760 000 ÷ 1024 ÷ 1024 (÷ 2²⁰); A1: 5.49 MiB.

Q4Bitmap & vector graphics · Core · Paper 1 style · 5 marks
  1. (a) A vector graphic is stored as a drawing list. Explain what is meant by a drawing object and by a property in a vector graphic. [2]
  2. (b) A rectangle is one object in the drawing list of a road-sign design. State three properties that would be stored for the rectangle. [3]
Show answer
  1. (a) A drawing object is a shape (such as a line, rectangle or circle) defined by its geometric data; a property is one value that defines how the object looks, such as its position, size or fill colour.
    B1 drawing object: a shape/component of the image defined mathematically / by geometric data. B1 property: a data item describing the object, e.g. coordinates, radius, line colour, fill colour, line thickness.
  2. (b) Any three of: coordinates of one corner (or of its centre), width, height, line (stroke) colour, line thickness, fill colour, rotation angle.
    1 mark each for any three of: position/corner coordinates; width; height; line colour; line thickness/style; fill colour; angle of rotation. Accept coordinates of two opposite corners for position + size (max 2).

  1. (a) Calculate the file size of the photograph in kibibytes (KiB). Show your working. [3]
  2. (b) State the number of different colours that can be represented with this colour depth. [1]
Show answer
  1. (a) 937.5 KiB

  2. (b) 65 536 (2¹⁶)

  2. (b) Calculate the file size of one photograph in kibibytes (KiB). Ignore the file header. [2]
  3. (c) The booth stores the photographs on a 2 GiB memory card. Calculate the maximum number of complete photographs that can be stored on the card. [2]

  2. (b) 468.75 KiB

  3. (c) 4473 photographs
    M1: 2 × 2³⁰ ÷ 480 000 (= 4473.9…); A1: 4473 (must round down to whole photographs).
Q7Bitmap & vector graphics · Standard · Paper 1 style · 4 marks
  1. (a) Explain the effect on the image and on the file size of increasing the colour depth from 8 bits to 16 bits, without changing the resolution. [2]
  2. (b) A student reduces the resolution of a bitmap image from 1200 × 900 pixels to 400 × 300 pixels and then displays it at the original size. Explain why the displayed image looks blocky (pixelated). [2]
Show answer
  1. (a) More colours can be shown (65 536 instead of 256) so colours are more accurate/realistic; the file size doubles because each pixel needs twice as many bits.
    1 mark each: more colours available / smoother, more accurate colour; file size increases (doubles) as more bits per pixel.
  2. (b) There are fewer pixels (one ninth as many), so each pixel must be enlarged to fill the same area; detail is lost and individual pixels become visible as blocks.
    1 mark each: fewer pixels store less detail; each pixel is stretched over a larger area so the pixels become visible / edges become jagged.
Q8Bitmap & vector graphics · Standard · Paper 1 style · 7 marks

A cricket club in Sialkot is designing a logo made from simple shapes. The logo will be printed on small membership cards and on a large banner above the stadium entrance. The designer stores it as a vector graphic.

  1. (a) Explain what is meant by a drawing list in a vector graphic. [2]
  2. (b) One object in the logo is a circle. Its centre is at (120, 80) and its radius is 40. State three other properties that would be stored for the circle in the drawing list. [3]
  3. (c) Explain why a vector graphic is more suitable than a bitmap for this logo. [2]
Show answer
  1. (a) A list of the commands/objects that make up the image; each object is stored with its properties (for example coordinates, size, colours) so the image can be redrawn from the list.
    1 mark each: a set of instructions/commands to draw the shapes (objects); each object has its properties stored, e.g. position, dimensions, line colour, fill colour.
  2. (b) Any three of: line (outline) colour, line thickness, fill colour, line style (solid/dashed), layer/drawing order, transparency.
    1 mark each for any three relevant properties other than centre and radius: line colour; line width/thickness; fill colour; line style; layer/z-order; opacity.
  3. (c) The logo is printed at very different sizes; a vector graphic can be scaled to any size without losing quality because it is redrawn from the drawing list, and its file size is small because it only has simple shapes.
    1 mark each, max 2: scales without pixelation / loss of quality (needed for both card and banner); file size small for simple geometric shapes / independent of output size; shapes can be edited individually.
Q9Bitmap & vector graphics · Standard · Paper 1 style · 5 marks

A tourism office in Gilgit has a simple map of hiking routes made of coloured lines and labelled triangles. It has one version stored as a bitmap and one as a vector graphic.

  1. (a) Describe what happens to the quality of each image when it is enlarged to four times its width and height. [4]
  2. (b) State one reason why the vector version of the map has a much smaller file size than the bitmap version. [1]
Show answer
  1. (a) Bitmap: each pixel is enlarged so the image becomes pixelated/blocky with jagged edges; no new detail is added. Vector: the shapes are recalculated from their properties and redrawn, so lines stay sharp and quality is unchanged.
    Bitmap (2): pixels stretched/made larger; image becomes blocky / blurred / jagged. Vector (2): objects redrawn using coordinates/properties; no loss of quality / edges remain smooth.
  2. (b) Only the properties of a few shapes (lines, polygons) are stored, rather than the colour of every pixel.
    B1: stores shape definitions/properties instead of data for every pixel.
Q10Bitmap & vector graphics · Standard · Paper 1 style · 5 marks

A banner for a food stall in Karachi is saved as a bitmap image of 640 × 360 pixels. The pixel data takes exactly 450 KiB.

  1. (a) Calculate the colour depth of the image. Show your working. [2]
  2. (b) The designer reduces the image to 256 colours without changing the resolution. Calculate the new size of the pixel data in KiB. [2]
  3. (c) Describe one visible effect of the change in part (b) on the image. [1]
Show answer
  1. (a) 16 bits per pixel
    M1 450 × 1024 × 8 = 3 686 400 bits; 640 × 360 = 230 400 pixels. A1 3 686 400 ÷ 230 400 = 16 bits.
  2. (b) 225 KiB
    M1 256 colours need 8 bits per pixel (half of 16). A1 230 400 bytes ÷ 1024 = 225 KiB.
  3. (c) Fewer colours are available, so smooth shading may show banding / colours may look less accurate.
    B1 colour banding / less smooth gradients / some colours replaced by the nearest available colour.
Q11Bitmap & vector graphics · Standard · Paper 1 style · 6 marks
  1. (a) The drawing list of a vector image holds three objects in this order: (1) a large blue rectangle filling the background, (2) a yellow circle, (3) a red triangle that partly overlaps the circle. Describe how the image is drawn from the drawing list and state which colour is seen where the triangle and circle overlap. [3]
  2. (b) The designer moves the circle object to the end of the drawing list. State the effect on the image. [1]
  3. (c) The designer wants the circle to be twice as large. Explain why this change does not reduce the quality of the image. [2]
Show answer
  1. (a) Objects are drawn in the order of the list, each new object on top of the earlier ones, so the rectangle is drawn first, then the circle, then the triangle; red is seen where the triangle overlaps the circle.
    B1 the objects are drawn one at a time in list order. B1 later objects are drawn over / hide earlier ones. B1 the overlap shows red (the triangle).
  2. (b) The yellow circle is now drawn last, so the overlapping region shows yellow.
    B1 the circle appears on top of the triangle / overlap now yellow.
  3. (c) Only the radius property is changed; the circle is recalculated from its geometric definition when drawn, so edges stay sharp and no pixels are stretched.
    B1 change the radius property (data value) only. B1 shape is redrawn/recalculated mathematically at the new size so no pixelation.

  3. (c) The file also contains a file header (metadata such as width, height and colour depth).
    B1: file header / metadata is stored in addition to the pixel data.

Q14Bitmap & vector graphics · Challenge · Paper 1 style · 7 marks

A heritage archive in Lahore scans old family photographs. Each photograph measures 6 inches × 4 inches and is scanned at 600 dots per inch (dpi) with a colour depth of 24 bits. Ignore any header data.

  1. (a) Calculate the size of the pixel data for one scanned photograph in MiB. Give your answer correct to 2 decimal places. [3]
  2. (b) The archive decides to scan at 300 dpi instead. Without repeating the full calculation, state the new size and explain your answer. [2]
  3. (c) Explain why the archive keeps the photographs as bitmaps rather than converting them to vector graphics. [2]
Show answer
  1. (a) 24.72 MiB
    M1 6 × 600 = 3600 and 4 × 600 = 2400 pixels, so 8 640 000 pixels. M1 × 3 bytes = 25 920 000 bytes. A1 ÷ 1 048 576 = 24.72 MiB.
  2. (b) About 6.18 MiB – one quarter of the size, because the number of pixels is halved in both width and height.
    B1 halving dpi halves both dimensions, so pixels × ¼. B1 24.72 ÷ 4 ≈ 6.18 MiB.
  3. (c) A photograph has continuous tones and fine detail with no clear geometric shapes, so it cannot be described efficiently by a drawing list; a vector version would be huge or would lose the realistic detail.
    B1 photographs have many colour variations / not made of simple shapes. B1 vector would not represent the detail realistically / drawing list would be very large.
Q15Bitmap & vector graphics · Challenge · Paper 1 style · 7 marks

A news website shows thumbnail images on a widescreen layout.

  1. (a) The width must be a multiple of 16 pixels and the height a multiple of 9 pixels, in the ratio 16 : 9 (width = 16k, height = 9k for a whole number k). The pixel data must not exceed 2 MiB and the colour depth is 24 bits. Calculate the largest resolution that can be used. Show your working. [4]
  2. (b) Calculate how many bytes of the 2 MiB limit are left unused at this resolution. [1]
  3. (c) Suggest one other way, apart from reducing resolution, to fit a larger image inside the limit, and state a drawback. [2]
Show answer
  1. (a) 1104 × 621 pixels (k = 69)
    M1 size in bytes = 16k × 9k × 3 = 432k². M1 limit 2 × 1 048 576 = 2 097 152 bytes, so k² ≤ 4854.5. M1 k = 69 (k = 70 gives 2 116 800 bytes, too big). A1 1104 × 621.

    B1 2 097 152 − 1104 × 621 × 3 = 2 097 152 − 2 056 752 = 40 400.
  3. (c) Reduce the colour depth (e.g. to 16 bits) – drawback: fewer colours so possible banding. (Or compress the image – lossy compression loses some detail.)
    B1 valid method (reduce colour depth / compress). B1 matching drawback.

Q24Number conversions & units · Standard · Paper 1 style · 5 marks

  1. (a) Write pseudocode for the function Shift(Ch : CHAR, N : INTEGER) RETURNS CHAR. Ch is always an upper-case letter and 0 ≤ N ≤ 25. The function moves Ch forward N places in the alphabet, wrapping round from 'Z' to 'A'. Use ASC(), CHR() and MOD. [4]
  2. (b) State the result of applying Shift with N = 3 to each letter of QUETTA and of ZOX. [2]
Show answer
  1. (a) FUNCTION Shift(Ch : CHAR, N : INTEGER) RETURNS CHAR DECLARE Pos : INTEGER Pos ← ASC(Ch) - ASC('A') Pos ← (Pos + N) MOD 26 RETURN CHR(Pos + ASC('A'))ENDFUNCTION
    1 mark each: convert to position 0–25 by subtracting ASC('A') (65); add N; MOD 26 for the wrap-around; convert back with CHR(… + 65) and RETURN.
  2. (b) TXHWWD and CRA
    B1 TXHWWD. B1 CRA (Z wraps to C).
