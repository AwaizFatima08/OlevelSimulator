    B1 * appears in the <term> rule, a lower level than + in <expr>. B1 lower-level parts are grouped/evaluated first.

Q65Memory management & virtual memory · Standard · Paper 3 style · 6 marks
  1. (a) Explain the difference between paging and segmentation. [3]
  2. (b) Describe how virtual memory allows a program larger than the available RAM to run. [3]
Show answer
  1. (a) In paging, memory is divided into fixed-size blocks: processes are split into pages that are all the same size, which are placed into page frames of the same size.     1 mark each, max 3: secondary storage used as extension of RAM; only needed pages in RAM; pages swapped in/out as needed; page table records where each page is.

Q69Memory management & virtual memory · Standard · Paper 3 style · 5 marks

  2. (b) Describe the steps the operating system takes to deal with a page fault. [4]
Show answer
  1. (a) The process tries to access a page that is not currently in RAM.
    B1.
  2.
