Q2Assembly language & addressing · Core · Paper 1 style · 6 marks
  1. (a) Describe immediate addressing and direct addressing. Give an example instruction for each. [4]

Show answer
  1. (a) Immediate: the operand is the actual value to be used, e.g. LDM #25. Direct: the operand is the address that holds the value to be used, e.g. LDD 25.
