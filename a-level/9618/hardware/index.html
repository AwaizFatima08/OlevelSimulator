Q8Logic gates & circuits · Standard · Paper 1 style · 5 marks

A logic circuit has inputs A, B and C.Gate 1 is a NAND gate with inputs A and B.Gate 2 is a NOR gate with inputs B and C.Gate 3 is an XOR gate whose inputs are the outputs of Gate 1 and Gate 2. Its output is X.

  1. (a) Write the logic expression for X. [2]
  2. (b) Complete the truth table for X for ABC = 000 to 111 in binary order. [3]
Show answer
  1. (a) X = (A NAND B) XOR (B NOR C) [equivalently X = (NOT(A AND B)) XOR (NOT(B OR C))]
    1 mark for each bracketed gate correct; XOR must join them.
  2. (b) X = 01110100A B C | X0 0 0 | 00 0 1 | 10 1 0 | 10 1 1 | 11 0 0 | 01 0 1 | 11 1 0 | 01 1 1 | 0
    Working columns: A NAND B = 11111100, B NOR C = 10001000. 3 marks all 8 correct; 2 marks 6–7 correct; 1 mark 4–5 correct.
Q9Logic gates & circuits · Standard · Paper 1 style · 5 marks

A circuit designer in a Lahore electronics firm wants to build every circuit from NAND gates only, because one chip type is cheaper to stock.

  1. (a) Describe how a single NAND gate can be used as a NOT gate. [1]
  2. (b) Describe how A AND B can be produced using only NAND gates. State how many gates are needed. [2]
  3. (c) Describe how A OR B can be produced using only NAND gates. [2]
Show answer
  1. (a) Connect the input to both inputs of the NAND gate (A NAND A = NOT A).
    B1 (accept: one input fixed at 1 and the other is the input).
  2. (b) Two NAND gates: A and B go into the first NAND gate; its output goes into both inputs of a second NAND gate (acting as NOT).
    1 mark first NAND of A, B; 1 mark second NAND used as NOT, 2 gates.
  3. (c) Three NAND gates: one NAND with both inputs A gives NOT A; one NAND with both inputs B gives NOT B; these two outputs go into a third NAND gate, giving NOT(NOT A AND NOT B) = A OR B.
    1 mark inverting A and B separately with NANDs; 1 mark third NAND combining them.

Q11Logic gates & circuits · Standard · Paper 1 style · 4 marks

A circuit produces the output X = NOT(A OR B) AND C, where A, B and C are inputs.

  1. (a) State the output X for ABC = 001, 100 and 111. [2]
  2. (b) Rewrite the expression X = NOT(A OR B) AND C using only NOT and AND, with no OR. [2]
Show answer
  1. (a) ABC = 001: X = 1; ABC = 100: X = 0; ABC = 111: X = 0.
    1 mark: X = 1 for 001 (NOT(0 OR 0) = 1, AND 1 = 1); 1 mark: X = 0 for 100 and 111 (NOT(1) = 0).
  2. (b) X = (NOT A) AND (NOT B) AND C
    M1: De Morgan: NOT(A OR B) = (NOT A) AND (NOT B); A1: X = (NOT A) AND (NOT B) AND C.

  1. (a) Using a truth table with columns A NAND B, A OR B, X1 and A XOR B, show whether X1 = (A NAND B) AND (A OR B) is equivalent to A XOR B. [4]
  2. (b) A student claims that NOT (A AND B) is the same as (NOT A) AND (NOT B). Give one input combination that proves the claim wrong, stating both outputs. [2]

Q14Logic gates & circuits · Challenge · Paper 1 style · 7 marks

A solar-powered irrigation pump on a farm in Tharparkar is controlled by a logic circuit with four inputs:S = 1 when the soil is dryT = 1 when the storage tank has waterR = 1 when rain is detectedM = 1 when the farmer presses the manual overrideThe pump runs (P = 1) when the tank has water and either the soil is dry and it is not raining, or the manual override is pressed.

  1. (a) Write a logic expression for P. [3]
  2. (b) A truth table for P has 16 rows. State how many rows give P = 1. [2]
  3. (c) The expression can be rewritten with T appearing only once. Write this version and state one advantage of it. [2]
Show answer
  1. (a) P = (S AND T AND NOT R) OR (M AND T)
    1 mark S AND T AND NOT R; 1 mark M AND T; 1 mark joined with OR.
  2. (b) 5
    M1 counting rows: T must be 1 (8 rows); of these, P = 1 when M = 1 (4 rows) or when M = 0, S = 1, R = 0 (1 row). A1 5.
  3. (c) P = T AND ((S AND NOT R) OR M). It needs fewer gates (one fewer AND gate), so the circuit is cheaper / smaller.
    1 mark correct factorised expression; 1 mark advantage.
Q15Logic gates & circuits · Challenge · Paper 1 style · 5 marks

X1 = (A AND NOT B) OR (B AND C)X2 = (A OR B) AND (NOT B OR C)

  1. (a) State the output of X1 for ABC = 100 and for ABC = 110. [2]
  2. (b) Using a truth table for all eight input combinations, decide whether X1 and X2 are equivalent. Justify your answer. [3]
Show answer
  1. (a) ABC = 100: X1 = 1; ABC = 110: X1 = 0.
    1 mark: 100 gives (1 AND NOT 0) OR (0 AND 0) = 1; 1 mark: 110 gives (1 AND 0) OR (1 AND 0) = 0.
  2. (b) Yes, X1 and X2 are equivalent. Both give 1 for ABC = 011, 100, 101 and 111, and 0 for the other four rows, so the outputs are identical in every row.

Q16Input/output devices & sensors · Core · Paper 1 style · 7 marks

A print shop in Rawalpindi uses a laser printer to produce revision booklets for students.

  1. (a) Describe how a laser printer prints a page. [5]
  2. (b) The printer has a buffer. Explain why. [2]
Show answer
  1. (a) Mark points (1 mark each, max 5):• the drum is given an electrostatic charge (by a charge roller / corona wire)• a laser beam scans across the rotating drum• it changes the charge on parts of the drum, forming an electrostatic image of the page• charged toner is attracted to the parts of the drum that form the image• the paper is given a charge so the toner is transferred from the drum to the paper• the fuser unit heats and presses the paper so the toner melts and sticks permanently• the paper/drum is discharged (and the drum cleaned) ready for the next page
    Points must be in a sensible order. No mark for 'ink' instead of toner.
  2. (b) The buffer temporarily stores the data waiting to be printed; the computer sends data much faster than the printer can print, so the computer can transfer the whole job to the buffer and continue with other tasks.
    1 mark temporary store of print data; 1 mark speed difference / CPU freed.

Q24Input/output devices & sensors · Standard · Paper 1 style · 3 marks
  1. (a) Explain why an analogue sensor's output must be converted by an analogue-to-digital converter (ADC) before a microprocessor can use it. [3]
Show answer
  1. (a) An analogue sensor produces a continuously varying voltage, but the processor works only with binary digital values. The ADC samples the voltage at intervals and converts each sample to a binary number, which the processor can then compare with thresholds and process.
    1 mark each for any three: analogue output is continuous; processor only works with binary/digital data; ADC samples and converts to binary; processor can then compare or process the value.

Q28Input/output devices & sensors · Challenge · Paper 1 style · 6 marks

A flower grower in Swat uses an automatic computer control system in a greenhouse. It has a temperature sensor, a heater and motor-driven roof vents.

  1. (a) Describe how the system keeps the greenhouse temperature between 22 °C and 26 °C. [6]
Show answer
  1. (a) 1 mark each, max 6:• a temperature sensor measures the temperature continuously / at regular intervals• the analogue reading is converted by an ADC• the microprocessor compares the reading with the stored values 22 and 26• if the reading is below 22 °C, it sends a signal to switch on the heater (actuator)• if it is above 26 °C, it sends a signal to an actuator to open the vents / switch on the fan (and switch the heater off)• a DAC may be needed to drive the actuators• feedback: the changed temperature is read again by the sensor, which affects the next output• the process repeats continuously (loop)
    Do not award marks for 'the sensor controls the heater' — the microprocessor makes the decision.

  2. (b) Explain why a long gap between readings could cause problems for a greenhouse control system. [2]

Q32Memory & storage · Core · Paper 1 style · 5 marks
  1. (a) Describe how data is written to and read from a magnetic hard disk. [4]
  2. (b) Give one reason why a solid-state drive (SSD) may be chosen instead of a hard disk for a laptop that is carried every day. [1]
Show answer
  1. (a) 1 mark each, max 4:• the disk has platters coated with magnetic material that spin at high speed• a read/write head on an actuator arm moves across the platter to the correct track/sector• to write, the head magnetises tiny areas in one of two directions, representing 1 and 0• to read, the head detects the direction of magnetisation of each area• data is stored in concentric tracks divided into sectors
  2. (b) No moving parts, so it is more robust if dropped / lighter / uses less power / faster access.
    B1.

Q36Memory & storage · Standard · Paper 1 style · 4 marks

Q40Memory & storage · Standard · Paper 1 style · 3 marks
  1. (a) Explain how virtual memory allows a computer to run a program that needs more RAM than is installed. [3]
Show answer
  1. (a) Part of the program's data is moved from RAM to a reserved area on secondary storage (page file/swap space). When it is needed again it is copied back into RAM. This lets the program run, but it is slower because the secondary storage is much slower than RAM.
    1 mark each for any three: part of RAM contents moved to secondary storage; reserved area (page file/swap); pages copied back when needed; slower than RAM.
Q41Memory & storage · Standard · Paper 1 style · 3 marks

Show answer
  1. (a) An SSD has faster access and data transfer because it has no moving parts; it is more durable/resistant to shock. An HDD has a lower cost per GB and usually larger capacity, but it is slower and more easily damaged by movement.

Q45Memory & storage · Challenge · Paper 1 style · 3 marks
  1. (a) Explain why reading a file that is fragmented (its parts are spread across different sectors of a hard disk) takes longer than reading a file stored in contiguous sectors. [3]
Show answer
  1. (a) The read/write head must move between several tracks/positions to collect the parts of the file, and each move adds seek time. The disk must also spin to each sector in turn, so the total access time is longer.
    1 mark each for any three: head must move to several places; seek time added for each movement; rotational delay for each separate sector; parts read one after another so total time increases.
