Q1Logic gates & circuits · Core · Paper 1 style · 3 marks
  1. (a) Complete the truth table for the logic expression X = (A AND B) OR (NOT C). List the output X for the eight input combinations in the order ABC = 000, 001, 010, 011, 100, 101, 110, 111. [2]
  2. (b) The AND gate in this expression is replaced by a single gate whose output is the inverse of AND. Name this gate. [1]
Show answer
  1. (a) X = 10101011A B C | X0 0 0 | 10 0 1 | 00 1 0 | 10 1 1 | 01 0 0 | 11 0 1 | 01 1 0 | 11 1 1 | 1
    2 marks for all 8 outputs correct; 1 mark for 6 or 7 correct. X is 1 whenever C = 0, and also for A = B = C = 1.
  2. (b) NAND
    B1 NAND (NOT AND).

Q6Logic gates & circuits · Standard · Paper 1 style · 6 marks

A greenhouse near Murree has an extractor fan controlled by a logic circuit with three inputs:T = 1 when the temperature is too highH = 1 when the humidity is too highW = 1 when the roof window is openThe fan output F = 1 when the window is closed and either the temperature or the humidity is too high.

  1. (a) Write a logic expression for F. [2]
  2. (b) Complete the truth table for F, giving F for THW = 000, 001, 010, 011, 100, 101, 110, 111. [2]
  3. (c) Describe a logic circuit for F that uses exactly three logic gates. [2]
Show answer
  1. (a) F = (T OR H) AND (NOT W)
    1 mark for (T OR H); 1 mark for AND NOT W. Accept F = (T AND NOT W) OR (H AND NOT W).
  2. (b) F = 00101010T H W | F0 0 0 | 00 0 1 | 00 1 0 | 10 1 1 | 01 0 0 | 11 0 1 | 01 1 0 | 11 1 1 | 0
    2 marks all correct; 1 mark for 6 or 7 correct.
  3. (c) T and H go into an OR gate; W goes into a NOT gate; the outputs of the OR gate and the NOT gate go into an AND gate, whose output is F.
    1 mark OR gate with T, H and NOT gate on W; 1 mark both outputs into an AND gate giving F.
Q7Logic gates & circuits · Standard · Paper 1 style · 5 marks

A logic circuit has inputs A, B and C.Gate 1 is a NAND gate with inputs A and B.Gate 2 is a NOR gate with inputs B and C.Gate 3 is an XOR gate whose inputs are the outputs of Gate 1 and Gate 2. Its output is X.

  1. (a) Write the logic expression for X. [2]
  2. (b) Complete the truth table for X for ABC = 000 to 111 in binary order. [3]
Show answer
  1. (a) X = (A NAND B) XOR (B NOR C) [equivalently X = (NOT(A AND B)) XOR (NOT(B OR C))]
    1 mark for each bracketed gate correct; XOR must join them.
  2. (b) X = 01110100A B C | X0 0 0 | 00 0 1 | 10 1 0 | 10 1 1 | 11 0 0 | 01 0 1 | 11 1 0 | 01 1 1 | 0
    Working columns: A NAND B = 11111100, B NOR C = 10001000. 3 marks all 8 correct; 2 marks 6–7 correct; 1 mark 4–5 correct.
Q8Logic gates & circuits · Standard · Paper 1 style · 5 marks

A circuit designer in a Lahore electronics firm wants to build every circuit from NAND gates only, because one chip type is cheaper to stock.

  1. (a) Describe how a single NAND gate can be used as a NOT gate. [1]
  2. (b) Describe how A AND B can be produced using only NAND gates. State how many gates are needed. [2]
  3. (c) Describe how A OR B can be produced using only NAND gates. [2]
Show answer
  1. (a) Connect the input to both inputs of the NAND gate (A NAND A = NOT A).
    B1 (accept: one input fixed at 1 and the other is the input).
  2. (b) Two NAND gates: A and B go into the first NAND gate; its output goes into both inputs of a second NAND gate (acting as NOT).
    1 mark first NAND of A, B; 1 mark second NAND used as NOT, 2 gates.
  3. (c) Three NAND gates: one NAND with both inputs A gives NOT A; one NAND with both inputs B gives NOT B; these two outputs go into a third NAND gate, giving NOT(NOT A AND NOT B) = A OR B.
    1 mark inverting A and B separately with NANDs; 1 mark third NAND combining them.

Q10Logic gates & circuits · Challenge · Paper 1 style · 6 marks

  3. (c) Explain why a manufacturer might build this function from four NOR gates rather than buying a dedicated gate. [1]

Q11Logic gates & circuits · Challenge · Paper 1 style · 6 marks
  1. (a) Using a truth table with columns A NAND B, A OR B, X1 and A XOR B, show whether X1 = (A NAND B) AND (A OR B) is equivalent to A XOR B. [4]
  2. (b) A student claims that NOT (A AND B) is the same as (NOT A) AND (NOT B). Give one input combination that proves the claim wrong, stating both outputs. [2]
Show answer
  1. (a) A B | A NAND B | A OR B | X1 | A XOR B0 0 | 1 | 0 | 0 | 00 1 | 1 | 1 | 1 | 11 0 | 1 | 1 | 1 | 11 1 | 0 | 1 | 0 | 0X1 and A XOR B are identical in every row, so they are equivalent.

Q12Logic gates & circuits · Challenge · Paper 1 style · 7 marks

A solar-powered irrigation pump on a farm in Tharparkar is controlled by a logic circuit with four inputs:S = 1 when the soil is dryT = 1 when the storage tank has waterR = 1 when rain is detectedM = 1 when the farmer presses the manual overrideThe pump runs (P = 1) when the tank has water and either the soil is dry and it is not raining, or the manual override is pressed.

  1. (a) Write a logic expression for P. [3]
  2. (b) A truth table for P has 16 rows. State how many rows give P = 1. [2]
  3. (c) The expression can be rewritten with T appearing only once. Write this version and state one advantage of it. [2]
Show answer
  1. (a) P = (S AND T AND NOT R) OR (M AND T)
    1 mark S AND T AND NOT R; 1 mark M AND T; 1 mark joined with OR.
  2. (b) 5
    M1 counting rows: T must be 1 (8 rows); of these, P = 1 when M = 1 (4 rows) or when M = 0, S = 1, R = 0 (1 row). A1 5.
  3. (c) P = T AND ((S AND NOT R) OR M). It needs fewer gates (one fewer AND gate), so the circuit is cheaper / smaller.
    1 mark correct factorised expression; 1 mark advantage.
Q13Input/output devices & sensors · Core · Paper 1 style · 7 marks

A print shop in Rawalpindi uses a laser printer to produce revision booklets for students.

  1. (a) Describe how a laser printer prints a page. [5]
  2. (b) The printer has a buffer. Explain why. [2]
Show answer
  1. (a) Mark points (1 mark each, max 5):• the drum is given an electrostatic charge (by a charge roller / corona wire)• a laser beam scans across the rotating drum• it changes the charge on parts of the drum, forming an electrostatic image of the page• charged toner is attracted to the parts of the drum that form the image• the paper is given a charge so the toner is transferred from the drum to the paper• the fuser unit heats and presses the paper so the toner melts and sticks permanently• the paper/drum is discharged (and the drum cleaned) ready for the next page
    Points must be in a sensible order. No mark for 'ink' instead of toner.
  2. (b) The buffer temporarily stores the data waiting to be printed; the computer sends data much faster than the printer can print, so the computer can transfer the whole job to the buffer and continue with other tasks.
    1 mark temporary store of print data; 1 mark speed difference / CPU freed.

Q17Input/output devices & sensors · Standard · Paper 1 style · 6 marks

An Urdu-learning app runs on a tablet. Students record themselves reading words using the tablet's microphone and listen to model pronunciation through its speaker.

  1. (a) Describe how the microphone captures a student's speech. [3]
  2. (b) Describe how the speaker plays the recorded model pronunciation. [3]
Show answer
  1. (a) 1 mark each, max 3:• sound waves make the diaphragm vibrate• a coil attached to the diaphragm moves within the field of a permanent magnet• this induces a varying electric current / voltage (an analogue signal)• an ADC converts the analogue signal into digital data
  2. Q19Input/output devices & sensors · Challenge · Paper 1 style · 6 marks

A power company in Gilgit gives its field workers handheld devices for recording meter readings outdoors in winter.

  1. (a) Explain how a capacitive touchscreen detects the position of a touch. [3]
  2. (b) The workers wear thick gloves. Recommend which type of touchscreen should be used and justify your choice. [2]
  3. (c) State one drawback of the type of screen you recommended in (b). [1]
Show answer
  1. (a) 1 mark each, max 3:• the screen has a layer of conductive material carrying an electrostatic field / charge• a finger (a conductor) touching the screen changes the capacitance at that point• sensors / circuits around the screen measure the change• a microprocessor calculates the coordinates of the touch from these measurements
  2. (b) Resistive: it detects pressure (two conductive layers pressed together to complete a circuit), so it works with gloved fingers, whereas a capacitive screen needs a conductive touch.
    1 mark resistive; 1 mark justification referring to gloves/pressure.
  3. (c) e.g. less sharp/clear image / less responsive / usually single-touch only (no multi-touch gestures) / outer layer more easily scratched.
    B1.
Q20Input/output devices & sensors · Challenge · Paper 1 style · 6 marks

A flower grower in Swat uses an automatic computer control system in a greenhouse. It has a temperature sensor, a heater and motor-driven roof vents.

  1. (a) Describe how the system keeps the greenhouse temperature between 22 °C and 26 °C. [6]
Show answer
  1. (a) 1 mark each, max 6:• a temperature sensor measures the temperature continuously / at regular intervals• the analogue reading is converted by an ADC• the microprocessor compares the reading with the stored values 22 and 26• if the reading is below 22 °C, it sends a signal to switch on the heater (actuator)• if it is above 26 °C, it sends a signal to an actuator to open the vents / switch on the fan (and switch the heater off)• a DAC may be needed to drive the actuators• feedback: the changed temperature is read again by the sensor, which affects the next output• the process repeats continuously (loop)
    Do not award marks for 'the sensor controls the heater' — the microprocessor makes the decision.

Q22Memory & storage · Core · Paper 1 style · 5 marks
  1. (a) Describe how data is written to and read from a magnetic hard disk. [4]
  2. (b) Give one reason why a solid-state drive (SSD) may be chosen instead of a hard disk for a laptop that is carried every day. [1]
Show answer
  1. (a) 1 mark each, max 4:• the disk has platters coated with magnetic material that spin at high speed• a read/write head on an actuator arm moves across the platter to the correct track/sector• to write, the head magnetises tiny areas in one of two directions, representing 1 and 0• to read, the head detects the direction of magnetisation of each area• data is stored in concentric tracks divided into sectors
  2. (b) No moving parts, so it is more robust if dropped / lighter / uses less power / faster access.
    B1.
Q23Memory & storage · Standard · Paper 1 style · 4 marks

A laptop sold in Islamabad has 16 GiB of DRAM main memory and 12 MiB of SRAM cache.

  1. (a) Explain why SRAM is used for cache memory and DRAM is used for main memory in this laptop. [4]
Show answer
  1. (a) 1 mark each, max 4:• SRAM uses flip-flops/latches and does not need refreshing, so it has faster access times — cache must be fast• SRAM is more expensive per bit / has lower density, so it is only used in small amounts• DRAM stores bits as charge on capacitors, which must be refreshed regularly• DRAM is cheaper per bit and has higher density, so large main memory (e.g. 16 GiB) is affordable
    Must link features to the use for full marks.

Q26Memory & storage · Challenge · Paper 1 style · 7 marks

A taxi company in Lahore fits dashcams that record video at 8 Mbit/s (1 Mbit = 1 000 000 bits) onto a 64 GiB flash memory card (1 GiB = 2³⁰ bytes).

  1. (a) Calculate the maximum number of whole minutes of video that can be stored on the card. Show your working. [3]
  2. (b) Explain why flash memory is a better choice than a magnetic hard disk for the dashcam. [2]
  3. (c) Describe how a bit is stored in flash memory. [2]
Show answer
  1. (a) 1145 minutes
    M1 card size in bits: 64 × 2³⁰ × 8 = 549,755,813,888 bitsM1 divide by 8 000 000 bits per second = 68719.5 sA1 ÷ 60 = 1145.32 → 1145 whole minutes

Q28Computers & embedded systems · Standard · Paper 1 style · 6 marks

An electricity company in Lahore is installing smart meters in homes. Each meter measures energy use every 30 minutes and sends the reading to the company over the mobile network.

  1. (a) Explain why the smart meter is an example of an embedded system. Refer to the scenario. [2]
  2. (b) Give two benefits of using an embedded system in the meter. [2]
  3. (c) Give two drawbacks of using an embedded system in the meter. [2]
Show answer
  1. (a) It contains a microcontroller built into the meter whose only task is to measure the household's electricity use and send the readings to the company — it cannot run general programs.
    1 mark built into the meter; 1 mark dedicated function described for this meter. Generic answers ('it is inside') score 0.
  2. (b) e.g. small enough to fit inside the meter; low power consumption; cheap to mass-produce; reliable / runs continuously without user input; readings sent automatically, so no meter reader visits.
    1 mark each.
  3. (c) e.g. difficult to upgrade (firmware); connected meter may be hacked; whole unit may need replacing if it fails; limited processing / storage.
    1 mark each.
Q29Computers & embedded systems · Standard · Paper 1 style · 4 marks

A supermarket in Hyderabad uses computerised checkouts.

  1. (a) Explain why the checkout computer needs each of the following: input devices, output devices, primary memory and secondary storage. Refer to the supermarket. [4]
Show answer
  1. (a) 1 mark each:• input – e.g. barcode scanner to read product codes / card reader for payment• output – e.g. screen showing prices to the cashier/customer, printer for receipts• primary memory – RAM holds the checkout program and the current customer's item list being processed by the CPU• secondary storage – non-volatile storage keeps the software / price file / sales records when power is off
    Each point must be linked to the checkout.
Q30Computers & embedded systems · Challenge · Paper 1 style · 6 marks

A car's anti-lock braking system uses a microcontroller connected to sensors on each wheel. If a wheel starts to lock during hard braking, the microcontroller releases and reapplies that wheel's brake many times a second.

  1. (a) Explain why the anti-lock braking system (ABS) is an embedded system. [2]
  2. (b) Explain why the ABS must respond in real time. [2]
  3. (c) The ABS program is stored in non-volatile memory. Explain why, and state one difficulty this causes when the manufacturer finds a bug. [2]
Show answer
  1. (a) The microcontroller is built into the car's braking system and has the single task of monitoring wheel-speed sensors and pulsing the brakes to stop the wheels locking.
    1 mark built into braking system/car; 1 mark dedicated function described.
  2. (b) Wheel lock happens in a fraction of a second; if the response is delayed, the wheels lock, the driver loses steering control and the car may crash.
    1 mark immediate response needed; 1 mark consequence of delay.
  3. (c) The program must be available immediately every time the car starts without loading it from elsewhere (and must not be lost when power is off); updating it needs special equipment / a visit to a service centre, so many cars may run the faulty version.
    1 mark reason for non-volatile; 1 mark difficulty of updating.
