Q1Protocols & TCP/IP suite · Core · Paper 3 style · 4 marks
  1. (a) Explain why protocols are needed for communication between devices. [2]
  2. (b) Name the four layers of the TCP/IP protocol suite, from the top layer down. [2]
Show answer
  1. (a) A protocol is an agreed set of rules (e.g. for data format, addressing, error checking, timing); devices from different manufacturers and with different software can only communicate if they follow the same rules.
    1 mark set of rules for data transmission; 1 mark allows different devices/systems to communicate/understand each other.
  2. (b) Application, Transport, Internet (Network), Link (Network access).
    2 marks all four in the correct order; 1 mark four correct in the wrong order or three correct in order.

Q3Protocols & TCP/IP suite · Core · Paper 3 style · 5 marks

Amina in Karachi sends an email to her friend Kofi in Toronto.

  1. (a) Describe the role of SMTP when Amina sends the email. [2]
  2. (b) Kofi reads his emails on a phone and a laptop and wants both to show the same inbox. State which protocol his devices should use to retrieve email, and explain why. [3]
Show answer
  1. (a) SMTP is a push protocol that transfers the email from Amina's mail client to her mail server, and then from her mail server to the recipient's mail server.
    1 mark sends/pushes email from client to sender's server; 1 mark relays it between mail servers to the recipient's server.
  2. (b) IMAP. Emails stay on the server and the devices synchronise with it, so reading, deleting or moving a message on one device is shown on the other. With POP3 messages are usually downloaded to one device and deleted from the server.
    1 mark IMAP; 1 mark messages kept on the server / synchronised; 1 mark contrast with POP3 downloading and deleting.

Q10Protocols & TCP/IP suite · Standard · Paper 3 style · 5 marks
  1. (a) Compare POP3 and IMAP. Give three differences. [3]
  2. (b) A field researcher works in remote areas of Gilgit-Baltistan with an internet connection only once a week, using a single laptop. Suggest which protocol is more suitable and justify your choice. [2]
Show answer
  1. (a) POP3 downloads messages to the client and normally deletes them from the server; IMAP leaves them on the server. IMAP synchronises folders/read status across many devices; POP3 does not. POP3 messages can be read offline after download and use little server storage; IMAP needs a connection (or a cached copy) and uses server storage. IMAP can download headers only and fetch the body when opened.
    1 mark each for any three valid differences (each must state both sides or be clearly comparative).
  2. (b) POP3 – all messages are downloaded when connected and can then be read offline for the rest of the week on the single laptop; synchronisation across devices is not needed.
    1 mark POP3; 1 mark justification linked to offline reading / one device.
Q11Protocols & TCP/IP suite · Standard · Paper 3 style · 6 marks
  1. (a) Describe the role of the transport layer when a large file is sent across the internet using TCP. [4]
  2. (b) Describe the role of the internet layer. [2]
Show answer
  1. (a) Splits the data into segments (packets); adds a header with source/destination port numbers so data reaches the correct application; adds sequence numbers so the receiver can reassemble segments in order; receiver sends acknowledgements and missing segments are retransmitted, giving reliable delivery; also controls flow (rate of sending).
    1 mark each for any four: segmentation; port numbers; sequence numbers / reassembly; acknowledgements; retransmission of lost segments; flow control; establishes the connection (handshake).
  2. (b) Adds the IP header containing source and destination IP addresses, and routes each packet across networks (via routers) towards the destination.
    1 mark IP addressing (source and destination IP in header); 1 mark routing packets between networks.
Q12Protocols & TCP/IP suite · Standard · Paper 3 style · 6 marks
  1. (a) Describe the role of the link layer. [2]
  2. (b) Explain two benefits of using a layered protocol suite such as TCP/IP. [4]
Show answer
  1. (a) Places the data on the physical medium: puts packets into frames with MAC (hardware) addresses for the next device on the local network, and transmits them as signals over the cable or wireless link.
    1 mark framing / MAC addresses of next hop on the local network; 1 mark physical transmission of bits over the medium; accept error detection on the link.
  2. (b) Each layer has a separate job, so a layer's protocol can be changed or improved (e.g. replacing wired Ethernet with Wi-Fi at the link layer) without changing the other layers. Different manufacturers can develop hardware/software for one layer independently, and products still work together because the interfaces between layers are standard. Complex communication is broken into simpler parts that are easier to design and debug.
    2 marks per benefit (identify + explain), any two.
Q13Protocols & TCP/IP suite · Standard · Paper 3 style · 6 marks
  1. (a) A user in Islamabad types the address of a news website into a browser. Describe how the TCP/IP layers on the user's computer prepare the request for transmission. [5]
  2. (b) State what happens to these headers at the web server. [1]
Show answer
  1. (a) Application layer: the browser creates an HTTP GET request for the page. Transport layer: TCP opens a connection, splits the request into segments and adds a header with port numbers (e.g. destination port for HTTP) and sequence numbers. Internet layer: each segment is put in an IP packet with source and destination IP addresses. Link layer: each packet is put in a frame with MAC addresses and transmitted over the Wi-Fi/Ethernet link to the router.
    1 mark HTTP request at application layer; 1 mark TCP segments with sequence numbers; 1 mark port numbers; 1 mark IP header with addresses; 1 mark link layer framing and transmission. Max 5.
  2. (b) Each layer removes (strips) its own header and passes the data up to the layer above until the HTTP request reaches the web-server application.
    B1.
Q14Protocols & TCP/IP suite · Standard · Paper 3 style · 6 marks

A university in Ghana distributes a large open-source operating-system image using BitTorrent.

  1. (a) Define each of these BitTorrent terms: (i) swarm (ii) seed (iii) tracker (iv) leech. [4]
  2. (b) Explain why BitTorrent is described as a peer-to-peer protocol. [2]
Show answer
  1. (a) (i) Swarm: all the peers connected and sharing the same torrent/file. (ii) Seed: a peer that has the complete file and uploads pieces to others. (iii) Tracker: a server that keeps a list of the peers in the swarm and tells a new peer which peers to connect to. (iv) Leech: a peer that downloads much more than it uploads (has a poor share ratio), harming the swarm.
    1 mark each. For leech also accept: a peer that is still downloading and does not yet have the complete file.
  2. (b) Each computer (peer) downloads pieces of the file from other peers and also uploads pieces it has to others; there is no single central server sending the whole file.
    1 mark peers both download and upload / act as client and server; 1 mark no central server supplies the file.
Q15Protocols & TCP/IP suite · Standard · Paper 3 style · 5 marks

An indie game studio in Lagos releases a free game update through BitTorrent.

  1. (a) Describe how a new user downloads the file using BitTorrent. [5]
Show answer
  1. (a) The user obtains the torrent file (metadata including the tracker address and the hashes of each piece) and opens it in a BitTorrent client. The client contacts the tracker, which returns a list of peers in the swarm. The client connects to several peers and requests different pieces simultaneously. Each piece is checked against its hash and re-requested if corrupt. As soon as it has pieces, the client uploads them to other peers. When all pieces are received the file is reassembled, and the user may stay as a seed.
    1 mark each to max 5: torrent file with metadata; contacts tracker; receives list of peers; downloads different pieces from several peers in parallel; pieces verified with hash; uploads pieces it has to others; reassembly / becomes a seed.
Q16Protocols & TCP/IP suite · Standard · Paper 3 style · 6 marks

A college in Jeddah runs an online examination portal.

  1. (a) Explain how the transport layer makes sure that data arriving at the server is passed to the correct application. [2]
  2. (b) Describe how TCP makes sure all the data of an online exam submission arrives correctly, even if some packets are lost or arrive out of order. [4]
Show answer
  1. (a) Each segment's header holds a destination port number that identifies the application/service (e.g. web server or mail server); the receiving computer uses the port number to pass the data to that application.
    1 mark port numbers in transport-layer header; 1 mark port identifies the application/process on the host.
  2. (b) Each segment has a sequence number; the receiver uses these to put segments back in the right order. The receiver sends acknowledgements for segments received. If the sender gets no acknowledgement before a timeout, it retransmits the segment. A checksum detects corrupted segments, which are discarded and resent.
    1 mark each: sequence numbers; reordering at receiver; acknowledgements; timeout and retransmission; checksum for errors. Max 4.

Q18Protocols & TCP/IP suite · Standard · Paper 3 style · 6 marks

A packet travels from a laptop in Multan to a server in Frankfurt through 12 routers.

  1. (a) Describe two items found in an IP packet header and explain why each is needed. [4]
  2. (b) Explain why the destination IP address stays the same for the whole journey but the link-layer (MAC) address changes at every router. [2]
Show answer
  1. (a) Source IP address – so a reply/error message can be returned to the sender. Destination IP address – so routers can forward the packet towards the correct host. Time to live (hop limit) – so a packet that cannot be delivered is discarded instead of circulating forever. Header checksum – to detect errors in the header. Protocol field – identifies the transport protocol (e.g. TCP) to pass the data to.
    2 marks per item (name + reason), any two.
  2. (b) The IP address identifies the final destination host, so it is not changed; the MAC address is only used on each local link, so each router re-frames the packet with the MAC address of the next device (next hop).
    1 mark IP is end-to-end/final destination; 1 mark MAC addresses are local to each link, replaced at each hop.

Q22Protocols & TCP/IP suite · Standard · Paper 3 style · 5 marks
  1. (a) Explain how TCP makes sure that segments arriving out of order are passed to the application in the correct order. [3]
  2. (b) A file is sent as four segments, numbered 1 to 4, and segment 2 is lost. Describe how the sender finds out that segment 2 has been lost and resends it. [2]
Show answer
  1. (a) Each segment has a sequence number. The receiver stores segments that arrive early in a buffer, waits for the missing segment, and then passes the data on in sequence-number order.
    1 mark: each segment has a sequence number. 1 mark: out-of-order segments are stored in a buffer. 1 mark: data is passed to the application only when the missing segments arrive, in sequence order.
  2. (b) The receiver keeps sending an acknowledgement for the last segment received in order (segment 1); the sender sees that segment 2 was not acknowledged and resends it after a timeout or after repeated acknowledgements.
    1 mark: receiver repeats the acknowledgement for the last in-order segment. 1 mark: sender retransmits segment 2 after a timeout or repeated acknowledgements.
Q23Protocols & TCP/IP suite · Challenge · Paper 3 style · 5 marks
  1. (a) Explain the process of encapsulation in the TCP/IP suite, and explain why it means a router does not need to process the application data. [5]
Show answer
  1. (a) Data from the application layer is passed down; each layer treats what it receives as its payload and adds its own header (TCP header, then IP header, then link-layer header and trailer). At the receiver, each layer removes its header and passes the payload up. A router works only up to the internet layer: it removes the link-layer frame, reads the IP header to choose the next hop, and re-frames the packet; it never opens the TCP segment or the application data inside, so it does not need to understand HTTP, SMTP etc.
    1 mark data passed down the layers; 1 mark each layer adds a header (and trailer at link layer) to the data from the layer above; 1 mark headers removed in reverse order at the receiver; 1 mark router only uses link and internet layers / reads IP header; 1 mark payload above IP left unchanged/unread.

Q26Protocols & TCP/IP suite · Challenge · Paper 3 style · 6 marks

Bilal, whose email provider is based in Islamabad, sends an email to Fatima, whose email address is with a company based in London.

  1. (a) Describe how the email travels from Bilal's computer to Fatima's phone. Refer to the protocols used and to the role of DNS. [6]
Show answer
  1. (a) Bilal's mail client uses SMTP to send the email to his mail server (the Islamabad provider). The sending server uses DNS to look up the mail (MX) record for Fatima's domain and find the IP address of her mail server. It then uses SMTP to transfer the email to Fatima's mail server, where it is stored in her mailbox. Fatima's phone uses IMAP (or POP3) to retrieve the email from her mail server. Q30Protocols & TCP/IP suite · Challenge · Paper 3 style · 5 marks

A 500 000 000-byte (500 MB) file is downloaded over a link with a speed of 20 Mbps. Each packet carries 2% extra overhead bits in addition to the file data.

  1. (a) Calculate the time, in seconds, needed to download the file if the download speed is the full 20 Mbps and the overhead is included. [3]

  1. (a) Describe circuit switching. [2]
  2. (b) Describe packet switching. [3]
Show answer
  1. (a) A dedicated communication path (circuit) is set up between the two ends before any data is sent; it is reserved for the whole communication and released at the end.

Q32Circuit & packet switching · Core · Paper 3 style · 4 marks

A telephone company in Peshawar compares switching methods.

  1. (a) Give two advantages of circuit switching for a live telephone call. [2]
  2. (b) Give two disadvantages of circuit switching. [2]
Show answer
  1. (a) Data arrives in order along a dedicated route; constant bandwidth and very little delay/jitter, so speech is not broken up; no reassembly needed.

  2. (b) The circuit's bandwidth is wasted when no data is being sent (e.g. silences); the circuit must be set up first, which takes time; if a link fails the connection is lost; no other user can use the reserved channel.

Q40Circuit & packet switching · Standard · Paper 3 style · 6 marks
  1. (a) Explain the role of a router in a packet-switched network. [3]
  2. (b) Explain why packets from the same message may arrive out of order, and how the receiver deals with this. [3]
Show answer
  1. (a) A router receives a packet, reads the destination IP address in its header, looks it up in its routing table and forwards the packet to the next router (next hop) on the best available route; it can choose another route if a link is busy or has failed.
    1 mark reads destination address; 1 mark uses routing table; 1 mark forwards to next hop / chooses route depending on traffic or failures.
  2. (b) Routers choose routes for each packet independently, so packets can take different paths with different lengths and congestion; the receiver uses the sequence numbers to reassemble them in the correct order, and asks for any missing packet to be resent.
    1 mark different routes; 1 mark different delays/congestion; 1 mark reorder using sequence numbers (request missing packets).

Q43Circuit & packet switching · Standard · Paper 3 style · 4 marks

  1. Q60Circuit & packet switching · Challenge · Paper 3 style · 4 marks

  2. (b) Explain the problem that occurs when more packets are sent in one session than there are sequence numbers, and describe one way the problem is avoided. [3]
Show answer
  1. (a) 65 536
