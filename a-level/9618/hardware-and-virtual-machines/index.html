Q1Boolean algebra & Karnaugh maps · Core · Paper 3 style · 5 marks

Notation: ¬A means NOT A, A.B means A AND B, A + B means A OR B.A logic circuit has inputs A, B, C. Its output X = 1 for ABC = 001, 011, 101, 110 and 111, and X = 0 otherwise.

  1. (a) Complete the Karnaugh map for X. Use rows A = 0, 1 and columns BC = 00, 01, 11, 10. [2]
  2. (b) Draw loops around groups of 1s (describe each group) and write the simplified sum-of-products expression for X. [3]
Show answer
  1. (a) A \ BC | 00 01 11 100 | 0 1 1 01 | 0 1 1 1
    2 marks all cells correct; 1 mark one error. Note column order 00, 01, 11, 10 (Gray code).
  2. (b) Groups: the four 1s in columns BC = 01 and 11 (both rows) → C; the pair A = 1, BC = 11 and 10 → A.B.X = C + A.B
    1 mark group of four; 1 mark pair; 1 mark correct expression.

Q11Boolean algebra & Karnaugh maps · Challenge · Paper 3 style · 5 marks

Notation: ¬A means NOT A, A.B means A AND B, A + B means A OR B.

  1. (a) Show, using Boolean algebra, that (A + B).(A + C) = A + B.C. State the laws you use. [4]
  2. (b) Explain why the simplified form is preferred when building the circuit. [1]
Show answer
  1. (a) (A + B).(A + C) = A.A + A.C + B.A + B.C (distributive law)= A + A.C + A.B + B.C (A.A = A, idempotent law)= A.(1 + C + B) + B.C (factorise)= A.1 + B.C = A + B.C (1 + X = 1; identity law)
    1 mark expansion; 1 mark A.A = A; 1 mark factorise A; 1 mark reaching A + B.C.
  2. (b) It needs fewer gates (one AND and one OR instead of two OR and one AND), so the circuit is cheaper / faster / uses less power.
    B1.

Q16Logic circuits, adders & flip-flops · Standard · Paper 3 style · 6 marks

An SR flip-flop is built from two cross-connected NOR gates. It has inputs S (set) and R (reset) and outputs Q and ¬Q (NOT Q).

Q17Logic circuits, adders & flip-flops · Standard · Paper 3 style · 5 marks
  1. (a) Explain the role of flip-flops in a computer. [2]
  2. (b) State how many flip-flops are needed for a 64-bit register. [1]
  3. (c) Explain why a clock signal is used with flip-flops in a register. [2]
Show answer
  1. (a) Each flip-flop stores one bit (it is a bistable circuit that stays in a state until changed); groups of flip-flops form registers and static RAM (SRAM) / cache.

    1 mark synchronise; 1 mark all bits change together / avoid errors.

Q20Virtual machines · Core · Paper 3 style · 4 marks
  1. (a) Explain what is meant by a virtual machine. [2]
  2. (b) Give two benefits of using virtual machines. [2]
Show answer
  1. (a) Software that emulates a complete computer system (hardware), allowing a guest operating system and its programs to run as if on a separate physical computer, on top of a host system.
    1 mark software emulation of hardware/computer; 1 mark guest OS runs on host.
  2. (b) Any two: several operating systems can run on one physical machine; software for one platform can run on another; a crash or malware in a VM does not affect the host / other VMs; easy to back up, copy or restore (snapshots); saves hardware costs.
    1 mark each.

Q24Virtual machines · Challenge · Paper 3 style · 6 marks

    B1.
Q25Parallel processing architectures · Core · Paper 3 style · 4 marks
  1. (a) Describe each of these computer architectures: SISD, SIMD, MISD, MIMD. [4]
Show answer
  1. (a) SISD: single instruction, single data — one processor carries out one instruction on one data item at a time.SIMD: single instruction, multiple data — several processors carry out the same instruction on different data items at the same time.MISD: multiple instruction, single data — several processors carry out different instructions on the same data.MIMD: multiple instruction, multiple data — several processors each carry out different instructions on different data (e.g. multicore computers).

Q27Parallel processing architectures · Challenge · Paper 3 style · 6 marks

The national meteorological department in Pakistan uses a massively parallel computer to produce monsoon forecasts.

  1. (a) Describe the characteristics of a massively parallel computer system that make it suitable for weather forecasting. [3]
  2. (b) Explain why the software must be specially written for this computer. [2]
  3. (c) Explain why some problems do not run much faster on a massively parallel computer. [1]
Show answer
  1. (a) 1 mark each, max 3:• thousands of processors work simultaneously• the forecast area can be split into many grid cells, each handled by a different processor• processors are linked by a high-speed network to exchange results for neighbouring cells• each processor has its own memory, so huge amounts of data can be processed at once
  2. (b) The program must be split into tasks that can run at the same time (parallel algorithms), and must coordinate / synchronise the processors and the data they share.
    1 mark split into parallel tasks; 1 mark coordination / communication.
  3. (c) If each step depends on the result of the previous step, the work cannot be divided, so most processors would be idle / communication overheads outweigh gains.
    B1.

(a) 1 mark each, max 4:• RISC has fewer, simpler instructions; CISC has many complex instructions• RISC instructions are mostly executed in one clock cycle; CISC instructions take several cycles• RISC instructions have a fixed length; CISC instructions vary in length• RISC has fewer addressing modes; CISC has many• RISC uses many general-purpose registers; CISC has fewer• RISC is hard-wired control; CISC often uses microprogrammed control• RISC is easier to pipeline• RISC programs need more instructions / more RAM; CISC programs are shorter (more work for the compiler with RISC)

Q29RISC/CISC & pipelining · Standard · Paper 3 style · 7 marks

A processor uses a 5-stage pipeline: instruction fetch (IF), instruction decode (ID), operand fetch (OF), instruction execute (IE) and write back (WB). Each stage takes one clock cycle. Assume there are no branches or interrupts.

  1. (a) Calculate how many clock cycles are needed to complete 8 instructions with pipelining, and how many without pipelining. Show your working. [3]
  2. (b) State which instruction is in each stage during clock cycle 4. [2]
  3. (c) Explain why RISC processors are well suited to pipelining. [2]
Show answer
  1. (a) With pipelining: 12 cycles. Without pipelining: 40 cycles.
    M1 first instruction takes 5 cycles, then one more instruction completes every cycle: 5 + (8 − 1) = 12A1 12B1 without pipelining 8 × 5 = 40
  2. (b) Instruction 1 in IE (execute), instruction 2 in OF (operand fetch), instruction 3 in ID (decode), instruction 4 in IF (fetch); the WB stage is empty.
    2 marks all correct; 1 mark two or three correct.
  3. (c) RISC instructions are of fixed length and most take one clock cycle, so each stage takes the same time and the stages stay in step / the pipeline flows smoothly.
    1 mark fixed length / one cycle; 1 mark stages balanced.
Q30RISC/CISC & pipelining · Challenge · Paper 3 style · 6 marks

A RISC processor uses a 5-stage pipeline.

  1. (a) Explain the problem caused when an interrupt occurs in a pipelined processor, and describe one way it can be handled. [3]
  2. (b) Explain how a conditional branch (jump) instruction reduces the performance of the pipeline. [2]
  3. (c) State one technique used to reduce this loss. [1]
Show answer
  1. (a) Problem: several instructions are partly processed in different stages when the interrupt arrives, so the processor state cannot be saved simply by storing one program counter value.Handling (any one, 2 marks): the instructions in the early stages are flushed/erased, the instruction(s) already in the execute stage are completed, and the address of the next instruction to restart is saved before the interrupt service routine runs; OR each stage has its own program-counter register so the contents of the pipeline can be saved and restored after the interrupt.
    1 mark problem; 2 marks a described method.
  2. (b) The next instructions are fetched in sequence before the branch is executed; if the branch is taken, these instructions are wrong and must be discarded (pipeline flushed), so cycles are wasted until the pipeline refills.
    1 mark wrong instructions already fetched; 1 mark flush / wasted cycles.
  3. (c) Branch prediction / speculative execution / delayed branch (filling the slot after a branch with a useful instruction).
    B1.
