Q26Procedures, functions & parameters · Core · Paper 2 style · 4 marks
  1. (a) Explain the difference between a procedure and a function. [2]
  2. (b) Explain the difference between passing a parameter by value and by reference. [2]
Show answer
  1. (a) A function returns a single value to the point where it was called and is used in an expression; a procedure does not return a value through its name and is called as a statement using CALL.
