Q1Passwords and authentication · Core · Paper 1 style · 6 marks

Ayesha uses the password ayesha2009 for her school email account.

  1. (a) Explain why this is a weak password. [2]
  2. (b) Give two features of a strong password. [2]
  3. (c) State two other actions Ayesha should take to keep her password secure. [2]
Show answer
  1. (a) It is easy to guess because it uses her own name and probably her year of birth, and it has no capital letters or symbols.
    1 mark each for any two of: contains personal information (her name) | number looks like a birth year/date, easily found | no upper-case letters | no special characters/symbols | all lower case so fewer combinations to try | could be cracked quickly by software trying names/dates.
  2. (b) At least 8 characters long; a mix of upper case, lower case, digits and symbols (and no personal information or dictionary words).
    1 mark each for any two of: at least 8 (or more) characters | mixes upper and lower case letters | includes numbers | includes special characters such as # or ! | not a dictionary word | no personal details such as names or dates.
  3. (c) Change it regularly; never tell it to anyone or write it down (and use a different password for each account).
    1 mark each for any two of: change it regularly | do not share it | do not write it down / store it where others can see | use a different password for each account | log out on shared computers | do not let browser remember it on a shared device | watch for shoulder surfing when typing it.
Q2Passwords and authentication · Core · Paper 1 style · 4 marks
  1. (a) A bank's mobile app asks a customer for a password and then sends a six-digit code by text message to the customer's phone. State the name of this method of authentication. [1]
  2. (b) Explain why this method is more secure than using a password alone. [3]
Show answer
  1. (a) Two-factor authentication (2FA).
    B1 two-factor authentication / two-step verification / multi-factor authentication.
  2. (b) Two different factors are needed: something the user knows (password) and something they have (the phone). A hacker who has stolen the password still cannot log in without the phone, and the code changes every time and expires quickly.
    1 mark each for any three of: needs two separate pieces of evidence | something you know plus something you have | stolen/guessed password alone is not enough | code is sent only to the registered phone | code is one-time / changes every login | code expires after a short time | user is alerted if a code arrives that they did not request.

Q7Passwords and authentication · Standard · Paper 1 style · 6 marks

A company gives each employee a small physical token. When pressed, it shows a number that changes every 30 seconds. Employees type this number after their password to log in from home.

  1. (a) Describe how the physical token and the company's system make sure the number is accepted only once. [3]
  2. (b) Compare a physical token with an electronic token (an authenticator app on a smartphone). [3]
Show answer
  1. (a) The token and the server share a secret and both run the same algorithm using the current time, so they generate the same number; the server checks the typed number matches the one it calculates for that time period, and once used (or after 30 seconds) it is no longer valid.
    1 mark each for any three of: token generates a one-time password (OTP) | token and server use the same algorithm/secret key | the number is linked to the time / changes every 30 s | server generates the same number and compares | if they match access is granted | the number expires and cannot be reused.
  2. (b) Both generate one-time codes used as a second factor and both must be in the user's possession. A physical token is a separate device that can be lost and costs money to issue, whereas the electronic token is software on a phone the user already owns, so it costs less, but it depends on the phone being charged and secure.
    1 mark for a similarity: both create one-time passcodes / both are 'something you have' / both used for two-factor authentication. Up to 2 marks for differences: physical is extra hardware vs app on existing phone | physical costs the company to buy/replace vs app is free/cheap | physical has no network or battery dependence on phone vs app needs a working phone | phone can be infected with malware whereas token is a closed device.
Q8Passwords and authentication · Standard · Paper 1 style · 4 marks
  1. (a) An online banking website asks a customer for the 2nd, 5th and 7th characters of a memorable word, chosen from drop-down menus, instead of the whole word typed on the keyboard. Explain why drop-down menus are used. [2]
  2. (b) Explain why the website asks for only some of the characters, and different ones each time. [2]
Show answer
  1. (a) Keylogging spyware records key presses; choosing characters from drop-down menus with the mouse means no keys are pressed, so the spyware cannot capture the word.
    1 mark: protects against keyloggers/spyware; 1 mark: because no keystrokes are recorded.
  2. (b) If someone sees or records one login they learn only a few characters, not the whole word, and the next login asks for different characters, so they cannot simply repeat what they saw.
    1 mark: whole word never revealed in one session; 1 mark: changing positions means a captured answer cannot be reused.
Q9Passwords and authentication · Standard · Paper 1 style · 5 marks
  1. (a) A 4-digit PIN uses only the digits 0–9. Calculate how many different 4-digit PINs are possible. [1]
  2. (b) A bank changes to 6-digit PINs. Calculate how many different 6-digit PINs are possible and how many times more combinations this gives than a 4-digit PIN. [2]
  3. (c) Even with many combinations, the bank also blocks a card after three wrong PIN attempts. Explain why. [2]
Show answer
  1. (a) 10,000
    10⁴ = 10,000 (B1).
  2. (b) 1,000,000 PINs; 100 times more.
    10⁶ = 1,000,000 (B1); 1,000,000 ÷ 10,000 = 100 (B1).
  3. (c) Without a limit, a thief could keep trying PINs until one worked (a brute-force attack); after three attempts the chance of guessing is tiny.
    1 mark: stops repeated guessing / brute force; 1 mark: only 3 of the many combinations can be tried.

Q11Passwords and authentication · Challenge · Paper 1 style · 8 marks

  2. (b) Evaluate the use of smart cards with a PIN for the students rather than user IDs and passwords. [6]

Q12Passwords and authentication · Challenge · Paper 1 style · 6 marks
  1. (a) A user receives a message that says their online account has been locked after three wrong password attempts. Explain why systems lock an account after a small number of failed attempts. [2]
  2. (b) Magnetic stripe cards and smart cards (chip cards) are both used to authenticate users. Describe two reasons why smart cards are more secure. [2]
  3. (c) Give two reasons why a user should not use the same password for every online account. [2]
Show answer
  1. (a) To stop a hacker using software to try thousands of possible passwords (a brute-force attack); locking after a few attempts makes guessing impractical and alerts the real owner.
    1 mark each for: prevents repeated guessing / brute-force attacks by programs | limits the number of tries so the chance of guessing is tiny / alerts the owner and administrator.
  2. (b) The chip data is encrypted and much harder to copy (clone) than a magnetic stripe; a smart card normally needs a PIN as well, and the chip can create a different code for each transaction.
    1 mark each for any two of: chip data is encrypted | magnetic stripe data is easily read and cloned (skimming) | chip used with a PIN = two factors | chip can generate a unique code each use | magnetic stripe can be damaged by magnets / easier to tamper with.
  3. (c) If one website is hacked and passwords are leaked, criminals can use that password to get into all the user's other accounts; one stolen password then exposes everything (email, bank, social media).
    1 mark each for any two of: a data breach at one site exposes all accounts | criminals try leaked passwords on other sites | the email account could be used to reset other passwords | damage from one phishing attack is multiplied.

Q23Cloud computing and file sharing · Standard · Paper 1 style · 5 marks

Q26Cloud computing and file sharing · Challenge · Paper 1 style · 6 marks

A manufacturing company keeps its customer database on servers in its own building but stores its marketing videos and staff training files with a cloud provider. Both systems are linked so staff can reach either from the same software.

  1. (a) Identify the type of cloud storage the company is using and justify your answer. [2]

  1. (a) Extranet. Transcripts contain personal data, so each alumnus should log in and see only his or her own records; a public website would let anyone see the pages. The extranet lets the university control who has access and remove access when needed, while still reaching alumni anywhere over the internet. Job adverts could be on either, but keeping them on the extranet gives a benefit to alumni.

Q104Internet, intranet and extranet · Challenge · Paper 1 style · 4 marks
  1. (a) Staff at an engineering company now work from home two days a week. They need to use the company intranet, which is hosted on servers in the office. Explain how a virtual private network (VPN) lets them do this securely. [3]
  2. (b) Give one risk that remains when staff use the intranet from home. [1]
Show answer
  1. (a) The VPN creates an encrypted connection (tunnel) across the internet between the home computer and the company network; the employee must log in to the VPN; once connected the computer acts as if it were on the office LAN, so the intranet can be used while outsiders cannot read the data.
    1 mark: encrypted connection over the internet; 1 mark: authentication to the VPN; 1 mark: appears as part of company LAN / intranet accessible.
  2. (b) The home computer could have malware that spreads to the company network, or family members could see confidential information on screen.
    1 mark.
Q105Internet, intranet and extranet · Challenge · Paper 1 style · 6 marks
  1. (a) A hospital in Rawalpindi plans to create an extranet so that local family doctors can log in to see their own patients' appointment dates and test results. Evaluate this plan. [6]
Show answer

(a) Advantages: doctors get results quickly without phone calls or posted letters; fewer errors from copying; available at any time; reduces hospital staff workload; better care because information is up to date.
