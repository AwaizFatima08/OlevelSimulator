Q1Databases vs other methods · Core · Paper 1 style · 6 marks
  1. (a) Describe what is meant by a flat-file database. [2]
  2. (b) Describe what is meant by a relational database. [2]
  3. (c) Give two advantages of a relational database over a flat-file database. [2]
Show answer
  1. (a) A database that stores all its data in a single table, so data about different things (for example customers and their orders) is held together in one file.
    1 mark each for: data held in one table/file | each record holds all the data / no links to other tables (data often repeated).
  2. (b) A database made of two or more tables that are linked by relationships using key fields (a primary key in one table matching a foreign key in another).
    1 mark each for: data stored in more than one table | tables linked using common/key fields (primary key – foreign key).
  3. (c) Data is stored only once, so there is less duplication (redundancy) and less storage is used; updating data in one place keeps it consistent everywhere, so there are fewer errors.
    1 mark each for any two of: less data redundancy/duplication | less storage needed | data consistency/integrity – change once | fewer data entry errors | more complex queries/reports across tables | easier to add new types of data | better security – access to tables can be restricted.

Q21Databases vs other methods · Standard · Paper 1 style · 6 marks

A teacher in Karachi keeps records of 400 students' marks in a spreadsheet. The school's IT manager suggests moving the records into a relational database.

  1. (a) Compare using a database with using a spreadsheet to store and process the student records. [6]
Show answer
  1. (a) Both store data in rows and columns and can sort and search it. A spreadsheet is better for calculations, what-if modelling and charts, whereas a database is better for storing large amounts of related data. A database can use validation and forms to control data entry more strongly and links several tables (students, subjects, marks) so data is stored once, whereas a spreadsheet often repeats data. A database is better for complex queries and reports and allows multiple users to edit records at the same time, while a spreadsheet is easier to set up and learn.
    1 mark for a similarity (both rows/columns, sort, search, filter, charts/reports). Up to 5 marks for linked differences: database handles large volumes of related data vs spreadsheet better for numerical calculation/modelling | database tables linked – less redundancy vs spreadsheet data duplicated | database queries on multiple criteria/reports easier | database forms and validation control input | database supports many simultaneous users/access rights | spreadsheet quicker to set up/easier to learn | spreadsheet better for graphs/what-if. Each difference must refer to both.

  1. (a) Explain what is meant by a calculated field in a database query, and give two reasons why calculated fields are used instead of a spreadsheet for this calculation in a large database. [4]
Show answer
  1. (a) A calculated field is a new field in a query whose value is worked out from other fields (e.g. [Price]*[Quantity]) each time the query is run, and is not stored in the table. Reasons, e.g. the result is always up to date with the stored data; no need to export the data to a spreadsheet so no copies that become out of date; it can be combined with criteria and sorting in the same query and used in reports; it works on very large numbers of records easily.
