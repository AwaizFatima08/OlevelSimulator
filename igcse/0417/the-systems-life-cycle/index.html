Practice questions

Original questions written by HomiLabs in the style of the exam, with answers and mark schemes. They are not Cambridge past paper questions and have not been reviewed by Cambridge. Try each one before opening the answer.

Q1Design: data capture forms and file structures · Core · Paper 1 style · 3 marks
  1. (a) A systems analyst is designing an on-screen data capture form for new members of a sports club in Abbottabad. Give three features of a well-designed on-screen form. [3]
Show answer
  1. (a) Any three, e.g. a clear title so users know the purpose; clear instructions/labels for each field; drop-down lists or radio buttons for fixed choices; tick boxes for yes/no answers; boxes of a suitable size for the data; fields in a logical order; navigation buttons (next/back/submit); no unnecessary fields/uncluttered layout; consistent font and colours; help/error messages.
    1 mark each for any three distinct features.
Q2Design: data capture forms and file structures · Core · Paper 2 style · 2 marks
  1. (a) State what is meant by a primary key in a database table. [1]
  2. (b) A car hire company in Sharjah stores these fields about each car: Make, Model, Colour, RegistrationNumber, Seats. State which field should be the primary key. [1]
Show answer
  1. (a) A field that uniquely identifies each record in the table.
    1 mark.
  2. (b) RegistrationNumber.
    1 mark.
Q3Design: data capture forms and file structures · Standard · Paper 2 style · 5 marks

A school library in Quetta is setting up a database table called BOOKS. Sample data for one record is shown.BookID: QL-0457Title: Hills of the NorthDatePurchased: 14/03/2025Price: 1850.00 (Pakistani rupees)OnLoan: YesCopies: 3

  1. (a) State the most suitable data type for each of the six fields. [3]
  2. (b) State which field should be the primary key and give a reason. [2]
Show answer
  1. (a) BookID: Text (alphanumeric)Title: TextDatePurchased: Date/TimePrice: Currency (accept Number with 2 decimal places)OnLoan: Boolean (Yes/No)Copies: Number – Integer
    All six correct: 3 marks; four or five: 2 marks; two or three: 1 mark.
  2. (b) BookID, because it is unique for each record/no two books have the same ID (Title could be repeated).
    1 mark for BookID, 1 mark for reason.
Q4Design: data capture forms and file structures · Standard · Paper 1 style · 4 marks
  1. (a) In a file of customer details, the analyst stores telephone numbers such as 03001234567 in a text field, not a numeric field. Explain why. [2]
  2. (b) The analyst stores each customer's date of birth rather than their age. Explain why. [2]
Show answer
  1. (a) A numeric field would remove the leading zero; telephone numbers may contain + or spaces/dashes; no calculations are carried out on them.
    1 mark each for any two points.
  2. (b) Age changes every year so the stored value would become wrong/need updating; age can always be calculated from the date of birth and today's date.
    1 mark each.
Q5Design: data capture forms and file structures · Standard · Paper 1 style · 3 marks
  1. (a) When designing a file of student records, an analyst decides to code some data, for example storing the city as LHR for Lahore and KHI for Karachi. Give two advantages of coding data. [2]
  2. (b) Give one disadvantage of coding data. [1]
Show answer
  1. (a) Any two, e.g. less storage space is needed; faster to type so data entry is quicker; fewer spelling errors/consistent entries; easier to validate against a list of codes; faster to search/sort.
    1 mark each.
  2. (b) Users must know or look up the meaning of codes; codes may be confusing/similar; information may be lost if the coding is too general; codes run out or need changing.
    1 mark.
Q6Design: data capture forms and file structures · Challenge · Paper 1 style · 6 marks
  1. (a) A clinic in Hyderabad needs an on-screen form to register new patients. The data needed is: full name, gender, date of birth, blood group (one of 8 types), telephone number and whether the patient has any allergies. Describe how the form should be designed to make data entry quick and accurate. Refer to the fields listed. [6]
Show answer
  1. (a) Title such as 'New patient registration' and short instructions; full name in a text box large enough for long names, perhaps split into first name/family name; gender chosen with radio buttons; date of birth entered with a date picker or set format dd/mm/yyyy; blood group from a drop-down list of the 8 types so it cannot be mistyped; telephone number in a text box with a set format/input mask; allergies as a yes/no tick box with a text box for details only if yes; fields in a logical order; validation on fields with clear error messages; submit/clear/next buttons; consistent layout, no clutter.
    1 mark per feature linked to a field or explained, max 6. Generic features without reference to the scenario max 3.
Q7Design: data capture forms and file structures · Challenge · Paper 2 style · 6 marks

An online bookshop in Lahore sends you a file ORDERS.csv to import into a new database table. These are the first two rows:OrderNo,CustomerCode,OrderDate,Total,Delivered,ItemsORD7711,C1043,03/11/2026,2499.5,Y,3ORD7712,C0098,04/11/2026,780,N,1

  1. (a) For each field, state the data type and any format you would set so that the data is stored and displayed correctly. Total must be shown in rupees with 2 decimal places and OrderDate as day/month/year. [5]
  2. (b) Explain why the design of the output formats, such as the delivery report, must be tested before the system is used. [1]
Show answer
  1. (a) OrderNo – Text (primary key); CustomerCode – Text (leading zero in C0098 kept); OrderDate – Date, format dd/mm/yyyy; Total – Currency (or Number, decimal) with 2 decimal places, shown with the Rs symbol; Delivered – Boolean (Yes/No); Items – Number, integer.
    1 mark for each correct pair, max 5 (six fields, any five correct).
  2. (b) To check the report shows all the required data, correctly laid out and formatted, so that users can read and use it.
    1 mark.
Q8Testing and test data · Core · Paper 1 style · 3 marks
  1. (a) Describe what is meant by each type of test data.(i) Normal data(ii) Abnormal data(iii) Extreme data [3]
Show answer
  1. (a) (i) Data within the acceptable range/of the correct type that should be accepted.(ii) Data outside the range or of the wrong type that should be rejected.(iii) Data on the boundaries of the acceptable range (the largest and smallest acceptable values) that should be accepted.
    1 mark each.
Q9Testing and test data · Core · Paper 1 style · 3 marks
  1. (a) State what is meant by a test plan. [1]
  2. (b) State two items that are recorded for each test in a test plan. [2]
Show answer
  1. (a) A document listing each test to be carried out, the test data to be used and the expected outcome (with space for the actual outcome).
    1 mark.
  2. (b) Any two, e.g. test number; what is being tested; test data; type of test data; expected outcome; actual outcome; remedial action.
    1 mark each.
Q10Testing and test data · Standard · Paper 1 style · 4 marks
  1. (a) A secondary school in Sialkot accepts students aged 11 to 18 inclusive. The Age field is validated. Give one example of normal data, two examples of extreme data and one example of abnormal data for this field, with the expected result for each. [4]
Show answer
  1. (a) Normal: any whole number 12–17 (e.g. 14) – accepted. Extreme: 11 – accepted and 18 – accepted. Abnormal: e.g. 9, 19, -3 or 'twelve' – rejected.
    1 mark normal, 1 mark each extreme (both 11 and 18), 1 mark abnormal; expected results must be correct.
Q11Testing and test data · Standard · Paper 1 style · 4 marks
  1. (a) Explain why a new computer system must be tested before it is implemented. [2]
  2. (b) Explain why the file structure of the new system must be tested. [2]
Show answer
  1. (a) To find and remove errors/bugs before real data is used; to make sure the system meets the requirements set in analysis; to check it works with real volumes of data; to avoid data loss or wrong results that would cost the company money.
    1 mark each for any two points.
  2. (b) To check that each field has the correct data type and size so that data can be stored without being cut short/rejected; to check the validation rules accept/reject the right data; to check links between tables/searching and sorting work.
    1 mark each for any two points.
Q12Testing and test data · Challenge · Paper 1 style · 5 marks

A field called ExamMark must contain a whole number from 0 to 100 inclusive. A tester uses these test values: 0, 57, 100, 101, −1, fifty.

  1. (a) For each test value, state the type of test data and whether it should be accepted or rejected. [3]
  2. (b) After testing with test data, the system is tested with live data. Explain what live data is and why it is used. [2]
Show answer
  1. (a) 0 – extreme, accepted57 – normal, accepted100 – extreme, accepted101 – abnormal, rejected−1 – abnormal, rejectedfifty – abnormal, rejected
    All six correct: 3 marks; four or five: 2 marks; two or three: 1 mark.
  2. (b) Real data from the organisation that has known results (e.g. data used with the old system); used to check the new system produces the same results as the old system/works with real data and real volumes.
    1 mark for meaning, 1 mark for reason.
Q13Testing and test data · Challenge · Paper 1 style · 4 marks

A hotel booking system in Murree only accepts a booking date from today up to and including 90 days after today. Today's date is 25/10/2026.

  1. (a) Give the two extreme test values for the booking date. [2]
  2. (b) Give one example of abnormal data for this field and explain why it should be rejected. [2]
Show answer
  1. (a) 25/10/2026 and 23/01/2027
    1 mark each. Days after today: 6 (rest of October) + 30 (November) + 31 (December) + 23 (January) = 90.
  2. (b) E.g. 24/10/2026 – a date in the past; or 24/01/2027 – more than 90 days ahead; or 31/11/2026 – not a real date.
    1 mark for value, 1 mark for reason.
Q14Analysis · Core · Paper 1 style · 3 marks
  1. (a) Name three methods a systems analyst can use to research the current system. [3]
Show answer
  1. (a) Any three of: observation; interviews; questionnaires; examining documents.
    1 mark each.
Q15Analysis · Core · Paper 1 style · 3 marks
  1. (a) Give two things a systems analyst can learn by examining the documents used in the current system. [2]
  2. (b) Give one disadvantage of examining documents. [1]
Show answer
  1. (a) Any two, e.g. what data is input/collected; what outputs are produced; the format/layout of current forms and reports; how much data is handled/volumes of data; the processing that takes place.
    1 mark each.
  2. (b) It can be time-consuming; documents may be out of date/incomplete; difficult to understand without knowing the business; does not show users' opinions.
    1 mark.
Q16Analysis · Standard · Paper 1 style · 4 marks
  1. (a) An analyst is studying how a busy hospital pharmacy in Lahore records medicines given to patients. Give two advantages of using observation to research the current system. [2]
  2. (b) Give two disadvantages of using observation in this pharmacy. [2]
Show answer
  1. (a) Any two, e.g. the analyst sees what actually happens rather than what staff say happens; reliable first-hand information; sees the whole process, including problems staff may not mention; relatively cheap/does not take staff away from work.
    1 mark each.
  2. (b) Any two, e.g. staff may work differently/better when they know they are watched; time-consuming for the analyst; the analyst may be in the way in a busy area; patient confidentiality – analyst may see private information; may not see rare problems during the visit.
    1 mark each.
Q17Analysis · Standard · Paper 1 style · 4 marks
  1. (a) A textile company has 800 employees working in offices in Karachi, Lahore and Faisalabad. Compare using questionnaires and interviews to find out what the employees think of the current system. [4]
Show answer
  1. (a) Both collect the views of users. Questionnaires can reach all 800 employees in different cities quickly and cheaply, whereas interviews take much longer and need travel; questionnaires can be anonymous so answers may be more honest, while in interviews staff may say what they think the analyst wants; interviews let the analyst ask follow-up questions and explain, but questionnaires have fixed questions; questionnaires may not all be returned; questionnaire answers are easier to analyse.
    1 mark per comparison point, max 4.
Q18Analysis · Challenge · Paper 1 style · 6 marks
  1. (a) A courier company in Karachi records parcel deliveries on paper. A systems analyst has been asked to produce a new computerised system. Describe the tasks the analyst carries out in the analysis stage. [6]
Show answer
  1. (a) Research the current system using observation/interviews/questionnaires/examining documents; record the inputs (e.g. parcel details, addresses), processing (e.g. allocating parcels to drivers) and outputs (e.g. delivery lists, receipts) of the current system; identify problems with the current system (e.g. lost parcels, slow tracking); identify user requirements (what staff need the new system to do); identify information requirements; identify the hardware and software needed for the new system; produce a requirements specification/cost-benefit.
    1 mark per task, max 6. Max 4 if no reference to the courier scenario.
Q19Implementation methods · Core · Paper 1 style · 3 marks
  1. (a) Name the four methods of implementing a new system. [2]
  2. (b) Describe direct changeover. [1]
Show answer
  1. (a) Direct changeover; parallel running; pilot running; phased implementation.
    All four: 2 marks; two or three: 1 mark.
  2. (b) The old system is stopped and the new system is started at the same time/immediately replaces it.
    1 mark.
Q20Implementation methods · Standard · Paper 1 style · 4 marks
  1. (a) A bank introduces a new payroll system using parallel running. Describe parallel running. [1]
  2. (b) Give two advantages and one disadvantage of parallel running for the bank. [3]
Show answer
  1. (a) The old and new systems are both used together for a period, processing the same data, until the new system is shown to work.
    1 mark.
  2. (b) Advantages (any two): if the new system fails, the old one is still running so no data/pay is lost; results of the two systems can be compared to check the new system is correct; staff can be trained gradually. Disadvantage (any one): expensive because data is entered twice/extra staff or overtime needed; extra workload for staff; takes longer to fully implement.
    1 mark each, max 2 advantages and 1 disadvantage.
Q21Implementation methods · Standard · Paper 1 style · 3 marks
  1. (a) A supermarket chain with 60 stores across Pakistan is introducing a new stock control system using pilot running. Describe pilot running in this context. [1]
  2. (b) Give one advantage and one disadvantage of pilot running for the supermarket chain. [2]
Show answer
  1. (a) The new system is introduced in one store (or a few stores) first; when it works there it is introduced in the other stores.
    1 mark.
  2. (b) Advantage: if the system fails only one store is affected; staff in the pilot store can help train others; problems can be fixed before full roll-out; cheaper than parallel running across all stores. Disadvantage: takes longer to implement across all 60 stores; if the system fails, the pilot store is affected/loses data; the pilot store may not be typical of all stores.
    1 mark each.
Q22Implementation methods · Challenge · Paper 1 style · 6 marks
  1. (a) Recommend the most suitable implementation method for each situation and explain your choice.(i) A hospital's new patient records system, where no data must be lost.(ii) A restaurant chain with 40 branches that all do the same work.(iii) A factory's new system made of separate stock, payroll and sales modules. [6]
Show answer
  1. (a) (i) Parallel running – the old system continues so if the new system fails records are not lost; results can be compared.(ii) Pilot running – try it in one branch first; any problems affect only one branch before roll-out to the others.(iii) Phased implementation – introduce one module at a time so each part can be tested and staff trained gradually; a failure affects only one part.
    For each: 1 mark for method, 1 mark for explanation.
Q23Implementation methods · Challenge · Paper 1 style · 6 marks
  1. (a) A small school in Murree is replacing its paper attendance registers with a computerised system. The head teacher wants to use direct changeover during the summer holidays. Evaluate this choice. [6]
Show answer
  1. (a) For: cheapest method – no duplication of work; the new system is used straight away so benefits are immediate; during the holidays no attendance is being taken, so there is time to set up and test before term; staff only have to learn one system. Against: if the new system fails at the start of term there is no backup, so attendance data could be lost (important for safety/fire registers); all staff need training before day one; any errors affect the whole school at once. Mitigations: test thoroughly; keep paper registers ready in case. Conclusion, e.g. suitable for a small school with a simple system, given the holiday timing.
    5–6: both sides developed with conclusion linked to the scenario; 3–4: both sides with some development; 1–2: simple points.

  1. (a) Name the most suitable validation check for each field.(i) StudentID must have exactly 6 characters.(ii) Gender must be M, F or X.(iii) Mark must be from 0 to 100.(iv) Email address must contain one @ symbol followed by a dot. [4]

  1. (a) (i) Length check(ii) Lookup check (list/table lookup)(iii) Range check(iv) Format check
    1 mark each.
Q25Design: validation routines · Standard · Paper 2 style · 3 marks

A hardware shop in Gujranwala uses a database table called SALES. The field Quantity must be a whole number from 1 to 50.

  1. (a) Write the validation rule you would enter for the Quantity field. [1]
  2. (b) State the data type and field size you would set so that only whole numbers are accepted. [1]
  3. (c) Write suitable validation text that would be shown if the rule is broken. [1]
Show answer
  1. (a) >=1 And <=50 (accept Between 1 And 50)
    1 mark for correct operators and both limits.
  2. (b) Number – Integer (accept Long Integer/Byte).
    1 mark.
  3. (c) E.g. 'Quantity must be a whole number from 1 to 50.'
    1 mark for a message that tells the user what to enter.
Q26Design: validation routines · Standard · Paper 1 style · 3 marks
  1. (a) A car park system stores vehicle registrations in the form ABC-123: three capital letters, a hyphen, then three digits. Describe how a format check would validate this field. [1]
  2. (b) Give one registration that would pass the format check and one that would fail. [1]
  3. (c) Explain why a registration that passes the format check could still be wrong. [1]
Show answer
  1. (a) It checks that the data matches the pattern: three letters, then '-', then three digits (in the right positions).
    1 mark.
  2. (b) Pass e.g. LEB-472; fail e.g. LEB472 / 12-ABC / LE-4721.
    1 mark for both correct.
  3. (c) Validation only checks that data is sensible/matches the rules, not that it is correct; e.g. LEB-427 typed instead of LEB-472 would pass.
    1 mark.
Q27Design: validation routines · Challenge · Paper 1 style · 4 marks

A bookshop checks book numbers using a check digit. The first 12 digits of a book number are 978627880415. The check digit is calculated like this:• multiply the 1st, 3rd, 5th … 11th digits by 1 and the 2nd, 4th, 6th … 12th digits by 3• add the results• find the remainder when the total is divided by 10• if the remainder is 0 the check digit is 0, otherwise the check digit is 10 minus the remainder.

  1. (a) Calculate the check digit for this book number. Show your working. [2]
  2. (b) A shop assistant types the number as 978627880451 followed by the check digit 1. Explain how the computer detects the error. [2]
Show answer
  1. (a) 1
    9×1 + 7×3 + 8×1 + 6×3 + 2×1 + 7×3 + 8×1 + 8×3 + 0×1 + 4×3 + 1×1 + 5×3 = 139 (M1); remainder 9, so check digit = 10 − 9 = 1 (A1).
  2. (b) The computer recalculates the check digit from the 12 digits typed: total becomes 131, remainder 1, check digit 9; 9 does not match the typed check digit 1, so the number is rejected (transposition error found).
    1 mark for recalculating and comparing, 1 mark for correct values 131/9.
Q28Documentation · Core · Paper 1 style · 5 marks
  1. (a) Give three items that are found in user documentation. [3]
  2. (b) Give two items that are found in technical documentation but not in user documentation. [2]
Show answer
  1. (a) Any three, e.g. how to load/run the software; how to save and print; how to add, edit and delete records; how to search/sort; hardware and software requirements; error messages and what to do (troubleshooting); FAQs; glossary; tutorials; screenshots; index/contents.
    1 mark each.
  2. (b) Any two, e.g. program listing/code; flowcharts/algorithms; file structures; validation rules; programming language used; system design/data flow diagrams; test plans and results; known bugs.
    1 mark each.
Q29Documentation · Standard · Paper 1 style · 3 marks
  1. (a) Explain why technical documentation is produced for a new system and state who uses it. [3]
Show answer
  1. (a) Used by systems analysts/programmers/technicians; so that the system can be maintained, updated or repaired later; so that errors can be found and fixed by someone who did not write the system; so that the system can be upgraded/extended.
    1 mark for who uses it, 2 marks for reasons.
Q30Documentation · Challenge · Paper 1 style · 6 marks
  1. (a) Compare user documentation and technical documentation. [4]
  2. (b) Explain why user documentation often includes a troubleshooting section. [2]
Show answer
  1. (a) Both describe the system and both include hardware/software requirements. User documentation is written for people who use the system, whereas technical documentation is for people who maintain/develop it; user documentation explains how to carry out tasks (save, print, search) in plain language, while technical documentation includes program code, file structures and validation rules; user documentation has tutorials/FAQs/troubleshooting, technical documentation has algorithms/flowcharts/test results.
    1 mark per comparison point, max 4; at least one similarity for full marks.
  2. (b) Users can solve common problems/error messages themselves without needing a technician; this saves time and support costs and the user can continue working.
    1 mark each.
