Q1Formulas and functions · Core · Paper 1 style · 4 marks
  1. (a) Explain the difference between a formula and a function in a spreadsheet. [2]
  2. (b) Give one example of each, using cell references. [2]
Show answer
  1. (a) A formula is a calculation entered by the user, using cell references, values and operators, e.g. =B2*C2. A function is a predefined/built-in named operation in the software that carries out a calculation on given arguments/a range, e.g. =SUM(B2:B10).
    1 mark: formula = user-written calculation with operators/cell references. 1 mark: function = built-in/predefined named routine. Examples alone not enough.
  2. (b) Formula e.g. =D4-E4 or =B3*1.17; function e.g. =AVERAGE(C2:C20) or =MAX(B2:B9).
    1 mark for a valid formula; 1 mark for a valid function.

Q11Formulas and functions · Standard · Paper 3 style · 6 marks

An electronics shop stores the sales tax rate, 17%, in cell F1. Prices of items (Rs) are in B2 to B20.

  1. (a) Write the formula in C2 to calculate the sales tax on the item in B2. It must give correct results when replicated down to C20. [2]
  2. (b) Explain why an absolute reference is needed in this formula. [2]
  3. (c) B2 contains 2400 and B5 contains 1850. State the values displayed in C2 and C5. [2]
Show answer
  1. (a) =B2*$F$1
    1 mark: B2 multiplied by F1. 1 mark: F1 made absolute ($F$1). Accept =B2*F$1.
  2. (b) When the formula is replicated, relative references change (B2 becomes B3, B4…) but the tax rate is always in F1, so the reference to F1 must not change; otherwise the formula would point to F2, F3… which are empty.
    1 mark: relative references change when copied. 1 mark: F1 must stay fixed / would refer to empty cells.
  3. (c) C2 408; C5 314.5
    B1 each: 2400 × 0.17 = 408; 1850 × 0.17 = 314.5.

Q23Formulas and functions · Challenge · Paper 3 style · 6 marks

A wholesaler gives a discount based on the order value. The table in F2:G5 is:F (order value from, Rs) | G (discount)0 | 0%5000 | 5%10000 | 8%20000 | 12%

  1. (a) Write the formula in C2 to find the discount rate for the order value in B2, using the table, so that it works when replicated. [2]
  2. (b) State the discount rate given for order values of Rs 4999, Rs 10 000, Rs 17 500 and Rs 25 000. [2]
  3. (c) Calculate the discount, in rupees, on an order of Rs 17 500. [1]
  4. (d) Explain why the values in column F must be in ascending order. [1]
Show answer
  1. (a) =VLOOKUP(B2,$F$2:$G$5,2,TRUE)
