Q41Generic file formats · Challenge · Paper 1 style · 5 marks
  1. (a) Explain the difference between lossy and lossless compression. [2]
  2. (b) State which type of compression should be used for each file and give a reason.(i) A spreadsheet of bank account balances.(ii) A song to be streamed to mobile phones. [3]
Show answer
  1. (a) Lossy compression permanently removes some data (detail that is least noticeable), so the original cannot be restored exactly; lossless compression reduces the file size without losing any data, so the original can be rebuilt exactly.
    1 mark each.

    (i) 1 mark for lossless with reason; (ii) 1 mark for lossy, 1 mark for reason.
Q42Generic file formats · Challenge · Paper 1 style · 4 marks

A recording of a qawwali performance is stored as a 40 MB uncompressed audio file. Converting it to .mp3 reduces the file size by 85%. Use 1 GB = 1024 MB.

  1. (a) Calculate the size of the .mp3 file in MB. [1]
  2. (b) Calculate how many whole .mp3 files of this size can be stored in 2 GB. [2]
  3. (c) State one drawback of using .mp3 for this recording. [1]
Show answer
  1. (a) 6 MB
    40 × (100 − 85) ÷ 100 = 6 MB
  2. (b) 341 files
    2 × 1024 = 2048 MB (M1); 2048 ÷ 6 = 341.33…, so 341 whole files (A1).
  3. (c) Some sound quality is lost permanently and cannot be recovered (lossy).
    1 mark.

Q46Generic file formats · Challenge · Paper 1 style · 4 marks

    1 mark each.

Q48Generic file formats · Challenge · Paper 1 style · 4 marks
  1. (a) A video-streaming service stores films as compressed .mp4 files. Describe how lossy compression reduces the size of a video file. [3]
  2. (b) Explain one reason why the service uses lossy rather than lossless compression. [1]
Show answer

    1 mark.
Q49Generic file formats · Challenge · Paper 1 style · 6 marks
  1. (a) A photographer in Hunza is sending landscape photos to a magazine that will print them on large pages. Discuss whether she should send the photos as highly compressed .jpg files or in a lossless format such as .png. [6]
Show answer
  1. (a) JPG (high compression): much smaller files, quick to upload over a slow mountain internet connection, fit email limits, use less storage; but lossy – fine detail and colour gradients (sky) may show blocks/artefacts when printed large, and quality cannot be recovered. Lossless (.png): keeps every pixel, best quality for large printing and further editing by the magazine; but files are much larger, slow to upload, may need cloud storage/file transfer. Middle way: JPG at high quality/low compression, or send small previews first then full files of chosen photos. Conclusion, e.g. lossless/high-quality files because print quality is the priority.
    5–6: both formats discussed in context with justified conclusion; 3–4: both sides with some development; 1–2: simple points.

Q59Generic file formats · Challenge · Paper 1 style · 3 marks
