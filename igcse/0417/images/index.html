Q1Editing images · Core · Paper 2 style · 3 marks
  1. (a) A newsletter for a cricket club in Sialkot contains a photograph that is 15 cm wide and 10 cm high. It must be resized so that it is 6 cm wide and the aspect ratio is maintained. Calculate the new height of the photograph. [1]
  2. (b) Explain why the aspect ratio of the photograph should be maintained when it is resized. [2]
Show answer
  1. (a) 4 cm
    B1: 10 × 6 ÷ 15 = 4 cm.
  2. (b) So that the image is not distorted/stretched or squashed; the proportions of the people and objects stay correct so the image still looks realistic/professional.
    1 mark: image not distorted (stretched/squashed). 1 mark: proportions (width to height) stay the same / people and objects keep their correct shape.
Q2Editing images · Core · Paper 2 style · 3 marks
  1. (a) A student is editing an image of a market stall for a school magazine. Describe the difference between cropping the image and resizing the image. [2]
  2. (b) State one reason why the student might crop the image. [1]
Show answer
  1. (a) Cropping removes unwanted parts from the edges of the image, so some content is lost and the remaining part is unchanged in scale. Resizing changes the size/dimensions of the whole image but keeps all of its content.
    1 mark: cropping cuts away/removes part of the image (from the edges). 1 mark: resizing makes the whole image bigger or smaller with all content kept.
  2. (b) e.g. to remove an unwanted person/object at the edge; to focus attention on the main subject (the stall); to change its shape to fit a space.
    1 mark for one valid reason.

    1 mark: insert the picture from the file. 1 mark: set text wrapping to square/tight. 1 mark: align/position image to the right margin.

Q31Editing images · Standard · Paper 1 style · 4 marks
  1. (a) Explain why images placed on web pages are usually compressed. [2]
  2. (b) Describe the difference between lossy and lossless compression of an image. [2]
Show answer
  1. (a) Compression reduces the file size so the image downloads faster and the web page loads more quickly; it also uses less bandwidth/storage on the server.
    1 mark: smaller file size. 1 mark: faster loading / less bandwidth or storage.
  2. (b) Lossy compression permanently removes some image data (detail the eye may not notice), so the original cannot be fully restored but the file is much smaller. Lossless compression reduces the file size without losing any data, so the original image can be restored exactly.
    1 mark: lossy removes data permanently. 1 mark: lossless — no data lost / original restored exactly.

Q44Editing images · Challenge · Paper 3 style · 4 marks
  1. (a) A photograph taken inside a dimly lit museum looks dark and dull: the dark areas and light areas look very similar. Explain the difference between adjusting the brightness and adjusting the contrast of an image. [2]
  2. (b) State which adjustments should be made to improve this photograph, giving a reason for each. [2]
Show answer
  1. (a) Brightness makes every pixel in the whole image lighter (or darker) by the same amount. Contrast changes the difference between the light and dark areas: increasing it makes light areas lighter and dark areas darker.
    1 mark: brightness = whole image lighter/darker. 1 mark: contrast = difference between light and dark parts.
  2. (b) Increase the brightness so that the details in the dark image can be seen; increase the contrast so that the light and dark areas are more clearly different/the image looks less dull.
    1 mark: increase brightness + reason. 1 mark: increase contrast + reason.
Q45Editing images · Challenge · Paper 1 style · 6 marks

Answers in prose comparing both sides needed for full marks.

  1. (a) An image 2400 pixels wide and 1800 pixels high is scaled to 35% of its width and 35% of its height. Calculate the new dimensions. [2]
  2. (b) The image is uncompressed. Calculate the new file size as a percentage of the original file size. [2]
  3. (c) A student says 'scaling to 35% makes the file 35% of its original size'. Explain why the student is wrong. [1]
Show answer
  1. (a) 840 pixels × 630 pixels
    B1: 2400 × 0.35 = 840. B1: 1800 × 0.35 = 630.
  2. (b) 12.25%
    M1: (840 × 630) ÷ (2400 × 1800) or 0.35². A1: 12.25%.
  3. (c) Both the width and the height are reduced, so the number of pixels is multiplied by 0.35 twice (0.35 × 0.35), not once.
    1 mark.
Q47Editing images · Challenge · Paper 3 style · 4 marks
  1. (a) A profile photograph is 1200 pixels wide and 900 pixels high. It must become a square image 250 pixels wide for a membership card, showing the person's face in the centre. Describe, with dimensions, the two edits needed and the order in which they should be done. [3]
  2. (b) Explain why resizing the original image straight to 250 × 250 pixels would not be suitable. [1]
Show answer
  1. (a) First crop the image to a square 900 × 900 pixels by removing 150 pixels from each side (left and right), keeping the face central. Then resize the square image, with aspect ratio locked, to 250 × 250 pixels.
    1 mark: crop to 900 × 900 (remove 300 pixels of width). 1 mark: 150 pixels from each side to keep face centred. 1 mark: then resize to 250 × 250 with aspect ratio kept.
  2. (b) The original is 4 : 3, not square, so forcing it to 250 × 250 would distort/squash the face.
    1 mark.
Q48Editing images · Challenge · Paper 3 style · 4 marks
  1. (a) An uncompressed image uses 3 bytes per pixel and has an aspect ratio of 4 : 3. Its file size must be no more than 600 KB, where 1 KB = 1024 bytes. Its width must be a multiple of 4 pixels. Calculate the largest possible width and height, and the file size in bytes at that size. [4]
Show answer
  1. (a) Width 520 pixels, height 390 pixels, file size 608 400 bytes
    M1: limit 600 × 1024 = 614 400 bytes. M1: w × (3w/4) × 3 ≤ 614 400 → w² ≤ 273 066.7 → w ≤ 522.5. A1: w = 520 (largest multiple of 4), h = 390. A1: 520 × 390 × 3 = 608 400 bytes (≤ 614 400). (524 × 393 × 3 = 617 796 is too big.)
Q49Editing images · Challenge · Paper 2 style · 3 marks
  1. (a) A newsletter is set on A4 portrait paper (21 cm wide). The left and right margins are each 2 cm. The page has two columns of equal width with 1 cm spacing between them. Calculate the width of each column. [2]
  2. (b) An image 12 cm wide and 9 cm high must fill the full width of one column with its aspect ratio maintained. Calculate the new height. [1]
Show answer
  1. (a) 8 cm
    M1: (21 − 2 − 2 − 1) ÷ 2. A1: 8 cm.
  2. (b) 6 cm
    B1: 9 × 8 ÷ 12 = 6 cm.

The teacher notes these problems:• the photograph looks squashed;• it overlaps the right margin by 1 cm;• the text stops above the photograph and starts again below it, leaving large empty spaces at the sides;• the top of the photograph covers part of the header.For each problem, describe how the student should correct it. Q51Editing images · Challenge · Paper 2 style · 4 marks

A 24-bit uncompressed image is 3840 pixels wide and 2160 pixels high. It is compressed so that the file is one tenth of its uncompressed size.

  1. (a) Calculate the compressed file size in MB (1 MB = 1 048 576 bytes). Give your answer to 2 decimal places. [4]
Show answer
  1. (a) 2.37 MB
    M1: 3840 × 2160 × 24 ÷ 8 = 24 883 200 bytes uncompressed. M1: ÷ 10 = 2 488 320 bytes. M1: ÷ 1 048 576. A1: 2.37 MB.

Q53Editing images · Challenge · Paper 2 style · 5 marks

A 16-bit colour image is 2000 pixels wide and 1000 pixels high. The device has 3 MB of free storage.

  1. (a) Calculate the uncompressed file size in bytes. [2]
  2. (b) Calculate the file size in MB (1 MB = 1 048 576 bytes) and state whether the image can be stored in the 3 MB of free space without compression. Show your working. [3]
Show answer
  1. (a) 4 000 000 bytes
    M1: 2000 × 1000 × 16 ÷ 8. A1: 4 000 000 bytes.
  2. (b) 3.81 MB, which is larger than 3 MB, so it cannot be stored uncompressed.
    M1: 4 000 000 ÷ 1 048 576 = 3.81 MB. M1: compare with 3 MB. A1: it cannot be stored uncompressed; it must be compressed or resized.
Q54Editing images · Challenge · Paper 2 style · 4 marks

A greeting card is to be printed 10 cm wide and 15 cm high at 200 pixels per inch. Use 1 inch = 2.54 cm.

  1. (a) Calculate the number of pixels needed across and down the image. Round to the nearest whole pixel. [4]
Show answer
  1. (a) 787 pixels across and 1181 pixels down
    M1: 10 cm ÷ 2.54 = 3.937 inches; × 200 = 787.4, so 787. M1: 15 cm ÷ 2.54 = 5.906 inches; × 200 = 1181.1, so 1181. A1 and A1 for each correct value.
Q55Editing images · Challenge · Paper 2 style · 6 marks

A school in Multan is putting hundreds of photographs of its events on its website. The camera files are very large, and the school wants the gallery to load quickly on a phone.

  1. (a) Discuss how a school should prepare and store its photographs so that the gallery loads quickly on the website but the images still look good. [6]
Show answer
  1. (a) Sample points: resize each image to the display size needed (not the full camera size); use JPEG for photos and compress to a sensible quality level; keep the aspect ratio; crop unwanted edges; keep the original full-size photos in a separate archive for printing; test the page to check load speed; avoid compressing a photo so much that it looks blocky. Trade-offs: a lower resolution or higher compression gives smaller files and faster loading but less detail; keeping high resolution gives good quality but slower loading and more storage space.
    Up to 6 marks: 2 marks for preparing the images (resize, crop, aspect ratio); 2 marks for compression and file format with reasons; 2 marks for a balanced discussion of the trade-off between quality, file size and loading speed, with a link to the website.
Q56Editing images · Challenge · Paper 2 style · 4 marks

A logo for a school website is a dark-blue shape on a plain white background. It must sit on a coloured page with no white box around it.

  1. (a) Describe the steps to make the white background of the logo transparent, and state the file format to save the logo in. [4]
Show answer
  1. (a) Select the background area with the select-by-colour (magic wand) tool or use a background removal tool; delete the selected background so it shows as a checkerboard; check the edges of the logo for any white halo and tidy them; save as a PNG file, which supports transparency.
    1 mark: selecting the background (magic wand or select by colour). 1 mark: deleting it so it becomes transparent. 1 mark: checking and tidying the edges. 1 mark: saving as PNG (not JPEG, which has no transparency).
Q57Editing images · Challenge · Paper 2 style · 3 marks

A 1920 × 1080 pixel image is placed on a 1024 × 768 pixel slide. The image must fit the full width of the slide and keep its aspect ratio.

  1. (a) Calculate the width and height the image occupies on the slide, in pixels, keeping the aspect ratio. [3]
Show answer
  1. (a) 1024 pixels wide and 576 pixels high

Q58Editing images · Challenge · Paper 2 style · 4 marks

An uncompressed image is 1000 × 1000 pixels with 8-bit colour depth. The colour depth is reduced to 4 bits per pixel.

  1. (a) Calculate the new file size in bytes and the percentage reduction in file size compared with the original. [4]
Show answer
  1. (a) New file size 500 000 bytes; the file is 50% smaller.
    M1: original size 1000 × 1000 × 8 ÷ 8 = 1 000 000 bytes. M1: new size 1000 × 1000 × 4 ÷ 8 = 500 000 bytes. M1: reduction 500 000 ÷ 1 000 000 × 100. A1: 50%.
