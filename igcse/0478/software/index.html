Q1Programming languages, translators and IDEs · Core · Paper 1 style · 3 marks
  1. (a) A games studio in Lahore writes most of its code in a high-level language. State two differences between a high-level language and a low-level language. [2]
  2. (b) Give one reason why a programmer at the studio might still write a small part of the game in a low-level language. [1]
Show answer
  1. (a) Any two, e.g. high-level uses English-like statements, low-level uses mnemonics or binary; high-level is machine independent, low-level is specific to one processor; one high-level statement may become many machine code instructions, one assembly instruction becomes one machine code instruction.
    1 mark each for any two differences, both sides of the comparison needed (or clearly implied). Do not accept 'high-level is harder'.
  2. (b) To directly control/manipulate the hardware (e.g. specific registers or memory locations), or to produce code that runs faster / uses less memory.
    1 mark for any one valid reason.

Q5Programming languages, translators and IDEs · Core · Paper 1 style · 4 marks
  1. (a) A coding club uses an interpreter while it is developing a quiz app. Explain why an interpreter is useful during development. [2]
  2. (b) When the app is finished, the club compiles it before sharing it. Give two reasons for this. [2]
Show answer
  1. (a) The interpreter stops at the line with an error and reports it, so the programmer can correct the error and continue/re-run straight away; parts of the program can be tested before the whole program is complete.
    1 mark: stops at/identifies the error line. 1 mark: error can be fixed and the program re-run immediately / test sections without translating the whole program.
  2. (b) Any two, e.g. the users do not need a translator to run it; the executable file runs faster than interpreted code; the source code is not shared, so it cannot easily be copied or changed.
    1 mark each for any two reasons.

Q10Programming languages, translators and IDEs · Standard · Paper 1 style · 3 marks

Show answer

Q11Programming languages, translators and IDEs · Standard · Paper 1 style · 4 marks
  1. (a) A program for recording exam marks was written in a high-level language on laptops at a school in Multan. The school now wants it to run on tablets that have a different type of processor. Explain why writing the program in a high-level language makes this easier. [2]

  2. (b) Machine code is specific to the processor's instruction set; the tablets' processor uses a different instruction set, so it cannot execute those instructions.
    1 mark: machine code is processor/machine specific. 1 mark: the tablet's processor has a different instruction set so cannot understand it.

Q13Programming languages, translators and IDEs · Challenge · Paper 1 style · 5 marks

Q14Programming languages, translators and IDEs · Challenge · Paper 1 style · 5 marks
  1. (a) A drone's flight controller has a small amount of memory and must respond to its sensors very quickly. Explain why its designers might write parts of the control program in assembly language instead of a high-level language. [4]
  2. (b) Explain why the same assembly language program could not be used on a drone that has a different type of processor. [1]
Show answer
  1. (a) Assembly gives direct control of the hardware (registers, memory addresses, ports), needed to read the sensors and drive the motors; each instruction translates to one machine code instruction, so the code can be written to be compact, which suits the small memory; the programmer can optimise the code so it executes faster, which suits the need for quick response.
    Up to 4 marks: 1 for each point and 1 for each linked expansion (direct hardware control; compact code for small memory; fast execution for quick response).
  2. (b) Assembly language is specific to a processor's instruction set, so a different processor would need a rewritten program.
    1 mark.
Q15Programming languages, translators and IDEs · Challenge · Paper 1 style · 4 marks
  1. (a) A student's program contains two syntax errors, one on line 14 and one on line 30. Describe what happens when the program is translated with an interpreter. [2]
  2. (b) Describe what happens when the same program is translated with a compiler. [2]
Show answer
  1. (a) Lines 1 to 13 are translated and executed; the interpreter stops at line 14 and reports that error; the error on line 30 is not reported until line 14 has been corrected and the program is re-run to that point.
    1 mark: runs until line 14 then stops and reports it. 1 mark: line 30 error only found after correcting line 14 and running again.
  2. (b) The compiler attempts to translate the whole program; it reports both errors (lines 14 and 30) in an error list at the end; no executable file is produced, so none of the program runs.
    1 mark: both errors reported together after translation. 1 mark: no executable produced / program does not run.

Q22System and application software, operating system functions · Standard · Paper 1 style · 4 marks
  1. (a) A delivery rider in Lahore uses a smartphone. The maps app is open while music plays and a messaging app receives a new order. Explain how the operating system manages memory and multitasking so that all three apps can run. [4]
Show answer
  1. (a) Memory management: the OS allocates each app its own area of memory and keeps track of it; it prevents one app from using/overwriting another app's memory; it frees memory when an app is closed.Multitasking: the OS shares processor time between the apps, switching rapidly between them so they appear to run at the same time; it decides priorities (e.g. the messaging alert).
    Up to 2 marks for memory management points and up to 2 marks for multitasking points.

Q24System and application software, operating system functions · Standard · Paper 1 style · 4 marks
  1. (a) A laptop needs hardware, firmware, an operating system and applications. Put these four layers in order, starting with the layer closest to the hardware. [1]
  2. (b) Describe the role of firmware such as the bootloader when the laptop is switched on. [2]
  3. (c) Explain why applications are run by the operating system rather than directly on the hardware. [1]

  1. (a) Hardware → firmware → operating system → applications
    1 mark for the correct order.

  3. (c) The OS provides a platform/standard services so applications do not need to manage the hardware themselves, and it controls their access to the hardware.

Q25System and application software, operating system functions · Challenge · Paper 1 style · 6 marks
  1. (a) A hospital uses computers that store patient records. Explain how three functions of the operating system help the computers to run safely and correctly in this hospital. [6]
Show answer
  1. (a) Any three explained in context, e.g.- managing system security / user accounts: each member of staff logs in with their own account and password, so only authorised staff can see patient records;- file management: the OS organises records into folders, controls opening, saving, copying and deleting, and sets access rights so records are not changed by the wrong people;- handling interrupts: urgent signals (e.g. a device error) are dealt with immediately so systems keep working;- memory management: each application has its own memory so one program cannot corrupt another;- managing peripherals: drivers let the computers use printers/scanners for records.

Q26System and application software, operating system functions · Challenge · Paper 1 style · 6 marks
  1. (a) A computer has 4 GiB of RAM. A student opens several large programs at once. Explain how the operating system manages the processes and memory so the student can keep working. [4]
  2. (b) The student notices that the computer slows down a lot when very many programs are open. Explain why. [2]
Show answer
  1. (a) The OS allocates memory to each process and keeps a record of which memory each uses; when RAM is full it can move data/pages not currently needed to virtual memory on secondary storage; it swaps them back into RAM when needed; it schedules processor time between the processes (multitasking) so each makes progress; it frees memory when a program is closed.
    1 mark each for any four points.
  2. (b) RAM is full so more data is held in virtual memory; data must be repeatedly swapped between RAM and secondary storage, which is much slower than RAM (disk thrashing).
    1 mark: virtual memory/secondary storage used. 1 mark: swapping data is slow compared with RAM.
Q27System and application software, operating system functions · Challenge · Paper 1 style · 5 marks
  1. (a) A games company says its new game 'needs an operating system to run'. Explain why application software depends on an operating system. [3]
  2. (b) Explain why the same game file may not run on a computer with a different operating system. [2]
Show answer
  1. (a) The OS provides the platform on which the application runs; it gives access to the hardware (screen, keyboard, sound) through drivers, so the game does not need its own code for each device; it allocates memory and processor time to the game; it handles files such as saved games.
    1 mark each for any three points.
  2. (b) The game is written to use the services/instructions provided by one particular operating system; another OS provides different services/file formats, so the game cannot call them correctly.
    1 mark: relies on the specific OS services. 1 mark: a different OS works differently so the calls fail.
Q28Ethics and software licensing (old syllabus) · Core · Paper 1 style · 4 marks

Mehwish downloads a photo-editing program for her laptop. The program is shareware.

  1. (a) State what is meant by copyright. [1]
  2. (b) Describe what is meant by shareware. [3]
Show answer
  1. (a) Copyright is the legal right of the creator (owner) of a work, such as a program, to control how it is copied, used and distributed.
    1 mark: legal protection / right of the owner or creator to stop others copying or distributing the work without permission.
  2. (b) Shareware is software that users can try free of charge for a limited trial period (or with some features disabled). To keep using it, or to unlock all features, the user must pay for a licence. It is still protected by copyright and the source code is not supplied, so users may not modify it.
    1 mark each for any three of: free to try / free trial; limited time or limited features; must pay (register / buy a licence) to continue or get full version; protected by copyright; source code not available / cannot be modified.

Q31Ethics and software licensing (old syllabus) · Challenge · Paper 1 style · 7 marks

A software house in Karachi is developing a delivery-tracking app. Three things happen during the project.

  1. (a) State what is meant by computer ethics. [1]
  2. (b) For each action below, explain why it is unethical, and state any law or licence it breaks.(i) Faraz copies large sections of program code he wrote for his previous employer into the new product, without permission.(ii) The office manager buys one single-user licence for a graphics program and installs it on all 20 office computers.(iii) A network technician reads customers' private messages stored on the company server because he is curious. [6]
Show answer
  1. (a) A set of principles (moral rules) about what is right and wrong when using computers.

(ii) licence allows one machine only (1); breach of licence / piracy, developer loses money (1). (iii) invasion of privacy / breach of confidentiality (1); misuse of authorised access / may break data protection law (1).
Q32Ethics and software licensing (old syllabus) · Challenge · Paper 1 style · 6 marks

A group of university students in Kuala Lumpur has written a timetable app. They are deciding whether to distribute it as freeware, shareware or free software.

  1. (a) The students hope to earn money from the app in future. Explain why distributing it as shareware would help them do this. [2]
  2. (b) Explain one drawback to the students of releasing the app as free software instead. [2]
  3. (c) The students used a code library written by another programmer. Explain what plagiarism is and how they can make sure they do not plagiarise the library. [2]
Show answer
  1. (a) Users can try the app free, which attracts many of them; after the trial (or to unlock all features) they must pay for a licence, which brings income to the students.
    1 mark: free trial attracts users / lets them see its value. 1 mark: users must pay to continue or to get the full version, giving income.
  2. (b) The source code must be made available and anyone may copy, change and redistribute it, so a competitor could release their own version (even sell it) and the students would find it hard to earn money from their work.
    1 mark: source code available / others may modify and redistribute. 1 mark: so others could copy or compete with it and the students lose control or income.
  3. (c) Plagiarism is presenting someone else's work or ideas as your own. They should credit (acknowledge) the library's author in the app and documentation and follow the terms of the library's licence.
    1 mark: definition – using another person's work and claiming it as your own. 1 mark: acknowledge / credit the author and keep to the library's licence terms.
Q33Interrupts · Core · Paper 1 style · 4 marks
  1. (a) State what is meant by an interrupt. [2]
  2. (b) Give one example of a hardware interrupt and one example of a software interrupt. [2]
Show answer
  1. (a) A signal sent to the processor from a device or from software, telling it that something needs attention/processing.
    1 mark: a signal to the processor. 1 mark: from hardware or software indicating it needs attention.
  2. (b) Hardware: e.g. a key being pressed, the mouse being moved, a printer running out of paper. Software: e.g. division by zero, two processes trying to use the same memory location, a program requesting input.
    1 mark for each correct example.
Q34Interrupts · Standard · Paper 1 style · 5 marks
  1. (a) Describe how a processor handles an interrupt. [5]
Show answer
  1. (a) The interrupt is placed in a queue/stored according to its priority; at the end of each fetch-decode-execute cycle the processor checks for interrupts; if the interrupt has a higher priority than the current task, the current task is suspended; the current state/register values are saved (on the stack); the interrupt service routine (ISR) for that interrupt is called/run; when the ISR is finished, the saved state is restored and the original task continues.
    1 mark each for any five points.
Q35Interrupts · Challenge · Paper 1 style · 6 marks
  1. (a) Asad is listening to music on his computer while a document prints. At the same moment he presses a key and the printer runs out of paper. Explain how the processor uses interrupts to deal with both events without the music stopping for long. [4]
  2. (b) Explain why using interrupts is more efficient than the processor repeatedly checking every device to see whether it needs attention. [2]
Show answer
  1. (a) Each device sends an interrupt signal; the interrupts are queued according to priority; at the end of each FDE cycle the processor checks the queue; it saves the state of the current task, runs the ISR for the highest-priority interrupt, then for the next one (e.g. shows an out-of-paper message, reads the key press); after each ISR the saved state is restored so the music program continues; this happens so fast the music continues smoothly.
    1 mark each for any four points applied to the scenario.
  2. (b) The processor does not waste time checking devices that do not need attention; it can carry on with other processing and only responds when a device sends an interrupt.
    1 mark: no time wasted polling idle devices. 1 mark: processor continues useful work and responds only when signalled.
