## Caveats
- Usually one variant per paper per session was tagged in full (mostly variant 2; variant 1 for 5054/5070/5090); other variants were spot-checked.
- Topic weights are estimates (each part tagged to one main topic, about ±2 marks per topic per paper).
- Examiner reports on the mirror site mostly stop after 2023, so "common mistakes" lean on 2022–2024.
- 2026 PDFs are third-party watermarked copies with long file names (e.g. `…-question-paper-22.pdf`).
