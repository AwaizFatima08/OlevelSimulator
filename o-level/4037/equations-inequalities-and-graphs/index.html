Q11Modulus and cubic graphs · Standard · Paper 2 style · 5 marks

Q30Modulus equations and inequalities · Challenge · Paper 1 style · 5 marks
  1. (a) Solve the equation |x − 1| + |x − 3| = 4. [3]
  2. (b) Hence write down the set of values of x for which |x − 1| + |x − 3| ≤ 4. [2]
Show answer
  1. (a) x = 0 or x = 4
    For x ≤ 1: (1 − x) + (3 − x) = 4 gives x = 0 M1; for x ≥ 3: (x − 1) + (x − 3) = 4 gives x = 4 M1; for 1 < x < 3 the sum is always 2, so there are no solutions there A1
  2. (b) 0 ≤ x ≤ 4
    The sum is 2 between 1 and 3, and increases to 4 at x = 0 and x = 4, so the sum is at most 4 for 0 ≤ x ≤ 4 B2
