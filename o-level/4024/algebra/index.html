Q1Graphs of functions · Core · Paper 1 style · no calculator · 5 marks
  1. (a) Complete the table of values for y = x² − 2x − 3.x: −2, −1, 0, 1, 2, 3, 4y: …, 0, −3, …, −3, 0, … [2]
  2. (b) By solving an equation, find the x-coordinates of the points where the curve y = x² − 2x − 3 crosses the x-axis. [2]
  3. (c) Write down the coordinates of the turning point of the curve. [1]
Show answer
  1. (a) x = −2: y = 5; x = 1: y = −4; x = 4: y = 5
    B2 for all three correct (B1 for two).
  2. (b) x = −1 and x = 3
    x² − 2x − 3 = 0, (x + 1)(x − 3) = 0 M1; x = −1, 3 A1.
  3. (c) (1, −4)
    B1 (from symmetry of the table).
Q2Graphs of functions · Standard · Paper 2 style · calculator · 7 marks
  1. (a) The table shows some values of y = x³ − 4x + 1.x: −3, −2, −1, 0, 1, 2, 3y: …, 1, …, 1, −2, …, 16Complete the table. [2]
  2. (b) Find the gradient of the straight line joining the points on the curve where x = 1 and x = 3. [2]
  3. (c) The line y = 2x + 1 meets the curve y = x³ − 4x + 1 at three points. Show that the x-coordinates satisfy x³ − 6x = 0 and find all three values. Give non-integer answers correct to 2 decimal places. [3]
Show answer
  1. (a) x = −3: y = −14; x = −1: y = 4; x = 2: y = 1
    B2 for all three correct (B1 for two).
  2. (b) 9
    (16 − (−2)) ÷ (3 − 1) M1; = 9 A1.
  3. (c) x = 0, x = 2.45, x = −2.45
    x³ − 4x + 1 = 2x + 1 ⇒ x³ − 6x = 0 M1; x(x² − 6) = 0 M1; 0, ±√6 = ±2.45 A1.
Q3Graphs of functions · Challenge · Paper 1 style · no calculator · 6 marks
  1. (a) Write x² − 6x + 5 in the form (x − a)² − b. [2]
  2. (b) Hence write down the coordinates of the turning point of y = x² − 6x + 5. [1]
  3. (c) Find the coordinates of the points where the curve crosses the axes. [2]
  4. (d) Find the range of values of k for which the equation x² − 6x + 5 = k has two different solutions. [1]
Show answer
  1. (a) (x − 3)² − 4
    a = 3 B1; b = 4 B1.
  2. (b) (3, −4)
    B1 ft.
  3. (c) (0, 5), (1, 0), (5, 0)
    y-intercept 5 B1; (x − 1)(x − 5) = 0 gives x = 1, 5 B1.
  4. (d) k > −4
    B1: the line y = k must lie above the minimum point.
Q4Algebraic fractions · Core · Paper 1 style · no calculator · 5 marks
  1. (a) Simplify (x² − 9)/(x² + 5x + 6). [3]
  2. (b) Write 3/x + 2/(x + 1) as a single fraction in its simplest form. [2]
Show answer
  1. (a) (x − 3)/(x + 2)
    (x − 3)(x + 3) B1; (x + 2)(x + 3) B1; cancel A1.
  2. (b) (5x + 3)/(x(x + 1))
    Common denominator x(x + 1) M1; numerator 3(x + 1) + 2x = 5x + 3 A1.
Q5Algebraic fractions · Standard · Paper 1 style · no calculator · 5 marks
  1. (a) Show that the equation 3/(x − 1) − 2/(x + 1) = 1 can be written as x² − x − 6 = 0. [3]
  2. (b) Solve 3/(x − 1) − 2/(x + 1) = 1. [2]
Show answer
  1. (a) x² − x − 6 = 0 (shown)
    Multiply by (x − 1)(x + 1) M1; 3(x + 1) − 2(x − 1) = x² − 1 M1; x + 5 = x² − 1 ⇒ x² − x − 6 = 0 A1.
  2. (b) x = 3 or x = −2
    (x − 3)(x + 2) = 0 M1; 3, −2 A1.
Q6Algebraic fractions · Challenge · Paper 1 style · no calculator · 7 marks
  1. (a) Simplify (2x² + 5x − 3)/(4x² − 1). [3]
  2. (b) Write 2/(x − 3) − (x + 9)/(x² − 9) as a single fraction in its simplest form. [4]
Show answer
  1. (a) (x + 3)/(2x + 1)
    (2x − 1)(x + 3) B1; (2x − 1)(2x + 1) B1; cancel A1.
  2. (b) 1/(x + 3)
    Denominator (x − 3)(x + 3) M1; numerator 2(x + 3) − (x + 9) M1; = x − 3 A1; cancel to 1/(x + 3) A1.
Q7Quadratic equations · Core · Paper 1 style · no calculator · 4 marks
  1. (a) Solve x² − 5x − 14 = 0. [2]
  2. (b) Solve 2x² + 7x + 3 = 0. [2]
Show answer
  1. (a) x = 7 or x = −2
    (x − 7)(x + 2) = 0 M1; A1.
  2. (b) x = −1/2 or x = −3
    (2x + 1)(x + 3) = 0 M1; A1.
Q8Quadratic equations · Standard · Paper 2 style · calculator · 7 marks

A rectangular garden has length (x + 4) metres and width (x − 1) metres. Its area is 40 m².

  1. (a) Show that x² + 3x − 44 = 0. [2]
  2. (b) Solve x² + 3x − 44 = 0. Give your answers correct to 2 decimal places. [3]
  3. (c) Find the perimeter of the garden. [2]
Show answer
  1. (a) x² + 3x − 44 = 0 (shown)
    (x + 4)(x − 1) = 40 M1; x² + 3x − 4 = 40 ⇒ A1.
  2. (b) x = 5.30 or x = −8.30
    Formula with a = 1, b = 3, c = −44 M1; √185 M1; 5.30 and −8.30 A1.
  3. (c) 27.2 m
    Reject the negative root; 2(2x + 3) = 4x + 6 M1; 27.2 A1.
Q9Quadratic equations · Challenge · Paper 1 style · no calculator · 7 marks

Sana cycles 60 km to a lake at an average speed of x km/h. She returns along the same route at an average speed of (x + 5) km/h. The return journey takes 1 hour less than the outward journey.
