  1. (a) Explain the difference between the internet and the World Wide Web. [2]

Q3Internet, WWW, URLs, browsers, HTTP(S), DNS and cookies · Core · Paper 1 style · 4 marks
  1. (a) Describe the difference between a session cookie and a persistent cookie. [2]
  2. (b) Give two uses of cookies. [2]
Show answer
  1. (a) A session cookie is stored temporarily (in memory) and is deleted when the browser is closed; a persistent cookie is saved on the user's storage and remains until its expiry date or until the user deletes it.
    1 mark for each type described.
  2. (b) Any two, e.g. storing items in a virtual shopping basket; saving login details so the user stays logged in; remembering user preferences such as language; tracking pages visited to show targeted adverts; storing the progress through a website.
    1 mark for each use.

Q6Internet, WWW, URLs, browsers, HTTP(S), DNS and cookies · Standard · Paper 1 style · 5 marks
  1. (a) Zainab types the URL of an online newspaper into her browser. Describe how the Domain Name Server (DNS) is used so that the web page can be found and displayed. [5]
Show answer
  1. (a) The browser sends the domain name/URL to a DNS server; the DNS server looks up the domain name in its database to find the matching IP address; if it does not have it, it passes the request to another DNS server (higher in the hierarchy); the IP address is returned to the browser; the browser uses the IP address to send a request to the web server; the web server sends the web page (HTML) back; the browser renders it.
    1 mark each for any five points in a logical order.
Q7Internet, WWW, URLs, browsers, HTTP(S), DNS and cookies · Standard · Paper 1 style · 4 marks
  1. (a) An online clothing shop uses HTTPS instead of HTTP. Explain the difference between HTTP and HTTPS. [2]
  2. (b) Explain why it is important that the shop uses HTTPS when customers pay. [2]
Show answer
  1. (a) Both are protocols used to transfer web pages between server and browser; HTTPS is secure – it uses SSL/TLS to encrypt the data sent, whereas HTTP data is not encrypted.
    1 mark: both are protocols for transferring web pages / rules for communication. 1 mark: HTTPS encrypts using SSL/TLS.
  2. (b) Card and personal details are encrypted, so if the data is intercepted it cannot be understood; it also confirms (via the certificate) that the customer is connected to the genuine shop server.
    1 mark: data encrypted / meaningless if intercepted. 1 mark: payment details protected / authenticity of website.
Q8Internet, WWW, URLs, browsers, HTTP(S), DNS and cookies · Standard · Paper 1 style · 4 marks
  1. (a) An online bookshop in Peshawar uses cookies. Bilal adds three books to his basket, closes the browser by mistake, then opens the site again the next day. His basket still contains the books and he is still logged in. Explain how cookies have made this possible. [3]
  2. (b) Explain why a session cookie could not have done this. [1]
Show answer
  1. (a) The website stored a cookie (a small text file) on Bilal's computer; it was a persistent cookie, so it was not deleted when the browser closed; it contained/identified his basket items and login details; when he returned, the browser sent the cookie to the website, which read it and restored his basket and session.
    1 mark each for any three points.
  2. (b) A session cookie is deleted when the browser is closed, so the basket and login information would have been lost.
    1 mark.

Q10Internet, WWW, URLs, browsers, HTTP(S), DNS and cookies · Standard · Paper 1 style · 4 marks
  1. (a) Describe what a browser cache is. [1]
  2. (b) Explain how a browser cache makes a web page load faster the second time it is visited. [2]
  3. (c) Give one reason why a user might clear the browser cache. [1]
Show answer
  1. (a) A store on the user's computer that keeps copies of recently visited web pages, images and files.

  2. (b) The browser loads the stored copies from the local device instead of downloading them again across the internet, which takes less time.
    1 mark: files are read from the local cache. 1 mark: no need to download them again over the network, so loading is quicker.
  3. (c) To free up storage space, or to make sure the browser loads the newest version of a page.
    1 mark: any sensible reason (storage space, out-of-date pages, privacy).

  1. (a) A student says: 'A URL and an IP address are the same thing.' Explain why the student is wrong. [2]
  2. (b) Explain why websites use URLs even though computers use IP addresses to find web servers. [2]
Show answer
  1. (a) A URL is a text-based address of a web page/resource that is easy for humans to remember; an IP address is a numeric address that identifies a device (the web server) on the network.
    1 mark for URL description. 1 mark for IP address description.
  2. (b) URLs (domain names) are easier for people to remember and type than a string of numbers; DNS converts the domain name into the IP address, so the web server's IP address can change without the URL changing.
    1 mark: easier to remember. 1 mark: DNS converts to IP / IP can change while URL stays the same.
Q12Internet, WWW, URLs, browsers, HTTP(S), DNS and cookies · Challenge · Paper 1 style · 6 marks
  1. (a) Explain how a web page is requested, located and displayed when a user types a URL into a web browser. Your answer should refer to the browser, DNS, IP address, web server, HTTP/HTTPS and HTML. [6]
Show answer
  1. (a) The user types the URL into the address bar of the browser; the browser sends the domain name to a DNS server; DNS looks up / finds the matching IP address (asking other DNS servers if needed); the IP address is sent back to the browser; the browser sends an HTTP/HTTPS request to the web server at that IP address; the web server sends the web page files (HTML) back using HTTP/HTTPS; the browser renders the HTML and displays the page (and may store cookies).
    1 mark each for any six points in a logical sequence.

Q14Internet, WWW, URLs, browsers, HTTP(S), DNS and cookies · Challenge · Paper 1 style · 4 marks
  1. (a) A user in Quetta types the domain name of a small travel website. The first DNS server contacted does not have this domain name in its database. Describe what happens next until the browser receives a result. [3]
  2. (b) Explain why the result of the look-up is often stored by the DNS server or browser for a short time. [1]
Show answer
  1. (a) The DNS server passes/forwards the request to another DNS server (higher up the hierarchy); this continues until a DNS server that holds the domain name is found; that server sends the IP address back (through the chain) to the browser. If no DNS server has the domain name, an error message is returned to the browser (e.g. the site cannot be found).
    1 mark: request forwarded to another DNS server. 1 mark: IP address found and returned to browser. 1 mark: error returned if domain not found.
  2. (b) So that the next request for the same domain can be answered quickly without asking other DNS servers again.
    1 mark.
Q15Internet, WWW, URLs, browsers, HTTP(S), DNS and cookies · Challenge · Paper 1 style · 5 marks
  1. (a) A student types the address of her school's results page and the browser shows 404 Not Found. Explain what the status code 404 means. [2]
  2. (b) A second student types a different domain name that does not exist and the browser shows that the site cannot be found. Explain why this error is different from a 404 error. Refer to DNS in your answer. [3]
Show answer
  1. (a) The browser connected to the web server, and the server responded that the requested page does not exist at that address.
    1 mark: the server was found and responded. 1 mark: the requested page or file does not exist on the server.
  2. (b) The DNS look-up fails, so the browser cannot get the IP address of the domain. No web server is contacted, so no status code is returned, unlike a 404 where the server was reached.
    1 mark: DNS cannot resolve the domain name to an IP address. 1 mark: the browser never reaches a web server. 1 mark: a 404 comes from a server that was reached and responded.

Q21Security solutions (SSL, firewalls, proxy servers, backups) · Standard · Paper 1 style · 5 marks
  1. (a) Describe how SSL (Secure Socket Layer) is used to set up a secure connection between a web browser and a web server. [5]
Show answer
  1. (a) The browser requests a secure connection from the web server; the browser asks the server to identify itself; the server sends a copy of its digital/SSL certificate (which includes its public key); the browser checks the certificate is authentic/valid (issued by a trusted authority); if valid, the browser sends a message to the server (acknowledgement); the server and browser agree encryption and a secure session begins; data sent is then encrypted.
    1 mark each for any five points.
Q22Security solutions (SSL, firewalls, proxy servers, backups) · Standard · Paper 1 style · 4 marks
  1. (a) A college network uses both a firewall and a proxy server. Describe two differences between what a firewall does and what a proxy server does. [4]
Show answer
  1. (a) Any two pairs, e.g. a firewall checks/filters traffic against rules and blocks it, whereas a proxy server acts as an intermediary that makes requests to web servers on behalf of the user; a proxy hides the user's IP address from web servers, a firewall does not; a proxy can cache (store) web pages to speed up later requests, a firewall does not; a firewall can be software on the computer as well as hardware, a proxy is a separate server that the requests pass through.
    For each difference, 1 mark for the firewall point and 1 mark for the matching proxy point.

  1. (a) A virus attaches itself to a file or program and needs the user to run that file to spread. A worm replicates itself and spreads across a network without needing a host file. Q51Digital currency and blockchain · Standard · Paper 1 style · 4 marks

Q54Digital currency and blockchain · Standard · Paper 1 style · 3 marks
  1. (a) Explain why a transaction recorded on a blockchain is very difficult to reverse once it has been added to the chain. [3]
Show answer
  1. (a) Each block is linked to the previous one by hashes, and many nodes hold copies. Reversing a transaction would need the block to be changed and all later blocks recalculated across the network, which most participants would reject. So there is no bank that can cancel the payment, and a buyer who pays a fraudster is unlikely to get the money back.
    1 mark: blocks are linked by hashes, so changing one breaks the chain. 1 mark: the copies on many nodes would have to agree to the change. 1 mark: no central authority can cancel the transaction, so the buyer may lose the money.

Q59Digital currency and blockchain · Challenge · Paper 1 style · 5 marks
  1. (a) Describe the steps a computer on the network takes to check a newly added block before accepting it into its copy of the blockchain. [5]
Show answer
  1. (a) The node checks that the new block's hash meets the required pattern (proof of work). It checks the hash stored in the block matches the previous block's hash.
